What you'll be doing

Engineer, build, and customize backend and frontend code for enterprise digital commerce solutions on Salesforce Commerce Cloud (SFCC/Demandware) using SFRA, delivering assigned scope dependably and to quality standards.

  • Develop using ISML, cartridges, jobs and services, Page Designer, Slots, and Business Manager administration.
  • Build full-stack functionality with JavaScript, Node.js, and REST/GraphQL APIs across the ecommerce space.
  • Contribute to code quality through unit and functional testing and code review, and support technical troubleshooting.
  • Support deployment, production issue resolution, and release reliability across CI/CD, delivering assigned scope dependably on time.
  • Use Claude Code for AI-assisted development to accelerate code generation and review while maintaining quality.

What you’ll need to succeed

  • Minimum 3 years of hands-on software development experience building enterprise ecommerce solutions, Headless, Services framework, and platform capabilities
  • Proficiency in SFCC (Demandware) using SFRA, including ISML, cartridges, HTML5, CSS3, JavaScript, JQuery, and Business Manager administration.
  • Strong skills in JavaScript, Node.js, REST/GraphQL APIs, and full-stack web development across backend and frontend.
  • Deep understanding of SFCC concepts like Catalog, Products, Campaigns, Promotions, Customer Groups, RESTful API development and JSON
  • Knowledge of Pipelines, JS Controllers, Demandware Script, and ISML Templates
  • Working knowledge of unit and functional testing, code review, CI/CD, and technical troubleshooting.
  • Familiarity with Claude Code for AI-assisted development.
  • Awareness of Dev Ops including Continuous Integration, Delivery, agile Configuration Management, Environment Management, and Release Management practices.
  • SFCC Developer Certificate required
  • Hands on experience with Pod migrations and other maintenance activities in SFCC
