About this Role

We are seeking an experienced AWS Network & Security Specialist to manage Level-3 operations, ensure architectural assurance, and strengthen the security posture of cloud-based network environments. This role focuses on supporting AWS cloud infrastructure that underpins enterprise and telecom workloads, while driving secure, scalable, and resilient solutions across hybrid and multi-cloud environments.

What you’ll do

Design and implement secure AWS cloud network architectures aligned with best practicesManage and enhance cloud security platforms, ensuring compliance with global standards such as ISO 27001, SOC2, and HIPAAImplement modern security frameworks including Zero Trust, SASE, ZTNA, and SSEOperate and secure firewalls, proxies, IDS/IPS systems, and hybrid network environmentsAct as the L3 escalation point for network and security incidents, leading investigation and resolutionConduct root cause analysis and implement corrective and preventive actionsDevelop and maintain monitoring tools, dashboards, and alerting systemsAutomate security operations using scripting and orchestration toolsCollaborate with cross-functional teams to embed security within the software development lifecyclePerform threat modelling, vulnerability assessments, and support penetration testingDrive risk assessment processes and manage mitigation strategiesSupport audits and regulatory compliance initiatives

Who you are

An experienced professional with strong expertise in AWS networking and security operationsProficient in AWS services such as VPC, Transit Gateway, Direct Connect, Security Hub, GuardDuty, and IAMSkilled in Fortinet technologies, including FortiGate, FortiManager, and FortiAnalyzerKnowledgeable in networking protocols (BGP, OSPF, EIGRP), MPLS, and Layer 2/3 switchingFamiliar with security technologies and protocols such as IPsec, SSL, VPN, and intrusion detection systemsExperienced in hybrid and multi-cloud environments (AWS and Azure)Competent in scripting and automation using tools such as Python, Bash, Ansible, or TerraformWell-versed in monitoring tools like Prometheus, Grafana, or CloudWatchStrong understanding of ITIL processes and security compliance frameworks (GDPR, PCI-DSS, SOC2, HIPAA)A collaborative individual with strong communication, analytical, and problem-solving skillsHolds or is working towards relevant certifications such as Fortinet NSE, CISSP, CCNP Security, or equivalent
