About the job

Your contribution to something big:

You will contribute to the development of innovative embedded software solutions for room controls, thermostats, and other accessories compatible with Bosch heating systems. You will work across the software development lifecycle, from design and implementation to testing and validation, collaborating with international and cross-functional engineering teams. Your main responsibilities will be:

  • Embedded Software Development: Design, develop, test, and maintain high-quality embedded software, following coding best practices and a strong quality mindset.
  • Software Testing & Validation: Develop and execute test plans to validate software functionality and performance, including unit testing and system integration testing.
  • Debugging & Troubleshooting: Identify, analyse, and resolve software defects and performance issues using appropriate debugging tools and methodologies.
  • Software & Hardware Integration: Support the integration of embedded software with hardware components, interfaces, and communication protocols.
  • Technical Documentation: Create and maintain technical documentation, including software designs, specifications, and test reports.
  • Technical Development: Contribute to technical decisions based on engineering knowledge, software development best practices, and applicable standards.
  • Cross-functional Collaboration: Work closely with software engineers, hardware engineers, product managers, and other stakeholders in an international development environment.

What distinguishes you:

  • Education: Master’s degree in Embedded Software, Computer Engineering, or a related technical field.
  • Experience: Around 2–3 years of experience in embedded software development.
  • Programming: Good programming skills in C/C++ and familiarity with real-time operating systems (RTOS).
  • Embedded Systems: Experience with hardware interfaces, communication protocols, software development toolchains, and debugging tools.
  • Development Tools: Knowledge of version control systems such as Git and familiarity with Agile development methodologies.
  • Problem Solving: Strong analytical and problem-solving skills, with a structured and quality-oriented approach.
  • Working Style: Proactive and responsible, with the ability to take ownership of assigned activities.
