About the job

As a Cloud Platform Engineer, you will focus on building and operating a secure and reliable data processing cloud infrastructure.

Key responsibilities:

  • Own, develop, and manage data processing pipelines and solutions in Azure Cloud using Python and Bash.
  • Manage cloud subscription-related topics using Terraform and Bicep.
  • Drive infrastructure reliability and operational readiness (availability, system administration, basic networking, cloud cost management).
  • Develop and manage observability infrastructure using Azure Monitor and Grafana.
  • Work with DevOps engineers on CI/CD pipelines and with platform stakeholders to ensure operational stability.
  • Bachelor’s or Master’s degree in Computer Science, Software Engineering, Information Technology, or a related field.
  • Minimum 3 years of experience in cloud infrastructure/operations with Microsoft Azure (e.g., Azure VNets, VMs, PaaS services), or equivalent experience with another cloud provider and familiarity with Azure Cloud.
  • Strong hands-on knowledge of infrastructure tooling, platform components (e.g., Terraform, ARM templates), automation (PowerShell, Bash), and monitoring.
  • Solid understanding of system administration and basic networking (e.g., Private Endpoints, DNS, routing, High Availability).
  • Experience with cloud cost and security topics (vulnerability and risk management, RBAC, networking, load scaling).
  • Ability to work autonomously, take ownership, and collaborate across teams.

Nice to have:

  • Experience enabling multiple product teams through shared cloud platforms.
  • Understanding of web development concepts.
  • Familiarity with containerization technologies: Docker and Azure Kubernetes Service (AKS).
