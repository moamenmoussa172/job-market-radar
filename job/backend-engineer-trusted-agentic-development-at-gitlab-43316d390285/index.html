An overview of this role

As an Intermediate Backend Engineer, Trusted Agentic Development, based in Poland, you'll build backend systems that help GitLab engineers trust the software they create with artificial intelligence agents. Agents can generate code and tests in seconds, but passing tests don't always mean the software works as intended. You'll contribute to validation approaches and feedback mechanisms that help agents catch that gap and self-correct while they work.

This isn't a quality assurance or test automation role. We’re looking for someone who has built with agents, run into the gap between passing tests and working software, and wants to help close it.

What you’ll do

  • Own backend features from design through production rollout, making the design calls within the architecture the team agrees on.
  • Build agentic code-review and validation workflows that check whether generated code does what was intended, not just whether its tests pass.
  • Prototype focused validation and feedback mechanisms with your teammates, and use what you learn to improve the platform.
  • Develop language-aware validation approaches, starting with Rust, Ruby, and Go, adapting techniques to each language while applying a shared definition of trusted software to assess whether agent-generated code delivers the intended behavior.
  • Implement feedback that helps agents identify problems and self-correct during development.
  • Collaborate with engineering teams to test these approaches in real workflows, measure adoption, engineer trust, and validation quality, and use those measurements to evaluate improvements.
  • Participate in code and design reviews, explain implementation trade-offs, and seek feedback on your work.
  • Take part in on-call or operational support where your team's ownership model requires it.

What you’ll bring

  • Hands-on experience building software with artificial intelligence agents and understanding why their output can pass tests yet fail to behave as intended, from encountering that gap yourself or building something to prevent it.
  • Backend development experience in at least one of Rust, Ruby, Go, or Python, with openness to working across languages.
  • Experience taking backend features from design into production, discussing implementation trade-offs, and knowing when to ask for guidance.
  • Comfort working inside a large existing codebase, not only on greenfield projects.
  • A practical approach to prototyping, learning from results, and turning useful ideas into working software.
  • Clear written communication and the ability to collaborate in an all-remote, asynchronous environment.
  • The ability to share decisions transparently and improve your work through iteration and feedback.
  • Familiarity with containerized services; Kubernetes experience is a plus.

About the team

The Trusted Agentic Development team sits within GitLab's Developer Experience group and builds the platforms our engineers rely on every day. We work across engineering teams and programming languages to understand how people use agents, test new approaches in real workflows, and create a shared model of trusted agentic development that teams choose to adopt.
