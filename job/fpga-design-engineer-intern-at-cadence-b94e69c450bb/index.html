6-month internship available

Job Title: FPGA Design Engineer Intern

Location: France, Rennes

Reports to: Sr Design Engineering Manager

Job Overview:

We are seeking a highly motivated student to lead a redesign of an existing FPGA development flow for one of our flagship products. The current design is implemented in Xilinx Vivado non‑project (script‑only) mode. To improve maintainability, accelerate verification, and enable a more intuitive developer experience, we will migrate the entire design to Vivado Project Mode, leveraging the GUI and Block Design environment.Job Responsibilities:

  • Convert the legacy non‑project flow (TCL scripts, manual file ordering) into a full Vivado Project with GUI‑driven Block Design
  • Re‑instantiate all required Xilinx IP in the Block Design and generate HDL wrappers
  • Port and organize XDC constraints (timing, I/O, placement) within the project hierarchy; refine to achieve timing closure
  • Develop reusable TCL scripts for project creation, IP configuration, and batch bitstream generation to ensure reproducibility
  • Produce a comprehensive migration guide to train the hardware team on the new project‑mode workflow

Job Qualifications:

Education:

Pursuing a B.S./M.S. in Electrical Engineering, Computer Engineering, Computer Science, or a related field

Technical skills:

  • Hands‑on experience with Xilinx Vivado (any version); familiarity with both script‑only and GUI flows is a plus
  • Proficiency in Verilog, SystemVerilog and/or VHDL; ability to read and understand legacy RTL
  • Basic TCL scripting for Vivado automation; Python knowledge for post‑processing is advantageous
  • Understanding of XDC constraints, timing analysis, and placement directives
  • Comfortable using Git for version control

Soft skills:

  • Excellent written and verbal communication; capable of clear technical documentation
  • Team‑player attitude with eagerness to collaborate in a multidisciplinary environment

Additional Skills/Preferences:

  • Prior exposure to Xilinx IP Integrator and block‑design methodology
  • Experience with Vivado Lab Edition for hardware bring‑up
  • Familiarity with UVM/SystemVerilog for verification
  • Experience with hardware debug tools (Integrated Logic Analyzer)

Stage de 6 mois à pourvoir

Intitulé : FPGA Design Engineer Intern

Localisation : France, Rennes

Rattachement hiérarchique : Sr Design Engineering Manager

Présentation du poste :

Nous recherchons un(e) étudiant(e) motivé(e) pour piloter la refonte du flot de prototypage FPGA existant pour l'un de nos produits phares. La conception actuelle est réalisée sous Xilinx Vivado en mode sans projet (scripts uniquement). Afin d'améliorer la maintenabilité, d'accélérer la vérification et d'offrir une expérience développeur plus intuitive, nous allons migrer l'ensemble de la conception vers le mode projet Vivado, en exploitant l'interface graphique et l'environnement Block Design.

Responsabilités du poste :

  • Convertir l'environnement Vivado existant (scripts TCL) en un projet Vivado complet avec gestion de Block Design et de l'interface graphique
  • Ré‑instancier tous les IP Xilinx requis dans le Block Design et générer les wrappers HDL correspondants
  • Transférer et organiser les contraintes XDC (timing, I/O, placement) au sein de la hiérarchie du projet ; affiner pour atteindre la fréquence requise
  • Développer des scripts TCL réutilisables pour la création du projet, la configuration des IP et la génération des bitstreams afin de garantir la reproductibilité
  • Produire un guide de migration complet pour former l'équipe hardware à la nouvelle méthode de travail

Qualifications requises :

Formation :

En cours d'obtention d'un diplôme d'ingénieur (Bac+5) ou Master en électronique numérique ou domaine connexe

Compétences techniques :

  • Expérience pratique avec Xilinx Vivado (toute version) ; la maîtrise des flux script‑only et GUI constitue un atout
  • Maîtrise du Verilog, SystemVerilog et/ou VHDL ; capacité à lire et comprendre du RTL legacy
  • Scripting TCL de base pour l’automatisation sous Vivado ; connaissance de Python appréciée
  • Bonne compréhension des contraintes XDC, de l’analyse de timing et des directives de placement
  • À l’aise avec Git pour le contrôle de version

Compétences transversales :

  • Excellentes aptitudes à la communication écrite et orale ; capacité à rédiger une documentation technique claire
  • Esprit d’équipe avec une réelle volonté de collaborer dans un environnement multidisciplinaire

Compétences supplémentaires/Préférences :

  • Expérience préalable avec Xilinx IP Integrator et la méthodologie de block‑design
  • Familiarité avec Vivado Lab Edition pour le bring‑up matériel
  • Connaissance d’UVM/SystemVerilog pour la vérification
  • Expérience avec des outils de debug matériel (Integrated Logic Analyzer)
