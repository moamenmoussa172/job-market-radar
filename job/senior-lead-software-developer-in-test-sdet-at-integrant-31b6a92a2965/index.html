About the job

About Integrant

For 34 years, Integrant has designed and delivered advanced software solutions for U.S. enterprises in biotech, medical devices, manufacturing, finance, and related highly regulated industries. Our expertise spans traditional web and mobile applications, AI/HPC infrastructure, data engineering, predictive AI, machine learning, and Agentic solutions.

We build long-term partnerships — two-thirds of our clients choose to work with us for five or more years — by solving mission-critical problems with rigor, empathy, and measurable outcomes.

Role Overview

This is a working lead role — not a management track.

The Senior Lead SDET owns the full testing roadmap, leads and mentors the team, and remains hands-on in the code. You will set quality benchmarks in collaboration with stakeholders, guide adoption of effective testing methodologies, and ensure the team delivers robust, high-quality solutions for U.S. enterprise clients in regulated industries.

Responsibilities

Quality Leadership

• Own the testing roadmap — define and evolve both automation and manual testing strategies across the team

• Collaborate with stakeholders to establish quality benchmarks, KPIs, and acceptance criteria

• Drive adoption of effective testing methodologies and continuously improve team processes

• Create, review, and oversee execution of test plans and test strategies

• Provide comprehensive test reports and quality metrics to project managers and clients

• Communicate proactively with the project manager on issues, schedule impacts, and performance concerns

Test Design and Execution

• Review requirements and system design to identify testability gaps early

• Design and review test cases, test scripts, and test data

• Define test case execution priority and conduct impact analysis

• Recommend, implement, and manage test management, defect management, performance, and automation tools

• Log, track, and drive defects through to closure

• Coordinate with engineers on defect and results status regularly

SDET — Hands-On Engineering

Core coding responsibilities — minimum 50% hands-on time is expected:

• Write unit tests for the API and business layer

• Enhance code testability in collaboration with developers

• Fix minor defects discovered during testing

• Implement test support features and automation utilities

• Document API endpoints and services to support both testing and development

• Actively participate in code reviews — contribute improvements to code quality and standards adherence

Agile and Team Collaboration

• Work within an agile, self-organizing Scrum team

• Champion quality ownership within the squad

• Stay current with emerging testing techniques, tools, and technologies — including AI-assisted testing

Requirements

Experience and Core Skills

• Experience: 12+ years of hands-on software testing and automation

• Programming: Proficient in one or more of C#, Java, JavaScript, or SQL with strong OOP foundations

• Automation frameworks: Selenium, TestNG, JUnit, NUnit

• Testing coverage: UI, System/Integration, API, Performance, and Agile testing — hands-on across all

• Test planning: Strong test planning and test strategy design skills

• BDD: Behavior-Driven Development using Cucumber or SpecFlow in production projects

• English: Proficient verbal and written English for direct U.S. client communication

• Database: SQL and database manipulation skills

SDET — Advanced Technical Requirements

• Advanced programming: Custom exceptions, intermediate LINQ, dependency injection, and loose coupling to increase testability

• CI/CD: Jenkins, GitLab, or equivalent pipeline tools

• Design patterns: Solid understanding of common design and architecture patterns

• Data structures: Dictionary, List, HashSet, and equivalents — applied in framework design

AI and Agentic Testing

• Agentic SDLC: Understanding of the Agentic Development Life Cycle

• AI application testing: Experience testing AI applications, LLM outputs, and agentic workflows across web, API, and integrated system layers

• Workflow design: Ability to create and validate workflows with rules and guardrails

• AI agent development: Hands-on experience building and using AI agents to support and enhance the software engineering process — spanning testing, code generation, defect triage, and release validation. At this level of the craft, the boundary between testing and development is increasingly blurred; the Senior Lead SDET is expected to operate confidently on both sides.

• Agentic toolchain integration: Experience integrating AI agents into CI/CD pipelines, test automation frameworks, or developer workflows — including MCP (Model Context Protocol) server integration and Playwright MCP Protocol where applicable.

• Formal AI evaluation: Ability to conduct structured evaluation of agentic and RAG systems — including metrics such as faithfulness, answer relevancy, context precision, and hallucination rate — with hands-on experience using Ragas, DeepEval, or similar evaluation frameworks.

Additional Skills

• Cloud, ETL, DevOps: Fair working knowledge of cloud platforms, ETL pipelines, and DevOps practices

• Estimation: Testing estimation techniques for sprint and release planning

Nice to Have

• ORM frameworks — .NET Entity Framework, Hibernate, or Spring

• Mocking frameworks — Mockito, NMock, or equivalent

• ISTQB CT-GenAI — Certified Tester Testing with Generative AI Preferred

• ISTQB CT-AI — Certified Tester AI Testing Preferred

Both certifications are preferred rather than mandatory — candidates who demonstrate genuine understanding of AI and agentic testing in practice will be equally considered.

Professional Attributes

• Strong analytical and problem-solving skills with keen attention to detail

• Self-motivated, collaborative team player with a positive attitude

• Strong communication and interpersonal skills

• Organized, reliable, and adaptable to client and project changes
