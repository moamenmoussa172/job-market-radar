About the job

Roles & Responsibilities :
Role summary

Designs, builds and owns test automation for the ServiceNow platform. Sets up the automation framework, standards and CI/CD quality gates so every team can release quickly and safely. Builds Automated Test Framework (ATF) and external test suites for catalog items, portals, workflows, integrations and AI services, keeps them stable and fast, and coaches testers and developers to automate as part of normal sprint work.

Job Description or Responsibilities

Automation strategy and framework

· Define the test automation strategy for the platform: what to automate at each level (unit, server-side, UI, API, end to end), tool choices and coverage targets.

· Design and maintain the ATF framework: suite structure, naming, reusable test templates and step configurations, parameterized and data-driven tests, and test data set-up and clean-up.

· Build an external automation framework where ATF falls short, using Playwright, Selenium or Tricentis Tosca for cross-browser UI tests and Postman/Newman or REST Assured for API tests.

· Set automation standards and review automated tests written by testers and developers.

· Keep the framework maintainable and upgrade-safe, with fewer brittle UI tests and more server-side and API tests.

CI/CD quality gates

· Integrate ATF and external suites into CI/CD pipelines (Azure DevOps, GitHub Actions, GitLab CI or Jenkins), using the ServiceNow CI/CD APIs to trigger suites and read results.

· Define quality gates for promotion between instances: required suites, pass thresholds, Instance Scan results and blocking rules.

· Set up scheduled regression runs, headless or cloud-based runners where available, and parallel execution to keep run times short.

· Publish results to dashboards and alert teams on failures.

Upgrades and non-functional testing

· Build and run the upgrade regression pack for platform releases, patches and Store app updates.

· Set up performance and load tests for high-volume portals and catalog items with JMeter, k6 or similar.

· Support security testing with the security architect through automated access and input-validation checks.

· Coach testers and developers on writing good automated tests, and run training on ATF and the framework.

· Work with lead developers so new features are built in a testable way

Experience and qualifications

  • Expert ATF knowledge: server-side and client-side steps, custom step configurations, test templates, parameterized tests, suites and scheduled runs.
  • Strong programming skills in JavaScript or TypeScript, plus working knowledge of Python or Java.
  • Hands-on experience with at least one browser automation framework (Playwright, Selenium or Tosca) and one API testing tool.
  • Experience integrating automated tests into CI/CD pipelines and source control (Git).
  • Good ServiceNow functional and technical knowledge: catalog, flows, portals, ACLs, REST APIs and instance management.
  • Experience designing test data strategies and handling test environments.
  • Experience with performance testing tools.
  • Experience in Agile DevOps teams, and coaching others on test automation.
  • Bachelor's degree in Computer Science, Engineering or a related field.
  • Certifications
  • Required: ISTQB Certified Tester Foundation Level (or equivalent).
  • Preferred: ISTQB Advanced Level Test Automation Engineer; ServiceNow Certified System Administrator (CSA); ServiceNow ATF learning paths or micro-certifications on Now Learning (check the current catalog).
  • Nice to have
  • Experience testing chatbots, virtual agents or large language model features.
  • Experience with contract testing (such as Pact) and service virtualization.
  • Hands-on experience using GenAI tools such as ChatGPT, GitHub Copilot, Microsoft Copilot
  • Ability to use AI tools for:
  • Test scenario and test case generation.
  • Automation script creation and optimization.
  • Test data generation.
  • Test result analysis and defect identification.
  • Test coverage analysis and test documentation.
  • Exposure to AI-enabled testing frameworks and agent-based testing approaches.

Knowledge of ServiceNow Now Assist, Virtual Agent, and AI-powered features is an added advantage.
