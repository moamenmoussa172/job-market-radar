About the job

Job Purpose:

The R&D Engineer designs and owns automation artifacts at source-code and framework level, enabling scalable and reliable automated testing. The role ensures automation systems remain stable, usable, and aligned with evolving project and product requirements.

IMPACT :

• Design and implement automation components and systems, owning system-level outcomes across implementation and stability.
• Translate QA/QC needs into scalable source-code-level automation solutions.
• Own automation components end-to-end from design to maintenance.
• Diagnose failures driven by engine behavior, timing, or integration gaps.
• Build systems improving execution reliability, diagnostics, and maintainability.
• Ensure components are reusable, documented, and aligned to QE usage.
• Handle complex automation challenges independently, making implementation decisions within defined architectural boundaries.

INNOVATION:

• Strengthen the automation ecosystem by building and enhancing features of the automation framework.
• Solve component-level automation challenges across game engines.
• Deliver reusable automation components reducing automation complexity and increasing scalability.
• Define improvements to automation systems based on system-level learnings and implementation experience.
• Translate experimentation outcomes into reusable and scalable solutions across projects.

KNOWLEDGE :

CORE COMPETENCIES
• End-to-end ownership of engineering outputs.
• High-quality technical documentation and system clarity.
• Supporting junior engineers through code reviews and feedback.
• Analytical problem-solving with scalable solution design and sound technical judgment.
• Technical mentorship and knowledge sharing with junior engineers and interns.
• Ownership of delivery quality aligned with engineering and QC standards.
TECHNICAL COMPETENCIES
• Strong C++ with C#/Python usage.
• CI/CD pipelines (Jenkins/TeamCity).
• Hands-on experience on game automation framework
• Engine integration and deep debugging.
• Version control best practices and code reviews.
BEHAVIORAL COMPETENCIES
• Communicates technical decisions clearly with stakeholders across automation, product, FQC, and co-dev teams.
• Collaborates proactively to align game design updates and ensure smooth feature and automation integrations.
• Shows strong initiative in exploring tools, frameworks, and optimization techniques to improve engineering outcomes.
• Approaches complex problems analytically and proposes practical, scalable solutions.

Seniority:
5-8 years development including 2–3 years tools/automation for QC;
BE/BTech/MTech/MS in Computer Science, Software Engineering, Electronics, or a related technical field. Equivalent demonstrated professional experience will be considered.
