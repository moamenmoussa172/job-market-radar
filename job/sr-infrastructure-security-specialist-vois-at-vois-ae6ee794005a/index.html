About this Role

We are seeking an Infrastructure Security Specialist to support the security, resilience and compliance of critical IT infrastructure. You will help maintain cyber security standards, monitor and remediate risks, investigate threats, manage vulnerabilities and strengthen security controls across Microsoft infrastructure, cloud services, servers and data centre environments.

This role is suited to an experienced IT security professional with practical knowledge of Microsoft technologies, infrastructure services, cloud platforms, vulnerability management and security incident response

What you’ll do

Drive compliance with cyber security standards and applicable security policies.Monitor security posture and coordinate the remediation of identified risks.Monitor the health and operation of security telemetry tools, including Microsoft Defender for Endpoint, Microsoft Defender for Identity and Mandiant.Investigate threat alerts and support appropriate response actions.Manage vulnerability remediation and operating system patching compliance using Microsoft Threat and Vulnerability Management and Qualys.Act as the single point of contact for relevant cyber security stakeholders.Conduct security risk assessments and maintain risk-management activities.Manage compliance with member server and domain controller hardening standards.Complete risk, security and impact assessments.Support account lifecycle management.Coordinate technology asset onboarding and offboarding activities.Maintain ACLxRAY and conduct permissions reviews.Define and manage secure build processes and system-compromise recovery procedures.Identify opportunities to improve security controls.Support security incident response activities

Who you are

  • You have at least six years of experience in IT security, infrastructure or IT support.
  • You have strong knowledge of Microsoft systems and technologies.
  • You understand cloud and virtualisation technologies, including Microsoft Azure, Microsoft 365, VMware and server hardware.
  • You have detailed technical knowledge of infrastructure services and components, including Active Directory, DHCP, DNS and Windows Server.
  • You understand configuration management and automated deployment practices.
  • You have experience interpreting and applying IT security requirements and related policies.
  • You can investigate security alerts, assess technical risks and work collaboratively with relevant stakeholders to support remediation.
  • You approach security, compliance and incident management in a structured and accountable way

What's in it for you

  • The opportunity to work across infrastructure security, cloud security and cyber risk management.
  • Exposure to enterprise security technologies, including Microsoft Defender, Mandiant, Qualys and Microsoft Threat and Vulnerability Management.
  • Experience supporting the protection and resilience of Microsoft infrastructure, cloud services, Windows servers and data centre environments.
  • The opportunity to contribute to vulnerability remediation, security compliance and incident-response activities.
  • Collaboration with technical and cyber security stakeholders on controls, assessments and risk reduction.

What skills you will learn

  • Advanced security posture monitoring and risk-remediation coordination.
  • Threat-alert investigation using enterprise telemetry and detection tools.
  • Vulnerability management and patch compliance across complex IT environments.
  • Server and domain controller hardening against established security standards.
  • Secure-build management and system-compromise recovery practices.
  • Security risk assessment, impact assessment and incident-response techniques.
  • Asset lifecycle, account lifecycle and access-permission governance
