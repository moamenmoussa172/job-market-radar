About the job

💼 Role Overview

We are looking for a motivated and enthusiastic individual to join Bosch for a fulfilling internship opportunity! This internship will provide valuable hands-on experience in a corporate environment, allowing you to contribute to ongoing projects while learning from experienced professionals. As an Intern, AIot Software Developer you will support operations and learning initiatives in collaboration with experienced team members.

🎯 What you will do (Key Responsibilities)

  • Develop new features for different customer solutions and reusable components
  • Build, ship and run new software components in Cloud/on-prem environments
  • Improving user experience of the services
  • Writing test cases, testing software and updating test results.
  • Writing and maintaining technical documentation

👤 What We're Looking For (Qualifications & Skills)

  • Currently pursuing a Bachelor's or Master's degree in Computer Science, Computer Engineering, or related field
  • Mandatory: JavaScript, Python, and Java programming skills
  • Familiarity with frameworks such as Angular, React, or Spring Boot
  • Solid software design skills with passion for automated testing and test automation
  • Strong analytical and problem-solving abilities with a collaborative mindset and ability to suggest innovative solutions
  • Familiarity with Generative AI/LLM development, including prompt design and API integration
  • Proficient in English for collaboration with international teams and technical documentation
