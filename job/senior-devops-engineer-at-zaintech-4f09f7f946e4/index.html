About the job

The Senior DevOps Engineer is responsible for supporting Linux-based systems, cloud infrastructure, automation, and secure software delivery across Microsoft Azure and Kubernetes environments.

This role focuses on Linux administration, infrastructure as code, CI/CD pipelines, and implementing basic DevSecOps practices to ensure secure, reliable, and efficient infrastructure operations.

Responsibilities:

  • Manage and troubleshoot Linux-based systems, including system administration, user permissions, services, processes, logs, networking, and basic shell scripting.
  • Support cloud infrastructure management and automation using Terraform, primarily within Microsoft Azure.
  • Manage Azure resources, Microsoft Entra applications, role-based access control (RBAC), and identity permissions.
  • Support Kubernetes environments, including private clusters, and manage application deployments using Helm and Kustomize.
  • Maintain and improve CI/CD pipelines using Jenkins, GitHub Actions, and GitLab CI/CD.
  • Support GitOps-based deployment and configuration management using Argo CD.
  • Implement and maintain cloud networking components, including virtual networks, routing, network security, DNS, VPNs, and private connectivity.
  • Apply DevSecOps best practices, including least-privilege access, secrets management, identity security, zero-trust principles, and single sign-on (SSO).
  • Support application security practices, including static application security testing (SAST) and software composition analysis (SCA).
  • Collaborate with multiple teams to troubleshoot issues, support production environments, and maintain business-critical services.
  • Follow Agile delivery practices using Jira and Confluence, including sprint planning, backlog refinement, user stories, and knowledge transfer.
  • Use AI-assisted engineering tools responsibly, ensuring sensitive information is not exposed and generated outputs are reviewed before implementation.

Our Culture & Code of Conduct:

At ZainTECH, we take pride in a culture built on collaboration, innovation, and uncompromising integrity. All employees are expected to uphold our Code of Conduct, which serves as a guiding framework for responsible behavior across everything we do — from ho we work with each other to how we engage with clients and partners globally.

Requirements

  • Linux Administration: Strong core knowledge of Linux, including package management, command-line operations, permissions, services, process management, log analysis, troubleshooting, and basic shell scripting.
  • Infrastructure as Code: Strong hands-on experience with Terraform for provisioning and managing infrastructure, including reusable modules, state management, and troubleshooting.
  • Microsoft Azure: Understanding of Azure resources, subscriptions, Microsoft Entra ID, application registrations, identity management, and role-based access control (RBAC).
  • Containers and Orchestration: Hands-on experience with containers and Kubernetes, including deploying applications, managing clusters, troubleshooting workloads, and operating private clusters.
  • Version Control: Working experience with GitHub, GitLab, or equivalent version control platforms, including branching, code reviews, and pull or merge requests.
  • CI/CD: Good hands-on experience building, maintaining, and troubleshooting CI/CD pipelines using Jenkins, GitHub Actions, or GitLab CI/CD.
  • Continuous Delivery and GitOps: Familiarity with Argo CD, Helm, and Kustomize for application deployment and configuration management.
  • Networking Fundamentals: Basic understanding of VLANs, VPNs, CIDR notation, subnetting, routing, DNS, and network security.
  • Security Fundamentals: Knowledge of DevSecOps principles, zero-trust security, identity and access management, secrets management, and least-privilege access.
  • Application Security: Basic awareness of static application security testing (SAST), software composition analysis (SCA), and secure software delivery practices.
  • Enterprise Identity: Familiarity with single sign-on (SSO) and enterprise identity providers.
  • Yocto Project: Experience building and customizing embedded Linux distributions using Yocto.
  • Ansible: Experience automating configuration management and infrastructure tasks using Ansible.
  • Air-Gapped Environments:Experience deploying, maintaining, and troubleshooting infrastructure and applications in air-gapped environments.
