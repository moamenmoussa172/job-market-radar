Make a real impact

In this dynamic environment, we are looking for ambitious and self-driven Network Security Engineers to join our Cyber Security Tech team.

  • Participate in the design, implementation and continuous improvement of enterprise network, network security, SASE, web application security and API security solutions
  • Deploy, configure and maintain enterprise security infrastructure, including SASE platforms, next-generation firewalls, Web Application Firewalls and API security platforms
  • Administer and support Palo Alto Networks and Fortinet security technologies, including firewalls, centralized management platforms, VPN services, threat-prevention capabilities and security policies
  • Administer and support Imperva and Fortinet application-security technologies, including Imperva WAF, Imperva API Security, FortiWeb and FortiAppSec Cloud
  • Support the implementation and operation of SASE capabilities, including Secure Web Gateway, Zero Trust Network Access, cloud-delivered firewall services, CASB integration and remote-user connectivity
  • Configure and maintain Palo Alto Networks technologies such as PAN-OS, Panorama, GlobalProtect, Prisma Access, FortiGate, FortiManager, FortiAnalyzer, FortiClient, FortiSASE, FortiWeb, FortiAppSec Cloud and Secure SD-WAN
  • Configure, maintain and optimize Web Application Firewall policies for internet-facing and internal web applications, including managed security rules, custom rules, access controls, IP reputation, geo-based restrictions and application-specific exceptions
  • Onboard websites, web applications and APIs to Imperva WAF, Imperva API Security, FortiWeb and FortiAppSec Cloud, coordinating DNS, certificates, origin servers, routing and application dependencies
  • Implement API security controls, including API discovery and inventory, OpenAPI and schema validation, JSON and XML protection, authentication validation, API-key controls, JWT validation, access restrictions and rate limiting
  • Protect web applications and APIs against common application-layer threats, including injection attacks, cross-site scripting, malicious file uploads, protocol violations, credential abuse, automated attacks and OWASP web and API security risks

What you bring matters

  • Bachelor's degree in computer science, Cybersecurity, Information Technology, or a related field
  • Minimum 2 years of hands-on experience as a Network Engineer, Network Security Engineer, Firewall Engineer or Application Security Engineer
  • ​Hands-on experience with Palo Alto Networks firewalls and technologies such as PAN-OS, Panorama and GlobalProtect
  • Hands-on experience with Fortinet technologies such as FortiGate, FortiManager, FortiAnalyzer and FortiClient
  • Hands-on experience with Web Application Firewall technologies, preferably Imperva WAF, FortiWeb or FortiAppSec Cloud
  • Experience with cloud-delivered security and SASE platforms, preferably Palo Alto Prisma Access, FortiSASE or equivalent technologies
  • Understanding of SASE and Security Service Edge capabilities, including Secure Web Gateway, Zero Trust Network Access, Firewall as a Service and Cloud Access Security Broker
  • Experience with SD-WAN architecture, deployment, routing, application steering and connectivity troubleshooting
  • Experience with firewall policy design, application-based controls, security profiles, NAT, URL filtering, intrusion prevention and threat-prevention services
  • Strong verbal and writing skills in English and Greek
