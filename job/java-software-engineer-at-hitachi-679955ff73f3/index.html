Job Description:

Job Summary**
We are seeking a highly skilled and motivated Java Software Engineer to join our innovative team at Hitachi, Ltd. In this role, you will be responsible for designing, developing, and maintaining robust and scalable software solutions that drive our cutting-edge products and services.
Job Responsibilities**
* Design, develop, and implement high-performance, fault-tolerant applications using Java and related technologies.
* Collaborate with product managers, architects, and other engineers to define requirements, scope, and technical designs.
* Write clean, well-documented, and testable code following best practices and coding standards.
* Participate in code reviews, providing constructive feedback to peers and ensuring code quality.
* Troubleshoot and debug complex software issues, providing timely and effective resolutions.
* Contribute to the continuous improvement of development processes, tools, and methodologies.
* Stay up-to-date with emerging technologies and industry trends, evaluating their potential impact on our products.
* Work effectively in an Agile/Scrum development environment.
Job Qualifications**
* Bachelor's or Master's degree in Computer Science, Software Engineering, or a related field.
* Proven experience (3+ years) as a Java Software Engineer, with a strong understanding of core Java principles and object-oriented programming.
* Proficiency in Spring Framework (Spring Boot, Spring MVC, Spring Security).
* Experience with relational databases (e.g., PostgreSQL, MySQL, Oracle) and ORM frameworks (e.g., Hibernate, JPA).
* Familiarity with RESTful API design and development.
* Experience with version control systems (e.g., Git).
* Knowledge of cloud platforms (e.g., AWS, Azure, GCP) is a plus.
* Experience with microservices architecture.
* Strong problem-solving skills and a meticulous attention to detail.
* Excellent communication and teamwork abilities.
