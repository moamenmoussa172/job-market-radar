About the job

Meet the Team:

Develops and Support software and AI components such as MCP tools, Agents, Agentic workflow, RAG consistent with Cisco ‘Design Thinking Principles’ with a focus on simplification and UX (User Experience) at its core, using secure coding practices, ensuring user privacy, and following software development guidelines.

Partners with other teams including design and product management to build the right solution for the customers. Creates technical design documentation to be used by the team as well as supplying to user documentation. Debugs and addresses software isses during development and in production systems to support customers. Brings new insights for product innovation and helps improve software development processes.

Your Impact:

  • Design, develop, test, and maintain AI-powered applications, services, and reusable platform components.
  • Build agentic AI workflows that integrate LLMs with tools, enterprise APIs, data sources, and business processes.
  • Implement Retrieval-Augmented Generation (RAG) pipelines, including document ingestion, chunking, embedding generation, retrieval, and response generation.
  • Develop and refine prompts, structured outputs, tool-calling patterns, and workflow orchestration.
  • Evaluate AI application quality through test datasets, automated evaluations, error analysis, and user feedback.
  • Help improve response quality, latency, reliability, and model usage costs.
  • Use AI-assisted development tools to support coding, testing, debugging, documentation, and code review while keeping ownership of correctness and security.
  • Follow development practices to keep implementation and tests aligned with approved requirements.
  • Review and validate AI-generated code against engineering standards, architectural requirements, and business expectations.
  • Develop backend services, APIs, integrations, and automated tests using established software engineering practices.
  • Participate in code reviews and contribute to reusable libraries, documentation, and platform standards.
  • Use Git-based version control and CI/CD pipelines to build, test, and deploy applications across environments.
  • Collaborate with product owners, architects, data engineers, security teams, and other collaborators.
  • Work within Agile delivery processes, using Jira to handle stories, tasks, defects, dependencies, and sprint commitments.

Minimum Qualifications:

  • Professional software development experience, with experience developing or integrating AI/LLM-powered applications.
  • Proficiency in Python, ReactJs and experience building backend applications, REST APIs, and integrations.
  • Solid understanding of software engineering fundamentals, including modular design, debugging, error handling, automated testing, and code reviews.
  • Working experience with Git, pull requests, dependency management, and collaborative development.
  • Bachelor’s degree in computer science, engineering, or a related field, or equivalent practical experience.

Preferred Qualifications:

  • Experience with an agent or LLM application framework such as LangGraph, LangChain, Semantic Kernel, or an equivalent framework.
  • Experience with vector databases or vector search capabilities.
  • Exposure to Model Context Protocol (MCP), tool integration standards, or reusable agent tools.
  • Experience with AI evaluation, tracing, observability, prompt versioning, or model comparison.
  • Familiarity with Docker, infrastructure as code, and cloud deployment services.
  • Experience with Spec Driven Development
  • Exposure to enterprise data platforms, data pipelines, or semantic layers.
