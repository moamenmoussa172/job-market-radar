Technical Project Manager_BCSC

Bosch Group · Suzhou, China

Onsite · Technical Project / Program Manager · Posted 3 November 2026

Apply on Bosch Group's site →Open in Radarak

About the job

岗位定位：

  • 聚焦智能驾驶业务全流程项目交付，以客户需求和产品线战略为核心，全面负责项目预算统筹、资源协调与成本精细化管控。
  • 通过搭建标准化预算数据体系、落地降本增效策略、沉淀项目成本与资源数据，支撑高层业务策略决策，同时反向赋能团队报价体系与项目风险管控，保障智驾项目高效、低成本、合规交付。

工作内容:

  • 预算规划与审批管理:
  • 独立负责智能驾驶各类项目的年度及单项目预算整体规划，根据项目交付需求精准拆解业务所需资源、预算；
  • 联动研发、财务、商务等跨部门团队，拉通资源需求与预算诉求，统筹全周期项目预算规划、资源整合；
  • 协同GTM/XTM/XPA/XCE高效推进预算审批落地，保障项目合规启动、资源足额到位。
  • 全流程监控项目费用支出：
  • 根据不同产品、客户策略建立智驾项目预算全生命周期管控机制；
  • 动态跟踪预算Run Rate，实时纠偏预算使用偏差，严控超支风险，确保所有智驾项目成本始终在规划基线内执行。
  • 提升项目成本效能:
  • 立足技术方案、人力配置、资源复用等维度挖掘降本空间
  • 牵头跨部门落地降本增效专项工作，持续优化项目交付成本，提升业务整体投入产出比。
  • 数据输出与高层决策支撑:
  • 以客户、产品线为双导向输出不同维度项目标准化预算数据流及分析报表 (开发费、OTP、现金流、EBIT 等)
  • 同步交付客户负责人、业务管理层，为公司客户经营、业务布局、高层战略制定提供精准数据支撑。
  • 日常复盘不同类型智驾项目、不同客户的资源消耗特征与资源池需求，沉淀真实业务数据，反哺报价团队优化报价模型，提升项目报价的精准度与可信度。
  • 常态化梳理汇总项目成本风险、预算偏差风险，沉淀风险识别标准与应对经验，同步赋能全体项目经理，实现项目风险前置探测、提前规避，降低交付损失。
  • 持续完善项目预算计划、管控工作流，为组织高效运转提供保障。
  • 经验要求：5年及以上智能驾驶行业项目管理相关经验，深度参与过智驾研发、客户交付、量产项目，具备完整的项目预算规划、费用管控、成本复盘实战经验
  • 能力要求：熟悉智驾项目成本构成、资源配置逻辑，精通项目预算申报、审批、管控、复盘全流程，具备独立跨部门推进降本增效项目的能力。
  • 语言要求：英文流利，可无障碍进行口语沟通、英文会议对接、英文预算报表及项目文档输出，可对接外籍客户及海外业务。
  • 数据能力：具备优秀的数据敏感度与数据分析能力，能够独立输出预算Run Rate、成本分析数据，可通过数据沉淀优化业务体系。
  • 综合素养：极强的跨部门沟通协调、资源整合、风险预判能力，业务导向、结果导向，抗压能力强，适配多项目并行管理工作。
  • 优先条件：有智驾项目管理经验、熟悉博世软硬件项目成本构成、具备项目预算管理或降本专项落地经验者优先。
