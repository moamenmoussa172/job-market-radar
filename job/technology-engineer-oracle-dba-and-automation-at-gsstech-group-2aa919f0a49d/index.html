About the job

We are looking for a senior Oracle Database Engineer to support critical technology projects and automate Oracle DBA operations using modern DevOps and automation tools.
This is a hands-on, high-pressure role involving multiple parallel projects, production environments, and strict delivery timelines.

Key Responsibilities

  • Administer and support enterprise-scale Oracle databases in production environments
  • Design and maintain Oracle RAC and Data Guard architectures
  • Perform database patching, upgrades, migrations, and performance tuning
  • Manage backup and recovery strategies using RMAN
  • Monitor and manage databases using Oracle Enterprise Manager (OEM)
  • Support cloud-based Oracle deployments on OCI and AWS
  • Automate repetitive DBA tasks using Ansible, Git, and scripting
  • Collaborate with Agile delivery teams across multiple concurrent projects
  • Ensure database stability, security, and high availability in regulated environments

Mandatory Technical Skills

  • 6+ years of experience in large enterprise environments
  • Strong hands-on expertise in:
  • Oracle Database Administration
  • Oracle RAC
  • Oracle Data Guard
  • Oracle Enterprise Manager (OEM)
  • RMAN (Backup & Recovery)
  • Database patching & upgrades
  • Performance tuning & optimisation
  • Database migration projects
  • Solid experience with Oracle Cloud Infrastructure (OCI) and AWS
  • Strong SQL and/or PL/SQL skills
  • Strong Unix/Linux administration knowledge
  • Experience working in Agile delivery models
  • Proven automation experience using:
  • Ansible
  • Git
  • Bash and/or Python scripting

Desirable Skills (Nice to Have, Not Mandatory)

  • Jenkins and Groovy
  • Terraform (Infrastructure as Code)
  • Exposure to other database technologies
  • Banking or financial services experience

Education & Certifications

  • Bachelor’s degree or higher in Computer Science (or equivalent) – Mandatory
  • Relevant Oracle / Cloud certifications – Preferred

Behavioural Competencies

  • Ability to work under pressure in production environments
  • Strong professional communication skills
  • High level of ownership and self-management
  • Ability to handle multiple projects simultaneously
