About the job

Job Description:

Skywise is a leading digital services company, wholly owned by Airbus. We deliver a first-of-its-kind offer that seamlessly integrates Planning & Operations Control, Flight, Technical, and Ground Operations. By providing interoperable digital solutions for end-to-end operations, Skywise combines aircraft manufacturer expertise and digital know-how to transform operational complexity into predictable and profitable performance, ensuring resilient and more sustainable operations.

As a Frontend Software Development Intern, you’ll join our engineering team to build intuitive, user-facing applications within a modern microservices architecture. You will contribute to responsive web applications that process critical aviation data, helping transform operational complexity into predictable performance while delivering seamless user experiences across Airbus operations.

The primary objective of this internship is to build practical expertise in digital technologies, management, business processes, and operations through hands-on participation in Software Factory projects, while applying Airbus Group standards. Within the Software Factory department, candidates will develop expertise in frontend web architecture, user interface design, component testing, version control, and Agile development lifecycles.

Responsibilities:

  • Develop clean, maintainable web application features and resolve user interface bugs based on technical specifications.
  • Write and execute unit, component, or integration tests to maintain software stability and application performance.
  • Participate in code reviews, follow established team coding standards, and adhere to clean code principles.
  • Collaborate with team members in daily Agile activities to debug issues and identify root causes.
  • Maintain clear technical documentation for tools, features, and user interface components.
  • Communicate project status, blockers, and solutions proactively within the team.

Must Haves:

  • Being a student in the final years of university studies (preferred fields of study: Computer Science, Software Engineering, Information Technology, or a related technical discipline).
  • Being available for part-time hours per week.
  • Experience with core web technologies, including JavaScript, TypeScript, and modern frontend frameworks (e.g., Vue.js, React, or Angular).
  • Basic knowledge of Object-Oriented Programming (OOP) concepts and software design practices.
  • Familiarity with version control concepts (such as Git) and testing principles.
  • Strong problem-solving skills, willingness to learn, and fluent spoken and written English communication skills.

Software/Technologies You’ll Use:

  • JavaScript / TypeScript
  • Modern Frontend Frameworks (Vue.js, React, or Angular)
  • Testing Tools (Jest, Vue Test Utils, or Selenium)
  • Git / Version Control Systems

Nice to Haves:

  • Exposure to cloud platforms (such as Amazon Web Services) or operating systems (Linux/Windows).
  • Academic or personal interest in aviation, flight operations, or air navigation principles.

What we offer:

  • 12-Month Fixed-Term Employment Contract
  • Additional 3 days off during the holiday season (floater days)
  • Additional 1 day off for thesis defense

Recruitment Roadmap:

  • Application Review: Initial screening of resume and qualification fit.
  • Technical Interview: Virtual discussion covering basic software engineering concepts, project experience, and mutual culture fit.
  • Interview with the Hiring Manager: in person conversation with the team lead to discuss specific role expectations, team dynamics, and potential technical projects
  • Offer & Onboarding: Formal offer extension and preparation for day one!
