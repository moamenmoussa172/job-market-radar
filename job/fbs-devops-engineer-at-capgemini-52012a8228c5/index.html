About the job

Looking for a DevOps Engineer to build and run a secure automated CI/CD pipelines from commit to production across Azure,Openshift, Google platforms Key responsibilities CI/CD pipeline creation – all stages Design, build and maintain Jenkins/CloudBees declarative pipelines (Jenkinsfile, shared libraries) covering every stage: Source & branching – trigger on Git Flow branches (feature, develop, release, hotfix, main); enforce PR checks and branch protection. Build – compile and package (Maven, Gradle, npm, pip); build container images with Docker/Buildah. Unit test & coverage – run automated tests and publish JUnit and coverage reports. Static analysis & quality gate – run SonarQube/SonarCloud scans; fail the build when the quality gate fails (coverage, bugs, code smells, duplication, security hotspots). Security scanning – run Wiz scans on images and IaC (Wiz CLI), plus SAST, SCA/dependency and secrets scanning; block on critical/high findings per policy. Artifact publishing – version, sign and publish artifacts and images to JFrog Artifactory; generate an SBOM. Deploy to Dev/QA – deploy to ROSA/OpenShift, AKS or GKE via Helm, Kustomize or GitOps (Argo CD / OpenShift GitOps). Integration, API & performance tests – trigger automated test suites and smoke tests in lower environments. Approval & promotion – manual or automated gates to Staging/UAT and Production with change records. Production release – blue-green or canary rollouts, with automated rollback. Post-deploy verification – health checks, monitoring and alert validation; DORA metrics capture. CloudBees & Jenkins administration Administer CloudBees CI controllers and Jenkins agents (including Kubernetes-based ephemeral agents). Maintain plugins, credentials, RBAC, folders and Configuration as Code (JCasC). Build reusable shared libraries and pipeline templates so teams onboard in minutes. Source control & Git Flow Implement and support Git Flow branching, semantic versioning and release tagging. Configure webhooks, PR policies and merge checks in GitHub, GitLab, Bitbucket or Azure Repos. Cloud & container platforms Provision and support workloads on Azure (AKS, App Service, Key Vault, Azure DevOps), Google Cloud (GKE, Cloud Run, Artifact Registry, Cloud Build) and ROSA (Red Hat OpenShift Service on AWS). Write Infrastructure as Code with Terraform/OpenTofu, Bicep or ARM; manage OpenShift projects, routes, operators and quotas. Quality, security & compliance (DevSecOps) Own SonarQube quality profiles and quality gates across projects. Triage Wiz findings (vulnerabilities, misconfigurations, exposed secrets) with dev teams and track to closure. Apply policy as code (OPA/Gatekeeper, Kyverno) and secrets management (HashiCorp Vault, Azure Key Vault). Artifact & dependency management Manage Artifactory repositories (local, remote, virtual), retention policies and permissions; integrate JFrog Xray where used. Observability & operations Set up monitoring, logging and alerting (Prometheus, Grafana, Azure Monitor, Cloud Logging, Splunk/Datadog). Join an on-call rotation, support incident response and write blameless post-incident reviews. Document pipelines, runbooks and onboarding guides. Required qualifications 1–3 years of hands-on experience in DevOps, build and release, cloud or site reliability engineering. Bachelor’s degree in Computer Science, IT or a related field, or equivalent practical experience. Built and maintained Jenkins or CloudBees CI pipelines using declarative Jenkinsfiles. Working knowledge of Git and Git Flow branching, pull requests and release tagging. Hands-on with at least one major cloud (Azure or Google Cloud) and exposure to OpenShift/ROSA or Kubernetes. Experience integrating SonarQube scans and quality gates into a pipeline. Exposure to security scanning in CI/CD (Wiz, or similar tools such as Trivy, Snyk or Prisma Cloud). Experience publishing and consuming artifacts from JFrog Artifactory (or Nexus). Docker and container fundamentals; basic Kubernetes objects (Deployments, Services, ConfigMaps, Secrets). Scripting in Bash plus one of Python, Groovy or PowerShell. Linux fundamentals, networking basics (DNS, TLS, load balancers) and troubleshooting skills. Some Infrastructure as Code experience with Terraform, Bicep or Ansible.
