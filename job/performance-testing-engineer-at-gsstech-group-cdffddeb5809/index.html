About the job

About the Role

We are looking for an experienced Performance Testing Engineer to check and protect the performance, scalability, stability and reliability of business-critical banking applications. You will design and run performance, load, stress, endurance and scalability tests across customer-facing digital channels, APIs, microservices and core backend systems. The focus is on high-volume banking transaction flows.

You will work closely with development, architecture, DevOps, QA and business teams. Together you will set performance benchmarks, find bottlenecks, trace root causes and recommend ways to optimise performance.

Key Responsibilities

Performance Test Strategy and Design

  • Define performance test strategies, workload models and test plans based on business volumes, peak transaction patterns and NFRs (non-functional requirements)
  • Work with business and architecture teams to set clear performance benchmarks, SLAs and acceptance criteria
  • Design realistic test scenarios for critical banking journeys such as login, fund transfers, payments, account inquiries, onboarding and card transactions

Test Execution

  • Build, run and maintain load, stress, spike, endurance (soak), volume and scalability tests
  • Run performance tests on web, mobile, API, microservices and backend layers
  • Build reusable, parameterised and correlated test scripts with JMeter, LoadRunner or similar tools
  • Prepare test data and keep test environments close to production conditions

Analysis and Bottleneck Identification

  • Analyse response times, throughput, error rates, concurrent user behaviour and resource use (CPU, memory, disk I/O, network)
  • Find bottlenecks across the application, API, database and infrastructure layers
  • Check database performance, including slow queries, locking, indexing and connection pool behaviour
  • Use APM and monitoring tools to trace root causes across distributed systems

Reporting and Optimisation

  • Produce clear performance reports with findings, risks and practical recommendations for technical and business stakeholders
  • Work with development and DevOps teams to tune the system and retest after fixes
  • Track performance trends across releases and flag regressions early

Automation and CI/CD

  • Add performance tests to CI/CD pipelines so performance is validated continuously
  • Help build a shift-left performance engineering culture across delivery teams

Required Skills and Experience

  • 5+ years of hands-on experience in performance testing and engineering
  • Strong expertise in JMeter and/or LoadRunner (NeoLoad, Gatling, k6 or similar are also welcome)
  • Proven experience in performance testing REST APIs, web and mobile applications
  • Solid understanding of microservices architecture and distributed systems
  • Strong ability to analyse response times, throughput, concurrency and resource use
  • Hands-on experience finding bottlenecks across application, API, database and infrastructure layers
  • Good knowledge of databases (Oracle, SQL Server, PostgreSQL or similar) and SQL query performance analysis
  • Experience with APM and monitoring tools such as Dynatrace, AppDynamics, New Relic, Grafana, Prometheus or Splunk
  • Experience adding performance tests to CI/CD pipelines (Jenkins, Azure DevOps, GitLab CI or similar)
  • Strong analytical, problem-solving and stakeholder communication skills

Highly Desirable

  • Experience in banking or financial services, especially transaction-heavy, high-availability systems
  • Exposure to core banking, payments, digital banking or card platforms
  • Experience with cloud environments (Azure, AWS or GCP) and containerised setups (Docker, Kubernetes, OpenShift)
  • Knowledge of messaging and middleware such as Kafka, MQ or API gateways
  • Scripting skills in Java, Groovy, Python or JavaScript
  • ISTQB Performance Testing or similar certification
