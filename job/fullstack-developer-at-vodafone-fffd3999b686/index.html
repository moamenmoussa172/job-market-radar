About this Role

We are seeking a Full Stack Software Engineer to deliver end-to-end platform features across modern Angular front-end applications and Java 21 backend services. The role brings together user interface behaviour, API contracts, business logic and data exchange to create maintainable, scalable and production-ready solutions. You will work closely with product, design, quality, DevOps and operations teams to ensure solutions are accessible, secure, performant, observable and supported by automated testing throughout the delivery lifecycle.

What you’ll do

  • Design and implement full-stack features using Angular, TypeScript, Java 21 services, REST APIs and integration components.
  • Ensure front-end and back-end contracts are clearly defined, tested, secure, maintainable and aligned to business objectives.
  • Contribute to unit, integration and end-to-end testing, CI/CD readiness, code reviews and release quality.
  • Investigate and resolve issues across the technology stack by analysing user interface behaviour, API interactions, logs, monitoring data and application flows.
  • Collaborate with product, user experience, quality assurance and operations teams to deliver production-ready user journeys.

Who you are

  • Experienced in Angular, TypeScript, RxJS, Java 21, REST APIs and microservice-based architectures.
  • Familiar with NgRx or similar state management frameworks, automated testing practices and front-end to back-end integration approaches.
  • Knowledgeable in CI/CD, observability, secure coding principles, performance optimisation and production support practices.
  • Able to collaborate across teams, clarify requirements and manage technical dependencies effectively.
  • Focused on delivering excellent user experiences while maintaining code quality, sustainability and business value
