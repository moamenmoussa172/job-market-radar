Software QA Intern

About the Role

We are looking for a curious and motivated Software QA Intern to join our team and gain hands-on experience in embedded software testing for Energy and Data Center products.

You will work alongside Software QA and Development engineers, contribute to real engineering projects, and learn how software quality is built into embedded products. This is a great opportunity to develop practical skills in software testing, test automation and CI/CD in a supportive and collaborative environment.

Key Responsibilities

  • Support the design, implementation and execution of software tests for embedded systems.
  • Support and maintain automation using Python and test automation frameworks.
  • Execute tests, analyse results and support failure investigation.
  • Contribute to test automation and CI/CD activities.
  • Collaborate with Software QA and Development engineers to improve software quality.

Qualifications

We welcome candidates who are eager to learn and grow. You do not need to have experience in all the areas listed below.

  • Currently pursuing a Bachelor's or Master's degree in Computer Science, Software Engineering, Telecommunications, Electronics, or a related field.
  • Programming skills, preferably in Python.
  • Interest in software testing, automation and embedded systems.
  • Curiosity and a structured approach to problem solving.
  • Good communication and teamwork skills
  • Ability to communicate effectively in English.

Nice to Have

Experience in these areas is a plus, but not required:

  • Python test automation or pytest.
  • Git/GitHub.
  • CI/CD concepts.
  • Embedded systems or firmware.
  • Software debugging and testing tools.

What You'll Gain

  • Hands-on experience in embedded software testing and test automation.
  • Practical experience with Python, test frameworks and CI/CD.
  • Exposure to real embedded products and development environments.
  • Mentoring and support from experienced engineers.
  • Experience collaborating in an international engineering environment.
  • The opportunity to contribute ideas, learn from others and develop your technical skills.
