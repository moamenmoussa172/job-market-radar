About the job

Job Summary

We are looking for an experienced Senior Software Engineer with 5 to 6 years of deep technical expertise in full-stack development to architect, build, and maintain robust, scalable, and secure enterprise applications. The ideal candidate brings mastery of the .NET ecosystem (.NET Core, ASP.NET, C#, Entity Framework, Dapper) alongside strong database engineering skills. Additionally, the role demands an AI-first mindset—actively leveraging AI tools and frameworks throughout the software development lifecycle to accelerate delivery, optimize code quality, and solve complex engineering challenges.

Job Objectives

  • Design and deliver high-quality, scalable, and secure software solutions that meet business and technical requirements.
  • Bridge front-end and back-end development to build complete, well-functioning, mobile-responsive applications.
  • Translate functional and technical requirements into efficient, maintainable application components.
  • Ensure applications are reliable, performant, and secure through rigorous testing, debugging, and best practices.
  • Continuously improve development processes and code quality by integrating AI-assisted tools and modern engineering standards.

Job Responsibilities

AI & Engineering Excellence

  • Integrate AI-assisted coding, code review, and automated testing tools (e.g., GitHub Copilot, Claude, Codex, Codium) into daily workflows to increase developer velocity.
  • Research, evaluate, and adopt emerging AI tools and generative AI workflows to optimize team efficiency and technical standardizations.
  • Mentor junior and mid-level engineers in leveraging AI effectively while ensuring code accuracy, security, and performance.

Solution Design & Architecture

  • Drive technical architecture decisions and technical design reviews, applying deep expertise in server-side and client-side systems.
  • Architect scalable RESTful APIs and modern database schemas built for performance and high availability.

Development

  • Build the frontend applications through appealing visual design.
  • Develop and manage well-functioning databases and applications.
  • Write effective and secure APIs.
  • Build and maintain application components using .NET Core, ASP.NET, C#, Dapper, and Entity Framework.
  • Build features and applications with a mobile responsive design.

Quality, Security & Maintenance

  • Test software to ensure responsiveness and efficiency.
  • Troubleshoot, debug, and upgrade software.
  • Create security and data protection settings.
  • Develop and write high-quality coding standards.

Documentation & Standards

  • Write technical documentation.
  • Implement best practices, standards, and procedures including quality and delivery methodologies.

Job Requirements

Educational Qualifications

  • Bachelor's degree in Computer Science, Software Engineering, Information Technology, or a related field.

Licenses & Certifications

N/A

Previous Work Experience

  • 5 to 6 years of hands-on software engineering experience demonstrating progressive technical leadership and expertise.
  • Demonstrated track record of incorporating AI tools into everyday engineering workflows to speed up development and debugging.
  • Proven experience in both front-end and back-end development (full-stack).
  • Hands-on experience with .NET Core, ASP.NET, and C# in a production environment.
  • Solid experience designing, developing, and managing databases and writing efficient queries.
  • Experience working within an Agile/Scrum development environment is preferred.

Skills & Abilities

  • AI Capabilities: Advanced proficiency in prompt engineering for code, AI-driven debugging, refactoring, and leveraging LLMs within IDEs.
  • Core Expertise: Expert-level mastery of C#, .NET Core, ASP.NET, Entity Framework, Dapper, and relational database optimization (SQL Server).
  • Strong proficiency in C#, .NET Core, ASP.NET, Entity Framework, and Dapper.
  • Solid front-end development skills (HTML, CSS, JavaScript, and modern front-end frameworks).
  • Strong knowledge of relational databases (e.g., SQL Server) including schema design, queries, and performance tuning.
  • Ability to design and consume secure, well-structured RESTful APIs.
  • Practical knowledge of using AI tools and techniques (e.g., AI-assisted coding, code review, and testing tools) to enhance development efficiency and quality.
  • Strong understanding of software security principles and data protection best practices.
  • Excellent problem-solving, debugging, and troubleshooting skills.
  • Strong communication skills and ability to collaborate effectively with cross-functional teams.
  • Ability to write clean, maintainable, and well-documented code following high coding standards.
