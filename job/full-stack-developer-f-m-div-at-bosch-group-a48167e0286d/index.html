About the job

Vehicle Care Assistant (VCA) is Bosch's connected fleet maintenance platform, helping workshops and fleet operators maximize vehicle uptime through telematics, service maintenance prediction and diagnostics.

As full stack developer, you will contribute to the design, development, and operation of VCA across the entire stack. You will work closely with product management and lead architect in Germany to deliver scalable cloud-native solutions.

Backend Development:

  • Design and develop microservices using Java and Spring Boot.
  • Create and maintain REST APIs for vehicle maintenance, telematics, and workshop management functionalities.
  • Integrate external systems and vehicle data sources.
  • Implement event-driven solutions using Kafka.
  • Optimize performance, reliability, and scalability of backend services.
  • Support cloud-native deployments and CI/CD pipelines.
  • Analyze and resolve production issues and bugs

Frontend Development

  • Develop modern web applications using Angular.
  • Collaborate closely with UX designers and product managers.
  • Ensure high frontend quality through testing and code reviews.
  • Improve usability and performance of existing Angular applications.

Architecture & Collaboration

  • Participate in solution architecture discussions.
  • Contribute to technical design decisions and development standards.
  • Work together with architects, product owners and external development partners.
  • Support technical refinements and effort estimations.
  • Experience with Backend development (Java, Spring Boot, REST API design and integration, Kafka or event-driven architectures, SQL databases, Microservices architecture, Git CI/CD pipelines, Docker and containerized deployments);
  • Experience with Frontend development (Angular, TypeScript, HTML5 / CSS3, Angular Material, REST API integration, Frontend testing frameworks);
  • Cloud & Devops technical skills (Kubernetes, Azure/AWS);
  • Strong hands-on developer with full-stack mindset. Able to move seamlessly between frontend and backend topics;
  • Pragmatic problem solver;
  • Quality-oriented and customer-focused;
  • Comfortable working in a fast-moving product organization;
  • Strong communication skills in international teams.
