About the job

We're looking for an Infrastructure Security Engineer to secure complex multicloud infrastructure, which runs mostly on Kubernetes. You'll join the security team as a hands-on engineer who builds, not just reviews: security processes, automating checks and working side by side with a team of skilled professionals.
InDrive is an AI-friendly company. We use AI tools in daily engineering work and encourage you to use them to automate security operations, speed up reviews and build better tooling.

  • Build, maintain and evolve the security of our multicloud environment, Kubernetes clusters and CI/CD systems.
  • Build and maintain vulnerability management processes using commercial and open-source tools, and help engineering teams drive remediation.
  • Contribute to the architectural design of infrastructure services, bringing security expertise across the full lifecycle, from design to production.
  • Run regular security assessments and hardening reviews, and turn findings into secure baselines and guardrails.
  • Automate security checks and operations with code, and use AI-assisted tooling where it makes the team faster.
  • Work with SIEM and monitoring to improve detection coverage for cloud and Kubernetes workloads.
  • Take part in incident response for cloud and Kubernetes environments.
  • 3+ years of hands-on experience in infrastructure security, including vulnerability management across cloud and on-prem environments.
  • Strong proficiency with cloud platforms (AWS or GCP) and with Kubernetes: applying security best practices for a high-load production infrastructure.
  • Strong knowledge of IaC tools (Terraform, Terragrunt, Ansible), GitOps (ArgoCD), and CI/CD pipeline security (e.g. GitHub Actions).
  • Understanding of risk based approach to vulnerability management and Cybersecurity in general
  • Automation skills in Python or Bash.
  • Understanding of Zero Trust principles and experience securing remote access with ZTNA solutions.
  • Experience with SIEM solutions.
  • Good written and spoken English.

Nice to have

  • Certifications: CKS (Certified Kubernetes Security Specialist) and/or AWS Certified Security – Specialty.
  • Experience with Kubernetes security tooling: policy engines, runtime security and network policies.
  • Hands-on experience with AWS native security services (GuardDuty, Security Hub, IAM Access Analyzer, CloudTrail).
  • Hands-on incident response experience in cloud or Kubernetes environments.
  • Familiarity with secret management tools (e.g. HashiCorp Vault, AWS Secrets Manager).
  • Experience using LLMs or AI agents to automate security workflows
