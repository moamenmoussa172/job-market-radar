About the job

Department Information:

  • ETA specializes in Mobility Engineering Solutions/ Engineering Tools Applications and Services.
  • Measurement, calibration, and diagnostics using ETAS products such as XETK and GETK, MDH, INCA, etc.

Role Overview: You will join our embedded-software team to design, develop and integrate real-time applications on Linux and/or QNX, and to build user-space components for MC-Gateway development.

Key Responsibilities

  • Implement and maintain embedded applications on Linux using CMake for cross-platform builds
  • Implement and integrate communication protocols (e.g. XCP)
  • Handle JSON-based config and data exchange
  • Directly communicate with German stakeholders
  • Develop inter-process communication modules on POSIX (named pipes, shared memory) if required
  • Bachelor’s or higher degree in Computer Science, Computer Engineering, Electrical/Electronic Engineering, Mechatronics or related fields
  • 3-7 years of hands-on experience in embedded application development on Linux. Fresher with good academic background and strong passion in embedded system is welcome to apply.
  • Strong experience with CMake, including cross-platform/cross-compilation build environments.
  • Experience implementing or integrating communication protocols, preferably XCP or similar protocols.
  • Experience working with JSON-based configuration and data exchange.
  • Good English communication skills, with the ability to communicate directly with international stakeholders, particularly German teams.
  • Nice to have:
  • Adaptive Autosar
  • POSIX IPC (named pipes, shared memory, semaphores)
  • C++ (modern standards, STL, concurrency)
  • Python scripting (automation, testing, data processing)
