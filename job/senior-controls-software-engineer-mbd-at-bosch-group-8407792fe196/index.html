Senior Controls Software Engineer - MBD

Bosch Group · bangalore, India

Onsite · Senior · Software Engineer · Posted 28 October 2026

C++CI/CDGitPythonTest automation

About the job

Roles & Responsibilities :
Model-Based Software Development & Power Systems Simulation

  • Develop and maintain BMS application/control software models using MATLAB/Simulink and Stateflow for BESS / automotive domain.
  • Perform verification and validation of a developed control software and automatic code generation using MathWorks tools.
  • Develop and integrate control algorithms for BMS applications – BESS / Automotive Domain.
  • Perform model reviews, model quality checks, and ensure compliance with defined development standards.
  • Develop automation tools frameworks/tools using MATLAB scripting capabilities.
  • Analyze generated code and support debugging of model-to-code issues.
  • Develop various controls strategies using classical or modern control systems.
  • Experience in using developed plant models for verification of Control models for BESS.

Experience: 6–10 years

Mandatory Technical Skills

MathWorks / Model-Basd Development

Extensive hands-on experience with:

  • MATLAB
  • Simulink
  • Stateflow
  • Simulink Test Manager
  • Simulink Check
  • Strong understanding of model-based development and automatic code generation.
  • Experience with Embedded Coder is highly desirable.

BMS

Strong understanding of:

  • Battery Management System architecture
  • Cell voltage and temperature monitoring
  • SOC / SOH estimation
  • Battery balancing
  • Charge/discharge control
  • Over-voltage / under-voltage protection
  • Over-current protection
  • Thermal management
  • BMS control algorithms
  • Battery pack and cell-level behavior

Verification & Validation

  • MIL – Model-in-the-Loop
  • SIL – Software-in-the-Loop
  • PIL – Processor-in-the-Loop
  • Open-loop testing
  • Closed-loop testing
  • Test automation
  • Requirement-based testing
  • Regression testing
  • Test coverage and traceability

Requirements & Code Quality

  • IBM DOORS or equivalent requirements-management tools
  • Polyspace / Parasoft
  • Simulink model-quality and static-analysis tools
  • Understanding of software development and verification processes

Programming / Scripting

  • Strong MATLAB / M-Scripting skills
  • Good Python programming/scripting skills
  • Understanding of C/C++ and embedded software concepts is desirable

Preferred Skills

  • Experience in automotive BMS, EV, hybrid vehicle, or energy-storage/BESS applications.
  • Experience with Embedded Coder and production code generation.
  • Knowledge of CAN/CAN FD and automotive communication protocols.
  • Experience with HIL testing and real-time simulation platforms.
  • Knowledge of ISO 26262 / functional safety.
  • Familiarity with AUTOSAR concepts.
  • Experience with CI/CD and automated testing pipelines.
  • Experience with Git or other version-control systems.
  • Knowledge of battery testing, battery characterization, and battery models.

Education

  • Bachelor's or Master's degree in Electrical Engineering, Electronics, Instrumentation, Control Systems, Mechatronics, Computer Science, or a related engineering discipline.
