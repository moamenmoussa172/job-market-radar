About the job

  • Autóipari gyártási adatok automatikus feldolgozása, megjelenítése
  • Data Pipeline rendszer fejlesztése Python nyelven (adatkezelés, API, stb.)
  • Idősoros adatbázis kezelése, adatbázis műveletek automatizálása
  • Fejlesztési projektben való aktív részvétel
  • Data Science pipeline fejlesztése (MLOps)
  • Fejlesztő csapat támogatása új technológiák vizsgálatával és értékelésével
  • Projektvezetők munkájának támogatása, költségvetés követése
  • BSC / MSC tanulmányok informatika, villamosmérnöki, mechatronika vagy egyéb műszaki területen
  • programnyelvek ismerete és programozási készségek, Python (pandas, numpy, scipy, matplotlib, tensorflow) és SQL
  • adatbányászat és data science területek elméleti hátterének ismerete
  • gördülékeny kommunikáció nemzetközi csapatban, angol nyelven
  • git verziókezelő szoftver ismerete
  • heti legalább 20 óra vállalása

Preferencia/előnyben részesített tudás/készségek:

  • végeselemes módszer ismerete és gyakorlati tapasztalat
  • munkatapasztalat mérnöki/szoftverfejlesztő területen
  • data engineering technológiák ismerete (PySpark, Kubernetes, Docker)
  • objektumorientált programozási készség
  • adatvizualizációs technológiák ismerete (Grafana, PowerBI, Tableau)
  • felhő technológiák ismerete (Microsoft Azure, Databricks)
  • MLOps technológiák ismerete
  • német nyelvtudás
  • ismeretek nagy nyelvi modellek (LLM) témájában
