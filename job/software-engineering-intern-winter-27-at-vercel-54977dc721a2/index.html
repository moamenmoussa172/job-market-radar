About the job

About Vercel:

Vercel is the agentic infrastructure company, freeing people and agents to ship what's next. For more than a decade we've helped builders move from idea to production with speed, security, and exceptional developer experience.

Now we're scaling our products for both agents and people to ship and run software, built in the open and trusted by OpenAI, PayPal, Ramp, Supreme, and millions of developers worldwide.

About the role

As a Software Engineering Intern for Winter 2027, you'll join a Vercel engineering team and ship production code that customers use. By the end of your internship, you'll have scoped, built, and shipped an end-to-end project, with mentorship from the engineers who own the system. This is a hybrid role based in San Francisco, in the office on Monday, Tuesday, and Friday.

What you’ll do

  • Own an end-to-end project: scope it with your manager, build it, and ship it to customers
  • Write production code and review pull requests alongside the engineers who maintain it
  • Debug live systems by tracing issues through the stack and fixing the root cause
  • Post written progress updates and flag blockers as soon as they come up

What you need

  • Currently pursuing a degree in Computer Science, Engineering, or a related field, graduating in Fall 2027 or Spring 2028
  • Built and shipped at least one project in JavaScript or TypeScript, through coursework, a prior internship, open source, or your own work
  • Use AI coding tools in your daily workflow, and can explain and debug every line you ship

Bonus if you

  • Have written code in Go or Rust
  • Have contributed a merged pull request to an open-source project
