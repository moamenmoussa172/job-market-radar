About the job

Main objective of the job:

  • Develop and maintain the core infrastructure on manufacturing co-intelligence platform, including semantic query engines, data ingestion pipelines, chat interfaces, and agent runtime systems, using AI technologies and robust, scalable microservices architecture.

Main attributions and responsibilities:

  • Design, implement, and maintain microservices for AI-powered applications, including semantic search, data processing, and intelligent automation.
  • Develop reliable APIs to handle complex machine learning workloads and real-time user interactions.
  • Build robust, scalable data ingestion and processing pipelines for real-time and batch data from diverse enterprise sources and formats, using workflow orchestration frameworks.
  • Implement vector-based search systems using embedding models, similarity algorithms, and retrieval-augmented generation architectures for intelligent information discovery.
  • Develop responsive natural language web interfaces integrated with large language model APIs, and orchestration layers for multi-agent AI workflows, task delegation, and autonomous decision-making processes.
  • Ensure system scalability, security, and observability across distributed platform components using containerization, cloud-native deployment patterns, and comprehensive monitoring.
  • Implement enterprise security infrastructure, including OAuth, JSON Web Tokens (JWT), role-based access control, audit logging, and compliance features.
  • Collaborate with AI Engineers and product teams to translate business requirements into scalable technical solutions.
  • Implement industry best practices for code quality, automated testing, and continuous deployment to build robust, maintainable, and well-tested software.
  • Reads, understands and applies the procedures from area of responsibility and other interdepartmental procedures, applicable within the company;
  • Fulfils any other tasks related to area of responsibility, as requested by direct superior.
  • University studies in IT domain or any other related field;
  • Language: English
  • Strong knowledge of Python 3.11+
  • Experience with REST API design and modern web frameworks.
  • Knowledge of asynchronous programming, concurrency, and event-driven design.
  • Strong SQL skills, including query optimization and relational database design.
  • Knowledge of data modeling, validation, database migrations, and NoSQL databases.
  • Understanding of Retrieval-Augmented Generation (RAG), semantic search, and vector databases.
  • Experience integrating Large Language Model (LLM) APIs and applying prompt engineering.
  • Knowledge of in-memory data stores and distributed caching.
  • Solid understanding of microservices and distributed systems architecture.
  • Proficiency with containerization and cloud-native orchestration platforms.
  • Knowledge of data pipelines, workflow management, and AI service orchestration.
  • Knowledge of authentication protocols, API security, and enterprise security practices.
  • Experience with unit, integration, and asynchronous testing.
  • Proficiency with Git workflows, package management, and environment isolation tools.
  • Knowledge of continuous integration and deployment (CI/CD), automation, and code quality tools.
  • Knowledge of modern JavaScript frameworks and enterprise API integration- nice to have
  • Familiarity with monitoring, metrics, and distributed tracing.
  • Strong problem-solving, communication, and teamwork skills; interest in AI and continuous learning
