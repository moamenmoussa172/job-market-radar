About the job

Title: Software Engineer II, Backend — Toast International
Location: Toronto, ON / Canada Hybrid (Ontario)
Level: Software Engineer II (SE2)

Who We Are

Toast is driven by building the restaurant platform that helps restaurants adapt, take control, and get back to what they do best: building the businesses they love.

Are you bready* for a change?

As a Software Engineer II on the Toast Tables International team, you will build and scale the cloud services powering modern table management, guest reservations, and front-of-house hospitality for high-volume restaurants across the UK, Europe, and Canada.

In this role, you will work hands-on with distributed microservices in Java and Kotlin—delivering high-impact capabilities such as payment integrations, messaging services, and core platform workflows. You will collaborate with senior engineers, product managers, designers, and mobile/web teammates across North America and Europe to deliver reliable, high-performance features.

About this roll* (Responsibilities)

  • Build, test, and deploy scalable backend microservices using Java / Kotlin and AWS infrastructure.
  • Implement core reservation and guest lifecycle APIs, including international phone validation, geoblocking rules, and two-way notification services.
  • Develop transactional and payment components for reservation , pre-authorizations, and Card workflows.
  • Build data sync endpoints and event consumers connecting with POS order data, fulfillment, and Guestbook profiles.
  • Write comprehensive automated unit, integration, and contract tests to ensure zero-regression releases and high test coverage.
  • Monitor service health, analyze logs and metrics (Datadog/CloudWatch), and participate in on-call rotations to maintain platform uptime.
  • Collaborate in team agile ceremonies, code reviews, and technical design discussions, leveraging modern development tools to ship quality software efficiently.

Do you have the right ingredients*? (Requirements)

  • 2–4 years of professional backend software development experience building RESTful APIs and distributed systems in production.
  • Proficiency in Java or Kotlin (or similar object-oriented languages like C#) and familiarity with modern frameworks (e.g., Spring Boot, Micronaut, Dropwizard).
  • Experience working with relational databases (e.g., PostgreSQL, MySQL) and writing efficient SQL queries and schema migrations.
  • Familiarity with distributed systems concepts, asynchronous messaging (Kafka, Pulsar, or AWS SQS/SNS), and cloud platforms (AWS).
  • Solid understanding of RESTful API design principles, JSON data modeling, and testing best practices (JUnit, Mockito).
  • Strong problem-solving skills, curiosity to learn restaurant domain workflows, and enthusiasm for collaborating in an agile, cross-functional team.
