About this Role

We are seeking a Senior Cloud Full Stack Developer with 7+ years of software development experience to design, develop, deploy and support secure, scalable enterprise applications.

Based in Pune in a hybrid working environment, this role combines hands-on application development with technical leadership, customer engagement and team development. You will work across React, RESTful Web APIs, Microsoft SQL Server, Azure technologies, Azure DevOps and GitHub while providing technical direction throughout the software development lifecycle.

You will also mentor junior developers, contribute to Agile delivery, troubleshoot complex application and production issues, and communicate technical solutions, dependencies and risks effectively with customers and stakeholders.

What you’ll do

  • Lead the design, development, enhancement and maintenance of secure, scalable, enterprise-grade applications using modern engineering practices.Translate solution designs and business requirements into effective technical components and take ownership of complex development activities.
  • Develop clean, maintainable and efficient code aligned with established architecture, security and engineering standards.Design and develop responsive user experiences using React and modern front-end technologies.Design, develop and consume RESTful Web APIs and integration services.
  • Design, optimise and maintain reliable application data solutions using Microsoft SQL Server.Conduct code reviews, design reviews and quality checks to maintain agreed engineering standards.Mentor junior developers through coaching, pair programming, knowledge sharing and practical technical guidance.
  • Serve as a technical point of contact for customers and stakeholders, communicating solution options, progress, dependencies, risks and technical issues clearly.Participate in requirement clarification, solution walkthroughs, demonstrations, incident discussions and service reviews.Perform unit testing and support integration testing, system testing, user acceptance testing, deployment, release and post-deployment activities.Investigate complex application defects, production incidents and performance issues, conducting root-cause analysis and implementing sustainable corrective actions.Collaborate with Product Owners,
  • Scrum Masters, Architects, QA Engineers, operations teams and business stakeholders to achieve agreed outcomes.Contribute to Agile ceremonies, estimation, technical planning, continuous improvement and engineering best practices.Use Azure DevOps and GitHub for source control, work-item tracking, CI/CD, release management and engineering governance.Evaluate relevant emerging technologies and development practices to support evolving business and customer requirements.
