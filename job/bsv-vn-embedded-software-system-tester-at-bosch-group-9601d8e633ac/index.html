About the job

Job Description

We provide comprehensive software engineering services for German customers in the automotive domain. Our teams deliver end-to-end software development across the entire lifecycle, covering all critical roles such as developers, testers, integrators, and specialized functions including Functional Safety and Cyber Security.

We provide end-to-end automotive software engineering services for German customer, covering development, testing, integration, project management, Functional Safety, and Cyber Security. We also work on advanced engineering topics, including software for future E/E architectures.

Join us in the mission of making cars safer and shaping the future of mobility—while building your career in life-saving, next-generation technologies.

As an Embedded Tester, you will be doing MiL Testing (Model-in-the-Loop)/SiL Testing (software-in-the-loop)/HiL Testing (hardware-in-the-loop) for software components in Automotive domain. Your main responsibilities include:

  • Perform Unit test, Component test, Model in the loop testing
  • Or perform System Test / HiL Testing (hardware-in-the-loop)
  • Creation of stimuli model to obtain predefined requirements of Requirement coverage; Equivalence class coverage; Boundary value coverage; Code coverage (DC, MC/DC)
  • Create test specification or test case to cover requirement
  • Test execution and test results analysis
  • Test report
  • Participation in the design, testing and optimization of the development and validation processes (regular technical meetings with test management and fellow test colleagues)
  • Requirements analysis and review
  • Derivation of test-specs from approved requirements
  • Support development of test process, methodology and tools
  • Develop test automation
  • Solve technical problems/queries
  • Communicate findings to colleagues in order to prevent technical problems/queries
  • Mentor junior members (for Senior level)
  • Major in Computer Engineering/ Electrical-Electronics/ Electronics-Telecommunication/ Mechatronics Engineering/ Physical Engineering or related fields
  • 2+ years of experiences in Embedded Testing/ Software Testing
  • Mandatory requirement
  • Good C/C++ programming
  • Have experience on Door or Code Beamer, Git,
  • Have experienced in Matlab Simulink/TPT/Embedded Coder
  • Have experience on EXAM or the same tool chain
  • Have experience with CANoe, CANape and NovaCarts or the same tool chain
  • Experience or knowledge in Software Development Lifecycle, V- model
  • Experience in emulators, simulators, debugging and test equipment
  • Basic embedded knowledge about micro-controller, Sensors, Actuator and semiconductor, communication protocol, network protocol
  • Automotive domain knowledge
  • Good analytical and debugging skills
  • Good English communication skills
  • It would be big advantage if you have:
  • Have knowledge in Matlab Simulink/ASCET or related model language
  • Have knowledge on Model-based Design with MATLAB/Simulink
  • ISTQB certificate (Foundation level)
  • Python/VBA scripting language
  • Autosar Software Architecture
  • Good knowledge in powertrain
  • German communication
