About the job

Backend Developer- Python

Description -

We are looking for a backend web developer to join our engineering team in Cambridge. You will be working on the HP Wolf Security Cloud Service - a web-based platform to manage our security software products that are installed on end-user PCs (see https://www.hpwolf.com/).

The HP Wolf Security Cloud Service is composed of several different services that serve various roles in the architecture. The HP Wolf Security Controller provides security policy and software updates for the endpoint security product installed on the client PCs. It also receives status, events and threat data from these clients, including malware traces which are used to produce interactive visualisations in the web-based UI and summarized in reports. The Controller is deployed at scale, both on-premises at individual corporate enterprises with tens of thousands of clients, and in the cloud across hundreds of AWS instances. We're continuing to scale further, while also adding support for new products and enhancing existing features.

The HP Wolf Security Portal is the unifying service for customers accessing the capabilities provided by HP Wolf Security on endpoints. Integrating with different SSO providers (Microsoft Entra ID, formerly Azure AD, and HP ID) for authentication, it enables self-service onboarding for entitlement to HP Wolf Security endpoint software. For small-medium businesses or consumers it provides a simplified license management and configuration portal, whereas for larger customers it provides integrated access to their own dedicated Controller. It has features to support partners and our HP support teams to help customers onboard and manage their HP Wolf Security products.

As part of the engineering team, you will deliver features and help improve service reliability, performance and maintainability. You will investigate and troubleshoot defects, contribute to code reviews and collaborate with engineers, product partners and other technical teams. You will work independently on day-to-day tasks and partner with teammates on more complex technical challenges.

There may also be an opportunity to work on other supporting cloud services where some make use of Go, along with others using our typical stack.

What you will do as a Backend Developer:

  • The API and UI back-end (Python, Django, Django REST Framework)
  • The background worker service / task queues (Celery, Dramatiq)
  • Container-based packaging (Linux, Nginx, PostgreSQL, Docker)
  • Supporting operational deployment using AWS (S3, ECS, RDS, etc.)
  • Integrations with other cloud systems (Elastic/Kibana, Salesforce, InterWorks, Azure, other internal HP systems)
  • Maintaining product compatibility for customers' self-hosted, on-premise servers (Windows, IIS, SQL Server)
  • Unit tests, Playwright/Selenium tests, automated installation tests, static code analysis, anything else we can have the CI system (Jenkins) do for us

About the HP Wolf Security Controller:

The HP Wolf Security Controller is a large-scale cloud platform that powers the management of our endpoint security products. Used by enterprise customers around the world, it delivers security policies, software updates and threat intelligence while processing vast volumes of security telemetry and event data. Operating across AWS and customer-hosted environments, the platform presents complex engineering challenges in scalability, reliability and performance, making it an exciting opportunity for engineers who enjoy building secure, high-impact software at scale. For more information, visit our website: HP Endpoint Security Solutions

About HP Wolf Security

HP Wolf Security develops industry-leading cybersecurity solutions that help protect devices, data and users from an ever-evolving threat landscape. Our unique approach combines endpoint security, isolation technology and cloud services to help organisations stay secure against both known and emerging threats. Joining HP Wolf Security means working on products that make a real difference to customers worldwide while collaborating with talented engineers, researchers and security experts.

To see what our engineering teams are working on, check out our technical blogs: HP Threat Research Blog

Our history:

Inspired by the isolation principles of traditional virtualization, our team known then as Bromium, created a game-changing technology called micro-virtualization to protect end users against advanced malware. Every task the user performs, such as opening a document or clicking on a link, is isolated in its own micro-VM, with access to just the resources required for that task, and existing just for the life of the task. Protection is thus provided through isolation, without relying on detection, hence reliably defending the user from polymorphic and even zero-day malware.

Bromium was acquired by HP Inc on 19 September 2019 forming HP Wolf Security.

For more information, visit our website: https://www.hp.com/uk-en/security/endpoint-security-solutions.html
