About the job

This is a fully remote job, open to people in Romania.

Caseware is one of Canada's original Fintech companies, having led the global audit and accounting software industry for over 30 years, with more than 500,000 users across 130 countries and available in 16 different languages. While you might not have heard of us (yet) over 36,000 accounting and audit professionals list Caseware as a skill on their LinkedIn profiles!

We’re looking for a Desktop Software Developer who enjoys working with complex logic, structured data and software that supports financial reporting.

Your primary focus will be developing content and scripting within CaseView and Caseware Working Papers, alongside building and maintaining C#/.NET integrations. You’ll help create financial reporting solutions used by clients across Europe, supporting IFRS, local GAAP and related disclosure requirements.

Previous CaseView experience is an advantage, but isn’t required. We welcome developers with strong Windows scripting and .NET skills who are interested in learning a specialised financial reporting platform.

❗Note: This role is full-time, permanent. Not for B2B contract.

What you will do:

  • Develop and maintain CaseView content and JScript automation for financial statements, assurance and tax preparation solutions.
  • Use the CaseView document object model to control tables, rows, paragraphs, formulas and conditional content.
  • Translate functional specifications and user stories into accurate, maintainable scripts.
  • Implement and troubleshoot complex conditional logic, including dependencies between formulas and document sections.
  • Review, debug and improve existing scripts across large content sets.
  • Maintain XBRL/iXBRL tagging and mappings to support reporting requirements.
  • Build and maintain C#/.NET integrations connecting desktop applications to REST APIs and local data sources, including CSV, XML and databases.
  • Handle authentication, response parsing and data mapping into document fields and tables.
  • Use AI-assisted and agentic development tools to support scripting, testing and content maintenance, reviewing generated output for accuracy.
  • Build automated workflows and internal tools that improve development efficiency.
  • Collaborate with QA and product owners to ensure generated documents meet specifications and applicable financial reporting requirements.
  • Contribute to the Knowledge Library structures used to package and distribute content.

What you will bring:

  • 3–5 years of software development experience, with hands-on work in C#/.NET, Windows desktop applications and scripting or automation.
  • Strong JavaScript fundamentals and the ability to work with object models in scripting environments.
  • Experience with Windows Script Host, COM/ActiveX automation or comparable desktop scripting technologies.
  • Experience integrating applications with REST APIs and structured data sources such as CSV, XML or databases.
  • Confidence handling authentication, parsing API responses and mapping data between systems.
  • Strong debugging skills and the ability to reason accurately about conditional logic, AND/OR precedence and dependencies.
  • Practical experience using AI coding agents in a development workflow, such as GitHub Copilot, Claude Code, Devin or equivalent tools.
  • Experience creating automation scripts, bots or development pipelines.
  • Good written and spoken English, with the ability to collaborate in an international team.
  • An interest in learning how accounting and financial reporting requirements translate into software behaviour.

Nice to have:

  • CaseView or Caseware Working Papers.
  • VB.NET.
  • XBRL/iXBRL tagging and reporting.
  • Accounting, audit, tax or financial reporting software.
  • IFRS or Dutch, German or Danish financial reporting requirements.
  • Dutch, German or Danish language skills.
  • Jira and Confluence in a distributed development environment.
