UI Technical Artist (March of Giants)

Ubisoft · Montreal, Canada

Unreal Engine

About the job

As a UI Technical Artist at Ubisoft Montréal, you will help bring gameflow interfaces and menus to life in Unreal Engine. You’ll transform UI mockups into functional, performant, and visually consistent experiences while working within the project’s technical requirements and collaborating closely with User Experience, UI Art, and UI Engineering teams.

What you’ll do

  • Integrate menus and gameflow systems in Unreal Engine using UMG and Blueprint
  • Break down UI designs into reusable widgets, interface structures, and logic flows
  • Implement menu animations and interactive interface behaviors
  • Optimize UI performance related to CPU, memory, textures, and materials
  • Collaborate with User Experience, UI Art, and UI Engineering teams to support smooth integration workflows
  • Create and refine UI materials and shaders to support visual quality targets
  • Manage and optimize UI textures and graphic assets for performance and consistency
  • Diagnose and resolve UI integration issues related to Blueprint, UMG, and interface implementation
  • Maintain visual consistency across menus and gameflow interfaces
  • Support technical problem-solving related to interface integration constraints

What you bring to the team

  • Strong proficiency with Unreal Engine, including UMG, Blueprint, and UI integration workflows
  • Knowledge of UI shaders and materials
  • Understanding of UI textures, including formats, optimization, and memory management
  • Balance visual quality with technical performance requirements
  • Apply a technical and solution-oriented approach to UI integration challenges
  • Collaborate effectively with cross-functional development teams
  • Communicate interface implementation constraints clearly and constructively
  • Adapt to evolving production and technical needs

What to send our way

  • Your CV highlighting relevant skills and experiences
  • Portfolio or project links showcasing relevant UI integration or technical art work
