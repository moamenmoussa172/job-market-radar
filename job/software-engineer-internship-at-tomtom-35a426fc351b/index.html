About the job

What you'll do:

  • Join the team behind TomTom’s EV Data Service, which supplies charging station data, live availability and pricing to Search, Routing and car makers, and take part in daily team work
  • Work on our daily data pipeline ro improve data quality checks, conflation and deduplication rules
  • Help bring in new charging data providers
  • Use logs, metrics and dashboards (Grafana, Prometheus) as your first step when investigating incidents, and add that context to tickets
  • Work inside our CI/CD pipelines: run builds, find which stage failed and fix simple pipeline or configuration issues
  • Write clean, tested code (Scala/Kotlin or Java) and learn from code reviews
  • Build supplier and coverage metrics: per-provider and per-country counts, availability coverage, pipeline run times. Share the results in simple tables or charts
  • Use AI coding agents and MCP tools, including our own Volt Bot, to speed up your coding, analysis and documentation
  • What you'll need: Must-have:
  • Currently studying Computer Science, Software Engineering, Data Engineering or a related field
  • Programming skills in at least one language, ideally a JVM language (Java, Kotlin or Scala)
  • A good grasp of basic data structures and algorithms
  • Basic SQL and an understanding of relational databases
  • Familiarity with Git and basic testing concepts (unit, functional and regression testing)
  • Hands-on use of AI tools for coding or research, and the habit of checking what they produce
  • Good English, curiosity and openness to feedback
  • Nice-to-have:
  • Apache Spark, Databricks or other big data processing experience
  • Exposure to CI/CD, Docker or Kubernetes, or a cloud platform such as Azure
  • Experience with an AI coding agent in your IDE or CLI, or with MCP clients
  • Python for scripting and data analysis
  • Interest in electric vehicles, maps, geospatial data or data quality
  • What can you expect:
  • Real work on a production data service used by car makers, with clear, measurable goals
  • A dedicated mentor and regular code reviews from experienced engineers
  • Team knowledge-sharing sessions and hands-on learning in Spark, cloud, CI/CD and AI tooling
  • Hybrid work from our Łódź office
