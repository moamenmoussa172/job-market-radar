About the job

Powered by world-class technology and a user-first mindset, Bybit delivers a seamless ecosystem across trading, payments, wealth management, custody, institutional services, and Web3 — connecting users to the future of digital finance.

Responsibilities

  • Design, develop, and continuously enhance platforms for secure software development and software supply chain security, embedding security capabilities into code commits, CI builds, artifact management, approvals, and production releases.
  • Design and implement automated security gates within existing development workflow management tools—including branching policies, code reviews, and end-to-end release workflows—to ensure secure application deployment.
  • Build trusted build and release capabilities, including dependency integrity verification, artifact hash reporting and deployment-time verification, artifact immutability, provenance tracking, signature verification, and cross-environment consistency.
  • Collaborate with security, architecture, and application development teams to translate security policies into scalable platform capabilities with low false-positive rates, phased rollout support, and policy exception mechanisms.

Requirements

  • A bachelor’s degree or above, preferably in Computer Science, Software Engineering, Information Security, or a related field; at least 5 years of experience in backend development, security engineering, or DevSecOps platform development.
  • Strong programming skills in Java or Go, with a deep understanding of multithreading and concurrent programming models.
  • A deep understanding of software supply chain security, including key attack surfaces and mitigation strategies across code repositories, dependency sources, build environments, artifact repositories, and deployment workflows.
  • An understanding of the principles behind Static Application Security Testing (SAST), Software Composition Analysis (SCA), secret scanning, and malicious code detection, with hands-on experience implementing security scanning platforms or CI/CD security gates.
  • Familiarity with dependency ecosystems such as Maven, npm, PyPI, and Go Modules, including dependency resolution, version pinning, dependency confusion, and package poisoning risks.
  • Familiarity with artifact management platforms such as JFrog and Harbor, with practical experience in centralized package source governance, artifact access controls, artifact immutability, and dependency and artifact integrity verification.
  • Familiarity with GitLab, Jenkins, or other CI/CD platforms, including branch protection, code reviews, pipeline templates, build runner isolation, credential management, and release approval mechanisms.
  • Strong cross-functional collaboration and execution skills, with the ability to translate security requirements into actionable, measurable platform solutions while balancing security risks with engineering productivity.
