Embedded Software Engineer About the Role As an Embedded Software Engineer, you will develop and maintain embedded software solutions for ADI's innovative products. This position requires demonstrated competence in embedded software development and the ability to work with moderate guidance on projects. You'll handle short-term projects and provide solutions to moderately complex software problems while understanding how your work impacts organizational objectives. Key Responsibilities

  • Develop and maintain embedded software solutions
  • Debug and optimize firmware code
  • Provide solutions to moderately complex software problems
  • Apply standard engineering principles and concepts
  • Contribute to technical documentation
  • May provide coaching to junior engineers
  • Work under regular supervision with periodic review
  • Participate in code reviews and design discussions

Must Have Skills

  • C/C++ Programming: Proficient programming skills with ability to develop efficient code for embedded applications
  • Microcontroller Experience: Practical knowledge of microcontroller programming and basic device drivers
  • RTOS Concepts: Basic understanding of real-time operating system principles and implementation
  • Debugging Tools: Knowledge of debugging techniques and tools for embedded systems
  • Version Control: Experience with collaborative development using version control systems
  • Problem-Solving: Strong ability to diagnose and resolve software issues independently
  • Communication: Effective skills in technical documentation and team collaboration

Preferred Education and Experience

  • Bachelor's degree in Computer Science, Computer Engineering, or related field
  • 2+ years of relevant experience in embedded software development
