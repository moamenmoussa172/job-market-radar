About the job

Integrant Inc is hiring a passionate "Senior Technical Lead - .Net Full-Stack". This role is the technical backbone of the project — owning architecture, engineering standards, and technical quality while partnering with the Technical Project Lead on delivery. Top candidates will demonstrate deep technical expertise across modern .NET, cloud, AI, and distributed systems, with the ability to elevate their team's skills and drive engineering excellence.

Duties & Responsibilities:

Architecture & System Design

  • Own and approve system architecture, design specifications, and technical direction.
  • Define bounded contexts and map context relationships using DDD patterns (Shared Kernel, Customer-Supplier, Anti-Corruption Layers).
  • Design event-driven systems: model domain events, implement async event processing, ensure event idempotency, and handle eventual consistency.
  • Design microservices communication strategies (sync/async), API gateways, database-per-service patterns, and distributed transaction handling.
  • Design distributed caching strategies including cache-aside, write-through, and cache invalidation/coherency patterns.
  • Design comprehensive testing strategies: contract testing, integration testing, end-to-end testing, and test data management.

AI & Agents

Basic (must have) :

  • LLM integration
  • Simple RAG
  • Simple AI workflow like n8n

Plus:

  • Design and implement multi-agent systems where agents collaborate using coordination frameworks or shared context for complex workflows.
  • Implement operational patterns for multi-agent reliability: retry logic, branching/conditional logic, fallback strategies, and long-running task management.
  • Establish agent evaluation frameworks — log agent actions, track errors/latency/success rates, and drive continuous improvement through feedback loops.

Cloud & Serverless

  • Implement advanced caching solutions using Redis/Azure Cache (strings, hashes, lists, sets, sorted sets, pub/sub).
  • Design complex serverless orchestration: function chaining, fan-out/fan-in workflows, connection pooling, and scalability optimization.
  • Design API gateway policies: request/response pipelines, hierarchical policy scopes (global, API, endpoint), authentication/authorization mechanisms, and transformation/caching policies.

Database

  • Design and implement database replication (master-slave) and high availability/failover strategies.

DevOps

  • Design multi-container applications using Docker Compose, manage volumes for data persistence, configure container networking, port mapping, and environment variables.
  • Drive CI/CD pipeline practices and source control workflows across the team.

Security

  • Secure AI API keys and model endpoints: key rotation, rate limiting, endpoint authentication, TLS, usage monitoring, cost controls, and IP allow listing.
  • Design agent authentication and authorization: agent identity management, service-to-service auth, credential rotation, and inter-agent communication security.
  • Understand and apply vulnerability scanning approaches (SAST, DAST, SCA) and tools (SonarQube, Snyk).

Engineering Standards & Quality

  • Enforce sound software engineering practices: iterative development, code reviews, unit testing, integration testing, and automation testing.
  • Review and sign-off on functional and technical specifications; monitor deliverables vs. specifications and provide corrective actions.
  • Champion best practices in design patterns, SOLID principles, and clean architecture.

Team Growth & Mentorship

  • Mentor and train team members on software design, design patterns, SOLID principles, and emerging technologies.
  • Conduct code reviews that are educational — raise the engineering bar for the whole team.
  • Assess team capabilities and advise the Technical Project Lead on task assignments based on technical strengths.

Collaboration with Technical Project Lead

  • Provide technical feasibility assessments and effort estimates for scope reviews and change requests.
  • Supply technical input for risk assessments, status reports, and delivery decisions.
  • Support client-facing technical discussions and demos when deep technical context is needed.

Requirements

  • 9+ years of experience in software engineering.
  • 2+ years as a Lead Software Engineer with hands-on technical leadership of cross-functional teams.
  • Strong hands-on experience with .NET Core, C#, and the modern .NET ecosystem.
  • Proficient with frontend technologies (Angular or React).
  • Hands-on experience with software architecture: DDD, Event-Driven Architecture, microservices, and distributed systems.
  • Experience designing and implementing multi-agent AI systems and agent observability.
  • Hands-on with cloud platforms (Azure and/or AWS) including serverless, caching, and API management services.
  • Experience with database replication, high availability, and failover strategies.
  • Hands-on with DevOps tools: CI/CD, source control, Docker, Docker Compose, and Kubernetes.
  • Understanding of security practices: vulnerability scanning (SAST/DAST/SCA), AI endpoint security, and agent authentication.
  • Agile methodology experience.
  • Strong client engagement skills — this role requires regular interaction with US clients.
  • Self-learner who stays current with software development trends.
