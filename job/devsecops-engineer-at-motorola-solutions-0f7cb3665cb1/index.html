Department Overview

CRFS is seeking a DevSecOps Engineer to join our DevOps team and help build security into the way we develop, build and release our products. As we provide the "gold standard" in spectrum intelligence to defense agencies, spectrum regulators, and systems integrators, our software must satisfy demanding customer and regulatory security requirements. You will help ensure that our embedded, desktop and web software is secure, resilient, and delivered through robust automated pipelines.
This is a hands-on, mid-level role. It will suit an engineer with a few years' experience of CI/CD and Linux, a genuine interest in security, and the ability to take ownership of well-defined areas of work with support from senior colleagues.


Job Description

Duties and Responsibilities

● CI/CD Pipelines: Build, maintain and improve the automated pipelines (GitLab CI and TeamCity) that build, test, scan, package and release CRFS software across our embedded Linux, Windows desktop, web and firmware products.

● Security Scanning: Implement and operate automated security testing within those pipelines, including static analysis (SAST), dependency analysis (SCA), secret detection, dynamic testing (DAST), vulnerability scanning and SBOM generation, with quality gates and clear, consolidated reporting.

● Vulnerability Management: Triage scanner findings and newly published CVEs with the development teams, assess their real impact on our products, track remediation through to release, and support regular security patch releases.

● Compliance & Hardening: Help CRFS meet customer and regulatory security requirements (e.g. NIST SP 800-53, DISA STIGs, FIPS 140) by hardening our Linux-based product images and servers, and producing the repeatable scan results and technical evidence needed for system certification.

● Build Infrastructure: Maintain and secure the build estate, including self-managed GitLab and TeamCity, Linux and Windows build agents, virtualized and cloud infrastructure, and internal package mirrors, using infrastructure-as-code where practical.

● Supply Chain Security: Protect the integrity of what we ship through dependency pinning and vetting, trusted internal mirrors, artifact and release signing, access reviews, and careful management of secrets, keys and tokens.

● Code Review: Review pipeline, infrastructure and application changes written by other engineers, providing constructive feedback and ensuring alignment with security standards.

● Documentation: Write clear runbooks, developer guides and security documentation to support system certification, in line with the CRFS Quality Management System.


Basic Requirements

Experience and Qualifications Required

● Relevant Experience: Three or more years in a DevOps, DevSecOps, build/release or platform engineering role, or equivalent CI/CD-focused software engineering experience.

● Linux: Strong hands-on experience administering and securing Linux systems (Ubuntu/Debian), including shell scripting and networking fundamentals.

● CI/CD: Practical experience building and maintaining pipelines in GitLab CI, TeamCity, Jenkins, GitHub Actions or similar.

● Automation: Proficiency in Python and Bash for automation and tooling, with a commitment to clean, maintainable code under version control (Git).

● Containers: Working knowledge of Docker, including writing Dockerfiles, managing images and registries, and running builds in containers.

● Security Fundamentals: Hands-on exposure to security tooling in a development pipeline (e.g. SAST, dependency or vulnerability scanning), the ability to interpret a CVE and judge its real impact, and a sound grasp of least privilege, secrets management and patching.

● Problem Solving: A methodical approach to diagnosing build, infrastructure and security problems across unfamiliar codebases and systems.

● Collaboration: Clear written and verbal communication, able to explain security findings constructively and to own assigned work through to completion.

Highly Desirable

● Regulated Environments: Experience working to security standards such as NIST SP 800-53 / RMF, DISA STIGs, CIS Benchmarks, FIPS 140, ISO 27001 or Cyber Essentials Plus, ideally in defense, aerospace or another regulated sector.

● Security Tooling: Experience with tools such as OWASP ZAP, OWASP Dependency-Check, Trivy, Semgrep, SonarQube, Nessus or OpenSCAP, and with SBOM formats (CycloneDX, SPDX).

● Infrastructure: Experience with Terraform or Ansible, virtualization platforms (e.g. Proxmox, VMware), self-hosted CI runners and AWS.

● Windows Build Environments: Experience with Windows build agents and PowerShell automation, including .NET/NuGet builds, code signing and installers.

Desirable Skills

● Academic Background: A science or engineering degree in Computer Science, Electronics, or a similar field, or equivalent practical experience.

● Build Systems: Familiarity with building C/C++ (CMake), Rust (Cargo), .NET and JavaScript/TypeScript projects on Linux and Windows; enough to debug a failing build and interpret scanner findings.

● Embedded Linux: Exposure to embedded Linux delivery, such as Debian or Alpine packaging, root filesystem and image builds, cross-compilation and kernel modules.

● Domain Interest: An interest in RF, signal processing or spectrum monitoring.
