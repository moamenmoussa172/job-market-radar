About the job

We are looking for a Working Student to join our team and cover the following responsabilities:

  • IT equipment fleet management
  • Install and deploy hardware and software according to IT standard processes
  • Deliver on-site support, investigate and solve issues
  • Ensure the proper follow-up in case of issues and requests
  • Provide technical assistance and consulting
  • Following IT service management processes
  • Document IT incidents cases
  • Support for IT Products and Services
  • Support for IT projects rollout
  • Collaboration with external suppliers
  • Purchasing IT hardware / software / services
  • Being proactive, identify and communicate potential improvements
  • A student willing to learn about IT technologies
  • Hardware skills (PCs, laptops, printers, multifunctional printers, tablets, smartphones, servers, monitors, phones, multimedia devices, etc.)
  • Software skills : Windows 7/8/10 troubleshooting, Command Line, File and Folder Security, Windows Services, Windows Server, Active Directory, Microsoft Office, SCCM
  • Strong Customer orientation skills
  • Good English skills - both written and spoken

LikeABosch Benefits:
