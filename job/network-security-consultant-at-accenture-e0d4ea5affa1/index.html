Network Security Consultant

Accenture · Riyadh, Saudi Arabia

Onsite · Security Engineer · Posted 1 November 2026

About the job

  • Design, deploy, and manage network security solutions, including firewalls, VPNs, IDS/IPS, WAF, and secure web gateways.
  • Monitor network traffic and security events to identify and respond to threats.
  • Perform security assessments, vulnerability scans, and remediation activities.
  • Configure and maintain network security devices such as Fortinet, Palo Alto, Cisco, Check Point, or similar technologies.
  • Investigate security incidents and support incident response activities.
  • Implement network segmentation, access control, and Zero Trust security principles.
  • Develop and maintain network security documentation, policies, and procedures.
  • Ensure compliance with organizational and regulatory security requirements.
  • Support disaster recovery and business continuity initiatives from a network security perspective.
  • Bachelor's degree in Computer Science, Information Security, IT, or a related field.
  • Hands-on experience with firewalls
  • Experience with vulnerability management and security monitoring tools.
  • Knowledge of cybersecurity frameworks and security best practices.
  • Strong troubleshooting and analytical skills.
