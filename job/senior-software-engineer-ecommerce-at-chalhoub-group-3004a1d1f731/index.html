What you'll be doing

Work fully hands-on to design, build, test, integrate, and operate enterprise ecommerce solutions on Shopify and Shopify Plus, owning complex implementation and code quality while providing technical guidance to other engineers.

• Design, build, test, integrate, and operate enterprise ecommerce solutions hands-on on Shopify and Shopify Plus.

•Develop across Shopify platform capabilities including Collections, Products, Discounts, and Promotions, using the Shopify Services framework and Shopify APIs.

•Build full-stack functionality with JavaScript, Node.js, REST/GraphQL APIs, and headless commerce across the ecommerce space.

• Own code quality through unit, functional, and regression testing and code review, and perform technical troubleshooting.

•Provide deployment support, production issue resolution, and release reliability across CI/CD, optimizing web performance and CDN/caching.

• Deliver dependably on time and provide technical guidance and mentoring to other engineers.

• Support OMS/ERP/WMS and SFSC/SFMC integrations.

• Use Claude Code for AI-assisted development to accelerate delivery while maintaining code quality.

What you’ll need to succeed

• Minimum 5 years of hands-on ecommerce engineering experience, working full-stack and primarily on Shopify and Shopify Plus.

• Strong proficiency with Shopify platform capabilities (Collections, Products, Discounts, Promotions), the Services framework, Shopify APIs, and headless commerce.

• Proficiency in JavaScript, Node.js, REST/GraphQL APIs, web performance, CDN/caching, and CI/CD across the ecommerce space.

• Strong unit, functional, and regression testing, code review, and technical troubleshooting skills, with a technical mentoring capability.

• Integration experience required with OMS/ERP/WMS and SFSC/SFMC; familiarity with Claude Code for AI-assisted development.
