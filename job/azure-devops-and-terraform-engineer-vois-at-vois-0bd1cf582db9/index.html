About this Role

We are seeking an Azure DevOps and Terraform Engineer to design, deliver and maintain enterprise-scale Infrastructure as Code capabilities across Vodafone Azure environments. You will create reusable Terraform modules, landing zones and automation solutions that enable secure, compliant and standardised cloud deployments.

Based in Pune within Data Centre Operations, this role requires strong experience in Terraform, Microsoft Azure, CI/CD, Git, cloud governance and Python automation. You will work with global stakeholders, Cyber Security and FinOps teams to support self-service adoption, improve deployment reliability and reduce manual provisioning.

What you’ll do

  • Design, develop and maintain Terraform-based Infrastructure as Code for Azure platforms.
  • Build reusable, version-controlled Terraform modules, landing zones and deployment patterns.
  • Manage Terraform state, remote backends, state locking and configuration-drift detection.
  • Develop and maintain Python automation that enables self-service cloud offerings.
  • Build and operate Infrastructure as Code pipelines using Azure DevOps or GitHub.
  • Integrate security, policy and compliance checks into CI/CD pipelines.
  • Implement Policy as Code, role-based access control, tagging, encryption and network controls.
  • Apply Vodafone security baselines and relevant regulatory standards to cloud deployments.
  • Collaborate with Cyber Security and FinOps teams to deliver governed, cost-conscious solutions.
  • Promote the adoption of standard Terraform modules and landing zones.
  • Improve deployment success rates, pipeline reliability and compliance.
  • Help reduce manual provisioning through scalable automation.

Who you are

  • You hold a bachelor’s degree in Information Technology, Computer Science or a related discipline, or possess equivalent professional experience.
  • You have six to eight years of overall technology experience, including at least four years working with Terraform or Infrastructure as Code.
  • You have strong hands-on experience with Microsoft Azure.
  • You understand Azure Infrastructure as a Service, networking, identity and security.
  • You have experience with Azure governance, policy and cloud security controls.
  • You can develop and maintain CI/CD pipelines using Azure DevOps or GitHub.
  • You are proficient in Git-based development and version-control practices.
  • You can automate Azure services using Python and the Azure SDK.
  • You understand Terraform state management, remote backends, state locking and drift detection.
  • You have experience provisioning or managing API Management through Infrastructure as Code.
  • You demonstrate accountability, effective documentation practices and a focus on quality.
  • You collaborate effectively with stakeholders across distributed and global teams.
  • You can work independently within a virtual team environment.
  • A Terraform Associate or relevant cloud certification would be advantageous.
