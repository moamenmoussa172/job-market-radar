About the job

Ubisoft’s IT Business Applications department is looking for an experienced .NET Full-Stack Developer to join the HR Development Team in Bucharest.

You will design, build, and modernize HR applications used in an international environment, working closely with product owners, HR stakeholders, and technical teams to deliver reliable and sustainable solutions.

What you'll do

  • Design and deliver maintainable full-stack HR applications using C#, .NET, Angular, and Microsoft SQL Server.
  • Build and integrate secure REST APIs that support reliable data exchange across HR systems.
  • Improve application performance, availability, testability, and operational reliability.
  • Package and deploy applications using Docker and Kubernetes.
  • Collaborate with product owners and HR stakeholders to translate business needs into sustainable technical solutions.

What you'll bring

  • Several years of professional experience designing, developing and delivering production web applications in a .NET environment.
  • Experience working across the software development lifecycle, from requirements analysis and technical design to implementation, testing, deployment, and production support.
  • Experience developing backend services and modern web interfaces using technologies such as C#, REST APIs, Angular, and Microsoft SQL Server.
  • Experience applying software design principles, coding standards, code reviews, and automated testing practices.

Technical Knowledge

  • Excellent knowledge of C#, REST APIs, ASP.NET MVC, ADO.NET.
  • Experience developing responsive web interfaces using HTML, CSS, JavaScript or TypeScript, and Angular.
  • Strong knowledge of Microsoft SQL Server, including relational data modelling, query development, and performance optimization.
  • Good understanding of object-oriented programming, software design principles, and distributed application concepts.
  • Awareness of current trends in business and web technologies.
  • Hands-on experience packaging and deploying applications using Docker and Kubernetes.

Soft Skills

  • Ability to adapt communication and approach to different audiences.
  • Autonomous, resourceful, and committed to excellence.
  • Comfortable driving change and implementing new ideas.
  • Creative, curious, and innovative; able to propose improvements and alternative solutions.
  • Strong interpersonal and communication skills.
  • Flexible and quick to adapt to new concepts or changes.
  • Persuasive, motivating, and supportive in guiding team members.
  • Able to prioritize effectively and deliver reliable results within agreed timelines.
  • Proficient in English, both written and spoken.
