About the job

This is a fully remote job, open to people in United States.

Role Summary

We’re looking for a Software Engineer II to join Temporal’s Cloud Enablement team and help build and improve the Temporal Proxy. This role will focus on implementing core proxy capabilities and helping consolidate multiple proxy implementations into a single, extensible, open-source, and productized solution used by both customers and Temporal Cloud infrastructure.

Check out our code here!

What You'll Do

  • Implement features in a proxy codebase, contributing production-quality code (primarily in Go or a comparable systems language).
  • Build and improve core components such as request handling, configuration, authentication/authorization integrations, and encryption-related hooks (as defined by the team’s design).
  • Add and maintain observability (logs, metrics, traces) and contribute to debugging issues in staging/production environments.
  • Write and maintain tests (unit/integration) to improve correctness, prevent regressions, and support safe iteration.
  • Collaborate with engineers across CGS, Security, Infra Foundations, and OSS Server to deliver scoped projects and land changes safely.
  • Contribute to developer experience through clear documentation, examples, and small improvements that make the proxy easier to adopt and operate.

What You'll Bring

  • Proficiency in Go (preferred) or another systems language, with the ability to ramp quickly into an existing codebase.
  • Working knowledge of service-to-service communication and distributed systems basics (e.g., HTTP/gRPC, reliability fundamentals).
  • Familiarity with security fundamentals such as mTLS, JWT, and OIDC/OAuth concepts, and willingness to learn deeper patterns as needed.
  • Ability to take a scoped problem, implement a solution end-to-end (including testing and documentation), and communicate progress clearly.
  • A collaborative mindset and comfort working with teammates across functions to deliver shared outcomes.

Nice to Have

  • 3+ years of experience with proxy/gateway systems, cloud networking, service mesh concepts, or security-oriented infrastructure.
  • Experience with observability tooling and operational practices (on-call debugging, incident follow-ups, performance testing).
  • Contributions to open source (code or documentation).
  • Familiarity with Temporal concepts (or strong interest in learning the platform).
