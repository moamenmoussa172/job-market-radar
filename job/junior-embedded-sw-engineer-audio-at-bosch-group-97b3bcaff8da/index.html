About the job

We're looking for a detail-oriented and analytical Junior Embedded Software Engineer specializing in Audio to join our team in Guadalajara, Mexico. In this role, you will develop and optimize embedded Linux software solutions for audio systems, working collaboratively with cross-functional teams to deliver high-quality, efficient code. You will have the opportunity to deepen your expertise in audio processing while contributing to innovative embedded systems projects.

  • Design, develop, and maintain embedded Linux software for audio applications using C/C++
  • Debug and troubleshoot audio firmware issues using industry-standard debugging tools and techniques
  • Implement and optimize audio processing algorithms for real-time performance
  • Collaborate with software architects to integrate software with audio components
  • Write clean, well-documented, and efficient code following established coding standards
  • Participate in code reviews and contribute to continuous improvement of development practices
  • Test audio functionality across various platforms and configurations
  • Work with audio protocols and communication standards (such as A2B, I2C, SPI, UART, CAN and other relevant interfaces)
  • Support the full software development lifecycle from design through deployment and maintenance

**Required Qualifications:**

  • Bachelor’s degree in Computer Science, Electronics & Communication Engineering, or equivalent.
  • Strong C/C++ programming languages, Object Oriented Programming concepts.
  • Hands-on experience with embedded systems development and microcontroller programming
  • Solid understanding of audio processing fundamentals and signal processing concepts
  • Experience with debugging tools and techniques for embedded systems
  • Familiarity with version control systems (Git or similar)
  • Strong analytical and problem-solving skills with attention to detail
  • Ability to work effectively in a team environment and communicate technical concepts clearly
  • Professional English proficiency (verbal and written)

**Preferred Qualifications:**

  • 1-3 years of professional experience in embedded software development
  • Experience with real-time operating systems (RTOS)
  • QNX platform
  • Familiarity with hardware debugging tools such as oscilloscopes and logic analyzers
  • Experience with DSP (Digital Signal Processing) or audio-specific microcontrollers
  • Background in Agile development methodologies
  • Previous projects involving audio systems or signal processing applications
  • CAN protocol proficiency
