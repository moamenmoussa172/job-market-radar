Summary & Role Information:

Join SAP Cloud Infrastructure and help shape the security foundation of the next generation of cloud services and platform capabilities powering SAP's sovereign and regulated cloud environments.

As a Product Security Expert in our Security Engineering team, you will define and document the security architecture that underpins SAP Cloud Infrastructure's expansion into new regions with distinct regulatory requirements. You will create externally publishable security reference architectures and security function descriptions that satisfy public authorities such as the BSI and external auditors — while simultaneously designing and implementing the security architecture of our OpenStack- and Kubernetes-based cloud platform. This is not a documentation-only role. We are looking for someone who combines the ability to articulate complex security architectures clearly with the hands-on skill to design and build them.

What You'll Do:

  • Author and maintain security reference architectures, security function and capability descriptions for SAP Cloud Infrastructure that meet the standards expected by public authorities (e.g. BSI) and external auditors.
  • Design security architectures for new and existing cloud services running on OpenStack and Kubernetes. Translate regulatory and customer requirements into concrete, implementable security controls.
  • Contribute to the implementation of security controls and services in Go and Python within SAP Cloud Infrastructure's technology stack.
  • Serve as a technical subject-matter expert during external regulatory assessments and customer audits. Ensure documentation and architecture stay aligned with evolving requirements as SAP Cloud Infrastructure expands into new regions (France, Netherlands, and beyond).
  • Shape architecture and long-term technical direction for security across multiple components, services, and strategic engineering areas.
  • Act as a technical sparring partner for engineers, architects, product stakeholders, and engineering leadership on security architecture topics.
  • Collaborate across teams to embed security architecture decisions into the platform lifecycle.
  • Mentor engineers through technical guidance, code reviews, and knowledge sharing.

What You Bring:

### Technical Foundation

  • Extensive hands-on experience designing and operating security architectures for IaaS cloud environments
  • Profound knowledge about OpenStack, Kubernetes and related tools.
  • Demonstrated ability to produce high-quality, externally publishable security architecture documentation (reference architectures, control frameworks, capability descriptions).
  • Strong programming skills in Go and/or Python, with the ability and motivation to remain hands-on.
  • Strong understanding of cloud security domains: identity and access management, network security, encryption, logging and monitoring, vulnerability management.
  • Familiarity with regulatory and audit frameworks relevant to cloud infrastructure (e.g. ISO 27001, SOC 2, C5, BSI IT-Grundschutz).
  • Experience with European regulatory environments, preferrably France (ANSSI), Germany, Netherlands, etc.
  • Ability to communicate complex technical topics clearly to both technical and non-technical audiences, including regulators, auditors, and customers.
  • Experience working in agile, collaborative environments with distributed international teams.

We don't expect you to have experience with every technology listed. If you have a strong foundation in several of these areas and are interested in learning the others, we'd be happy to hear from you.
