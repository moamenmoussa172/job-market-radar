About the Role:

We’re looking for a Senior Product Security Engineer to help Hex ship secure products at the pace we’re building. You’ll partner closely with product and engineering teams to expand security coverage through threat modeling, security design reviews, code reviews, and vulnerability remediation. You’ll also build the tools and reusable protections that make secure development easier across the company.

AI will be a core part of how you do this work. You’ll use coding assistants, agents, and automated workflows throughout the software development lifecycle to understand changes, uncover vulnerabilities, test assumptions, and accelerate fixes. You’ll bring strong security judgment to those workflows: knowing how to validate results, where automation is useful, and when deeper investigation is needed.

This is a hands-on engineering role with impact across teams. Success means broader security coverage, high quality threat modeling, shorter review cycles, and fewer recurring vulnerabilities as Hex grows.

Key Responsibilities:

  • Partner early on product design. Lead threat modeling and security design reviews for new features and architectural changes. Use AI to help map data flows, surface abuse cases, and explore attack paths, then validate those findings against the actual system.
  • Expand code review coverage. Combine hands-on review with AI-assisted analysis to identify vulnerabilities across application code, APIs, and integrations. Build workflows that highlight security-sensitive changes and give developers timely, actionable feedback.
  • Build security into everyday development. Integrate useful checks into coding environments, pull requests, and CI/CD. Give developers and coding agents reusable security guidance, examples, and tests that help them get implementations right the first time.
  • Drive vulnerabilities through resolution. Reproduce findings, assess exploitability and customer impact, and work with engineers to deliver and verify fixes. Use AI to accelerate investigation, propose patches, and generate regression tests while maintaining clear ownership of the final result.
  • Turn recurring problems into reusable protections. Build secure defaults, shared libraries, and automated checks that prevent entire classes of vulnerabilities. Focus on areas such as authorization, tenant isolation, secrets handling, and safe processing of untrusted input.
  • Reduce review bottlenecks. Establish clear criteria for which changes need deeper security involvement. Create self-service workflows for routine questions and common patterns so teams can move quickly while higher-risk work gets focused attention.
  • Help secure AI-powered product capabilities. Partner with engineers on risks involving prompt injection, sensitive data exposure, agent permissions, tool execution, and access to customer data. Translate those risks into concrete controls and repeatable security tests.
  • Make AI-assisted security reliable. Evaluate workflows against known vulnerabilities and realistic code changes. Measure missed issues, false positives, and developer usefulness; establish appropriate access, data handling, and validation for security agents and tools.
  • Own improvements from discovery through adoption. Prioritize the most consequential gaps, ship practical solutions, and help teams use them. Track review turnaround, security coverage, remediation time, and recurring findings to understand whether the work is improving outcomes.

What we’re looking for

  • Significant experience in product or application security, typically 5+ years, or equivalent experience delivering security improvements in production software.
  • Strong application security fundamentals, including authentication, authorization, tenant isolation, injection vulnerabilities, and web and API security. You can trace an issue from an architectural decision to an exploitable implementation.
  • Hands-on software engineering ability. You’re comfortable reading unfamiliar code, writing tools and tests, and contributing production fixes. Experience with TypeScript, JavaScript, or Python is especially useful.
  • Practical experience using AI coding tools or agents in engineering or security work. You can explain workflows you’ve built, how you verified their results, and where they failed.
  • Experience integrating security into developer workflows and delivery pipelines, with attention to finding quality, developer effort, and adoption.
  • Sound prioritization in a fast-moving environment. You can distinguish urgent vulnerabilities from lower-risk issues, explain tradeoffs, and carry work through to resolution.
  • Clear communication and a collaborative approach. You build trust with engineers, make recommendations concrete, and help others develop their security judgment.

Nice to have

  • Experience securing LLM applications, agent workflows, or systems that execute user-provided code.
  • Experience with multi-tenant SaaS, data platforms, developer tools, or complex authorization models.
  • Experience building security analysis tooling, evaluating AI-assisted vulnerability discovery, or turning penetration test and vulnerability disclosure findings into lasting engineering improvements.
