What you’ll build

As part of the SAP LinuxLab, you will help advance Linux as a key platform for SAP solutions. Your work ensures that SAP products run reliable and efficiently across physical hardware, virtualized environments, and leading cloud providers.

In this role, you will:

  • Test and certify physical hardware, virtual machines, Linux distributions, Linux software, cloud providers and cloud products.
  • Install and validate Linux and SAP products on both physical servers and cloud environments.
  • Collaborate with Linux partners and internal SAP teams to evaluate new developments and test upcoming technologies.
  • Support the continuous improvement of SAP on Linux by contributing ideas, identifying optimization opportunities, and validating new approaches.
  • Work with modern cloud focused technologies as SAP continues its cloud transformation.
  • Provide Linux development support for customers and SAP cloud operation teams

What you bring

You are a collaborative team player with a strong enthusiasm for Linux as an operating system, and you bring:

  • A master’s degree in computer science or natural science (or equivalent technical experience)
  • Knowledge or hands-on skills in one or more of the following areas:
  • Linux distributions, applications and tools
  • Linux administration and shell scripts
  • Development skills in C/C++, Python, ABAP, Rust, Go or similar languages are beneficial
  • Processor architectures like x86-64, aarch64, ppc64 and others
  • CI/CD pipeline design and implementation (GitHub Actions, Jenkins)
  • Container expertise (Docker image creation, multi-stage builds, registry management)
  • Kubernetes deployment and orchestration (manifests, Helm charts, operators)
  • Experience in Linux Kernel Virtual Machine or other hypervisor technologies
  • Linux security tools (e.g. SELinux)
  • SAP applications and SAP system administration
  • Fluent German and English

Where you belong

At the SAP LinuxLab, you will join a highly skilled engineering team dedicated to ensuring SAP runs best on Linux across environments. We value collaboration, curiosity, hands on experimentation, and a passion for open source technologies.
You will thrive here if you enjoy technically deep work, diverse testing scenarios, and partnering with internal and external Linux experts in a fast evolving cloud and platform landscape.
