About the job

  • Install, configure and maintain infrastructure components in a virtualized Linux Environment
  • Fully manage the installation, configuration and troubleshooting of all aspects of Linux servers
  • Architect, install, configure and optimize computing systems and networks in a Linux based environment
  • Administer, troubleshoot, and resolve failures and critical alerts on Linux and Windows servers

Requirements

  • Bachelor's degree in Engineering or Computer Science
  • 5+ years of hands-on experience with Linux Red Hat and Unix Administration
  • Proficient in written and spoken English
  • Strong analytical, troubleshooting, and communication skills
  • Linux Red Hat Certification preferred
  • Experience in Red Hat Enterprise Linux System Administration including installation, software configuration, and network setup
  • Patch management, system backup and restore, performance tuning
  • Familiarity with Linux scripting languages and storage (LVM, Snapshot, ISCSI)
  • Experience with Linux security (Firewalld, SELinux) and virtualization (VMware, Hyper-V)
  • Experience with Red Hat Satellite and preferably Red Hat OpenShift
  • Basic knowledge of network technologies and protocols
