About the job

This is a fully remote job, open to people in Canada, United States.

The Platform team creates the technology that enables Spotify to learn quickly and scale easily, enabling rapid growth in our users and our business around the globe. Spanning many disciplines, we work to make the business work; creating the infrastructure, tooling, frameworks, and capabilities needed to welcome a billion customers.

Security engineers at Spotify help protect our environment and more than 700 million users. Within Platform, our Product Security team evaluates and communicates Spotify's security posture, helping developers and leadership make informed decisions about security risks. We own the vulnerability management platform, supporting the full lifecycle of identifying, attributing, remediating, and reporting security vulnerabilities.

As AI changes how vulnerabilities are discovered and exploited, we're evolving how Spotify responds. We're looking for a Security Engineer to help transform vulnerability findings into reliable, actionable code improvements using agentic AI. You'll build the tools, workflows, and evaluation frameworks that make automated remediation more effective, scalable, and safe, while helping developers focus on building great experiences for our users.

What You'll Do

  • Build and improve agentic AI workflows that turn security vulnerability findings into tested, review-ready code changes for engineering teams across Spotify.
  • Design and implement evaluation frameworks to measure the quality of automated fixes, including correctness, completeness, safety, build and test success, and pull request merge rates.
  • Develop tools and processes to compare remediation approaches, evaluate AI models, and continuously improve the reliability and effectiveness of generated fixes.
  • Research and apply emerging practices in AI-assisted vulnerability remediation, including prompt engineering, context engineering, and vulnerability-specific fix guidance.
  • Identify which vulnerability types are suitable for automated remediation, balancing security impact, technical feasibility, and developer experience.
  • Collaborate with developers and security stakeholders to collect feedback through code reviews, pull requests, support channels, and interactive sessions, using these insights to improve remediation quality.
  • Help shape how Spotify approaches security posture management by building scalable solutions that reduce security risks and make it easier for teams to address vulnerabilities.
  • Who You Are
  • You have experience in software engineering, particularly within security engineering, developer experience, or internal infrastructure.
  • You can confidently read, understand, and write code in one or more languages such as Java, Python, Scala, C++, or TypeScript.
  • You have experience designing and building scalable systems, with an understanding of software architecture and reliable engineering practices.
  • You have worked with agentic AI systems or AI-assisted development workflows and understand how to apply them to real-world engineering challenges.
  • You understand common security risks, attack vectors, and vulnerabilities, including those affecting AI and machine learning systems, and approaches to mitigating them.
  • You have experience integrating security tools or automated workflows into production engineering environments.
  • You are familiar with agentic AI frameworks and approaches to evaluating the quality, reliability, and safety of AI-generated outputs.
  • You enjoy collaborating across teams, learning from feedback, and navigating ambiguity. You're comfortable experimenting with new approaches while balancing innovation with thoughtful security decisions.
  • Where You'll Be
  • This role is based in Toronto
  • We offer you the flexibility to work where you work best! There will be some in person meetings, but still allows for flexibility to work from home.
