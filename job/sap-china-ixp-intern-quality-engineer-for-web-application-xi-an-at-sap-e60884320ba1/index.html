About the job

We help the world run better
At SAP, we keep it simple: you bring your best to us, and we'll bring out the best in you. We're builders touching over 20 industries and 80% of global commerce, and we need your unique talents to help shape what's next. The work is challenging – but it matters. You'll find a place where you can be yourself, prioritize your wellbeing, and truly belong. What's in it for you? Constant learning, skill growth, great benefits, and a team that wants you to grow and succeed.

What you’ll build:

We are looking for software Quality Engineers with strong programming skills and a passion for creating great user experience. Successful applicants will have a strong ability to learn, combined with the tenacity to solve problems independently and a strong focus on the details required to create first rate software.

In this position, you will:

  • Focus on Software quality, performance and scalability
  • Develop your skills in testing of browser-based user interfaces in JavaScript and/or writing server-side logic in JavaScript and Java
  • Develop your skills in utilizing AI/LLM to improve coding & testing efficiency
  • Build a strong foundation in relational database concepts
  • Contribute innovative new ideas to shape the test methodology and products.
  • Collaborate with developers, product managers, UX designers, and user assistance developers
  • Work with a group of committed, driven and talented software developers and architects who are passionate about that they do

What you bring:

  • Graduate or college student in computer science, software engineering, computer engineering, or a related discipline
  • Experience in UI development using JavaScript
  • Experience in databases
  • Experience developing on Windows, Mac, and/or Linux
  • Strong problem solving and communication skills
  • Mindset with AI/LLM. Experience in AI/LLM is a plus
  • Experience with Java, Node.js, JavaScript, jQuery, CSS, XML, HTML5, and/or full-stack development is a plus
  • Significant hobby programming experience (including personal projects, hackathons and programming contests) would be appealing
  • Strong academic performance (for recent graduates) is preferred
  • Proficiency in English language; daily communication will be done in English

Where you belong:

SAP HANA is our revolutionary in-memory columnar database technology that allows data to be analyzed faster than ever before. It opens a world of possibilities by letting people develop valuable insight and answer important questions using big data.

Come join the SAP HANA tooling team and help us create world-class, web-based tools that our customers use to create, deploy and monitor their own groundbreaking applications using SAP HANA. We strive to expose powerful database features in an intuitive way so that customers can achieve their own goals quickly, efficiently and easily.

Our passion is creating a world class user experience. Our strength comes from both the energy and creativity of our young developers and from the skill and knowledge of our more experienced colleagues. We organize ourselves using Agile principles and use state of the art development tools including JavaScript, Node.js, jQuery and SAP UI5.
