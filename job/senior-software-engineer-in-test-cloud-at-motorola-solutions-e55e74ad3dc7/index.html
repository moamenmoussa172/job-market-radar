Job Description

We are looking for a Senior Software Engineer with System Test & Automation specialization to become the quality champion and test automation owner for our cloud platform team. This is a unique hybrid role that combines deep test automation expertise with hands-on software development.

You will own end-to-end system testing for our multi-tenant SaaS cloud application and its integration with on-premise hardware components. You'll work closely with our R&D Integration Automation team, adopting and extending their Python/Pytest-based e2e framework while contributing to our Krakow team's Node.js/TypeScript production codebase.

This is a senior individual contributor developer role with automation specialization, not a pure QA position.

What You Will Do

  • System Test & E2E Automation (60-70% of time)
  • Own system testing strategy for multi-tenant cloud-native SaaS application
  • Adopt and extend the Python/Pytest-based e2e automation framework
  • Build comprehensive test coverage across box, integration and system levels
  • Develop automation for cloud & on-premise hardware integration scenarios
  • Implement API testing (REST/GraphQL) and UI automation (Selenium preferred)
  • Drive CI/CD integration - embed automated tests into Jenkins pipelines with Docker/Kubernetes as well as automation of provisioning isolated test environments and test data management
  • Analyze and troubleshoot test failures, identify root causes, bottlenecks/latency of the system, and collaborate with developers on fixes
  • Champion quality practices - establish testing standards, code review guidelines, and best practices
  • Collaborate on framework alignment and knowledge sharing
  • Software Development (30-40% of time)
  • Contribute to production code in Node.js/TypeScript/NestJS backend services and build custom tooling/scripts for software verification.
  • Build test infrastructure and tooling using TypeScript where appropriate
  • Enhance testability - work with developers to improve code architecture for better test coverage
  • Contribute to the system design to ensure that the architecture of solution is actually testable
  • Participate in code reviews from both development and quality perspectives


Basic Requirements

  • Cross-Language Engineering Experience
  • 5+ years of software engineering experience with strong focus on test automation
  • Python proficiency - solid OOP skills, comfortable with Pytest framework and test automation libraries
  • Node.js/TypeScript experience - can read, understand, contribute to, and review production code in our stack
  • Comfortable switching between languages and choosing the right tool for the job
  • Test Automation Expertise
  • Proven track record building system/integration/e2e test frameworks for distributed systems
  • Hands-on experience with API testing (REST/GraphQL) using tools like Postman, Pytest, or similar
  • Practical experience with UI automation tools (Selenium or Playwright)
  • Strong understanding of test design patterns, page object models, and maintainable test architecture
  • Experience writing box tests, integration tests, and regression suites as part of agile workflows
  • Cloud & Infrastructure:
  • Experience testing cloud-native applications on major platforms (AWS, Azure, or GCP)
  • Working knowledge of Docker and Kubernetes for containerized test environments
  • CI/CD pipeline expertise (Jenkins, GitHub Actions, GitLab CI) - building and maintaining automated test runs
  • Understanding of distributed systems challenges and how to test them effectively
  • Collaboration - experience working in cross-functional teams (developers, QA, DevOps, cloud engineers)

Big Advantages (Bonus Points):

  • NestJS or Express framework experience
  • Testing multi-tenant SaaS architectures and tenant isolation
  • Zero Trust Architecture (ZTA) and mTLS testing
  • Infrastructure as Code (Terraform, Helm, Pulumi)
  • Observability stacks (Prometheus, Grafana, ELK, Datadog) for test monitoring
  • Experience with AI-assisted development tools (GitHub Copilot, Cursor, Claude)
