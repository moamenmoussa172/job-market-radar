About the job

Designs, builds, and maintains solutions on the ServiceNow enterprise platform across core modules (ITSM, ITOM, HAM, OTSM, Service Portal, and custom scoped applications). Turns business requirements into robust, upgrade-resilient solutions using platform best practices, working as an active member of an Agile squad under the guidance of the Lead Developer and Platform Architect.

Key Responsibilities

  • Platform Development: Configure and develop features across core modules (e.g. Incident, Problem, Change, Request, Knowledge, and custom scoped apps in ServiceNow Studio / App Engine Studio).
  • Workflows & Scripting: Build robust automations using Flow Designer, subflows, and actions. Write clean, maintainable server-side and client-side code (Business Rules, Script Includes, Client Scripts, UI Policies).
  • Service Catalog & Portal: Develop dynamic catalog items, record producers, and order guides with variable sets and fulfillment flows. Build and configure Service Portal and Employee Center widgets.
  • Integrations: Configure and support REST/SOAP integrations, IntegrationHub spokes, MID Server queries, and import sets with transform maps.
  • Quality & Agile Delivery: Participate actively in sprint refinement, estimation, and daily standups. Build automated test cases using Automated Test Framework (ATF), participate in peer code reviews, and support UAT bug resolution.
  • Platform Health: Support semi-annual platform family upgrades by reviewing skipped records and refactoring legacy code back to baseline out-of-the-box (OOTB) functionality.

Experience & Qualifications:

  • Experience: 3 to 5 years in software engineering, with at least 2 to 3 years of hands-on ServiceNow configuration and development experience.
  • Technical Skills: Strong JavaScript fundamentals; hands-on proficiency with Glide APIs, Flow Designer, NowAssist, Service Catalog, and REST integrations; solid grasp of the ServiceNow relational data model and ACL security rules.
  • Methodology: Practical experience working within Scrum/Agile environments (Jira / ServiceNow Agile).
  • Education: Bachelor’s degree in Computer Science, Information Technology, or equivalent practical experience.

Certifications:

  • Required: ServiceNow Certified System Administrator (CSA), Certified Application Developer (CAD).
  • Preferred: Certified Implementation Specialist in one of ServiceNow product (CIS - ITSM), ITIL 4 Foundation.
