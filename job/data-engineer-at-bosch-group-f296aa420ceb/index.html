About the job

Main objective of the job:

  • Design, develop, and maintain secure and scalable data pipelines on Azure Databricks as an intermediate data engineer, heavily leveraging Python, PySpark, and AI-assisted validation tools to automate code quality checks, compliance, and routine engineering tasks

Main attributions and responsibilities:

  • Design, develop, optimize, and maintain scalable data pipelines, primarily using Python and SQL on the Azure Databricks platform.
  • Pioneer and refine the integration of AI agents to automate code reviews, verify work quality, and ensure strict adherence to internal development processes.
  • Implement, test, and maintain robust data quality frameworks, validation tools, and pipeline monitoring systems.
  • Collaborate closely with the Data Governance team to support the implementation, adoption, and scaling of data quality concepts.
  • Support internal business stakeholders by debugging pipeline issues, optimizing query performance, and ensuring high data availability.
  • Champion professional software engineering standards, clean code practices, and the continuous improvement of automation within the team.
  • University degree in Computer Science, Business Informatics, Data Science or a comparable field.
  • Language: English
  • Proven intermediate-level professional experience in data engineering, building, and maintaining complex data pipelines.
  • Mandatory, hands-on production experience utilizing Azure Databricks and writing distributed data processing tasks with PySpark.
  • High proficiency in Python and SQL with a strong foundation in clean code principles, software development best practices, and systematic debugging.
  • Strong hands-on capability to utilize AI agents or LLMs to verify code quality, check compliance, and automate routine administrative or review tasks.
  • Familiarity with modern DevOps practices, including Git workflows and Azure CI/CD pipelines to accelerate automation tasks.
  • Exceptional attention to detail with a proactive, self-starting mindset focused on data reliability, quality assurance, and workflow automation.
