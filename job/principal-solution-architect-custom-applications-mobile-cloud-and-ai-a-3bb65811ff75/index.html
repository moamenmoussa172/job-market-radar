About the job

Roles & Responsibilities :
Principal Solution Architect – Custom Applications, Mobile, Cloud & AI

Role Purpose

We are looking for an experienced Principal Solution Architect – Custom Applications, Mobile, Cloud & AI to drive solutioning, customer engagement and business growth for our Custom Applications practice.

The practice delivers non-ERP digital solutions across:

  • Java and Microsoft technology stacks
  • Web and portal applications
  • Native and cross-platform mobile applications
  • Cloud-native application development
  • Application modernization and migration
  • Enterprise integrations and APIs
  • Data and AI-enabled applications
  • DevSecOps and modern engineering

The architect will work at the intersection of customer consulting, technology strategy, solution architecture, AI-led innovation, pre-sales and business growth.

The individual will engage customers to understand business problems and upcoming opportunities, conceptualize innovative solutions, select appropriate technologies, define architectures and delivery approaches, develop proposals and estimates, and help convert opportunities into successful engagements.

Key Responsibilities

1. Customer Engagement & Opportunity Shaping

  • Engage with customer business, digital, IT and technology leadership teams to understand their business objectives, application landscape, pain points and transformation priorities.
  • Conduct discovery and solution workshops with customers.
  • Identify and shape opportunities across:
  • Custom application development
  • Digital platforms and portals
  • Mobile application development
  • Application modernization
  • Legacy transformation
  • Cloud migration
  • Cloud-native development
  • Enterprise integration and API modernization
  • AI/GenAI-enabled applications
  • Intelligent automation
  • Translate high-level or partially defined customer requirements into structured technology solutions.
  • Build multi-phase transformation roadmaps that can convert an initial engagement into a larger strategic program.

2. Solution Architecture

Own and drive end-to-end architecture for proposed solutions across business, application, integration, data, cloud, security, AI and mobile layers.

Java / Open-Source Stack

Understanding of:

  • Java
  • Spring / Spring Boot
  • Microservices
  • REST APIs
  • Kafka
  • Kubernetes
  • API gateways
  • React
  • Angular
  • SQL and NoSQL technologies

3. Mobile Application Architecture

Mobile application development should be a significant competency for this role.

The architect will be expected to shape solutions for enterprise, B2B, B2C, employee-facing and customer-facing mobile applications.

Native Mobile Technologies

Experience or strong architectural understanding of:

Android

  • Android SDK
  • Kotlin
  • Java
  • Jetpack / Jetpack Compose
  • Android application architecture
  • Google Play deployment

iOS

  • Swift
  • SwiftUI
  • UIKit
  • iOS application architecture
  • Apple App Store deployment

Cross-Platform Development

Strong understanding of one or more of:

  • Flutter / Dart
  • React Native
  • .NET MAUI
  • Progressive Web Apps where appropriate

The architect must be capable of determining when to select native Android/iOS versus cross-platform development based on UX, performance, device capabilities, development effort, maintainability and time-to-market.

Mobile Architecture Considerations

Ability to design mobile applications covering:

  • Mobile UI/UX architecture
  • Responsive and adaptive design
  • Mobile Backend-for-Frontend patterns
  • API and microservices integration
  • Offline data synchronization
  • Local data storage and caching
  • Push notifications
  • Deep linking
  • Authentication and Single Sign-On
  • OAuth 2.0 / OpenID Connect
  • Biometrics
  • Device capabilities such as camera, GPS and NFC
  • Application telemetry and analytics
  • Crash/error monitoring
  • Mobile application performance
  • Data encryption
  • Secure local storage
  • Certificate management
  • Mobile application security
  • Application versioning and release management
  • Apple App Store and Google Play Store deployment
  • Enterprise mobile application distribution
  • CI/CD for mobile applications

The architect should also understand how mobile applications securely connect to enterprise APIs, cloud services, identity platforms, SaaS systems and legacy backend applications.

4. AI-Led Solutioning

The individual must bring an AI-first mindset when evaluating new customer opportunities.

Responsibilities include:

  • Identify practical opportunities to embed AI and GenAI into existing and new applications.
  • Develop AI-assisted customer and employee experiences.
  • Architect conversational applications, intelligent assistants and copilots.
  • Identify opportunities for:
  • Generative AI
  • RAG architectures
  • Enterprise knowledge assistants
  • AI agents and agentic workflows
  • Intelligent search
  • Document intelligence
  • Summarization
  • Natural-language interfaces
  • AI-enabled mobile experiences
  • AI-assisted business processes
  • Evaluate appropriate LLM/models and AI platforms.
  • Understand responsible AI, security, governance, privacy, grounding, hallucination mitigation and observability.
  • Apply AI-assisted engineering across the SDLC using tools such as GitHub Copilot and other AI engineering platforms.

5. Cloud & Application Modernization

Lead solutioning for:

  • Cloud-native application development
  • Application migration
  • Rehosting
  • Replatforming
  • Refactoring
  • Legacy modernization
  • Containerization
  • Microservices transformation
  • Serverless architecture
  • Kubernetes
  • API modernization
  • DevSecOps
  • Hybrid-cloud architecture
  • SaaS integration

Strong knowledge of Microsoft Azure is preferred, with working knowledge of AWS and/or Google Cloud advantageous.

The architect should be able to assess an existing application portfolio and determine an appropriate modernization strategy instead of defaulting to complete redevelopment.

6. Integration Architecture

Define integration solutions across:

  • REST APIs
  • API Management
  • Microservices
  • Event-driven architectures
  • Kafka/event streaming
  • Messaging/queues
  • Integration platforms
  • Webhooks
  • Identity services
  • SaaS integrations
  • Legacy applications
  • Mobile/backend integration
  • Cloud-to-cloud and hybrid integrations

Although the practice focuses on non-ERP applications, solutions will frequently need to interface with enterprise platforms such as SAP, Microsoft Dynamics 365, Salesforce, ServiceNow and other core systems.

7. Pre-Sales, Proposals & Solution Development

The architect will play a central role in converting customer opportunities into business.

Responsibilities include:

  • Participate in RFI/RFP/RFQ responses.
  • Conduct discovery sessions.
  • Develop solution concepts.
  • Create architecture diagrams.
  • Define technology stacks.
  • Develop solution options and recommendations.
  • Define MVP and subsequent phases.
  • Estimate project effort.
  • Determine team composition and skill requirements.
  • Develop implementation roadmaps.
  • Identify technology and delivery risks.
  • Define assumptions and dependencies.
  • Contribute to commercial solutioning.
  • Support Proofs of Concept and prototypes.
  • Prepare and deliver customer presentations.
  • Participate in solution defense and technical evaluation sessions.
  • Work with sales and account leadership through opportunity closure.

The architect must be comfortable taking a requirement that is only partially defined and translating it into a credible, commercially viable and executable solution.

8. Estimation & Delivery Planning

Translate solution architecture into an executable delivery model covering:

  • Work breakdown
  • Technology selection
  • Effort estimation
  • Resource planning
  • Skill mix
  • Delivery methodology
  • MVP definition
  • Release planning
  • Agile delivery
  • Dependencies
  • Risks
  • Cloud costs
  • Build versus buy decisions
  • Migration strategy

A key differentiator of this role is a clear responsibility for business growth.
