About this Role

We are seeking a skilled and motivated Software Engineer to join our microservices integration team within VOIS India. This role focuses on designing and building scalable, cloud-based integration solutions using modern microservices architecture. The successful candidate will work within a Scrum squad in a SAFe environment to deliver robust, high-quality APIs and services, contributing to the transformation of Vodafone’s integration layer and enhancing seamless data flow across systems.

What you will do

  • Develop and maintain microservices within a Scrum/Kanban squad operating in a SAFe framework
  • Design and build solutions using TIBCO technologies (EMS, BW, Admin)
  • Develop and enhance RESTful APIs within a microservices architecture
  • Ensure quality, reliability, and performance of owned services using best practices
  • Participate in sprint planning, backlog refinement, and delivery of user stories
  • Apply continuous improvement through learning, collaboration, and feedback
  • Maintain high standards of code quality, testing (including JUnit), and defect resolution
  • Support integration across systems using event-driven architecture and messaging tools such as Kafka and RabbitMQ

Who you are

  • Experienced in developing applications using TIBCO (EMS, BW, Admin)
  • Strong knowledge of REST APIs and microservices architecture
  • Proficient in Java and frameworks such as Spring Boot
  • Understanding of SOA principles, object-oriented programming, and collections
  • Experience with data streaming and storage technologies such as Kafka and MongoDB
  • Familiarity with DevOps tools and practices including Maven, Git, Jenkins, and branching strategies
  • Exposure to containerisation using Docker and orchestration tools such as Kubernetes
  • Knowledge of event-driven architecture, Apache Camel, routers and processors
  • Experience with performance tuning, caching, and monitoring tools such as Splunk, Prometheus, Grafana, or AppDynamics
  • Strong problem-solving mindset with a passion for learning and improving
  • Ability to collaborate effectively and contribute to team success
