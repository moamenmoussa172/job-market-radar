Senior Software Engineer - Developer Tools

CODEFUSION STUDIO

Analog Devices (NASDAQ: ADI) designs and manufactures semiconductor products and solutions. We enable our customers to interpret the world around them by intelligently bridging the physical and digital worlds with unmatched technologies that sense, measure, and connect.

About the Role

The CodeFusion Studio Development team within ADI’s Software and Security Group is expanding, and we are looking for a Software Engineer to join our Developer Tools team.

In this role, you will build and design production quality tools such as the Package Manager, Backend Configuration Tools and supporting infrastructure behind CodeFusion Studio (CFS), ADI’s next-generation embedded development environment used by developers worldwide. This is an excellent opportunity for an engineer who is interested in developer tooling, automation, CI/CD, and software infrastructure, and who wants to grow under the mentorship of experienced engineers.

Responsibilities

· Design, implement, test, and maintain backend services and developer tools for CodeFusion Studio Package Manager and Configuration Tools.

· Develop backend capabilities for configuration workflows, including data models, schemas, validation, dependency and constraint resolution, and generation of project artifacts.

· Define practical packaging conventions and reusable workflows for SDKs, middleware, examples, device support, and other embedded software modules.

· Build clear APIs and command-line interfaces that integrate package and configuration capabilities with CodeFusion Studio and related engineering systems.

· Improve automated build, test, release, and delivery pipelines across Windows, Linux, and macOS, with attention to reliability, traceability, and software supply chain security.

· Diagnose complex integration and production issues, improve observability and failure handling, and reduce recurring maintenance work through automation.

· Collaborate with product managers, UX designers, embedded software teams, and other engineers; contribute to technical design reviews, code reviews, planning, and mentoring.

Required Qualifications

• Several years of professional software development experience.

• Strong programming skills in Python, TypeScript and Node.js, C or C++, or comparable languages.

• Experience with package managers, build systems, release engineering, artifact repositories, or software distribution workflows.

• Proficiency with Git, collaborative development workflows, automated testing, and CI/CD systems such as GitHub Actions, Jenkins, or similar platforms.

• Ability to make sound technical tradeoffs, break down ambiguous problems, communicate designs clearly, and deliver work across team boundaries.

• Degree on Software Engineering, Electronic Engineering, or equivalent practical experience.

Preferred Qualifications

• Knowledge of embedded development workflows, SDKs, middleware, compilers, debuggers, or target-specific build systems.

• Familiarity with containers, package signing and software supply chain security practices.

• Familiarity with Microsoft Visual Studio Code, command-line developer experiences, and open-source development practices.

• Experience supporting multi-platform build and release environments across Windows, Linux, and macOS.

Why Join the Team

• Build core capabilities used to deliver and configure software across the CodeFusion Studio ecosystem.

• Work on technically varied problems spanning backend services, developer tools, automation, and embedded software workflows.

• Take meaningful ownership while collaborating with an experienced, globally distributed engineering team.

• Help establish reliable and secure practices for packaging and distributing software modules at scale.
