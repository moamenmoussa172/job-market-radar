Job Summary:

We are seeking an experienced Database Administrator (DBA) with strong expertise in Microsoft SQL Server
environments. The candidate will be responsible for administering, maintaining, securing, and optimizing SQL Server
databases while ensuring high availability, performance, backup reliability, and operational continuity across enterprise systems.

Key Responsibilities:

  • Administer, monitor, and maintain Microsoft SQL Server databases in production and non-production environments.
  • Perform database installation, configuration, patching, upgrades, and migrations.
  • Monitor database performance, availability, storage utilization, and system health.
  • Implement database backup, recovery, disaster recovery, and high availability solutions.
  • Perform database performance tuning, query optimization, and indexing improvements.
  • Troubleshoot and resolve database-related incidents, failures, and performance issues.
  • Manage SQL Server security, user access, roles, and permissions.
  • Configure and maintain SQL Server Always On, clustering, replication, and failover solutions.
  • Support database refresh, cloning, and environment synchronization activities.
  • Collaborate with application, infrastructure, and security teams to support business applications.
  • Ensure compliance with security policies, operational standards, and audit requirements.
  • Develop and maintain database documentation, SOPs, and operational reports.
  • Participate in change management, incident management, and on-call support activities.
  • Required Qualifications:
  • Bachelor’s degree in Computer Science, Information Technology, or related field.
  • 5+ years of experience in Microsoft SQL Server database administration.
  • Strong hands-on experience with SQL Server 2016/2019/2022 environments.
  • Experience with database backup, recovery, and disaster recovery planning.
  • Strong knowledge of SQL Server performance tuning and query optimization.
  • Experience with SQL Server Always On Availability Groups and clustering.
  • Good understanding of Windows Server environments.
  • Experience with monitoring and database management tools.
  • Strong analytical and troubleshooting skills.
  • Excellent communication and teamwork abilities.
  • Preferred Certifications:
  • Microsoft Certified: Azure Database Administrator Associate
  • Microsoft SQL Server Certifications
  • ITIL or related operational certifications are a plus
  • Technical Skills:
  • Microsoft SQL Server
  • SQL & T-SQL Scripting

  • Database Security Management
  • Clustering & Replication
  • Windows Server Administration
