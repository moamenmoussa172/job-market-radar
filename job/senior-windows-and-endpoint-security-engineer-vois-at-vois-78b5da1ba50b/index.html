About this Role

We are seeking an experienced Senior Windows & Endpoint Security Engineer to manage enterprise-scale Windows Server environments across on-premises and Microsoft Azure platforms. The role focuses on secure and highly available Windows workloads, Active Directory services, Microsoft Defender for Endpoint (MDE), security compliance and L3 technical support. The position is based in Pune and sits within Data Center Operations.

What you’ll do

  • Administer Windows Server 2016, 2019 and 2022 environments at enterprise scale, covering build, hardening, patching, upgrades, performance, capacity and decommissioning.
  • Act as an L3 escalation point for complex Windows Server incidents and technical problems.
  • Manage Microsoft Defender for Endpoint onboarding and server health, including antivirus policies, exclusions and agent lifecycle management.
  • Collaborate with SOC and Cyber Security teams and support security audits and compliance reporting.
  • Drive Windows security baselines, patch compliance, vulnerability remediation and security posture improvements.
  • Design, administer and optimise Active Directory Domain Services, including GPO structures, OU design, delegated administration, Domain Controllers, replication, FSMO roles and recovery scenarios.
  • Support Active Directory security hardening, logging and privileged access monitoring.
  • Administer Windows Server workloads hosted on Microsoft Azure IaaS, including virtual machines, availability sets/zones, scaling strategies, monitoring agents and security integrations. [
  • Support hybrid identity scenarios and on-premises-to-Azure migration and post-migration optimisation.
  • Troubleshoot Azure networking, VM health, extensions and performance issues, while using automation and operational standards to reduce recurring problems.

Who you are

You bring 6–8+ years of experience working with Windows Server and Active Directory environments.
You have advanced Windows Server administration expertise and practical knowledge of AD DS, GPO, DNS and DHCP.
You have strong hands-on experience with Microsoft Defender for Endpoint, particularly for Windows Servers.
You have proven experience administering Windows Servers on Microsoft Azure IaaS and working with hybrid Active Directory environments.
You can use PowerShell for scripting and automation.
You understand patch management, vulnerability remediation and virtualisation technologies such as Hyper-V and VMware.
You bring strong analytical, troubleshooting, technical communication and mentoring capabilities, with a security- and compliance-focused approach.
A bachelor’s degree in IT/Computer Science or equivalent experience is required. Microsoft certifications covering Windows, Azure or Security are preferred.

What's in it for you

This role provides the opportunity to work with enterprise-scale Windows infrastructure across both on-premises and Microsoft Azure environments, alongside SOC and Cyber Security teams. You will gain exposure to endpoint security, hybrid identity, vulnerability management, Azure migration and automation while contributing to the stability and security of business-critical infrastructure

What skills you will learn

The role provides opportunities to further develop expertise in:

  • Enterprise-scale Windows and hybrid cloud operations.
  • Microsoft Defender for Endpoint and endpoint security management.
  • Advanced Active Directory security and privileged-access monitoring.
  • Microsoft Azure IaaS architecture, availability and migration.
  • Security baseline implementation and vulnerability remediation.
  • PowerShell-based infrastructure automation.
  • L3 troubleshooting across Windows, Active Directory and Azure environments.
