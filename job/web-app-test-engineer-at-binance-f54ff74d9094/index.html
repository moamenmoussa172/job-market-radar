Role Overview

Responsible for end-to-end quality assurance across Web and App (mobile) surfaces — combining automated and exploratory testing to ensure product stability, compatibility, and interaction experience from the user's perspective. The core requirement is cross-platform testing capability (Web + App), with the ability to design and maintain an automated testing system and to think deeply about troubleshooting and user-experience-oriented quality.

In one sentence: This role is the quality gatekeeper for Web/App products — someone who can write automation scripts, test interaction experiences, investigate data issues, and use engineering methods to replace manual testing with systematic automated quality coverage. Not a manual tester — a QA engineer with real coding ability.

Key Responsibilities

  • Design and maintain comprehensive Web/App test cases and test plans covering functionality, compatibility, and interaction
  • Develop and maintain UI/API automated tests using Java, Python, or JavaScript to ensure high coverage and reliability
  • Combine automation and manual exploratory testing to validate user scenarios and discover potential experience issues
  • Perform root cause analysis on test failures and production issues, and drive fixes to closure
  • Identify blind spots in test coverage and continuously improve automation effectiveness
  • Participate in testing for new features — define expected behaviors, system impact, and risk points from a user-experience perspective
  • Conduct App compatibility testing across devices, OS versions, and screen sizes, as well as Web cross-browser and cross-resolution testing
  • Participate in performance testing (page load time, App cold start / warm start, etc.) and ensure stability under high-concurrency and weak-network scenarios
  • Requirements
  • Strong coding ability in at least one of Java, Python, or JavaScript (live coding assessment required)
  • Extensive Web/App automation testing experience with tools such as Selenium, Appium, Playwright, etc.
  • Solid understanding of Web/App testing methodologies and automation framework design
  • Proficiency in SQL for data validation and issue troubleshooting
  • Proven root cause analysis ability to solve complex quality problems
  • Familiarity with Web front-end technologies (HTML/CSS/JS) and mobile platform fundamentals (Android/iOS architecture and characteristics)
  • Experience building testing tools, platforms, or quality infrastructure
  • Ideal Candidate Profile Background:
  • 1–5 years of QA or test development experience, including at least 1 year of Web or App automation testing
  • Strong coding skills — able to write code from scratch, not just scripts
  • Proficient in SQL for independent data validation and troubleshooting
  • Hands-on mobile or Web testing experience
  • Core Competencies:
  • Automation capability: Can design and develop automation frameworks, not just use existing tools
  • Root cause analysis: Can trace test failures or production issues back to their root cause
  • SQL & data validation: Can write complex SQL to verify data consistency and troubleshoot data-related bugs
  • Cross-platform understanding: Understands Web/App architecture, including front-end/back-end interaction, network requests, cache mechanisms, and WebView
  • UX sensitivity: Can identify experience issues from the user's perspective, not just whether functionality works
  • Test tooling: Experience building test platforms, tools, or quality infrastructure
  • Collaboration drive: Can push developers to fix issues rather than passively waiting
  • Soft Skills:
  • Rigorous and detail-oriented
  • "Destructive thinking" mindset — adept at finding system weaknesses
  • Strong communication — bridges developers and product managers
  • Quality ownership mentality — treats quality as personal responsibility
  • Bonus Points
  • Payment, transaction, or financial system QA experience
  • AI tooling usage experience
  • Crypto / Web3 industry background
  • Hands-on App compatibility testing experience using cloud device platforms such as Testin or WeTest
  • Weak-network testing experience using tools such as Charles or Fiddler
