About the job

As a Cloud Solution Architect, you will be responsible for designing, implementing, and optimizing secure, scalable, and high-performing cloud solutions based on Microsoft Azure. You will work closely with business stakeholders and technical teams to define cloud architectures, support application modernization, and drive cloud migration and transformation initiatives.

Responsibilities

  • Design and implement end-to-end Azure cloud architectures for enterprise applications.
  • Define application hosting and modernization strategies using PaaS, containers, and serverless services.
  • Design secure, resilient, and scalable networking solutions across cloud and hybrid environments.
  • Lead cloud migration and transformation initiatives, ensuring governance, security, and compliance requirements are met.
  • Collaborate with stakeholders and technical teams to deliver scalable, high-performing cloud solutions.
  • Optimize cloud environments with regard to security, availability, performance, and cost efficiency.
  • Define and promote cloud architecture standards, best practices, and reusable solutions.

Education

  • University degree in Computer Science, Information Technology, Engineering, or a comparable field.
  • Relevant professional certifications in Microsoft Azure / Cloud Architecture are an advantage.

Experience

  • Several years of professional experience in Cloud Architecture, with a strong focus on Microsoft Azure.
  • Proven experience designing and implementing enterprise-scale cloud solutions.
  • Experience with application hosting, cloud-native architectures, and enterprise networking.
  • Experience in cloud migration, governance, security, monitoring, and cost optimization.

Technical Skills

  • Strong expertise in Microsoft Azure.
  • Experience with:
  • Azure App Services
  • Azure Kubernetes Service (AKS)
  • Azure Functions
  • Azure Container Apps
  • Azure API Management
  • Azure Front Door
  • Application Gateway and Load Balancers
  • Azure Virtual Networks (VNet)
  • Hub-and-Spoke Architecture
  • Azure Firewall
  • Private Endpoints and Network Security
  • Hybrid Connectivity
  • Experience with Infrastructure as Code, particularly Terraform, Bicep and/or ARM.
  • Knowledge of Azure DevOps and CI/CD.
  • Knowledge of AWS and/or GCP is an advantage.
  • Good understanding of cloud security, governance, monitoring, availability, and cost optimization.

Soft Skills

  • Strong analytical and problem-solving skills.
  • Excellent communication and stakeholder management skills.
  • Ability to translate business requirements into scalable technical solutions.
  • Structured and proactive approach to work.
  • Ability to work independently as well as collaboratively in international and cross-functional teams.
  • Strong sense of ownership and responsibility.

Languages

  • Good command of English, both written and spoken.
  • Knowledge of German is an advantage.
