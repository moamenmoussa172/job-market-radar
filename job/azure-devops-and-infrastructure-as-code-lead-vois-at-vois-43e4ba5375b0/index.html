About this Role

We are seeking an experienced Azure DevOps and Infrastructure as Code professional to lead and govern enterprise-scale Terraform and Azure DevOps capabilities across Vodafone’s global Azure environments. Based in Pune, this role will define platform strategy, technical standards, reference architectures and secure automation practices that enable compliant, standardised and scalable cloud deployments. The successful candidate will combine hands-on expertise in Terraform and Microsoft Azure with strategic technical leadership, design authority and effective collaboration across Architecture, Cyber Security, FinOps and Delivery teams. The role will also enable platform engineers and Infrastructure as Code specialists to adopt reliable self-service cloud deployment practices at scale.

What you’ll do

  • Define and maintain Terraform standards, reusable Infrastructure as Code modules, reference architectures and Azure landing zones.
  • Provide design authority for infrastructure automation across Vodafone Azure platforms.
  • Develop platform roadmaps aligned with Vodafone’s cloud, security and governance strategies.
  • Develop and operate Infrastructure as Code pipelines using Azure DevOps and GitHub.
  • Establish CI/CD standards for secure and consistent infrastructure delivery.
  • Integrate security, policy and compliance validation into deployment pipelines.
  • Implement Policy as Code, role-based access control, tagging, encryption and network controls.
  • Introduce appropriate security gates, governance controls and policy enforcement throughout CI/CD workflows.
  • Ensure cloud platforms comply with Vodafone security baselines and applicable regulatory standards.
  • Collaborate with Architecture, Cyber Security, FinOps and Delivery teams.
  • Serve as a senior technical point of contact for architecture, security and infrastructure delivery matters.
  • Guide and mentor platform engineers and senior Infrastructure as Code specialists.
  • Improve the adoption of standard Terraform modules and landing zones.
  • Reduce manual provisioning while improving pipeline reliability and deployment success rates.
  • Maintain clear technical documentation and promote consistent quality practices across globally distributed teams

Who you are

  • You have a bachelor’s degree in Information Technology, Computer Science or a related discipline, or equivalent practical experience.
  • You bring 8 to 10 years of relevant professional experience, including at least six years working in cloud or Infrastructure as Code leadership roles.
  • You have advanced, hands-on knowledge of Terraform and Microsoft Azure.
  • You understand Azure infrastructure services, networking, identity, governance, policy and security.
  • You have strong experience with Azure DevOps, GitHub and enterprise CI/CD platforms.
  • You understand Policy as Code, cloud security controls and automation frameworks.
  • You have experience managing APIs through Infrastructure as Code.
  • You can use the Python SDK for Azure to develop cloud automation solutions.
  • You communicate effectively with senior stakeholders and collaborate across global, virtual teams.
  • You apply sound judgement, take accountability for decisions and work effectively with limited supervision.
  • You demonstrate strategic thinking, a quality-focused approach and a commitment to clear documentation.
  • You can coach technical colleagues and support capability development.
  • Azure and DevOps certifications, such as AZ-400, AZ-305 or a Terraform certification, are desirable.

What's in it for you

  • An opportunity to influence enterprise-scale cloud automation across Vodafone’s global Azure environments.
  • The ability to shape Terraform standards, cloud platform architecture and secure infrastructure delivery practices.
  • Collaboration with specialists across Architecture, Cyber Security, FinOps and Delivery.
  • Exposure to global cloud governance, regulatory compliance and platform engineering challenges.
  • Opportunities to mentor technical professionals and contribute to the development of cloud and Infrastructure as Code capabilities.
  • A role in which you can improve self-service cloud adoption, deployment reliability and operational efficiency.

What skills you will learn

  • Enterprise-scale design and governance of Terraform-based cloud platforms.
  • Development of secure, reusable Azure landing zones and Infrastructure as Code modules.
  • Advanced integration of policy, security and compliance controls within CI/CD pipelines.
  • Strategic platform roadmap development across complex global cloud environments.
  • Cross-functional collaboration with Architecture, Cyber Security, FinOps and Delivery teams.
  • Coaching, technical decision-making and stakeholder communication in a global technology organisation.
  • Measurement and improvement of Infrastructure as Code adoption, deployment reliability and provisioning efficiency.
