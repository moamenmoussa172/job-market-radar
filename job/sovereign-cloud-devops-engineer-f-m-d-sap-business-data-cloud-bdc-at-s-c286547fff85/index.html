Sovereign Services & Delivery teams are collaborating closely with all Board areas to establish a harmonized, scalable, and consistent offering with transparent and standardized deliverables.

YOUR FUTURE ROLE

We are looking for a DevOps Engineer (f/m/d) who will focus on the Sovereign Cloud activities of SAP Business Data Cloud (BDC).

In this role, you will join the Multi-Tenant Platforms team: We own, build, and harden, the internal SAP Sovereign Cloud environments used as reference by the regional Operations teams. You will help deliver SAP Business Data Cloud (BDC) applications to SAP Sovereign Cloud customers aiming at functional completeness, streamlined deployments, and smooth operation.

You will be working closely with technical product managers, engineers, our security team, as well as SAP product team members, and operations teams. You will have the opportunity to solve the intricate Sovereign Cloud challenges of scale and security, while using your skills to deploy applications.

You will be the subject matter expert of the Sovereign Cloud BDC environment setup, leveraging your functional & technical expertise, complexity analysis, and stakeholder management. You will engage closely with regional Operations colleagues, Security, QA, as well as the other Sovereign Cloud Engineering teams. You will drive the end-to-end deployment of product capabilities - from defining implementation concepts, to performing functional & technical assessments, hardening, ultimately culminating in automated deployments for customer adoption.

WHAT YOU BRING

  • Bachelor's degree in computer science, engineering, or similar field
  • Professional experience in Cloud Delivery related fields and technologies
  • In-depth knowledge of hyperscalers like AWS required
  • In-depth experience in technologies used for deploying and managing Cloud-native applications:
  • Container Orchestration tools e.g. Gardener (preferred), Kubernetes, Docker
  • Helm charts
  • Repository management e.g. Artifactory (preferred), JFrog (preferred)
  • Service management tools e.g. Consul (preferred), Zookeeper
  • API Management tools e.g. Apigee (preferred)
  • Understanding of deployment automation and the tools e.g. Ansible, Chef
  • Experience with Infrastructure as Code - Terraform preferred
  • Experience with CI/CD pipelines e.g. ArgoCD (preferred), GitLab CI/CD (preferred), Jenkins
  • Experience with Monitoring e.g. Dynatrace, CloudWatch
  • Experience with Logging e.g. Splunk (preferred), Elasticsearch, Logstash
  • Experience with Cloud Networking tools e.g. AWS VPCs (preferred), VNet
  • Familiarity with GitLab and/or GitHub
  • Scripting background e.g. PowerShell, Python (preferred)
  • Security best practices including hardened containers and images (STIG)
  • Experience with Security tools e.g. Hashicorp Vault (preferred), GitHub Secrets
  • Database knowledge like SAP HANA
  • Expertise with OS e.g. Linux, RHEL
  • Excellent oral and written communication skills in English
  • Familiarity with Cloud Foundry is a plus
  • Prior exposure to OpenStack deployment or CLI tools is a plus
  • Knowledge of SAP and the SAP solution portfolio is a plus

WORK EXPERIENCE

  • 5+ years of professional experience in Cloud Delivery related fields and technologies
  • 2+ years of experience in cloud operations - developing, delivering and maintaining Cloud Products
  • Development experience in at least one programming language
  • Professional experience in software engineering roles
