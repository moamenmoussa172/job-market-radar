Technical Writer

Jisr · Maadi, Egypt

Onsite · Technical Writer · Posted 29 October 2026 · Arabic required

Apply on Jisr's site →Open in Radarak

About the job

  • Collaborate with teams to understand upcoming releases of Jisr Software Solution in the purpose of creating relevant demonstrational content
  • Develop clear and concise knowledge base articles, user guides (manuals), educational videos, and presentations.
  • Ensure accuracy, clarity, and completeness by verifying information and conducting testing.
  • Format materials with visuals for enhanced comprehension.
  • Incorporate feedback from concerned teams to continually improve documentation quality.
  • Create translations for all materials in English for Non-Arab Users
  • Adhere to project timelines and manage multiple documentation projects.
  • Proven experience creating release supporting materials for software products.
  • Familiarity with software development
  • 3-5 Years of experience in SaaS OR Software companies
  • High Technical English and Arabic proficiency
  • Strong technical aptitude for understanding complex software functionalities.
  • Proficiency in using documentation and picture editing tools for educational purposes.
  • Zendesk, Hubspot, Intercom (knowledgebase)
  • Meeting Deadlines ontime
  • Able to deliver the information without cascading any technical terminologies.
  • HRMS Background preferably
