Digital Identity & Security Access Management Specialist

Accenture · Riyadh, Saudi Arabia

Onsite · Security Engineer · Posted 25 November 2026

Apply on Accenture's site →Open in Radarak

About the job

-Administrate and operate system, data, and application security solutions, including File Integrity Monitoring using NNT Change Tracker, Database Protection with Imperva, Data Loss Prevention through Microsoft DLP, Data Classification and Information Protection using Microsoft Purview, and Endpoint Detection and Response and Anti-Virus capabilities.

-The role also covers operating and supporting application and API security controls using FortiWeb.

- Maintain expert knowledge of security technologies and lead the delivery of process and system improvements, ensuring best practices are consistently applied across the team.

-Continuously identify, enhance, and maximize the value of unutilized features within existing security solutions to achieve maximum business and security value.

-Design and support security architectures across on-premises and cloud environments, covering system, data, and application layers.

-Identify, analyze, and remediate security gaps, misconfigurations, and exposure risks, including web and API-related threats.

-Ensure security solutions are patched, updated, and aligned with vendor recommendations and organizational security standards.

-Support security incident investigations related to data leakage, endpoint threats, and application or API attacks, and provide technical input for audits, assessments, and reporting activities.

- At least 4–7+ years of experience in system, data, endpoint, or application security domains.

-Hands-on experience with data protection, endpoint security, and application or API security technologies.

-Strong understanding of data protection controls, system hardening, and application security principles.

-Experience supporting on-premises and cloud environments.

- Proven troubleshooting, root cause analysis, and continuous improvement skills. -Relevant security certifications are considered an advantage.
