About the job

Our solutions foster the collaboration that’s critical for safer communities, safer schools, safer hospitals, safer businesses, and ultimately, safer nations. Department Overview

Our still-growing Department is composed of well balanced agile teams with a full range of software development experience and the embedded mindset of DevOps culture and continuous delivery approach. Teams are responsible for end-to-end software development including: design, implementation, testing, delivery and maintenance in a 24/7 support model.


Job Description

Joining the Emergency Call Handling team in Krakow, you will contribute to extending capabilities of our mission critical , highly available(99.999%) platform and enhancing the existing technologies we use. Watch to learn more about VNXT Call Handling!

Tech stack:

Kubernetes/Docker, Java, Kotlin, Spring Boot, Quarkus, GitHub, Azure DevOps, ELK Stack + Prometheus/Grafana, Redis, Azure & AWS, Proxmox, Openshift, SIP/RTP/WebRTC/MSRP , RabbitMQ, Gstreamer, RUST, Asterisk, Postgresql, NGINX, Angular, TypeScript, JavaScript, Selenium/Playwright


Basic Requirements

  • 1+ years of commercial experience in Java development
  • Foundational understanding of microservices and RESTful APIs
  • Basic familiarity with containerization (Docker) and Git version control
  • English skills (B2) allowing for daily technical collaboration with international teammates
  • Understanding of Java fundamentals and Object-Oriented Programming (OOP)
  • Basic hands-on experience with Docker (creating, building, and running containers)
  • Basic understanding of HTTP / REST protocols
  • Eagerness to learn CI/CD pipelines and modern Cloud infrastructure under the guidance of a mentor

Nice to have — you will learn these on the job):

  • Basic exposure to Kubernetes, Cloud platforms (AWS/Azure), or Linux environments
  • Interest in Infrastructure as Code concepts (Ansible, Terraform)
  • Curiosity about message brokers (RabbitMQ, Kafka) or real-time streaming (WebRTC, SIP)
  • Academic or personal projects demonstrating an interest in automation and DevOps tooling

In return for your expertise, we’ll support you in this new challenge with coaching & development every step of the way.
