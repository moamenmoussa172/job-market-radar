About the job

Responsibilities:

  • Develop embedded software for configuring Ethernet switches.
  • Assist in creating demonstrators, proof-of-concept solutions, and validating test setups.
  • Implement scripting solutions to automate test environments.
  • Benchmarking and analyzing of automotive ethernet devices

Profile:

  • Currently enrolled in a Master’s program in Computer Science, Electrical Engineering, or a related field, preferably undertaking courses in embedded systems and communication networks or similar areas.
  • Experience with:
  • Programming language C and C++ (or other object oriented language)
  • Experience with scripting languages like python.
  • 32-bit Arm microcontroller programming and debugging skills.
  • Knowledge of:
  • Solid understanding of Ethernet protocols and TCP/IP communication.
  • Usage of lab instruments (e.g. oscilloscope, function generator) – basic understanding
  • A proactive team player with the ability to work independently.

What NXP Offers:

  • An attractive hourly wage of €19.40
  • 30 vacation days per year
  • Flexible working hours
  • The possibility to work in a hybrid setup
  • Access to an on-site cafeteria
  • Networking initiatives and Employee Resource Groups such as Young Community, No Extra Planet, NXP Equal, Women in NXP, and more — fostering both professional and personal exchange

Please note: The successful candidate may/will be responsible for security related tasks. The assignment may/will be in scope of security certifications, therefore a conscious and reliable way of working is necessary.
