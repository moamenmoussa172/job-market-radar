Job Summary:

We are looking for an experienced Senior Infrastructure Engineer with strong expertise in Microsoft Azure and on-premises Nutanix AHV hypervisor environments. The role will be responsible for designing, implementing, managing, monitoring, and troubleshooting hybrid infrastructure platforms across cloud and data center environments.

The ideal candidate should have hands-on experience in Azure infrastructure services, Nutanix AHV, Prism Central, Prism Element, virtualization, storage, networking, backup, disaster recovery, Windows Server, Active Directory, and infrastructure security.

Key Responsibilities:

Microsoft Azure Cloud Infrastructure

  • Design, deploy, and manage Azure infrastructure services including Virtual Machines, Virtual Networks, Storage Accounts, Azure Backup, Azure Site Recovery, Azure Monitor, Load Balancers, and Application Gateway.
  • Manage Azure subscriptions, resource groups, RBAC, policies, tagging, governance, and cost optimization.
  • Configure and support Azure networking including VPN, ExpressRoute, NSG, UDR, Private Endpoints, and Azure Firewall.
  • Support cloud migration, hybrid connectivity, backup, and disaster recovery initiatives.
  • Monitor Azure performance, availability, security, and capacity.
  • Nutanix AHV On-Premises Infrastructure
  • Administer and support Nutanix AHV clusters using Prism Central and Prism Element.
  • Manage virtual machines, images, snapshots, templates, storage containers, volume groups, and networks on Nutanix AHV.
  • Perform Nutanix cluster health checks, capacity planning, performance tuning, upgrades, and patching.
  • Troubleshoot AHV-related issues including VM performance, storage latency, networking, host failures, and cluster alerts.
  • Manage AHV networking including VLANs, virtual switches, bridges, IPAM, and VM network connectivity.
  • Support high availability, live migration, snapshots, replication, backup, and disaster recovery for Nutanix workloads.
  • Coordinate with vendors for hardware, firmware, licensing, and support cases.
  • Infrastructure Operations
  • Manage Windows Server, Active Directory, DNS, DHCP, GPO, file services, and certificate services.
  • Support backup and recovery solutions for Azure and Nutanix workloads.
  • Monitor infrastructure using tools such as Azure Monitor, Nutanix Prism, SolarWinds, SCOM, PRTG, or similar tools.
  • Handle Level 3 incidents, problem management, root cause analysis, and change implementation.
  • Maintain infrastructure documentation, diagrams, SOPs, runbooks, and operational reports.
  • Support disaster recovery testing and business continuity planning.
  • Security & Compliance
  • Apply infrastructure security best practices across Azure and Nutanix AHV.
  • Manage access control, RBAC, patching, vulnerability remediation, hardening, and audit requirements.
  • Work with cybersecurity teams to support security monitoring, incident response, and compliance activities.
  • Ensure infrastructure services meet internal policies, availability targets, and regulatory requirements.
  • Required Qualifications:
  • Bachelor's degree in Computer Science, Information Technology, Computer Engineering, or related field.
  • 7+ years of experience in infrastructure engineering, systems administration, or data center operations.
  • Strong hands-on experience with Nutanix AHV hypervisor.
  • Strong experience with Prism Central and Prism Element.
  • Strong experience with Microsoft Azure infrastructure services.
  • Strong knowledge of Windows Server, Active Directory, DNS, DHCP, GPO, and hybrid identity.
  • Good understanding of networking concepts including VLANs, routing, firewalls, VPN, load balancing, and IP addressing.
  • Experience with backup, disaster recovery, monitoring, capacity planning, and performance troubleshooting.
  • Ability to manage critical production incidents and work under pressure.
  • Strong documentation and communication skills.
  • Preferred Qualifications:
  • Nutanix Certified Professional - Multicloud Infrastructure, NCP-MCI.
  • Nutanix Certified Master - Multicloud Infrastructure, NCM-MCI.
  • Microsoft Certified: Azure Administrator Associate, AZ-104.
  • Experience with automation using PowerShell, Azure CLI, Terraform, Ansible, or Nutanix Calm.
  • Experience with backup tools such as Veeam and Azure Backup.
  • Experience with Nutanix disaster recovery solutions such as Nutanix Leap.
