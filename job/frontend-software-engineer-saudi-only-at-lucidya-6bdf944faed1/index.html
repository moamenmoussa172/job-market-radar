About the job

Lucidya is a leading AI-powered Customer Experience Management (CXM) platform in the MENA region, enabling enterprises to understand, engage, and serve their customers across digital channels at scale.

As we continue to scale our platform and move toward IPO-scale engineering, we are looking for a Frontend Software Engineer who is passionate about building high-quality user experiences, learning quickly, and using modern engineering practices — including AI — to deliver better software faster.

This role is ideal for an engineer with 0–2 years of professional experience who has a solid foundation in frontend development and wants to grow in an environment where ownership, speed, quality, collaboration, and continuous improvement matter.

We don't measure impact by how many lines of code you write. We care about your ability to understand problems, build maintainable solutions, collaborate effectively, and continuously improve the way you work.

Please note that this position is strictly open to Saudi nationals only. Applications from non-Saudi nationals will not be considered and will be disqualified from the recruitment process.

Requirements

What You Will Work On

Modern Frontend Development

  • Build and maintain production-grade web applications using React, JavaScript, and TypeScript.
  • Develop reusable, maintainable, and scalable frontend components.
  • Turn product requirements and designs into clean, intuitive, and responsive user experiences.
  • Integrate frontend applications with REST APIs and real-time communication services.
  • Work with WebSockets / Socket.IO to build real-time user experiences.
  • Understand and work with event-driven flows connected to RabbitMQ and backend messaging systems.
  • Handle real-time updates, reconnection scenarios, error states, and synchronization between live events and UI state.
  • Manage server state efficiently using React Query / TanStack Query.
  • Manage complex client-side state using Redux / Redux Toolkit when appropriate.
  • Contribute to improving frontend architecture, performance, code organization, and maintainability.

Quality & Testing

Quality is part of development — not something that happens after development.

  • Write reliable unit and integration tests using Jest.
  • Build and maintain end-to-end tests using Playwright.
  • Test your work thoroughly before considering it complete.
  • Participate actively in code reviews and learn from feedback.
  • Identify regressions, edge cases, and potential production issues before they reach users.
  • Debug issues systematically and focus on root causes rather than temporary workarounds.
  • Write code that is easy for other engineers to understand, review, test, and maintain.

AI-Enabled Engineering

We expect engineers to use AI as an engineering accelerator, not as a replacement for engineering judgment.

  • Use AI coding tools effectively to research, prototype, implement, debug, test, and refactor solutions faster.
  • Know how to provide AI tools with the right context, requirements, and constraints to generate useful results.
  • Critically review and validate AI-generated code instead of accepting it blindly.
  • Use AI to automate repetitive work and spend more time solving meaningful engineering problems.
  • Continuously explore better AI-assisted workflows that improve productivity and engineering velocity.
  • Maintain high standards for quality, security, performance, and maintainability, regardless of whether code was written manually or with AI assistance.

The goal isn't simply to write code faster. It's to deliver better outcomes in less time without sacrificing quality.

Ownership & Collaboration

  • Take ownership of your work from understanding the requirement through implementation, testing, review, and production.
  • Communicate clearly when requirements are unclear or when you identify technical risks.
  • Collaborate closely with frontend engineers, backend engineers, QA, product managers, and designers.
  • Ask questions when necessary while developing the ability to investigate and unblock yourself.
  • Give and receive constructive feedback during code reviews and technical discussions.
  • Help teammates when needed and actively share what you learn.
  • Take responsibility for the quality of what you ship.
  • Treat the product as something you own — not simply a collection of assigned tickets.

Stack

Our frontend ecosystem includes:

  • React
  • JavaScript (ES6+)
  • TypeScript
  • React Query / TanStack Query
  • Redux / Redux Toolkit
  • Jest
  • Playwright
  • WebSockets / Socket.IO
  • RabbitMQ
  • REST APIs
  • Git
  • Modern AI-assisted development tools

Experience with every technology is not required, but you should have strong fundamentals and the ability to learn quickly.

What We Are Looking For

  • Bachelor's degree in Computer Science or a closely related field.
  • 0–2 years of professional frontend development experience.
  • Strong understanding of JavaScript fundamentals.
  • Hands-on experience building applications with React.
  • Good understanding of TypeScript and type-safe development.
  • Good understanding of React fundamentals, including components, hooks, state management, rendering, and component lifecycle.
  • Experience integrating frontend applications with APIs and handling asynchronous data.
  • Familiarity with React Query / TanStack Query and Redux / Redux Toolkit.
  • Understanding of frontend testing and experience with tools such as Jest and Playwright.
  • Familiarity with real-time frontend architectures using WebSockets / Socket.IO.
  • Basic understanding of message queues and event-driven systems, especially RabbitMQ.
  • Understanding of common real-time challenges such as reconnection, duplicate events, stale data, race conditions, and keeping UI state synchronized.
  • Solid understanding of HTML, CSS, responsive design, and browser fundamentals.
  • Familiarity with Git and collaborative development workflows.
  • Ability to debug problems rather than only work around them.
  • Ability to write clean, readable, and maintainable code.
  • Practical experience using AI tools to improve software engineering productivity.
  • Strong willingness to learn and continuously improve.
  • Good communication and teamwork skills.

This Role Is a Strong Fit If You...

  • Can take a feature from requirement to production instead of stopping when the code simply "works."
  • Care about both speed and quality — you don't believe one has to come at the expense of the other.
  • Use AI to multiply your productivity while still understanding and owning every solution you ship.
  • Don't blindly copy AI-generated code — you question it, review it, test it, and improve it.
  • Try to understand why something works, not only how to make it work.
  • Investigate bugs and edge cases instead of immediately passing them to someone else.
  • Treat testing as part of development rather than an optional final step.
  • Care about code readability, scalability, and maintainability.
  • Can receive code-review feedback and use it to improve.
  • Communicate early when you are blocked.
  • Enjoy collaborating and sharing knowledge with other engineers.
  • Are curious about the product, not just the ticket assigned to you.
  • Look for opportunities to improve existing code and engineering processes.
  • Have a strong sense of ownership and don't need constant follow-up to get things done.
  • Want to become a significantly stronger engineer over the next few years.
