Senior Oracle Database Administrator

Egyptian Banks Company · New Cairo City, Egypt

Onsite · Senior · Database Administrator · Posted 17 October 2026

Database administrationLinuxOracle

About the job

  • Experience in Oracle Exadata and ZDLRA
  • Strong troubleshooting and problem-solving skills.
  • Very Good knowledge in Linux/Windows operating systems.
  • Install and maintaining the Oracle database software.
  • Create storage database structures with high-level security features.
  • Altering storage structures to meet the evolving needs of the company.
  • Setup database user accounts.
  • Apply TDE and Column level encryption.
  • Apply Needed Security controls and follow PCI policies.
  • Apply Database Partitioning and Database Sharding.
  • Train users on how to access the information in the database.
  • Find and debug malfunctioning programs affecting the database integrity.
  • Create autonomous database backups.
  • Regularly updating the database security protocols.

Requirements

  • +6 years of experience in similar role
  • Experience in Oracle Database administration with setup, design, implementation, and configuration.
  • Experience in Oracle database administration, database maintenance and troubleshooting.
  • Must have Experience in Oracle high availability solution - RAC, Grid and ASM administration.
  • Experience in Oracle Data Guard.
  • Experience in Oracle Enterprise Manager.
  • Experience in managing Oracle Backup and Recovery Administration.
  • Experience in managing Oracle Backup and Recovery using the RMAN with all needed policies.
  • experience in Oracle Exadata and ZDLRA
