About the role

We are seeking a proactive and experienced Senior App Modernization and DevOps Engineer to lead the transformation of legacy applications and drive the implementation of modern DevOps practices on Azure. This role requires strong expertise in cloud computing, application modernization, and containerization, with a particular focus on Azure Kubernetes Service (AKS) and Azure-native solutions. The ideal candidate will have a proven track record in modernizing enterprise applications and optimizing CI/CD pipelines within a cloud-first environment.

Job responsibilities

  • Application Modernization Support: Assist in the migration and modernization of legacy applications to Azure, working closely with senior engineers to refactor, rearchitect, and containerize applications.
  • CI/CD Pipeline Assistance: Support the development, maintenance, and optimization of CI/CD pipelines using Azure DevOps, ensuring smooth integration and deployment processes.
  • Infrastructure as Code (IaC) Support: Assist in the implementation and management of infrastructure using IaC tools such as ARM templates, Bicep, or Terraform.
  • Azure Kubernetes Service (AKS) Support: Help deploy, manage, and scale containerized applications using Azure Kubernetes Service (AKS), learning best practices for orchestration, management, and security.
  • Azure App Services Management: Assist in deploying and managing applications on Azure App Services, learning best practices for scalability, security, and performance optimization.
  • SonarQube Integration: Support the integration of SonarQube for code quality analysis within CI/CD pipelines, ensuring adherence to coding standards and practices.
  • Automation Tasks: Help automate routine tasks to enhance productivity and reduce manual interventions, using scripting languages like PowerShell or Bash.
  • Monitoring & Logging: Assist in setting up monitoring and logging for applications and infrastructure, ensuring visibility into performance and operational health.
  • Collaboration: Work closely with development, operations, and security teams to ensure applications are deployed reliably and securely.
  • Documentation: Contribute to the creation and maintenance of documentation related to deployment processes, system configurations, and best practices.
  • Learning and Development: Engage in continuous learning to stay updated on Azure services,
  • DevOps tools, and application modernization techniques.

Job requirements

Education: Bachelor’s degree in computer science, Information Technology, or a related field, or equivalent work experience.

Experience: 6+ years of experience in DevOps, cloud computing, or application development, with a Fair understanding of Azure services.

Technical Skills:

  • Fair knowledge of Azure DevOps, including Pipelines, Repos, and Artifacts.
  • Familiarity with cloud computing concepts, particularly on Azure.
  • Fair understanding of Infrastructure as Code (IaC) tools such as ARM templates, Bicep, or Terraform.
  • Familiarity with Azure Kubernetes Service (AKS) and containerization technologies like Docker.
  • Fair knowledge of Azure App Services for hosting applications and APIs.
  • Understanding of code quality tools like SonarQube and their integration into CI/CD pipelines.
  • Proficiency in scripting languages such as PowerShell, Bash, or Python.
  • Knowledge of monitoring tools and practices is a plus.
