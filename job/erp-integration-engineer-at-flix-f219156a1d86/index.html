ERP Integration Engineer

About the job

Rate: 89 – 172 PLN/hour (B2B)

We are looking for an experienced Workday Integration Engineer to join Flix on a freelance/service agreement basis (B2B contract). This is a contractor engagement for a seasoned integration professional who wants to work on impactful, hands-on engineering challenges.

Scope of Services

Design, build, and maintain AWS-based integrations between our Workday HRIS and the internal and external systems within FlixTech People Enablement Stream. Work closely with HR, IT Infrastructure, various internal stakeholders, and external vendors to ensure seamless data flow and automation across platforms.

About the Engagement

  • Design, build, and deploy scalable integrations on AWS connecting HR, payroll, and workforce platforms — consuming data from systems like Workday, Deel, Greenhouse, and other third-party providers
  • Architect and maintain event-driven and API-based integration workflows using AWS services including EventBridge, Lambda, API Gateway, ECS/Kubernetes, SQS, and S3
  • Use Python to develop integration services, automation scripts, and data transformation and mapping logic to ensure accurate and consistent data exchange between systems
  • Use Infrastructure as Code, such as Terraform, to provision and maintain cloud infrastructure in a consistent and repeatable manner
  • Implement CI/CD pipelines using Git and DevOps tools to streamline code versioning, testing, and deployment
  • Implement secure integration pipelines using OAuth 2.0, SFTP, certificate-based authentication, AWS KMS encryption, fine-grained access controls, and PII masking to ensure GDPR compliance and protect international employee data
  • Implement monitoring, logging, and error-handling mechanisms to support troubleshooting, data integrity, and reliable production operations
  • Collaborate with functional teams to understand business processes and translate them into robust integration solutions
  • Troubleshoot and optimize integration performance in development, testing, and production environments
  • Provide technical guidance, best practices, and consulting to other developers

About You

  • Experience connecting diverse HR, ATS, payroll, and EOR systems (Workday, Deel, Greenhouse, etc.), with a strong grasp of employee lifecycle events, organizational structures, and payroll cutoffs
  • Experience with API-based integrations using REST, SOAP, and JSON/XML
  • Experience with AWS, API Gateway, Terraform, and Infrastructure as Code
  • Familiarity with CI/CD pipelines, version control systems, and modern DevOps practices
  • Experience with secure data exchange, including SFTP, certificate management, encryption, and API authentication
  • Strong communication skills to collaborate with HR, Finance, IT, and external vendors to turn business needs into integration designs
  • Fluent in English; German language skills are a welcome bonus

Preferred Skills:

  • Experience with Workday Integration technologies such as Workday Studio, PECI, Core Connectors, or EIBs

Collaboration Model

  • Cooperation based on a service agreement (B2B/freelance contract), not an employment contract
  • You will operate as an independent contractor, responsible for delivering agreed services and submitting invoices
  • Location: open for contractors based in Poland
