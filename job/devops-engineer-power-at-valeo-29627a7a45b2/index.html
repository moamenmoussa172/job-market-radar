About the job

Valeo is a tech global company, designing breakthrough solutions to reinvent the mobility. We are an automotive supplier partner to automakers and new mobility actors worldwide. Our vision? Invent a greener and more secured mobility, thanks to solutions focusing on intuitive driving and reducing CO2 emissions. We are leader on our businesses, and recognized as one of the largest global innovative companies.

We are seeking a dedicated CI/CD & DevOps Engineer to join our automotive test automation team.

Our team focuses on providing automation features for Testing in ECU-TEST, as well as our Focus on the infrastructure, pipeline architecture, and deployment mechanisms that make those tests run efficiently.

You will contribute to the Jenkins ecosystem, managing the complex orchestration required to run automated software tests on physical Hardware-in-the-Loop (HIL) test benches. This is a specialized DevOps role that bridges the gap between modern CI/CD practices and automotive hardware testing, ensuring our integration and delivery pipelines are scalable, fast, and highly reliable.

What You Will Do

  • Pipeline Architecture & Development: Design, build, and maintain advanced declarative and scripted Jenkins CI/CD pipelines to automate software builds, HIL testing, and deployment.
  • Jenkins Administration: Manage Jenkins controllers and agents, specifically focusing on the allocation, health, and routing of jobs to specialized HIL test bench nodes.
  • Infrastructure & Containerization: Utilize Docker to containerize build environments, test tools, and utility scripts to ensure consistent pipeline execution across different machines.
  • Toolchain Integration: Integrate Jenkins with version control (Git/Bitbucket), test execution tools (TraceTronic ECU-TEST), artifact repositories, and analytics dashboards (TEST-GUIDE).
  • Scripting & Automation: Write and maintain Jenkins Shared Libraries in Groovy, and develop backend automation scripts in Python or Bash/PowerShell to optimize pipeline performance.
  • Monitoring & Reliability: Implement monitoring and alerting for CI/CD infrastructure to proactively resolve bottlenecks, pipeline failures, or offline HIL nodes.
  • Security & Compliance: Ensure CI/CD pipelines adhere to internal security guidelines, managing credentials, access control, and secure artifact storage.

What We Are Looking For (Required Qualifications)

  • Experience: 1–2 years of dedicated experience in a DevOps, Release Engineering, or CI/CD focused role.
  • Education: Bachelor’s degree in Computer Science, Software Engineering, IT, or a related technical field.
  • CI/CD & Jenkins Skills: Practical experience building and maintaining pipelines in Jenkins. You are able to write standard Jenkinsfiles, configuring jobs, and understanding the basics of managing Jenkins nodes and agents.
  • Programming & Scripting: Strong coding skills in Groovy (for Jenkins pipelines and Shared Libraries) and Python or Bash/PowerShell for general automation.
  • DevOps Tooling: Hands-on experience with Docker (containerization) and advanced version control workflows (Git branching strategies, code review enforcement).
  • System Administration: Foundational knowledge of operating systems (Windows and Linux) and networking, as HIL test benches require specialized node configuration.
  • Analytical Problem Solving: Excellent troubleshooting skills for debugging pipeline failures, environment inconsistencies, and network connectivity issues.

Nice to Have (Bonus Points)

  • Previous exposure to the automotive domain, specifically Hardware-in-the-Loop (HIL) environments or TraceTronic tools (ECU-TEST, TEST-GUIDE).
  • Experience with Infrastructure as Code (IaC) tools like Ansible or Terraform.
  • Familiarity with monitoring stacks (e.g. Grafana,..) for tracking pipeline health.
