About the job

  • Must Have hand on experience in Database clustering and replication technologies including EDB Enterprise Failover Manager (EFM) & PGD and CitusData.
  • PostgreSQL & Cassandra DB Administration: Expert in installing, configuring, and maintaining PostgreSQL & Cassandra instances in production, staging, and development environments.
  • Database Performance Optimization: Advanced skills in query optimization, indexing, partitioning, and caching strategies to boost database performance & Optimize database stability and performance throughout the migration lifecycle.
  • High Availability & Disaster Recovery: Skilled in setting up replication (synchronous & asynchronous), failover mechanisms, and backup strategies to ensure maximum uptime and data protection.
  • Scalability & Load Balancing: Experience in implementing horizontal and vertical scaling techniques, managing large datasets, and balancing loads to improve performance.
  • Database Security: Ensuring database security through access control, encryption, and regular audits to protect sensitive data and comply with industry standards.
  • SQL & PL/pgSQL Development: In-depth knowledge of writing complex SQL queries, stored procedures, functions, and triggers for both transactional and analytical applications.
  • Data Migration & ETL: Expertise in migrating large volumes of data across different PostgreSQL instances and performing ETL operations.
  • Infrastructure: Experience in deploying and managing PostgreSQL databases on different platforms.
  • DevOps & Automation: Familiarity with infrastructure as code (IaC), CI/CD pipelines, and automation tools like Ansible, Docker, and Kubernetes for seamless PostgreSQL deployment and management.
  • Execute migration of Oracle and SQL Server databases to PostgreSQL environments.
  • Ensure all migration activities comply with the Change Advisory Board (CAB) process, coordinating pre-production and production releases.
  • Implement and enforce the principle of least privilege across all database users and roles.
  • Configure and enable Transparent Data Encryption (TDE) with minimal impact on production environments.
  • Conduct daily operational health checks to ensure optimal database performance.
  • Provide timely business and application support to resolve database-related issues.\
  • Perform patching and minor version upgrades while minimizing system downtime.
  • Document all database activities, procedures, and incidents comprehensively.
  • Redis database experience.
  • hands on experience in Database clustering and replication technologies including EDB Enterprise Failover Manager (EFM) & PGD and CitusData.

Requirements

  • 3+ Years in similar role, experienced in managing and supporting PostgreSQL (version 14 and above) on both Linux and Windows platform.
  • Hands on experience in Database clustering and replication technologies including EDB Enterprise Failover Manager (EFM) & PGD and CitusData
  • Database administration certifications
  • Experience with MS SQL Server, and Cassandra DB.
  • Proven experience as a Database Administrator with strong knowledge of database management systems (e.g., Oracle, MySQL, SQL Server).
  • Experience in database security and data protection measures.
  • Familiarity with backup and recovery processes.
