About the job

Roles & Responsibilities :
We are looking for a hands-on software engineer with intrinsic motivation to build and run Generative AI workflows for Bosch's global Intellectual Property (IP) organization.

You will own workflows from start to finish. You will work directly with IP attorneys, patent analysts, and engineers to understand how they work. You will turn their problems into clear specifications and ship production tools with an AI-first engineering workflow. You will be responsible for specific workflows yourself and coordinate overall direction with the AI platform lead.

The role is between our AI platform (Python / FastAPI) and our core enterprise IP Management applications. The scope grows with what AI makes possible and what our IP teams need, e.g. semantic search, automated document classification, portfolio intelligence, and strategic decision-support tools.

What You Will Do

  • Own workflows end to end: Work with internal users to understand their workflows, prototype and validate ideas in interactive UI frameworks, and bring what works into production, where users run it at scale from our core enterprise platforms, without a middleman.
  • Build AI-powered backend services: Design and extend Python / FastAPI services that power IP workflows such as semantic search, automated document analysis, clustering, and structured information extraction.
  • Design for the user: Care how the output is used: watch users work, cut steps, and make results easy to review and trust.
  • Integrate with our IP Management System: Work with the enterprise applications team so their platform can trigger, consume AI workflows, and contribute on integration of APIs and web interfaces as required.
  • Build data pipelines: Ingest and transform data from large-scale external databases and enterprise data platforms, handling rate limits, retries, pagination, and validation.
  • Run what you build: Monitor quality, latency and LLM costs in production, and improve prompts, queries and architecture based on real user feedback.

Educational qualification:

  • B.E. / B.Tech / M.Tech / MCA in Computer Science, IT or a related engineering field.

Experience :

  • 3+ years of professional software engineering experience, mainly writing production backend code in Python.

Mandatory/requires Skills :

  • Experience building REST APIs (FastAPI preferred; Flask/Django acceptable), including async programming, Pydantic validation and authentication.
  • Strong SQL skills with relational databases (e.g., Oracle, PostgreSQL, or SQL Server).
  • Hands-on experience building LLM workflows via API (Gemini, Claude, GPT): context assembly, multi-step prompt chaining, embeddings/retrieval, and making output quality measurable and reproducible (evaluation sets, regression checks, tracing), whether outputs are free text or structured.
  • Daily use of AI coding agents (e.g. GitHub Copilot, Claude, Cursor) with clear specs, and owning correctness: you decide where review and tests matter, and you verify behaviour before it reaches users.
  • Solid Git / GitHub workflow (branches, pull requests, code review).
  • Fluent English, written and spoken, for direct work with users and colleagues in Germany and worldwide.

Preferred Skills :

  • Exposure to patents or IP: patent data, claims, invention disclosures, and public/commercial patent databases, or being an inventor or patent agent yourself. We will gladly teach the IP domain to a strong engineer.
  • Familiarity with modern frontend frameworks (e.g., Angular/TypeScript), interactive data prototyping tools (e.g., Streamlit), or enterprise data lakehouses (e.g., Databricks/PySpark).
  • Experience running services on Windows Server (PowerShell, scheduled tasks).

Scope note: This is a software engineering role. Not patent searching, project management or BI dashboarding role.
