What you'll be doing

We are looking for a Server-Side Swift Developer to join the backend team at Level Shoes. The team builds and operates the Vapor-based microservices that power our iOS, Android and web storefronts across six GCC markets in English and Arabic. This is a hands-on senior role with real production ownership. You will design, build, review and ship backend services, and you will be accountable for how they behave in production — including under sale-day load and when the systems we integrate with misbehave.

• Design, develop and maintain scalable backend services in Swift using Vapor.

• Own services end to end: design, implementation, code review, deployment and production health.

• Build and maintain the RESTful APIs behind customer-facing commerce flows — accounts and

authentication, catalogue, cart, checkout, payments and orders.

• Ensure correctness across multiple stores and languages, where every request is scoped to a market and a locale.

• Design and maintain integrations with third-party systems — commerce platform, order management, search, CMS, and payment/BNPL gateways — including webhook handling and safe degradation when those systems are slow or unavailable.

• Build concurrency-safe, idempotent processing for operations that run across multiple service replicas and must never be applied twice.

• Model data and optimise queries in MongoDB; implement caching and session strategies in Redis.

• Implement and tune Elastic Search-backed search and listing functionality.

• Ship behaviour changes behind feature flags with staged, measured rollouts.

• Investigate production issues from logs and metrics, and validate fixes with evidence.

• Maintain CI/CD pipelines and deployment workflows on Kubernetes.

• Explore AI-driven capabilities such as vector search for personalisation.

• Review teammates' changes; all code is reviewed before merge regardless of seniority.

What you’ll need to succeed

  • 6+ years of professional software development experience, including at least 3 years building production backend services in server-side Swift (Vapor). Client-side Swift alone does not satisfy this requirement — the role requires Swift running on a server, under load, with a database behind it.
  • Prior iOS/macOS or backend experience in other languages is welcome for the remaining years.
  • Strong command of Swift concurrency, protocol-oriented design and Codable, including decoding payloads from external systems.
  • Demonstrable experience with concurrency, race conditions and idempotency in services running as multiple instances — a specific production bug you found, diagnosed and fixed, not theoretical
  • knowledge.
  • Strong understanding of RESTful API design, authentication and token lifecycle.
  • MongoDB in production, including data modelling, indexing and query performance.
  • Redis for caching and session state, including graceful behaviour when it is unavailable.
  • ElasticSearch for search and listing.
  • Experience integrating payment gateways and third-party APIs, including webhook-driven flows.
  • Kubernetes: deploying and operating containerised services, and reading logs and metrics to a defensible conclusion.
  • Git, CI/CD pipelines and automated testing; Swift Package Manager for dependency management.
  • Strong grasp of performance, scalability and security best practices.
  • E-commerce, payments or another domain where defects have direct financial consequences.
  • Integration experience with Magento or a comparable commerce platform, or with an order management system.
  • Multi-tenant or multi-region systems where data isolation is a correctness requirement.
  • Localisation beyond string swapping, including right-to-left languages.
  • AWS or another cloud platform for hosting backend services.
  • Logging and monitoring tools such as New Relic, used for investigation rather than dashboards alone.
  • Feature-flagging and progressive rollout platforms.
  • Jenkins and Gerrit.
  • Agile development methodologies.
