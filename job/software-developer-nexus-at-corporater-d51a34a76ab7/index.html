About the job

About the role

We are hiring a Software Engineer to join Corporater's Product Engineering team in India. Nexus is Corporater's new platform for managing leads, cases, partners and the sales pipeline, built in-house as a custom application on AWS. You will help us build it.

You will join a small team of developers and a QA engineer, led by a hands-on Tech Lead, and work closely with the Product Owner and colleagues in Norway. You will take on real tasks from your first weeks, learn how a production system is designed, tested and operated, and grow with guidance from the senior engineers.

We are looking for someone with a solid foundation in software engineering and databases, who is curious, asks good questions and wants to become a strong engineer.

What you will do

In this role, with support from the senior engineers, you will:

  • Build and test features across Nexus in Java and Spring Boot, and in React and TypeScript, working from clear tasks that grow in size as you learn and keeping to the module boundaries the team has agreed.
  • Work with the relational and graph data models: write queries, migrations and tests for PostgreSQL, and help keep the relationships between accounts, people and Cases correct and fast.
  • Help build REST API endpoints, events and webhooks, including idempotency keys, retries and the audit log that every write needs.
  • Help build integrations with Microsoft Entra ID, Outlook, Teams and SharePoint through Microsoft Graph, and with our HR, ERP, e-signature, marketing and support systems.
  • Apply the access rules in code, such as field and file visibility and partner access, with review from a senior engineer.
  • Write automated unit and integration tests, work with the QA engineer on end-to-end and load tests, and fix bugs found in testing and production.
  • Learn how we run the platform: AWS, Terraform, CI/CD pipelines, monitoring with OpenTelemetry and alerting, and help with runbooks and documentation.
  • Take part in code reviews, planning and design workshops with the people who use Nexus, and ask questions early.
  • Use AI tools, including AI coding assistants, with good judgement, and help integrate the AI service into the features that use it.

What we are looking for

  • A degree in computer science or a related field, or equivalent practical experience, and 2–4 years of professional software engineering experience, including work on a production application.
  • Solid Java skills and experience with Spring Boot, or strong skills in a comparable object-oriented language and the willingness to move to Java quickly. Good knowledge of data structures, algorithms and object-oriented design.
  • Working knowledge of TypeScript and React. You are comfortable working across the stack.
  • Relational database (RDBMS) skills: you can design normalised tables, write SQL with joins, aggregates and indexes, read a query plan, and explain transactions and constraints. Experience with PostgreSQL is welcome, and MySQL or SQL Server experience counts too.
  • Graph database skills: you understand nodes, relationships and properties, and can model connected data and write queries in a graph query language such as Cypher or Gremlin, for example with Neo4j or Amazon Neptune. You can explain when a graph model fits better than tables, and when it does not.
  • Knowledge of how web services work: HTTP, REST APIs, JSON, and the basics of authentication.
  • Experience working in a team with Git, pull requests and code review, and a habit of writing automated tests for your code.
  • Care for security and privacy: you know why access control, personal data under GDPR and audit logs matter.
  • Clear written and spoken English, and the ability to work well with colleagues and users in another country and time zone.
  • Curiosity about AI tools and a willingness to build with them, including using AI coding assistants with good judgement. You do not need to be an AI specialist.

Nice to have

  • A side project or open-source contribution that uses a database in a real application, with a repository we can look at.
  • Experience with Spring Boot, or with building a REST API in any framework.
  • Basic knowledge of AWS, such as S3, containers or Lambda, of Docker, and of infrastructure as code such as Terraform.
  • Familiarity with CI/CD pipelines, GitHub and automated testing tools.
  • Awareness of Microsoft services such as Entra ID, Outlook, Teams or SharePoint.
  • Knowledge of event-driven designs, such as queues and the outbox pattern.
  • First-hand experience with LLM features, for example calling a hosted model through an API such as Amazon Bedrock, or retrieval (RAG) with pgvector.

Technology and environment

We build, run and own Nexus ourselves. You do not need to know all of this on day one; we will teach you.

Our stack:

  • Application: Java and Spring Boot as a modular monolith, with React and TypeScript for the front end.
  • Data: Aurora PostgreSQL with pgvector, and graph data models for connected data.
  • Cloud: AWS, in accounts that Corporater owns, with Amazon ECS, SQS and EventBridge, and Terraform for infrastructure as code. We own the source code, infrastructure code and data.
  • AI: Amazon Bedrock, with every AI model call going through one controlled service.
  • Identity and integrations: Microsoft Entra ID single sign-on and Microsoft Graph for Outlook, Teams, and SharePoint, plus a versioned REST API, webhooks, and OAuth 2.0 client credentials for tools and integrations.
  • Delivery: GitHub, CI/CD pipelines, automated tests, and OpenTelemetry for monitoring.
  • Regions: We store data in the EU by default. Data owned by the Saudi Arabia office stays in Saudi Arabia.

Why Join Corporater?

You will be part of the Product Engineering organisation being built in Corporater India, working on a shared platform capability used across multiple global products.

You will solve interesting engineering problems across rich user experiences, component architecture, accessibility, performance, API integration, and enterprise-scale frontend development, with direct influence on how the platform evolves.

If you enjoy solving meaningful engineering problems, building elegant user experiences, and building products rather than simply implementing requirements, we would like to hear from you.
