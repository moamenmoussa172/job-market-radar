About the job

Experience: 10+ Years
Role: Senior Full Stack Developer
Technology Stack: Python, React.js, Next.js, TypeScript, SQL, Azure DevOps, Azure Container Apps, AI

Role Overview

We are looking for an experienced Senior Full Stack Developer with strong hands-on expertise in Python, React.js, Next.js and Microsoft Azure. The ideal candidate should have proven experience in designing, developing, deploying and maintaining complex business applications used by production users.

The role requires strong technical ownership across backend and frontend development, database management, CI/CD pipelines, containerized application deployment and end-to-end software delivery. The candidate should be comfortable working in an Agile environment and collaborating with cross-functional teams to deliver scalable, secure and high-quality applications.

Key Responsibilities

  • Design, develop and maintain scalable backend services and REST APIs using Python.
  • Build responsive, high-performance frontend applications using React.js, Next.js, JavaScript and TypeScript.
  • Develop and integrate frontend and backend components, ensuring seamless application functionality.
  • Design and manage SQL databases, including schema design, migrations, query optimization and performance troubleshooting.
  • Manage source code using Git, perform code reviews and follow established development best practices.
  • Use VS Code or comparable IDEs for application development, debugging and local execution.
  • Develop, maintain and troubleshoot CI/CD pipelines using Azure DevOps Repos, Boards and Pipelines.
  • Deploy and operate containerized applications using Azure Container Apps or equivalent Azure container services.
  • Work with Docker to containerize applications and establish repeatable development environments.
  • Design and execute automated unit, integration, API and end-to-end tests.
  • Support User Acceptance Testing (UAT), production deployments and incident resolution.
  • Implement secure coding practices, authentication, authorization, application logging and monitoring.
  • Collaborate with architects, product owners, developers and QA teams in an Agile delivery environment.
  • Maintain technical documentation, contribute to engineering standards and take ownership of application delivery.

Mandatory Technical Skills & Experience

  • Overall Experience: 10+ years of professional software development experience, with recent hands-on ownership of complex production applications.
  • Backend Development: Strong practical experience in Python, including backend services and REST API development.
  • Frontend Development: Hands-on expertise in React.js, Next.js, JavaScript, TypeScript, HTML and CSS.
  • Database Management: Working knowledge of SQL databases, schema design, database migrations, performance tuning and troubleshooting.
  • Development Tools: Proficiency in VS Code or equivalent IDE, Git, code reviews, Docker and local application execution.
  • Azure DevOps: Practical experience with Azure Repos, Boards and CI/CD pipelines, including build and deployment troubleshooting.
  • Azure Container Services: Hands-on experience deploying or operating containerized applications on Azure Container Apps or equivalent Azure container platforms.
  • Testing & Quality: Experience with automated unit, integration, API and E2E testing, UAT and production support.
  • Engineering Fundamentals: Strong understanding of REST APIs, authentication, authorization, secure coding, logging, monitoring and Agile methodologies.

Educational Qualifications

Bachelor’s degree in Computer Science, Information Technology, Software Engineering or a related discipline. Equivalent professional experience may also be considered.

Preferred Candidate Profile

  • Strong problem-solving and analytical skills.
  • Ability to independently own technical deliverables from development through production deployment.
  • Experience working on enterprise-grade business applications.
  • Strong debugging, troubleshooting and production issue-resolution capabilities.
  • Excellent communication and collaboration skills.
  • Ability to work independently while contributing effectively to a collaborative engineering team.
