About the job

About this Role:

This role is in one of ArpuPlus’ business units, CloudCom, and will play a key role in building and scaling the API gateway layer supporting CloudCom’s telecom and Network API capabilities.

Key responsibilities

· Build backend microservices for API exposure, mediation, onboarding, usage tracking, and platform administration.

· Implement CAMARA-style APIs and TM Forum API integrations.

· Develop adapters to connect the gateway with operator BSS/OSS and network systems.

· Create and maintain OpenAPI specifications.

· Write clean, testable, and maintainable code.

· Work with QA to support automated testing, contract testing, and regression testing.

· Support production troubleshooting, bug fixing, and performance optimization.

Requirements

  • Bachelor’s degree in computer science or any other field.
  • 4 to 6 years of experience.
  • Front and Backend development experience using languages such as angular, .net core, Java, Go, Python, Node.js, or similar.
  • Strong understanding of REST APIs, JSON, OpenAPI, and microservices.
  • Experience with databases, message queues, caching, and distributed systems.
    Familiarity with Kubernetes, Docker, and CI/CD pipelines.
  • Telecom API, TM Forum, CAMARA, or API gateway experience is a plus.
