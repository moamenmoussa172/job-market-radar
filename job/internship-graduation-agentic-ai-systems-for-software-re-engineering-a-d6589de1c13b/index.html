Description of assignment

Modernizing software is one of the most challenging and time-consuming activities in software engineering. Upgrading existing systems affects architecture, dependencies, interfaces, testing and deployment standards simultaneously, consuming capacity that could otherwise go into new functionality. Generative AI already supports individual coding tasks, but this assignment explores taking automation to the next level by evaluating whether autonomous AI agents can handle complete end-to-end migrations.

Using a representative, real-world software module as a case study, you will research, design, and demonstrate an agentic migration system. You will investigate how autonomous AI agents can understand, plan, implement, test, and validate a software migration while ensuring that every change remains reviewable, traceable, and under human control.

Department description

You will join the engineering team developing ADAPTO, Vanderlande’s shuttle-based automated storage and retrieval system (AS/RS), within the Technology organization. ADAPTO enables fast and accurate order fulfillment for high-volume e-commerce and retail distribution centers worldwide. The team continuously improves ADAPTO and its software while collaborating closely with product management, engineering teams, and customer project teams.

You will work on your research assignment fully embedded within an agile, multidisciplinary engineering team that is eager to explore AI-driven software development. Throughout the assignment, you will receive close guidance and support from two dedicated supervisors.

Tasks/responsibilities

  • Explore state-of-the-art Agentic AI and analyze its possibilities for large software migrations.
  • Establish a baseline for a representative software module, covering architecture, tests, and build quality.
  • Design a reference architecture for an agentic migration system using specialized AI agents.
  • Build a proof-of-concept executing migrations in small, reviewable steps in an isolated environment.
  • Evaluate autonomy levels, code quality, test results, human interventions, and overall effort.

Your profile

  • Strong programming and software engineering fundamentals in languages such as C#, Java, or Python, with Git experience.
  • Interest in software architecture, software modernization, Generative AI, LLMs, and AI agents.
  • Affinity with DevOps, CI/CD, and automated testing.
  • Good written and spoken English communication skills.
  • *Mandatory enrolment to a Dutch Education System & resident of The Netherlands
