About The Role

CoverGo is hiring an Application Security Engineer to use AI to find and prevent vulnerabilities before they reach production, and to give engineering teams the tools and guardrails that stop vulnerabilities from being introduced in the first place. The Security team is small and growing, and works AI-first: everyone uses AI to automate their own work and to scale security across a large engineering organisation.

What You Will Do

  • Use AI tools such as Claude and OpenAI models to find and triage vulnerabilities in code, dependencies and designs before changes are merged.
  • Embed security checks into developer workflows and CI/CD pipelines so issues surface as code is written.
  • Select, configure and tune code-security tools such as GitHub Advanced Security, Snyk and Checkmarx, keeping the signal high enough that engineers act on the findings.
  • Build self-service tools, guardrails and guidance that help engineering teams prevent common vulnerability classes.
  • Partner with engineering leads and security champions across product teams to prioritise and fix findings.
  • Review security-relevant designs and changes, ranking risk by what an attacker could realistically reach.
  • Track and report on application-security risk and remediation progress.

What We Need

  • 3+ years in application security or a closely related security role.
  • An AI-native approach to securing software: you already use LLMs to find, detect and explain vulnerabilities.
  • Enough fluency in at least one modern programming language to read, understand and fix vulnerable code. A software-engineering background is not required.
  • Hands-on experience with code-security tools such as GitHub Advanced Security, Snyk or Checkmarx.
  • A solid grasp of common vulnerability classes, such as the OWASP Top 10, and how to prevent them.
  • A practical, enabling style of working with engineers.

Nice to have

  • Experience building custom security tooling or automations on LLM APIs.
  • Experience securing applications on AWS, Azure or GCP.
  • Experience in insurance, financial services or another regulated SaaS environment.
