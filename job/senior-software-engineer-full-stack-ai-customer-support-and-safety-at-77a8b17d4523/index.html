About the job

We are looking for a Senior Software Engineer to build and run backend services and internal web applications for our AI teams. You will write production-grade Go, Python and TypeScript, own your services from design to on-call. You bring hands-on experience building AI agents in production: tool calling, state, reliability and observability of LLM-based systems. You will work with data scientists, backend engineers, QA and product managers.

  • Design, build and run backend services in Go and Python, and own them in production: delivery, monitoring, on-call.
  • Build and evolve backend services that run LLM-based agents: tool calling, MCP integrations, structured output, conversation state and guardrails in code.
  • Build internal web applications in React and TypeScript, from simple admin pages to complex interactive interfaces.
  • Support and develop existing production services together with the team: reviews, on-call, fixes and new features.
  • Design data models and APIs for configuration-heavy products, with attention to consistency, history and safe changes.
  • Integrate services with the wider backend: sync (HTTP, gRPC, GraphQL) and async (Kafka) communication, built for reliability.
  • Build observability end to end: metrics, logs, dashboards, tracing, alerting and runbooks.
  • Drive technical research and design for new features. Weigh trade-offs and write them down.
  • Take part in code and design reviews and help raise the engineering bar. Mentor engineers and hold AI-generated changes to the same review standard as human ones.
  • 5+ years of commercial software engineering, with production work on both backend and frontend. You have written production code without coding agents.
  • Strong Go: you know and have used its advanced features in production.
  • Strong Python for service code: async, typing, testing, and a modern web framework such as FastAPI.
  • Hands-on experience building and running AI agents in production
  • Strong TypeScript and React: you have built and maintained non-trivial web applications, including complex forms, editors and data visualisation.
  • Strong SQL: schema design, indexes, query optimisation and migrations. Experience with Redis or similar key-value stores.
  • Experience with sync and async service communication (HTTP, gRPC, GraphQL, Kafka), with a focus on reliability.
  • Docker, CI/CD pipelines, and working Kubernetes knowledge. Experience with AWS/GCP core services (compute, storage, networking, IAM).
  • Experience designing and running observability: metrics, logging, dashboards, tracing (Prometheus, Grafana, OpenTelemetry or similar).
  • Git workflows and code review, comfortable Linux command line, and networking basics.
  • Ability to explain a trade-off clearly to a data scientist, a product owner and an on-call engineer.
  • Experience using AI coding agents with full review of generated changes.
