What you'll be doing

Support the AI/ML squad by preparing model training datasets, executing feature engineering tasks, and assisting with prompt design and API integration for the Group's generative AI and machine learning models.

• Query, prepare, and clean model training datasets using SQL and Python (Pandas, NumPy) in Jupyter Notebooks.

• Execute basic feature engineering tasks under the guidance of senior engineers.

• Assist in prompt design and testing AI agents on the company's enterprise GenAI platform (Alia).

• Support the build and testing of generative AI features using LLM APIs and AI tools.

• Support API integration for machine learning models via REST APIs.

• Run model training and evaluation experiments, recording metrics and results.

• Assist with model monitoring, flagging performance or data quality issues to senior engineers.

• Document datasets, experiments, and observations to support reproducibility.

• Collaborate with AI/ML engineers, learning and applying engineering best practices.

What you’ll need to succeed

• Minimum 1 year of experience in data science, machine learning, or a related technical

area.

• Working proficiency in Python (Pandas, NumPy) and Jupyter Notebooks.

• Working knowledge of SQL for querying and preparing data.

• Foundational understanding of machine learning concepts, feature engineering, and model evaluation.

• Exposure to generative AI and prompt design is an advantage.

• Familiarity with cloud AI platforms (Azure AI, Google Vertex AI, AWS SageMaker) and REST APIs.

• Familiarity with AI coding assistants (e.g. Claude Code, GitHub Copilot, Cursor) is an advantage.
