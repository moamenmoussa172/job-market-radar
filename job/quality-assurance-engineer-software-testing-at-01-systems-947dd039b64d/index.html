About the job

The ideal candidate will be an experienced Quality Assurance Engineer with minimum 2 years of relevant experience.
Duties & Responsibilities
Your Responsibilities s as a QA Engineer will include, but are not limited to, the following:

  • Writing and executing test cases for server/client/database levels, Installations & configurations, data verification (database level), trouble shooting, Issue tracking, bug reporting, API testing, Security testing etc.
  • Load testing and test automation is also part of the responsibility.
  • Maintain proper communication and coordination with product developers and technical support specialists on product issues.
  • Bachelor’s Degree in Computer Science, Computer Engineering, or Information Systems.
  • Must have strong problem-solving and analytical skills
  • Must be a self-motivated person with a drive for continuous learning and improvement.
  • Must be flexible to work independently or as part of a team.
  • Excellent communication skills
  • Excellent troubleshooting skills
  • Hands-on Experience in software solution testing for web based and client server applications.
  • Good experience in SQL/Oracle scripting and understanding of database management.
  • Good knowledge in Windows/Unix/Linux operating systems
  • Candidate should have experience in one or more of the following:

- Automated testing tools Like Microsoft Playwright, Selenium, QTP, Visual Studio Test Suit etc.
- Load Testing tools like JMeter, Visual Studio Test Suit.
- Programming experience in C, C++, C#, ASP.NET, JavaScript etc.
- Hands on experience with Continuous Integration tools - Jenkins, Bit bucket, GitHub etc.

Experience/Knowledge in one more of the below will be considered as a plus:

  • Testing mobile apps.
  • API testing tools like postman, SoapUI
  • Experience in Security testing. Knowledge of network analyzer/interceptor tools like Fiddler, HTTP Analyzer.
  • Handling of XML, XSL, JSON
  • Experience in bug reporting tools like JIRA.
  • Working Knowledge in MAC iOS
  • Working experience with Xcode, Android Studio.
  • Industry certifications such as MCSD
