About this Role

We are seeking a Cloud DevOps Engineer with hands-on expertise in cloud infrastructure, container orchestration, automation, CI/CD and observability. You will independently manage and improve cloud infrastructure across development and operational environments, with particular focus on Microsoft Azure, Azure OpenAI Services, AWS, AKS/EKS, Kubernetes, networking, security and monitoring.

The role combines cloud engineering and DevOps with operational responsibilities including incident, problem, change, release and deployment management. You will work closely with development teams to automate delivery, troubleshoot complex infrastructure and application issues, improve reliability and support secure, scalable cloud environments.

What you’ll do

  • Maintain and continuously improve cloud and DevOps infrastructure, including continuous integration infrastructure, build platforms, test systems and development environments.
  • Manage cloud infrastructure end to end, including monitoring, reporting, networking, DNS and security.
  • Build and manage Kubernetes clusters, including Microsoft Azure Kubernetes Service (AKS) and Amazon Elastic Kubernetes Service (EKS), with the ability to set up clusters from scratch.
  • Set up and script cloud environments using infrastructure-as-code and automation practices.
  • Develop and maintain CI/CD pipelines using tools such as GitHub Actions and Jenkins.
  • Establish continuous delivery tooling and procedures covering build servers, automated deployment and configuration management.
  • Automate infrastructure provisioning and configuration using Terraform, Ansible and relevant cloud-native technologies such as AWS CloudFormation.
  • Support software rollouts across development, test and production environments.
  • Partner with development teams on infrastructure, scalability, security and automation requirements.
  • Configure and support Microsoft Azure OpenAI Services, including networking, firewall, API Management (APIM) and related generative AI services.
  • Configure and support APIs through the Apigee platform.
  • Monitor applications and infrastructure using tools such as Dynatrace, Instana, Grafana and Datadog.
  • Perform log analysis, including Fluentd-based logging, to identify and resolve application and infrastructure issues.
  • Apply ITIL practices across incident resolution, Incident Management, Problem Management, Change Management and deployment.
  • Perform root-cause analysis, identify known errors and coordinate corrective actions.
  • Support release and deployment activities within Unix/Linux-based environments.
  • Apply Git branching, tagging and versioning strategies across software repositories.
  • Support build and continuous integration activities using Maven and Gradle.
  • Contribute effectively within DevOps and Agile/Scrum delivery teams.

Who you are

  • You have excellent knowledge of cloud platforms and services, particularly Microsoft Azure, AWS and/or Google Cloud Platform (GCP).
  • You have hands-on experience managing cloud infrastructure and setting up monitoring and reporting.
  • You have strong expertise in DevOps, automation and CI/CD/CT practices.
  • You have hands-on experience with containers, Kubernetes and cluster creation and deployment using AKS and EKS.
  • You understand cloud networking, DNS, security and encryption.
  • You have experience with scripting languages such as Bash, Python or Ruby.
  • You have experience with Terraform, Ansible, AWS CloudFormation, GitHub Actions and/or Jenkins.
  • You understand Git branching, tagging and versioning strategies.
  • You have experience with build tools such as Maven and Gradle.
  • You have strong knowledge of observability and log analysis, with exposure to Dynatrace, Instana, Grafana, Datadog and Fluentd.
  • You understand NoSQL technologies such as Azure Cosmos DB, MongoDB and Cassandra.
  • You have practical knowledge of ITIL processes, particularly Incident Management, Problem Management, Change Management, release and deployment.
  • You have experience using ticketing and work management tools such as Remedy and Jira.
  • You have experience with configuration management and software deployment across multiple environments.
  • You understand Spring application development and the Spring Boot framework.
  • You have practical experience with Microsoft Azure OpenAI Services, networking, firewalls, Azure API Management (APIM) and related generative AI services.
  • You have a good understanding of the Apigee platform and API configuration.
  • You bring analytical troubleshooting and root-cause analysis skills, alongside a collaborative approach to problem solving.
  • You communicate clearly, work effectively within a team and navigate disagreements constructively.
  • Knowledge of Java is beneficial.
  • Microsoft Azure and/or AWS certifications are beneficial.
  • Experience working across international, multi-location teams is beneficial.
  • You are comfortable learning new technologies, working independently and focusing on measurable outcomes.
  • You understand software development and service management processes, including SDLC and ITIL, and can contribute to process improvement and innovation.
