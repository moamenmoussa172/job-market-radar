About the job

This is a fully remote job, open to people in Egypt.

About the Role

We are looking for a Mid-Level Frontend Engineer with strong experience in building scalable, customer-facing web applications using React.js and Next.js. The ideal candidate has experience working on production applications, collaborating with cross-functional teams, and writing clean, maintainable, and performant code.

Responsibilities

  • Develop and maintain modern web applications using React.js and Next.js.
  • Build responsive, reusable, and accessible UI components.
  • Collaborate with designers, backend engineers, and product teams to deliver new features.
  • Optimize application performance, Core Web Vitals, and user experience.
  • Integrate REST APIs and GraphQL services.
  • Implement state management solutions such as Redux Toolkit or TanStack Query.
  • Participate in code reviews and maintain high code quality.
  • Troubleshoot production issues and monitor application performance.
  • Contribute to frontend architecture and reusable component libraries.
  • Follow Agile development practices and participate in sprint planning.

Requirements

  • 3–5 years of frontend development experience.
  • Strong experience with React.js.
  • Good experience with Next.js.
  • Strong knowledge of JavaScript (ES6+) and TypeScript.
  • Solid understanding of HTML5, CSS3, and responsive design.
  • Experience with Tailwind CSS or Bootstrap.
  • Experience consuming REST APIs and/or GraphQL.
  • Familiarity with state management using Redux Toolkit, Redux, or TanStack Query.
  • Experience using Git.
  • Understanding of frontend architecture and reusable component design.
  • Good problem-solving and debugging skills.
  • Very Good English communication skills.
