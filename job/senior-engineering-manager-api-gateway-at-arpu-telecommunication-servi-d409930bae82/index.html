About the job

About this Role:

This role is in one of ArpuPlus’ business units, CloudCom, and will play a key role in building and scaling the API gateway layer supporting CloudCom’s telecom and Network API capabilities.

. Design and build the API gateway layer for CAMARA-style and TM Forum-aligned APIs.

· Implement routing, authentication hooks, rate limiting, throttling, request validation, and policy enforcement.

· Define gateway patterns for multi-tenancy, versioning, API lifecycle management, and high availability.

· Work with the Telecom Standards Architect to translate API standards into deployable services.

· Guide backend engineers on API design, OpenAPI specifications, and platform engineering practices.

· Evaluate and integrate gateway technologies such as Kong, Apigee, Tyk, NGINX, Envoy, or similar.

· Support performance tuning, scalability, and resilience of the platform.

Requirements

  • Bachelor's degree in computer science or any other related field.
  • More than 10 years of experience in the related field
  • Strong backend engineering experience with API platforms or gateway technologies.
  • Experience with REST APIs, OpenAPI, OAuth2, OIDC, mTLS, and API security.
  • Strong cloud-native experience, preferably Kubernetes and microservices.
  • Experience building highly available, production-grade platforms.
  • Telecom, fintech, cloud platform, or identity platform experience is a strong plus.
