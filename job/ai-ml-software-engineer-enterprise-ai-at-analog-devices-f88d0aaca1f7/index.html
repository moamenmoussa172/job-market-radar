AI/ML Software Engineer - Enterprise AI

About the role

Join the Enterprise AI team to build and run production LLM and agentic systems that serve ADI customers and internal teams, such as agents for customer support, product marketing and market intelligence. You will work on individual products and on shared platform components.

Responsibilities

- Build and operate LLM-powered services and multi-step agents, covering retrieval, tool use, orchestration and guardrails

- Build and maintain evaluation pipelines (golden datasets, LLM-as-judge, regression tests) so that prompt, model and retrieval changes are measured, not guessed

- Improve retrieval quality over technical content using hybrid search, embeddings, reranking and query understanding

- Help run these systems in production, managing latency, token cost, rate limits, model failover and observability

- Apply security and responsible-AI practices, including prompt-injection defences, least-privilege tool access and data-handling controls, and support architecture and RAI reviews

- Work with product managers, UX designers and engineers to turn requirements into working solutions

- Contribute to reusable platform components and shared services used across teams

- Take part in code review, architecture discussion and technical planning

- Keep up with how the field is moving (models, agent frameworks, protocols such as MCP) and share what is worth adopting

Required

- Bachelor's or Master's degree in Computer Science, Engineering or a related field, or equivalent experience

- 2+ years of software engineering experience, including hands-on work building LLM-based applications (RAG, prompt engineering, agentic workflows)

- Strong Python, with good engineering practice (testing, code review, CI/CD, version control)

- Familiarity with agent and orchestration frameworks such as LangGraph, LangChain or LlamaIndex, and with tool or function calling

- Experience evaluating LLM outputs

- Experience with a major cloud platform (Azure, AWS or GCP) and its managed AI services (for example Azure AI Foundry/OpenAI, AWS Bedrock, Vertex)

- Experience with relational and vector databases (PostgreSQL/pgvector, OpenSearch, Azure AI Search)

- Docker, and an understanding of microservice or serverless architectures

- Strong analytical, problem-solving and communication skills

Preferred

- Experience running LLM systems in production

- Experience with MCP and similar protocols

- Kubernetes

- Observability and product analytics (PostHog)

- Classical ML (PyTorch, scikit-learn) for ranking, classification or embeddings

- Semiconductor industry experience
