About the job

This is a fully remote job, open to people in United Kingdom.

At Amazon, we're working to be the most customer-centric company on earth. To get there, we need exceptionally talented, bright, and driven people. If you'd like to help us build the place to find and buy anything online, this is your chance to make history.
Protective Services Global Events (PSGE) is responsible for the safety and security of Amazon's global events portfolio. We are seeking an experienced Event Security Manager to lead security planning, operations, and execution for large-scale events. This role requires a security professional who can assess risk, develop mitigation strategies, manage vendor relationships, and deliver seamless security experiences for VIPs, attendees, and staff. The ideal candidate thrives in ambiguous, fast-paced environments and demonstrates a bias for action while maintaining the highest security standards.
Key job responsibilities
• Lead end-to-end security planning and execution for large-scale events, including advance work, on-site operations, and after-action reviews.
• Provide guard force management and oversight across multiple event sites and venues.
• Identify, assess, and manage emerging threats specific to event environments.
• Develop and implement VIP security protocols, ensuring a professional and low-profile security presence.
• Manage the deployment and quality of physical security measures, including access control, screening, and crowd management.
• Lead planning and execution of security vendor service level agreements, key performance indicators, and contractual obligations.
• Conduct security risk assessments for event venues and develop tailored mitigation plans.
• Manage security incidents, conduct post-event reviews, and implement corrective actions.
• Interface regularly with security vendors, law enforcement, and venue security teams.
• Develop security awareness briefings and training programs for event staff and stakeholders.
• Build and foster professional relationships with internal partners and external security professionals.
• Manage event security budgets, financial reviews, and resource allocation.
• Create and distribute security-related communications across cross-functional teams.
• Identify opportunities to improve security processes, dive deep into data, and implement scalable solutions.
