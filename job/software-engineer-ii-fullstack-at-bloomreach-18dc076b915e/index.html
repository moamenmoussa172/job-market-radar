About the job

About the Team: Dashboard Team

The Dashboard Team is responsible for building and evolving the customer-facing applications that power the Bloomreach platform. We create intuitive, reliable, and scalable user interfaces that enable customers to configure, manage, and optimize their search and merchandising experiences.

Our team owns the dashboards that customers use every day to understand how Bloomreach is delivering value to their business. This includes merchandising and search configuration tools, analytics and insights dashboards, and reporting experiences that help customers measure performance, understand shopper behavior, and make data-driven decisions to improve product discovery and business outcomes.

Working across React.js, Java Spring Boot, and Python, we build full-stack solutions that combine rich user experiences with scalable backend services and data pipelines, enabling customers to get the most out of the Bloomreach platform.

The Role

As a Full Stack Software Engineer II on the Dashboard Team, you will build and maintain the customer-facing applications that power Bloomreach's search, merchandising, and analytics experiences. You'll work across the stack, developing intuitive React-based user interfaces, scalable Spring Boot APIs, and Python-based data processing services that enable customers to configure, monitor, and optimize their search experience.

You'll collaborate closely with Product, Design, and fellow engineers to deliver reliable, performant, and user-friendly features used by customers every day.

What You'll Do

  • Design, build, and maintain customer-facing dashboard features using React.js, Java Spring Boot, and Python.
  • Develop intuitive, responsive, and performant user interfaces for search, merchandising, and analytics workflows.
  • Build scalable backend services and REST APIs using Spring Boot.
  • Develop and maintain Python services and data pipelines that power customer insights and dashboard analytics.
  • Collaborate with Product, Design, and Engineering teams to translate product requirements into high-quality software.
  • Write clean, maintainable, and well-tested code following engineering best practices.
  • Participate in design discussions, code reviews, and technical planning.
  • Monitor production systems, troubleshoot issues, and contribute to improving system reliability and performance.
  • Continuously improve developer productivity, code quality, and application performance.

What You'll Bring

Technical Skills & Experience

  • 3–6 years of professional software development experience.
  • Strong programming experience in Java, with hands-on experience building backend applications using Spring Boot.
  • Experience building modern web applications using React.js, JavaScript/TypeScript, HTML, and CSS.
  • Experience developing RESTful APIs and integrating frontend applications with backend services.
  • Experience writing Python applications or services for automation, data processing, or backend development.
  • Good understanding of relational databases and SQL.
  • Familiarity with cloud platforms such as AWS or GCP.
  • Experience with Git, CI/CD pipelines, automated testing, and modern software development practices.
  • Familiarity with container technologies such as Docker and Kubernetes is a plus.

Engineering Mindset

  • Strong problem-solving and debugging skills.
  • Passion for building high-quality customer-facing products.
  • Ability to work effectively in a collaborative, agile environment.
  • Strong communication skills and willingness to learn from peers.
  • Ownership mindset with the ability to independently drive features to completion.

What Success Looks Like in the First 30/60/90 Days

First 30 Days: Learn & Ramp Up

  • Team & Product Understanding: Build a strong understanding of the Dashboard team's mission, development processes, and engineering practices. Become familiar with the customer workflows around search, merchandising, and analytics dashboards.
  • Technical Onboarding: Set up your development environment, understand the architecture of our React, Spring Boot, and Python services, and learn how the different components interact.
  • Build Relationships: Collaborate with teammates, actively participate in design discussions and code reviews, and become comfortable with the team's development and release processes.
  • First Contribution: Successfully deliver your first production change, such as a bug fix or a small feature enhancement.

First 60 Days: Build & Own

  • Feature Ownership: Independently deliver medium-sized features across the frontend and backend, taking ownership from design through production deployment.
  • Technical Proficiency: Develop a solid understanding of the Dashboard platform, APIs, and data pipelines that power customer-facing analytics and configuration experiences.
  • Operational Excellence: Participate in production support, investigate issues, and contribute to improving application reliability, performance, and code quality.
  • Collaboration: Work closely with Product, Design, and Engineering teams to refine requirements and deliver high-quality user experiences.

First 90 Days: Deliver Impact

  • End-to-End Ownership: Lead the implementation of a significant feature or enhancement, collaborating with stakeholders and ensuring a smooth production rollout.
  • Technical Contributions: Proactively identify opportunities to improve application performance, developer experience, system reliability, or maintainability, and help drive those improvements.
  • Engineering Excellence: Become a trusted contributor through thoughtful code reviews, technical discussions, and by sharing knowledge with the team.
  • Customer Focus: Demonstrate a strong understanding of customer needs by building features that improve usability, performance, and the overall dashboard experience.
