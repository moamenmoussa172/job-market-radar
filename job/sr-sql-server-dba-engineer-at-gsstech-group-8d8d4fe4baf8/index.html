About the job

We are looking for a highly experienced Senior SQL Server DBA Engineer with strong expertise in Microsoft SQL Server Administration, Database DevOps, High Availability (HA), Disaster Recovery (DR), and database automation. The ideal candidate will be responsible for designing, administering, optimizing, securing, and automating enterprise-scale SQL Server environments while ensuring high availability, reliability, performance, and operational excellence across mission-critical platforms.

The role requires strong hands-on experience with SQL Server administration, database infrastructure, automation, cloud platforms, and modern DevOps practices in large enterprise environments.

Requirements

Key Responsibilities

  • Administer, monitor, and maintain enterprise Microsoft SQL Server environments.
  • Design, implement, and support highly available and disaster recovery database solutions.
  • Automate SQL Server administration tasks including provisioning, patching, upgrades, deployments, backups, and health checks.
  • Perform SQL Server installation, configuration, patching, upgrades, and migrations across enterprise environments.
  • Design, implement, and manage High Availability (HA) and Disaster Recovery (DR) architectures.
  • Configure and administer SQL Server Always On Availability Groups (AG), Distributed Availability Groups (DAG), SQL Clustering, Replication, Mirroring, and Windows Failover Clusters.
  • Perform database performance tuning, query optimization, and troubleshooting for mission-critical applications.
  • Analyze execution plans and optimize SQL queries using Query Store, SQL Profiler, and other SQL Server performance tools.
  • Manage database backup, restore, recovery strategies, and disaster recovery testing.
  • Implement SQL Server security best practices including Auditing, TLS encryption, authentication, authorization, and compliance controls.
  • Plan and execute database migration and upgrade activities with minimal downtime.
  • Collaborate with infrastructure, application, cloud, and DevOps teams to deliver highly available database platforms.
  • Support Agile delivery teams and participate in release planning, deployment activities, and production support.
  • Maintain database documentation, operational procedures, and platform standards.
  • Troubleshoot complex production incidents and proactively improve database reliability and operational efficiency.
