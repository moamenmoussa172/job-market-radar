About the job

NICE is looking for a talented Cloud DevOps & Applications Operations Engineer interested in delivering the latest in Application Operations (SaaS) using AWS

At NiCE, we don't limit our challenges. We challenge our limits. Always. We're seeking highly skilled DevOps to build and operate end-to-end IaC in AWS for our product portfolio. The ideal candidate is comfortable across the entire stack — from responsive front-end interfaces and robust back-end services to databases, networking, and cloud deployment.

As a DevOps application engineer you will be responsible to design scalable APIs and data models, automate infrastructure and deployments, and collaborate closely with development, product support, and operations teams to deliver secure, reliable, high-performing software in the NiCE Cloud.

How will you make an impact?

  • Programing skills: Design and build responsive front-end interfaces and scalable back-end services and APIs, delivering features end to end.
  • Cloud Management: Leverage AWS services (EC2, IAM, RDS, S3, EBS, CloudWatch) to design and manage application infrastructure, ensuring high availability, security, and performance.
  • Infrastructure Automation: Implement and manage infrastructure as code using Terraform, and containerized workloads using Kubernetes and Helm for scalable, reliable deployments.
  • Database Engineering: Design, deploy, and optimize relational databases such as PostgreSQL, Oracle, MySQL, or Aurora (including AWS RDS); write and tune queries, manage backups, and resolve performance issues.
  • Scripting & Automation: Write and maintain Python (and PowerShell/Perl where relevant) scripts to automate build, deployment, and operational tasks, integrating tools and services.
  • Configuration Management: Use Ansible to automate configuration management, software deployment, and orchestration across environments.
  • Monitoring & Troubleshooting: Implement monitoring and logging (e.g. CloudWatch) to ensure the health of applications and infrastructure, and troubleshoot issues across the stack as they arise.
  • Networking & Security Awareness: Apply a working understanding of IP networking, TCP/IP, VPN, firewalls, and SSL to build and secure cloud-hosted applications.
  • Collaboration: Work closely with development, product support, and operations teams to ensure smooth deployment and operation of applications.
  • Security Compliance: Ensure that application code, infrastructure, and deployment processes comply with industry security standards and best practices.
  • 5+ years of total experience, with 3+ years of hands-on DevOps & IaC (and/or other major languages such as python, c# JavaScript/TypeScript, Java, or Perl).
  • Proven experience building full stack web applications — front-end frameworks plus back-end services and RESTful APIs.
  • In-depth knowledge of AWS services and best practices for cloud architecture and management.
  • Experience managing AWS infrastructure using Terraform (infrastructure as code).
  • Experience with Kubernetes for container orchestration and container deployments using Helm.
  • Application deployment and configuration management using Ansible.
  • Hands-on experience with relational databases (PostgreSQL, Oracle, MySQL, SQL Server, or Aurora) and AWS RDS, including backups, restores, and performance tuning.
  • Strong knowledge of Linux/Unix systems (RHEL, Amazon Linux); Windows server familiarity is a plus.
  • Working understanding of networking and security concepts (TCP/IP, VPN/IPSec, firewalls, SSL) for cloud-hosted, multi-tenant architectures.
  • Experience providing 24x7 support to production SaaS infrastructure, including on-call rotation and out-of-hours support when needed.
  • Understanding of ITIL processes — incidents, service requests, and change management.
  • B.E/B.Tech/M.Tech/M.Sc. in Computer Science, IT, or a related engineering discipline, or equivalent experience.
  • Certifications such as AWS Certified DevOps Engineer or Certified Kubernetes Administrator (CKA) are a strong plus.
  • Proven ability to learn new technologies quickly and work effectively within a distributed, global team.
  • Detail-oriented and task-driven, with excellent communication skills and a strong customer-service focus.
  • Ability to work in a high-pressure, highly flexible environment against both short- and long-term objectives.

All your information will be kept confidential according to EEO guidelines.
