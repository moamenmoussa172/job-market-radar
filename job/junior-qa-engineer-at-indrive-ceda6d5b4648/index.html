About the job

The QA Operations team at inDrive is looking for a Junior QA Engineer who is passionate about quality and eager to develop their skills in a fast-paced, global environment. You'll become part of a collaborative team focused on building reliable and seamless experiences for our users

Responsibilities

  • Run regression test cases;
  • Report found bugs;
  • Correct test cases;
  • Write test cases and other test documentation;
  • Communicate with people within and outside the team.

Requirements

  • Have basic knowledge of testing theory.
  • Test design, writing test cases and checklists, creating bug reports.
  • Understand the principles of client server applications.
  • Have practical experience in testing mobile applications on Android and iOS.
  • Use emulators/simulators, intercept traffic Charles/Proxyman etc, understand the specifics of testing for different OS, take logs from real devices.
  • Test the backend. Send and read API requests Postman etc, work with databases CRUD, know the basic commands of bash/zsh.
