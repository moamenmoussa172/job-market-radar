About the job

About Vercel:

Vercel is the agentic infrastructure company, freeing people and agents to ship what's next. For more than a decade we've helped builders move from idea to production with speed, security, and exceptional developer experience.

Now we're scaling our products for both agents and people to ship and run software, built in the open and trusted by OpenAI, PayPal, Ramp, Supreme, and millions of developers worldwide.

About the role

We're looking for a Software Engineer to join the Next.js team. In this role, you'll work on the core of the framework, collaborating directly with the open-source community, shaping the future of the web, and delivering impactful features to a global audience of developers.

Our team is responsible for advancing Next.js and its ecosystem, enabling developers to build faster, more scalable, and more performant applications. If you’re passionate about web standards, open source, and developer experience, you’ll thrive here.

You’ll work on challenges such as server rendering, routing, bundling, performance optimizations, and integrating emerging web standards – all while ensuring the framework remains intuitive and stable.

What you'll do

  • Design and implement core features in Next.js, from RFC to release
  • Collaborate with internal teams (like Vercel’s platform and runtime teams) to build seamless integrations between framework and infrastructure
  • Engage with the open-source community through issues, PRs, RFCs, and discussions
  • Optimize performance across the full stack – from server to browser to edge
  • Stay up-to-date with emerging web standards (e.g., React Server Components, Partial Prerendering, Web Streams)
  • Contribute to developer tooling, docs, and examples that help others succeed with Next.js

What you need

  • Strong experience in JavaScript, TypeScript, and React
  • Deep understanding of web fundamentals: HTML, CSS, HTTP, rendering models, caching
  • Experience building production-grade web applications or frameworks
  • Familiarity with build tools (e.g., Webpack, Turbopack, Babel, SWC, or similar)
  • A collaborative mindset and clear communication – especially when working in public/open-source

Why Vercel:

  • Work on one of the most widely used web frameworks in the world
  • Collaborate with the team behind Next.js, Turbopack, and other open-source tools
    Fast-moving, developer-focused culture with autonomy and ownership
  • Competitive compensation, equity, and benefits (remote-first team, generous PTO, learning stipends)

Benefits & Compensation:

  • Competitive compensation package, including equity.
  • Inclusive Healthcare Package.
  • Learn and Grow - we provide mentorship and send you to events that help you build your network and skills.
  • Flexible Time Off.
  • We will provide you the gear you need to do your role, and a WFH budget for you to outfit your space as needed.

The San Francisco, CA base pay range for this role is $196,000-$294,000. Actual salary will be based on job-related skills, experience, and location. Compensation outside of San Francisco may be adjusted based on employee location, and the total package includes benefits and equity-based compensation.
