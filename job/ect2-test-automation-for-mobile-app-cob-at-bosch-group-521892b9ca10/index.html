About the job

Tasks / Responsibilities:

  • A skilled Automation Tester for mobile and web applications, with strong expertise in Robot Framework.
  • The role involves designing, developing, and maintaining automated test scripts for iOS and Android mobile applications using Robot Framework with Appium, XCUI Test, and UI Automator, as well as web application automation using Robot Framework with Selenium.
  • The ideal candidate should also have working knowledge of Playwright.
  • The role requires experience in testing applications that interact with embedded devices, firmware, or hardware systems, and the ability to implement robust automation solutions across mobile and web platforms.

Expected skill set:

  • Strong hands-on experience with Robot Framework using Appium and Selenium.
  • Hands-on experience in setting up and managing test environments using Android Studio and Xcode IDEs.
  • Proficiency in working with macOS and Linux, including command-line operations.·
  • Experience in preparing and executing test strategies, test plans, and test specifications using Jira and Xray. Ability to integrate automation test suites with CI/CD pipelines.
  • Experience in UI and API test automation using Robot Framework.
  • Strong knowledge of mobile element locators (XPath, Accessibility ID, ID, ClassName).
  • Hands-on experience with Android Studio, Xcode, emulators, simulators, and real devices.
  • Working knowledge of Appium Inspector, Desired Capabilities, and Appium drivers.
  • Ability to analyze test results, ensure proper reporting, and maintain adequate test coverage.
  • Experience in maintaining test data, test environments, and automation frameworks.
  • Strong communication skills.

Added advantage / Good to Have Skills:

  • Knowledge on AWS Serverless architecture with AWS API Gateway, AWS Lambda, S3 would be an added advantage.
  • ISTQB or any other relevant certifications in testing would be an added advantage
  • Experience in Playwright test automation.
  • B.E/B.Tech Computer science or similar
  • 5 to 8 years
