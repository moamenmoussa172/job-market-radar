About the Role
We're looking for a Cloud SDET Engineer II to join the team building CrowdStrike's AI Gateway. The gateway provides a common way for applications to access AI models across AWS, Azure, Google Cloud, and other providers, handling authentication, routing, usage controls, and the differences between provider APIs.

You'll build the test frameworks, tools, and automation needed to validate the gateway across real cloud environments. This includes testing provider integrations, API compatibility, streaming, performance, and failure scenarios.

This is a coding-heavy role. You'll work directly with backend engineers, investigate problems across services and cloud providers, and help ensure new functionality can be reliably tested and shipped without depending on manual regression testing.

What You'll Do

  • Design, build, and maintain automated test frameworks for our AI Gateway, backend services, and cloud integrations.
  • Develop end-to-end, integration, API, and regression tests covering gateway functionality across multiple AI providers.
  • Test integrations with AWS Bedrock, Azure OpenAI, Google Vertex AI, OpenAI, Anthropic, and other model providers.
  • Automate cloud authentication scenarios involving API keys, IAM roles, role assumption, service accounts, and identity federation.
  • Validate AI API behavior, including streaming responses, tool calling, embeddings, multimodal requests, and provider-specific error handling.
  • Test gateway functionality such as routing, retries, failover, rate limits, quotas, budgets, authentication, authorization, and usage metering.
  • Build reusable test utilities, provider mocks, simulators, and automated cloud test environments.
  • Develop performance, load, and resilience tests, including provider outages, throttling, timeouts, network failures, and partial responses.
  • Integrate automated tests into CI/CD pipelines, improve test reliability, and reduce feedback time for developers.
  • Investigate defects using logs, metrics, traces, and source code, and turn production issues into automated regression tests.
  • Work closely with software engineers on feature design, testability, and quality throughout the development lifecycle.

What You'll Need

  • 2+ years of experience in software development, SDET, test automation, or a similar engineering role.
  • Strong programming skills in Go, Python, Java, or another modern programming language.
  • Hands-on experience developing automated testing frameworks and tools, beyond writing individual test cases.
  • Experience testing backend services, REST APIs, and integrations between distributed systems.
  • Good understanding of HTTP, JSON, networking fundamentals, authentication, and common failure scenarios.
  • Comfortable working with Linux, Git, Docker, and debugging tools.
  • Ability to read production code, investigate failures across services, and identify root causes.
  • Solid understanding of test design, regression testing, negative testing, and automated integration testing.
  • Ability to work independently on assigned features and collaborate effectively with other engineers.

Bonus Points:

  • Experience with Go for backend development or test automation.
  • Experience testing API gateways, proxies, microservices, or cloud infrastructure platforms.
  • Familiarity with LLM APIs and providers such as AWS Bedrock, Azure OpenAI, Google Vertex AI, OpenAI, or Anthropic.
  • Experience testing streaming protocols such as Server-Sent Events (SSE), WebSockets, or gRPC.
  • Experience with performance and load-testing tools such as k6, Locust, or JMeter.
  • Familiarity with OAuth/OIDC, IAM, RBAC, SSO, and enterprise identity systems.
  • Experience with OpenTelemetry, Prometheus, Grafana, or distributed tracing.
  • Experience testing multi-tenant SaaS applications, rate limiting, quotas, or usage-based billing systems.
