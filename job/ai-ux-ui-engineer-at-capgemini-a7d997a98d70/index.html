About the job

Own the design and implementation of the Wireframe Vibecoding Track: the capability that turns design intent into interactive wireframes and vibecoded UX components deployed directly into the client's Box & Tree MFE shell, feeding downstream into the SAFe decomposition pipeline (Story/Gherkin generation).

This is a hybrid design/engineering role delivered as part of Capgemini's engagement. Wireframes here are intermediate artifacts in a code-generation pipeline, not visual deliverables — the person needs to be credible on both sides of that seam.

Responsibilities

  • Design and build the wireframe generation and vibecoding workflow end to end, from intent capture through component output into the UI shell
  • Curate the client's enterprise design system into a machine-consumable form the agent can encode and enforce — components, tokens, interaction patterns, accessibility rules
  • Establish Storybook as the canonical artifact and visual review surface
  • Define the human-in-the-loop review model: what UX approves, at what fidelity, with what confidence signals
  • Partner with the client's UX team as both stakeholders and end users; partner with delivery partners on scope alignment within SOW as applicable

Nice to Have

  • Prior work turning design systems into agent context

Insurance or regulated-industry experience

Requirements

  • 8+ years across UX engineering / design systems / frontend, with production ownership of a design system at enterprise scale
  • Strong React and modern frontend; able to ship components, not just specs
  • Hands-on with AI-assisted design and code-gen tooling — Claude Code, Claude Design, Figma Make, Stitch, v0, or equivalent — with a real point of view on where each breaks down
  • Storybook, component-driven development, and MFE/micro-frontend integration
  • Accessibility depth (WCAG 2.1 AA) and the ability to encode it as agent constraints rather than manual review
  • Comfort working in a governed environment (TGB/ARB/AI Council review paths)
