About the job

Roles & Responsibilities :
We’re looking for a Senior Flutter Developer who builds with AI coding agents every day. You’ll help shape modular, high performance and secure apps that patients and clinicians use with connected medical devices. AI speeds up your scaffolding, testing and documentation, so your own time goes into architecture, verification and patient safety. You use AI heavily, but you own and can explain every line that ships.

You’ll work in a collaborative, design driven, regulated (MedTech) environment alongside stakeholders, designers, architects, regulatory and QA teams. As a senior team member, you’ll take full ownership of your work from architecture to delivery and help shape our mobile platform.

Educational qualification: B.E/B.Tech

Experience : 5-6 years

Mandatory/requires Skills :
· Build and maintain features in a modular, feature-first Flutter codebase (Dart 3) targeting iOS and Android.

· Implement state management and dependency injection with Riverpod (codegen), and immutable data models with Freezed.

· Implement navigation with go_router, including shell routes, deep linking, and typed navigation.

· Develop reliable BLE communication flows with connected medical devices, including pairing, reconnection, and background handling.

· Integrate with backend services (REST and/or GraphQL, Backend-for-Frontend architecture) using Dio and/or a GraphQL client, with code generation for types and clients.

· Implement secure authentication with a managed identity provider (e.g., Auth0) using OIDC/OAuth 2.0 with PKCE, including multi-organisation access and JWT-based authorisation.

· Integrate native SDKs via platform channels where needed (e.g., real time communication or telehealth SDKs).

· Implement offline first data handling and local persistence (e.g., Drift or another SQLite-based solution) with sync to the backend.

· Ensure error handling and performance optimisation: efficient rebuilds, lazy loading, deferred components, and app size control.

· Use AI agents to automate routine work, including:

o Feature, screen and widget scaffolding, Riverpod providers, and Freezed/json_serializable models from API specs

o Test coverage gap analysis and test generation (widget, golden, integration)

o Code review feedback and PR descriptions

o Bug and crash triage from logs and crash reports

o Accessibility checks and fixes (Semantics, text scaling, contrast)

o Localisation (ARB generation and translation workflow)

Migrate existing apps to Flutter from other cross-platform or native stacks using AI assisted conversion

Preferred Skills :
· AI in a regulated SDLC: Using AI tools within our Quality Management System (IEC 62304 / ISO 13485). Every AI generated change is reviewed by a human, traceable to requirements, and covered by verification tests. No patient data, PHI or customer-confidential material goes into prompts or external tools

· Prompt and context engineering: Giving AI agents the right context (codebase conventions, specs, constraints) and refining prompts until they produce correct, idiomatic Dart/Flutter code, then reviewing the result to production standard.

· Claude Code (preferred): Hands on use of Claude Code or a comparable agentic coding CLI for coding, refactoring, debugging and documentation. This includes project context files (e.g., CLAUDE.md), custom commands and skills, subagents, hooks and MCP servers.

· Model selection: Picking the right model for the task by weighing capability, speed and cost.

· Other AI coding tools: Working knowledge of at least one other AI assisted tool, such as GitHub Copilot, OpenAI Codex, Cursor or Windsurf.

· Agentic Workflows: Breaking features into well scoped tasks for AI agents, with clear context, guardrails and validation, then reviewing the output until it meets production standards

· AI-Driven Testing: Using LLMs to generate unit, widget, golden, and integration tests, mocks, and edge case scenarios

· Documentation Automation: Using AI to maintain real time documentation, API contracts, and architectural decision records (ADRs)

Experience:

Must have:

  • 5+ years in mobile development, including 4+ years shipping production Flutter apps to the App Store and Google Play (signing, environments, TestFlight / Play Console tracks)
  • Deep Dart 3 and Flutter knowledge: sealed classes, records, pattern matching, isolates; widget/element/render trees, rebuild optimisation, profiling with DevTools
  • Riverpod (including codegen), Freezed and go_router in production
  • Designed or maintained a modular, feature-first architecture on a medium-to-large app (50+ screens) with several developers
  • Strong testing discipline: unit, widget, golden and integration tests
  • Daily use of AI coding agents (see AI section)
  • Secure mobile coding practices (OWASP MASVS, secure storage, certificate pinning)

Strongly preferred:

  • BLE or other device connectivity (e.g., flutter_blue_plus), including pairing, reconnection and background handling
  • Software delivery under IEC 62304 / ISO 13485 or a similar regulated framework

Nice to have:

  • Platform channels / FFI, with native Swift and Kotlin interop
  • Offline-first data with local persistence and sync
  • OIDC/OAuth 2.0 authentication flows
  • Migrating apps from other stacks to Flutter
  • Tooling: FVM, Melos / Dart pub workspaces, Sentry, Fastlane, Azure DevOps or GitHub Actions

Soft Skills

· Excellent verbal and written communication skills

· Self-driven and highly autonomous : you thrive with minimal supervision and demonstrate professionalism and accountability in all your interactions.

· Strong cross-functional collaboration experience : you've worked closely with product managers, designers, quality assurance, and other engineering teams.

· AI-First Mindset : You use AI for implementation wherever it helps, and put your own effort into architecture, review, validation and business logic.

· Mentorship : you raise the bar for the team on Flutter best practices and AI augmented workflows.
