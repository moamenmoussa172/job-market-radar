About the job

Adree a subsidiary of Master Works, bridges business and technology through innovative digital solutions. Its expertise spans Quality Assurance, Quality Control, Low-Code/No-Code development, application performance, and application lifecycle management.

We are looking for a motivated fresh graduate to join our development team as a Junior Software Developer. You will work alongside senior engineers to design, build, test, and maintain web applications using Angular on the front end and .NET on the back end, supporting digital transformation projects for clients across the Kingdom.

Key Responsibilities

• Develop and maintain responsive front-end features using Angular, TypeScript, HTML5, and CSS/SCSS.

• Build and maintain back-end services and RESTful APIs using C# and ASP.NET Core.

• Write clean, readable, and maintainable code following team standards and best practices.

• Work with SQL Server to write queries, stored procedures, and basic database designs.

• Write unit tests and fix bugs identified during testing and code reviews.

• Integrate front-end components with back-end APIs and third-party services.

• Participate in daily stand-ups, sprint planning, and code reviews in an Agile/Scrum environment.

• Prepare basic technical documentation for the features you develop.

• Use Git for version control and follow the team's branching and pull request process.

• Continuously learn new tools & technologies and take feedback from senior team members.

Requirements

• Bachelor's degree in computer science, Software Engineering, Information Technology, or a related field.

• Graduated within the last 2 years, or graduating soon (internship or graduation project experience is a plus).

• Solid understanding of programming fundamentals: OOP, data structures, and algorithms.

• Hands-on knowledge of Angular (components, services, routing, forms, RxJS) and TypeScript.

• Hands-on knowledge of C# and .NET / ASP.NET Core (Web API, MVC basics, Entity Framework Core).

• Working knowledge of SQL and relational databases (SQL Server preferred).

• Good knowledge of HTML5, CSS3, and JavaScript.

• Familiarity with Git and basic RESTful API concepts.

• Good command of English (written and spoken); Arabic is a plus.

Preferred Skills (Nice to Have)

• Exposure to Agile/Scrum, Azure DevOps, or Jira.

• Basic knowledge of unit testing frameworks (xUnit, Jasmine/Karma).

• Familiarity with Bootstrap, Angular Material, or similar UI libraries.

• Basic understanding of authentication concepts (JWT, OAuth).

• Awareness of low-code platforms (e.g., OutSystems) or cloud services (Azure).

Personal Attributes

• Strong problem-solving and analytical thinking.

• Eagerness to learn and ability to accept feedback.

• Good communication and teamwork skills.

• Attention to detail and ownership of assigned tasks.

• Ability to manage time and meet deadlines.

Location: Client Site
