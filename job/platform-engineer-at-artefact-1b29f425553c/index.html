About the job

Mission

Join the most advanced community of AI makers.

The world's leading companies run their AI on what you build. You design and run the foundations that make their applications and agents work at scale: cloud infrastructure, data platforms, delivery pipelines, model serving and the runtime that agents run on. Your work lets product teams ship safely and keeps cost, latency and security under control.

This role is for you if your users are other engineers and you care about what happens at scale.

Artefact is the trusted AI deployment team to the world's leading companies. In France, you join its Engineering department, about 300 people, in the AI Applied Engineer chapter and the Platform Engineer archetype.

Activities & Responsibilities

Who you work with

Product Engineers and AI Engineers deploy on the platforms you build. You agree with them on what they need and support them in production.
On a data platform, you own the foundation: infrastructure, security, network and compute. Context Engineers own what flows in it. You also work with the client's IT, security and cloud teams, review code with your peers and help newer colleagues.

What you do

  • Set up cloud infrastructure as code and run cloud migrations.
  • Build CI/CD pipelines, and MLOps and LLMOps tooling.
  • Build reusable deployment templates, shared services, self-service environments and engineering accelerators
  • Build the agent harness: runtime, evaluation tooling, observability.
  • Serve models and control their cost and latency.
  • Put security foundations in place: IAM, networking, secrets, agent access rights, protection against prompt injection.
  • Build connectors and MCP servers that several agents reuse.
  • Own reliability: monitoring, incident handling, cost reporting.

Required Skills

Must-haves:

  • You have built and run cloud infrastructure on Google Cloud, Azure or AWS, using infrastructure as code.
  • You set up CI/CD pipelines and containerised deployments, for example on Kubernetes.
  • You apply security basics in your daily work: IAM, network rules, secrets management.
  • You monitor what you run and take part in incident handling.
  • You write maintainable code and documentation for the engineers who use your platform.
  • You already use coding agents in your daily work and check what they produce.

Bonus, not required:

  • Data platform experience, for example on Databricks, BigQuery or Snowflake.
  • MLOps or LLMOps experience: model serving, model registry, evaluation pipelines.
  • Agent observability or LLM gateway experience: tracing, cost tracking, routing.
  • FinOps: cost reporting and optimisation.
  • AI security: agent access rights, red teaming, guardrails.
  • A cloud certification.

You don't need to tick every box to apply. If you match most must-haves and want to learn the rest, we want to hear from you.
