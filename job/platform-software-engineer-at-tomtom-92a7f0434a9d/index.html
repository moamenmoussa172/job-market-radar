About the job

The Developer Enablement & Security (DE&S) team within Platform Engineering owns the tooling that TomTom engineers use to write, build, store and secure code. This covers GitHub platform management, artifact management with JFrog Artifactory, security scanning, developer tooling and AI governance platforms. We treat internal developers as our customers and aim to make the secure path the easy path.

What you will do

  • Administer and automate GitHub Enterprise: repository settings, rulesets, access and governance across a large repository estate.
  • Operate and improve JFrog Artifactory, including repository configuration, cleanup, permissions and support for our hybrid cloud setup.
  • Replace repetitive admin work with scripts and automation using Python, Bash and REST APIs.
  • Build and maintain GitHub Actions workflows and support teams whose pipelines pull and publish packages.
  • Manage platform configuration as code with Terraform or similar tools.
  • Use AI tools to speed up automation and support work, and help developers adopt them safely in line with our AI governance approach.
  • Take ownership of well-defined platform tasks from start to finish, asking for guidance when needed.
  • Troubleshoot developer issues across DNS, TLS, proxies and authentication.
  • Write and maintain documentation and runbooks that let developers help themselves.
  • Explain platform policies clearly and work with developers to adopt them.
  • What you need
  • 2 to 5 years of experience in DevOps, platform, build or infrastructure engineering.
  • Git and GitHub: comfortable with branching, pull requests, reviews and repository settings; hands-on experience with GitHub Actions.
  • Scripting and automation: Python or Bash, with experience calling REST APIs.
  • CI/CD basics: you have built or maintained pipelines and understand how builds pull and publish packages.
  • Package ecosystems: working knowledge of at least two of Maven/Gradle, npm, PyPI, Docker and NuGet.
  • Linux and networking: you can find your way around a server and troubleshoot DNS, TLS, proxy and authentication problems.
  • Infrastructure as Code: some experience with Terraform or a similar tool, ideally for managing platform configuration.
  • AI in day-to-day work: good understanding of AI coding assistants and agents such as GitHub Copilot or Claude, and hands-on experience using them to write scripts, automate tasks, troubleshoot and document your work.
  • Nice to have
  • Cloud basics in Azure or AWS.
  • Identity basics: exposure to SSO, SAML/OIDC or SCIM.
  • Security awareness: secrets management, least privilege and dependency scanning; exposure to Black Duck, Coverity or Veracode is a plus.
  • Admin experience on a developer platform such as GitHub, GitLab, Artifactory, Nexus or Jenkins.
  • How you work
  • You write clear docs and runbooks, because platform teams depend on them.
  • You treat internal developers as customers and can explain a policy without creating friction.
  • You keep learning; you pick up new tools quickly rather than relying on knowing one specific product.
