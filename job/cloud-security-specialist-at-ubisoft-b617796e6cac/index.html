About the job

As a Cloud Security Specialist at Ubisoft Montréal, you will help development and platform teams design, build, and use cloud infrastructure securely at scale. You’ll create reusable security solutions, automate controls, and work closely with teams to make secure delivery practical.

What you’ll do

  • Develop infrastructure as code modules and reusable code libraries that help teams design, build, and use infrastructure securely at scale.
  • Partner with project teams to understand their needs and deliver practical, scalable security solutions without unnecessary friction.
  • Integrate infrastructure as code scanning and policy as code into continuous integration and continuous delivery platforms and source repositories.
  • Build secrets management patterns and help teams replace hardcoded credentials and long-lived access keys.
  • Coach development and platform teams on secure delivery practices without slowing their work.
  • Document all implemented security controls and measures.
  • Automate security assessments and reporting on the impact of security controls to support rollout and implementation.
  • Build and maintain security configuration templates and hardening standards.
  • Prototype and validate security improvements and solutions.
  • Hands-on proficiency with GitLab CI or similar tools, Terraform, and CloudFormation, including pipeline configuration and reusable modules.
  • Practical experience with Amazon Web Services (AWS).
  • Understanding of AWS Identity and Access Management (IAM), including roles, policies, OpenID Connect (OIDC) federation, and the risks of static credentials.
  • Familiarity with Checkov, tfsec, Open Policy Agent (OPA), or Trivy, including when to use each tool.
  • Knowledge of Cloud Security Posture Management (CSPM) platforms such as Tenable, Wiz, Prisma, or similar tools.
  • Proficiency in scripting and automation with Python, Bash, or Go, with an understanding of vendor application programming interfaces (APIs).
  • A collaborative approach to building trust with development teams and making security an enabler rather than a barrier.
  • Understanding of cloud networking, including virtual private clouds (VPCs), security groups, routing, private endpoints, and firewalls.
