About this Role

We are seeking an experienced PostgreSQL & MySQL Database Administrator with 6+ years of relevant PostgreSQL DBA experience and strong database administration expertise across enterprise, cloud and hybrid environments. The role covers database installation and configuration, administration, performance tuning, high availability, replication, backup and recovery, disaster recovery, security, migrations and automation.

You will work with PostgreSQL and MySQL technologies across production and non-production environments and support database reliability, scalability and performance. The role also requires knowledge of Linux, AWS/cloud infrastructure, database automation and the ability to work in a 24x7 environment.

What you’ll do

PostgreSQL Administration

  • Install, configure, administer and maintain PostgreSQL database environments.
  • Create and manage PostgreSQL databases, schemas and user access.
  • Monitor database performance and implement appropriate changes to maintain reliability and availability.
  • Perform performance tuning and SQL query optimisation.
  • Manage PostgreSQL indexes, partitioning and system catalogues.
  • Perform database backup, recovery and Point-in-Time Recovery (PITR) activities.
  • Manage transaction logs and Write-Ahead Logging (WAL).
  • Administer PostgreSQL databases in clustered and non-clustered configurations.
  • Implement and support high-availability solutions, including replication and clustering.
  • Design, implement and document disaster recovery strategies.
  • Monitor database capacity and usage and support database capacity planning.
  • Implement PostgreSQL tools including BART, EFM, PEM, BARMAN and pgBackRest.
  • Perform regular database maintenance, including VACUUM, re-indexing and archiving.
  • Use pgAdmin and other relevant PostgreSQL administration and monitoring tools.
  • Support planning, implementation and growth of AWS cloud infrastructure.
  • Develop database automation and maintenance scripts.
  • Document and administer database policies, procedures and standards.

What you’ll do

MySQL Administration

  • Install, configure, administer, upgrade, patch and maintain MySQL databases across Development, QA, UAT, Pre-Production and Production environments.
  • Manage MySQL Community, MySQL Enterprise, Percona Server, MariaDB and cloud-based MySQL platforms.
  • Perform database provisioning, deployment, cloning, migrations, refreshes and decommissioning.
  • Design and support highly available, scalable and secure database architectures.
  • Configure, administer and troubleshoot MySQL replication, including Asynchronous, Semi-Synchronous, GTID, Delayed, Multi-Source and Group Replication.
  • Administer InnoDB Cluster, ClusterSet and MySQL Router.
  • Execute failover, switchover, disaster recovery and HA/DR testing activities.
  • Monitor database health, availability, capacity and performance and proactively resolve issues.
  • Optimise SQL queries, indexes, partitions, schemas, execution plans and server configurations.
  • Troubleshoot replication issues, locking, deadlocks, resource bottlenecks, data inconsistencies and production incidents.
  • Develop and maintain backup and recovery solutions using MySQL Enterprise Backup, Percona XtraBackup, MariaBackup, mysqldump and MySQL Shell, including PITR and restore validation.
  • Manage database security, including users, roles, privileges, authentication, encryption, SSL/TLS, vulnerability remediation and compliance requirements.
  • Implement monitoring and alerting using Zabbix, Grafana, Prometheus, CloudWatch, Azure Monitor and other enterprise monitoring platforms.
  • Automate health checks, backups, deployments, patching, monitoring and other DBA activities using Shell, Python, PowerShell, Ansible and Terraform.
  • Administer cloud databases including AWS RDS, Amazon Aurora, Azure Database for MySQL Flexible Server and Google Cloud SQL, as well as hybrid and on-premises environments.
  • Support containerised and cloud-native database deployments using Docker, Podman and Kubernetes.
  • Configure and manage ProxySQL, HAProxy and MaxScale, including load balancing, connection pooling and database routing.
  • Perform cross-platform database migrations involving MySQL, MariaDB, PostgreSQL, Oracle, SQL Server and cloud database services.

Who you are

  • You have 6+ years of relevant experience as a PostgreSQL DBA.
  • You have hands-on expertise in PostgreSQL architecture, installation, configuration and database administration.
  • You understand PostgreSQL backup, recovery, PITR, WAL, replication, clustering, partitioning, indexes and system catalogues.
  • You have practical experience with PostgreSQL performance tuning and SQL query optimisation.
  • You are familiar with PostgreSQL administration tools such as pgAdmin, BART, EFM, PEM, BARMAN and pgBackRest.
  • You have experience administering MySQL and related database technologies such as MySQL Community/Enterprise, Percona Server and MariaDB.
  • You understand MySQL replication, high availability, disaster recovery and backup/recovery technologies.
  • You have experience managing databases across cloud, hybrid and/or on-premises environments.
  • You have knowledge of Linux operating systems.
  • You have experience with database automation using technologies such as Shell, Python, PowerShell, Ansible or Terraform.
  • You have knowledge of database monitoring technologies including Zabbix, Grafana, Prometheus, CloudWatch or Azure Monitor.
  • You understand database security, authentication, privileges, encryption and SSL/TLS.
  • You are comfortable supporting database services within a 24x7 environment
