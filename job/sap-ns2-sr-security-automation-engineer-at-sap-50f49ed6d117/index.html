COMPANY DESCRIPTION

SAP is the global market leader for business software and related services. SAP National Security Services Inc.® (SAP NS2®) is an independent U.S. subsidiary of SAP. At SAP NS2, we leverage best-in-breed technologies engineered by SAP to protect the lives, assets and information of Americans. We offer SAP solutions with specialized levels of security and support to meet the requirements of U.S. national security and critical infrastructure customers.

Must be a US Citizen; this position requires access to customer data. All internals must have Manager’s approval to transfer.

NS2 Security Automation Engineers provide technical leadership and guidance on security automation and secure system engineering topics to both internal and external teams and are responsible for architecting, configuring, and maintaining automation tooling and pipelines for the Enterprise Security team.

Key Responsibilities:

  • Develop and maintain infrastructure-as-code (IaC) using tools such as Terraform, Helm, or Ansible
  • Design, implement, and manage microservice system architectures on cloud platforms including Amazon EKS/ECS, Google GKE, and Azure AKS to ensure high availability, scalability, and performance
  • Implement Kubernetes security best practices, including IAM integration, secrets management, and network policies
  • Troubleshoot and resolve issues related to container orchestration, cloud networking (VPCs, load balancers), and resource allocation across cloud providers and security boundaries
  • Architect, develop, and maintain distributed, scalable logging pipelines using tools such as AWS Lambda, Kinesis, Vector, and Splunk
  • Automating builds and configurations of security tooling infrastructure using CI/CD pipeline tools such as ArgoCD, Concourse, and GitHub Actions

Minimum Qualifications:

  • BS degree in Computer Science, MIS, Computer Engineering, or 10+ years' equivalent technology experience
  • 3+ years’ experience administering Kubernetes clusters on cloud platforms
  • 3+ years’ experience building scalable security utilities and tools
  • 3+ years’ experience in host, network, and application security
  • 5+ years’ experience with web protocols and Linux/Unix tools and architecture
  • 5+ years’ hands-on experience building and administering AWS workloads

Preferred Qualifications:

  • Effective communication and collaboration skills
  • Continuous learning mindset to stay current with the tools and the rapidly evolving cyber threat landscape
  • Motivated with a positive attitude and a strong bias towards taking corrective action and providing resolutions
  • Experience using automation tools such Ansible and Terraform
  • Experience designing, implementing, or administering microservice system architectures such as Kubernetes
  • Exprerience leveraging LLMs to cond uct and validate technical work
  • Experience with CI/CD technologies
  • Expertise in log management and parsing strategies

Candidates with the following relevant certifications and experience will be given preferential consideration:

  • AWS/Azure/GCP Cloud Provider Certifications
  • CKA/CKS/CKAD
  • Prior DOD/FedRAMP experience
  • Experience with distributed log collection architectures
