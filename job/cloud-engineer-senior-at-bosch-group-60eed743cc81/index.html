About the job

Main objective of the job:

  • Deployment, configuration, management, and continuous support of secure and optimized Microsoft Azure cloud infrastructure and services, driving automation through Infrastructure as Code (IaC) to support reliable application hosting and operations.

Main attributions and responsibilities:

  • Provision, configure, and maintain Azure compute, storage, application hosting, and foundational cloud infrastructure.
  • Implement and support robust Azure networking, hybrid connectivity, strict access controls, and security configurations.
  • Support modern application deployment and container hosting utilizing Azure App Services, AKS, Container Apps, and Functions.
  • Automate infrastructure provisioning and streamline routine operations using Terraform, Bicep, PowerShell, and CI/CD pipelines.
  • Monitor system health, investigate alerts, troubleshoot infrastructure incidents, and execute operational runbooks.
  • Apply security best practices, remediate Defender for Cloud findings, and enforce RBAC and Azure Policy compliance.
  • Identify and implement optimization opportunities to improve infrastructure performance, reliability, and cloud cost efficiency.
  • Build and maintain comprehensive technical documentation, deployment procedures, and team knowledge articles.
  • Collaborate closely with architects, developers, security, and IT operations teams to deliver scalable and resilient Azure solutions.
  • University degree in Computer Science, Business Informatics or a comparable field.
  • Language: English
  • 3–5 years of dedicated, hands-on experience deploying, configuring, managing, and supporting production-grade Microsoft Azure infrastructure.
  • Solid experience hosting applications using Azure Virtual Machines, App Services, Azure Functions, and container platforms like AKS or Container Apps.
  • Practical Azure networking and security skills covering VNets, NSGs, Private Endpoints, Azure Firewalls, Load Balancers, RBAC, PIM, and Key Vault.
  • Proficiency in Infrastructure as Code (IaC) specifically using Terraform or Bicep, combined with scripting capabilities in PowerShell and Azure CLI.
  • Familiarity with Azure DevOps practices, including Git workflows, Azure Repos, Azure Pipelines, and automated cloud deployment.
  • Experience with Azure operations, including monitoring, alerting, troubleshooting, and writing KQL queries in Azure Monitor and Log Analytics.
  • Strong understanding of Azure governance frameworks, resource tagging strategies, Azure Policy, and Azure Cost Management.
