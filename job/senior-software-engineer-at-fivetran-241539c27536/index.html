About the Role

We’re looking for a Senior Software Engineer for our data pipeline service to build and work on data pipelines that moves data from various sources to data warehouses. The work is very diverse — all the way from patching software to building warehouse data writers, to optimizing the behavior of sync services operating on our global Kubernetes compute cluster.

You will be responsible for ensuring the technical excellence for your team and owned services, by contributing to the code, reviewing code, designing features and mentoring our junior colleagues.

You will understand the key values that make our product great, and implement those values in the many small decisions you make every day as a product designer.

Technologies You’ll Use

  • Java, PostgreSQL, Cloud Data Warehouses, AWS, GCP, Azure, Temporal, Grafana, Kubernetes, Docker

What You’ll Do

  • Work on core features of the product, systematic enhancements, and bug fixes
  • Write new or optimize the existing data writer platform to load data to warehouses
  • You'll be working with Cloud APIs, Datawriters, SQL DBs, SQL Warehouses, etc
  • You'll be working on the core data pipeline that moves terabytes of data from all our customer sources to data warehouses by processing data, splitting it into files formats like CSV/AVRO/Parquet, merging and loading to warehouses.
  • As a senior engineer in the team, you will own and drive features within the technology team, pitch design ideas, work closely with leads in the team to perform design reviews, and contribute directly to code.

Skills We’re Looking For

  • Strong technical and problem-solving skills with 5+ years of professional experience writing Java code in the distributed production environment
  • Experience in reliable data intensive distributed systems, with an emphasis on high-volume data management platforms that operate under strict SLAs
  • Understanding complex SQL merge queries, plans, and their best practices
  • Robust and reliable system design skills to satisfy project feature requirements and optimise the existing systems
  • Strong troubleshooting skill to debug problems with in existing code, connect the dots, come up with detailed RCA
  • Understand how to use AI code assist and coding agents to automatically generate code for features, bugs, testing, and investigation
  • Ability to use conversational AI systems (like Claude, ChatGPT, and internal chatbots) to support researching, authoring, reviewing, and synthesizing various SDLC artifacts such as TDDs, PRDs, Postmortems, Test Plans, and Proposals

Bonus Skills​

  • Experience with Data Warehouses like BigQuery, Databricks, SQL Like with exposure to their internals
  • Experience in data processing (ETL, ELT)
  • Experienced working in a cloud environment utilizing AWS, GCP, Azure, Kubernetes, Docker, BuildKite, or similar technologies.
