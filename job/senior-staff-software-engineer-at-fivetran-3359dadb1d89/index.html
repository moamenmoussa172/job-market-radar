About The Role

Fivetran is building data pipelines to power the modern data stack for thousands of companies. We're looking for a Senior Staff Software Engineer to join our Systems Engineering team and lead the engineering behind our internal AI-powered application ecosystem.

This is a high-leverage, high-visibility role with three interlocking mandates. First, you will own the development and governance of a code library and set of agent rules that will serve as the architectural foundation for multiple internal AI-enabled webapps at Fivetran. Second, you will work with stakeholders to develop, productionalize, and enhance custom apps built on this foundation. Third, you will act as a trusted advisor to engineering leadership, shaping policy and governance for how non-engineers should use AI to safely develop, productionalize, and deploy apps.

This position sits at the crossroads of software engineering, platform architecture, and AI-assisted development. You will partner closely with business stakeholders and engineering platform teams across the company, translating a fast-moving, experimental "everyone builds" culture into production software held to a high standard of security, reliability, and maintainability.

This is a full-time position based out of our Oakland, CA office. Our hybrid work model offers a blend of remote flexibility and in-person collaboration, including two days in the office each week to connect and build as a team.

Technologies You’ll Use

  • Python, TypeScript/React
  • Kubernetes, GCP Cloud SQL (PostgreSQL)
  • BigQuery data sources, Claude API, Agent SDK
  • GTM systems - Salesforce, Outreach, Gong, and Zendesk

What You’ll Do

  • Independently design and implement features and performance improvements to create highly scalable distributed data pipelines on the cloud
  • Develop, maintain, and test code
  • Conduct design and code reviews
  • Collaborate with peers, product managers, customer support, and other stakeholders to deliver the best product with high quality, performance, and scalability
  • Understand and fix challenges related to performance and scalability.
  • Participate periodically in on-call rotation
  • Participate in the hiring process
  • Mentor Junior developers
  • Make Fivetran the most reliable and secure component of our customers’ data infrastructure

Skills We’re Looking For

  • 10+ years of experience in the software industry with a passion for solving complex software engineering problems - experience designing and developing reusable libraries and experimentation platforms for backend and frontend from scratch leveraging industry best practices
  • Experience working with distributed systems and cloud security concepts
  • Demonstrated ability to write well-structured and performant code
  • Ability to independently lead software and infrastructure design to satisfy project requirements
  • Can identify design flaws in existing systems and come up with improvements
  • Experience in code reviews, design, troubleshooting and testing
  • Experience programming in an object oriented / systems language such as Java, C++, C# etc
  • Hands-on experience working with any cloud technologies(AWS, GCP, Azure) and containerization methodologies like Docker, K8s
  • Experience interacting with continuous integration tools like BuildKite
  • Knowledge of observability tools like New Relic/Grafana is a plus
  • Understand how to use AI code assist and coding agents to automatically generate code for features, bugs, testing, and investigation
  • Ability to use conversational AI systems (like Claude, ChatGPT, and internal chatbots) to support researching, authoring, reviewing, and synthesizing various SDLC artifacts such as TDDs, PRDs, Postmortems, Test Plans, and Proposals

Bonus Skills​

  • Experience in data processing (ETL, ELT) and/or cloud-based platforms
