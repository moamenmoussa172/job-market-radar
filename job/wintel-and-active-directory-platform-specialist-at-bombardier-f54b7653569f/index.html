Role overview

The Wintel & Active Directory Platform Specialist is responsible for the administration, implementation, technical evolution, and continuous improvement of the enterprise Windows Server and Active Directory platforms. The role provides senior technical expertise across Windows Server, Active Directory Domain Services, Group Policy, identity-related infrastructure, authentication services, and associated Microsoft infrastructure technologies. The role is expected to operate independently, provide technical leadership, and ensure Windows and Active Directory services are secure, resilient, scalable, performant, and aligned with enterprise technology standards.

Working closely with Infrastructure, Cloud, Network, Security, Virtualization, Application, Architecture, and project teams, the position supports complex operational issues while leading or contributing to Windows and Active Directory projects, platform modernization, migrations, upgrades, security initiatives, and technology lifecycle activities.

What are your contributions to the team?

  • Windows & Active Directory Platform Ownership: Administer and maintain enterprise Windows Server and Active Directory platforms, including domain services, domain controllers, Group Policy, DNS integration, authentication, configuration, patching, upgrades, and lifecycle management.
  • Platform Engineering & Implementation: Design, configure, implement, and validate Windows and Active Directory solutions, including new deployments, domain services, migrations, upgrades, consolidation, and integration with enterprise infrastructure.
  • Active Directory Architecture & Governance: Maintain and evolve the Active Directory structure, including forests, domains, organizational units, Group Policy, administrative delegation, service accounts, trust relationships, and associated directory services in accordance with enterprise standards.
  • Operational Reliability & Troubleshooting: Lead investigation and resolution of complex Windows and Active Directory incidents, authentication issues, Group Policy problems, performance issues, system failures, and systemic platform issues, including root-cause analysis and corrective actions.
  • Security & Resilience: Implement and maintain security controls for Windows and Active Directory environments, including privileged access, hardening, patching, auditing, configuration compliance, recovery, high availability, and alignment with cybersecurity requirements.
  • Projects, Migration & Technology Evolution: Lead or provide senior technical expertise for Windows and Active Directory projects, including server modernization, operating system upgrades, domain migrations, virtualization, cloud integration, application migrations, and platform consolidation.
  • Automation, Monitoring & Optimization: Develop and promote automation for server provisioning, configuration, patching, Group Policy management, monitoring, compliance, and routine administration using PowerShell, automation platforms, APIs, or other appropriate technologies.
  • Technical Leadership & Standards: Act as the senior Windows and Active Directory SME, provide technical guidance to Infrastructure, Cloud, Virtualization, Network, Security, and project teams, contribute to enterprise standards and technology roadmaps, and champion continuous improvement.

How to thrive in this role?

Required Qualifications

  • Bachelor degree in Computer Science, Information Technology, Systems Engineering, or a related discipline, or an equivalent combination of education and professional experience.
  • 5+ years of professional experience in Windows Server administration, Active Directory engineering, systems engineering, or related enterprise infrastructure disciplines, with demonstrated senior-level responsibility.
  • Strong hands-on experience with Windows Server and Active Directory, including domain controllers, AD DS, DNS, Group Policy, authentication, organizational structures, administrative delegation, and lifecycle management.
  • Demonstrated experience designing, implementing, upgrading, migrating, and troubleshooting complex Windows and Active Directory environments within large enterprise organizations.
  • Strong knowledge of Windows Server infrastructure technologies, including clustering, virtualization integration, file and print services, certificates, DNS, DHCP, PowerShell, and related Microsoft infrastructure services.
  • Strong understanding of Active Directory security and identity principles, including privileged access, service accounts, Group Policy security, authentication, delegation, auditing, hardening, and recovery.
  • Experience supporting Windows infrastructure across on-premises data centers, virtualized environments, and cloud/hybrid environments, preferably including Azure.
  • Working knowledge of automation and scripting, particularly PowerShell, with an understanding of configuration management, Infrastructure-as-Code, and DevOps practices.
  • Strong analytical, communication, and collaboration skills, with the ability to independently resolve complex technical issues and act as a senior technical SME across Infrastructure, Cloud, Virtualization, Network, Security, Architecture, and project teams.
  • Fluency in English and French, both written and spoken.

Preferred Qualifications

  • Strong experience with Microsoft Active Directory, Windows Server, Group Policy, DNS, DHCP, PKI, Microsoft Entra ID, and hybrid identity environments.
  • Experience with Active Directory modernization, domain consolidation, Microsoft cloud integration, Windows Server migration, and hybrid infrastructure transformation.
  • Relevant professional certifications such as Microsoft Certified: Windows Server Hybrid Administrator Associate, Azure Administrator, Azure Identity and Access Administrator, or equivalent certifications.
  • Experience developing enterprise Windows and Active Directory standards, reference architectures, security baselines, automation practices, and multi-year platform technology roadmaps.
