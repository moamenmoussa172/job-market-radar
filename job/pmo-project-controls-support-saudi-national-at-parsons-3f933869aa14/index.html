Job Description:

Parsons is seeking a Project Controls Support ( Saudi National) professional to contribute to the development and implementation of controls processes, data structures and performance reporting within the PMO project in Riyadh, KSA. The role applies practical project controls experience to schedule, cost, progress, risk and change controls and their implementation within the approved project management information system (PMIS).

Working with the Project Controls and PMIS Specialists, the position translates controls requirements into system data, workflows, reports and dashboards and participates directly in configuration, testing and implementation. Practical PMIS configuration and technical support capability is developed through supervised implementation assignments and structured knowledge transfer, with increasing responsibility for assigned system functions as competence is demonstrated.

What You'll Be Doing:

Project Controls Development

  • Contribute to the development of controls procedures, work and cost breakdown structures, project coding conventions and consistent data definitions.
  • Help establish baseline management, progress measurement, forecasting, risk and change control processes and their associated reporting requirements.
  • Develop and refine controls templates, reporting calculations and process maps, identifying opportunities to improve consistency and reduce manual handling.
  • Translate approved controls methods into practical requirements for PMIS data structures, forms, workflows and performance reports.

Schedule Cost and Performance Analysis

  • Prepare and analyse schedule, cost, progress and forecast information, identify variances and trends, and develop recommendations for review.
  • Contribute to baseline development, progress validation and assessment of change impacts under the relevant Project Controls Specialists.
  • Reconcile performance information across planning, cost and reporting tools, checking assumptions, reporting periods, coding and source data.
  • Develop and validate performance measures and reporting logic, including earned value measures where applicable to the programme.

PMIS Requirements and Configuration

  • Define functional requirements with process owners, including data fields, validation rules, workflow steps, approval routes and reporting outputs.
  • Work with the PMIS Specialists to configure project structures, cost codes, forms, templates, workflows and reports in the designated test environment.
  • Translate approved responsibilities and delegations into proposed workflow assignments and user access requirements for specialist review.
  • Implement assigned configuration changes under specialist guidance and maintain configuration specifications that support testing, troubleshooting and future changes.

Data Migration and Reporting Development

  • Prepare and validate project controls data for import, map source fields to PMIS structures and reconcile migrated information against agreed source records.
  • Support repeatable data transfers between planning, cost and reporting tools and the PMIS, working within the approved integration approach.
  • Develop and refine reports and dashboards using approved reporting tools, validating calculations, filters, data relationships and performance measures.
  • Investigate inconsistent coding, missing data and reconciliation differences, and help establish validation rules that improve data integrity.

Testing Deployment and Technical Support

  • Prepare test scenarios and expected results for controls calculations, workflows, permissions, baseline records and reporting outputs.
  • Perform functional testing and support user acceptance testing, investigate defects with the specialists and verify corrections before release.
  • Support deployment of approved configurations and diagnose functional, data and reporting issues during system operation.
  • Apply agreed system change controls and retain test evidence and configuration history; production releases and access changes follow authorised approval arrangements.

Technical Capability Development

  • Develop practical PMIS configuration skills through structured training, supervised implementation tasks and knowledge transfer from the PMIS Specialists.
  • Demonstrate the ability to configure, test, document and support assigned functions before taking on broader technical responsibility.
  • Progressively undertake configuration and technical support of assigned PMIS modules, workflows and reports in line with demonstrated competence and agreed authority.
  • Develop technical working instructions and support user training on the controls processes and system functions implemented within the role.

What Required Skills You'll Bring:

  • Bachelor’s degree or equivalent experience in business administration, project management, information systems, or a related field.
  • 5 years minimum practical experience in project controls, including planning, progress monitoring, cost control or performance reporting.
  • Knowledge of project controls principles, including baselines, variance analysis, forecasting, risk and change control.
  • Experience preparing or analysing project controls data and reports, with strong proficiency in Microsoft Excel.
  • Experience using planning, cost or reporting tools and an ability to understand data structures and relationships.
  • Ability to translate project controls processes into clear system and reporting requirements and investigate data inconsistencies.
  • Strong analytical, problem-solving, organisational and communication skills, with attention to accuracy and the ability to manage technical priorities.
  • Ability to develop and apply PMIS configuration, workflow and data management skills through practical implementation assignments.

What Required Skills You'll Bring:

  • Familiarity with using a PMIS or comparable digital project controls system.
  • Familiarity with Power BI, database queries or comparable reporting and data analysis tools.
  • Experience in earned value management, progress measurement, controls process improvement or system implementation activities.
