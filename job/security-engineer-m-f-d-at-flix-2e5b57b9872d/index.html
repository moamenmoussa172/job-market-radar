About the job

Rate: 90 – 120 PLN/hour (B2B)

We are looking for an experienced Security Engineer to join Flix on a freelance/service agreement basis (B2B contract). This is a contractor engagement for a seasoned security professional who wants to work on impactful, hands-on security challenges.

Scope of Services

Bring expertise in application, cloud, and email security to help improve Flix's security posture and security automation. Work across a cross-functional engineering environment collaborating with security engineers, infrastructure and software engineers, and business stakeholders — focusing on preventive cloud and application security, implementing and configuring client-side security applications, and responding to security incidents.

About the Engagement

  • Support IT teams to deliver on preventive security measures such as SIEM monitoring, application security reviews, cloud security reviews, or set up and configure client security tools related to email security, access management, and asset protection
  • Automate incident responses and repetitive security work with Python (SOAR automation) whenever possible to decrease the amount of manual work and free up team capacity
  • Collaborate with stakeholders across the organization to solve client security incidents such as account compromise and phishing incidents, DDoS attacks and sensitive data exposure
  • Review and assess security posture at Flix and propose concrete improvements to services, detections and response runbooks

About You

  • Experience in a wide range of security topics such as email security, phishing, endpoint protection, SIEM, WAF, cloud security, application security
  • Experience in Cloud Security and the associated services: Cloud Security Posture Management, Threat Detection, Data Protection, Identity and Access Management
  • Experience with incident response and service desk ticket response
  • Solid programming skills in Python and interest in writing clean, maintainable code for process automation
  • Solid Terraform skills and general understanding of software application architecture
  • Experience with monitoring or SIEM tools (e.g. Splunk, ElasticSearch, Datadog)
  • Fluent in English (written and spoken)

Preferred Skills:

  • Familiar with AI and how to leverage AI to safely improve or automate related processes
  • Familiar with AI Security topics and preventive measures
  • AWS SAA or AWS Certified Security – Specialty

Collaboration Model

  • Cooperation based on a service agreement (B2B/freelance contract), not an employment contract
  • You will operate as an independent contractor, responsible for delivering agreed services and submitting invoices
  • Location: open for contractors based in Poland
