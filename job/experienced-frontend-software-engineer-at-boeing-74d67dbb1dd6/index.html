About the job

Experienced Frontend Software Engineer

Company:

Boeing Poland sp. z o.o. EFS

An exciting opportunity has become available to join Boeing Poland sp. z o.o. as an Experienced Frontend Software Engineer based in Gdańsk, Poland.

Boeing AvionX develops and produces avionics and electronics systems designed for use on aircraft and other platforms for purposes such as navigation, flight controls, information systems, and other core avionics functions. We have set our sights high – to design, develop, and manufacture the most technically advanced and reliable avionic components in the world. We are innovating and developing new products to address the future of the urban air mobility as well as our next generation of commercial, tactical, and trainer aircraft markets.

As an Experienced Frontend Software Engineer you will join the AvionX Poland team consisting of highly skilled, high performing engineering team members supporting multiple product lines across Boeing AvionX.

Hiring details:

  • This requisition is for a locally hired position in Poland. Benefits and pay are determined at the local level and are not part of Boeing U.S. based payroll.
  • This position is hybrid. This means that the selected candidate will be required to perform some work onsite at Gdańsk office. This is at the hiring team's discretion and could potentially change in the future.

Position Responsibilities:

  • Design, implement and maintain responsive, accessible, and performant Javascript/TypeScript applications using modern frontend frameworks
  • Own end to end frontend features: design, implementation, testing, and delivery
  • Write and maintain unit and integration tests to ensure code quality and reliability
  • Perform thorough, constructive code reviews and mentor other engineers on best practices
  • Collaborate with product owners, UX designers, backend engineers and QA to deliver high quality user experiences
  • Use Git for source control and run CI/CD pipelines; follow standard branching process and merge request workflows
  • Work in container based development environments (Docker) and coordinate with OS/DevOps teams as needed
  • Stay current with web standards, browser support, and emerging web platform features; recommend pragmatic adoption strategies
  • Contribute to estimation, sprint planning, and continuous process improvement

Basic Qualifications (Required Skills/Experience):

  • 3+ years of professional frontend development experience
  • Experience with two or more JavaScript frameworks/libraries (React preferred)
  • Experience with a component library such as MUI (Material UI)
  • English proficiency

Preferred Qualifications (Desired Skills/Experience):

  • Bachelor of Science degree from an accredited course of study in engineering, engineering technology (includes manufacturing engineering technology), chemistry, physics, mathematics, data science, or computer science
  • Excellent understanding of HTML5 and CSS3
  • Solid experience with Git and code review workflows
  • Demonstrable experience writing unit and integration tests for frontend code (Vitest, Jest, Testing Library, Cypress, etc.)
  • Strong proficiency with TypeScript
  • Experience with Next.js, React ecosystem (TanStack React Query, Redux/RTK, Context, hooks), or other frameworks such as Vue or Svelte
  • Experience with containerized development and local environments using Docker
  • Knowledge of modern build tools and bundlers (Vite, Webpack) and performance optimization techniques
  • Experience with CI/CD, test automation, and observability for frontend apps
  • Understanding of security best practices for web applications (CSP, XSS mitigation, secure cookie handling)
  • Demonstrated experience mentoring peers and leading technical design discussions

Conflict of Interest:

Successful candidates for this job must satisfy the Company’s Conflict of Interest (COI) assessment process.

  • Cooperate and exchange knowledge with world class global engineering team
