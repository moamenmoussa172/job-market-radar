About the job

This is a fully remote job, open to people in India.

Job Summary

We are looking for an experienced Senior IBM Integration Developer with strong hands-on expertise in IBM API Connect and IBM DataPower to design, develop, implement and support enterprise-level integration solutions.

The ideal candidate should have extensive experience in API development, integration architecture, API security, data transformation and middleware technologies, preferably within the banking or financial services domain.

Key Responsibilities

  • Design, develop and implement enterprise integration solutions using IBM API Connect and IBM DataPower.
  • Develop, configure and manage RESTful and SOAP APIs.
  • Work on API lifecycle management, including API creation, publishing, deployment and migration.
  • Configure API security policies, including OAuth 2.0, JWT, Mutual TLS and WS-Security.
  • Develop custom policies and API logic using GatewayScript and XSLT.
  • Implement API rate limiting, authentication, authorisation and traffic management policies.
  • Configure IBM DataPower Multi-Protocol Gateway (MPG) and XML Firewall.
  • Perform XML/JSON data transformation, payload validation and message processing.
  • Work with IBM App Connect Enterprise (ACE) and IBM MQ for enterprise application integration.
  • Develop REST/JSON services and Node.js-based APIs.
  • Provide L2/L3 production support, troubleshooting and root cause analysis.
  • Monitor middleware services, analyse logs and ensure high availability of integration platforms.

Required Technical Skills

  • Strong hands-on experience with IBM API Connect (APIC).
  • Extensive experience with IBM DataPower Gateway.
  • Proficiency in GatewayScript and XSLT.
  • Strong understanding of REST, SOAP, XML and JSON.
  • Experience implementing OAuth 2.0, JWT, Mutual TLS and WS-Security.
  • Experience with IBM ACE and IBM MQ.
  • Knowledge of API management, gateway configuration and security policies.
  • Experience with Node.js and API development.
  • Familiarity with Oracle, MySQL, Git, GitHub, Postman and SoapUI.
  • Experience with API Connect migration, preferably V5 to V10.

Preferred Qualifications

  • Bachelor's degree in Computer Science, Information Technology or a related discipline.
  • Previous experience working on banking or financial services integration projects.
  • Experience supporting enterprise-scale middleware and API integration environments.

What We're Looking For

A hands-on integration specialist who can independently manage API development, middleware integration, security implementation and production support within complex enterprise banking environments.
