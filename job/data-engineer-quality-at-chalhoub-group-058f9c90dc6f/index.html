What you'll be doing

Execute automated data validation and daily data quality checks, perform data cleansing, and harmonize master data entities across e-commerce, POS, and ERP feeds to maintain high data accuracy and integrity.

• Execute automated data validation tests (e.g. dbt tests, Great Expectations, Soda) across data pipelines.

• Monitor daily data quality checks in Google BigQuery or another MPP data warehouse (e.g. Snowflake), and escalate failures and anomalies.

• Perform data profiling and data cleansing to correct errors and improve data accuracy.

• Harmonize master data entities across e-commerce, POS, and ERP feeds.

• Build and maintain data quality rules and tests using SQL, Python, and dbt.

• Support reconciliation of data discrepancies across systems under guidance.

• Support data cataloging and lineage (DataHub) and produce data quality reports and scorecards using Looker and Excel. Data & AIReports to Senior Manager, Data Governance Bengaluru

What you’ll need to succeed

• Minimum 3 years of experience in data quality or data engineering.

• Proficiency in SQL and Python, with experience in dbt and automated data validation tools (e.g. Great Expectations, Soda).

• Experience monitoring data quality in MPP cloud data warehouses (e.g. Google BigQuery, Snowflake), profiling, and performing data cleansing.

• Experience harmonizing master data across e-commerce, POS, and ERP feeds.

• Familiarity with data quality dimensions and reconciliation concepts.

• Familiarity with data cataloging (Datahub), Looker, and Excel for data quality reporting.

• Hands-on experience with AI coding assistants (e.g. Claude Code, GitHub Copilot, Cursor) for AI-assisted development.
