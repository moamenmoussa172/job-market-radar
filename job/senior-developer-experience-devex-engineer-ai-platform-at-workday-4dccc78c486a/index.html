About the Role

We are seeking a Senior DevEx Engineer to own developer productivity and authoring tooling across our enterprise AI Skills platform. In this role, you will build the internal developer platform (IDP), IDE tooling, and context-ingestion architecture that enables engineers and domain experts to build high-quality, schema-compliant AI skills effortlessly.

You will bridge the gap between AI coding assistants and enterprise platform standards - optimizing developer workflows, curating AI editor rules, and creating starter templates to ensure code natively adheres to Model Context Protocol (MCP) standards before entering CI/CD pipelines.

Key Responsibilities

  • Developer Environment & IDE Curation: Architect and maintain internal editor configurations (e.g., Cursor, VS Code) using .cursorrules, system prompts, and custom extensions to streamline AI skill authoring.
  • Local CLI & Validation Tooling: Develop local CLI utilities, linters, and pre-commit hooks that give developers instant feedback on schema correctness, formatting, and syntax before pushing code.
  • Developer Productivity Metrics: Track developer friction, template adoption, and first-pass build success rates to continuously reduce time-to-publish for new skills.
  • Tool Orchestration & Abstraction: Experience building function-calling abstractions, wrapping existing enterprise REST APIs into MCP schemas, and maintaining standard Python/TypeScript skill libraries.
  • MCP Templates & SDK Tooling: Design and distribute standard templates, boilerplate generators, and SDKs for Model Context Protocol (MCP) tool schemas and JSON-RPC skill contracts.
  • Context Ingestion & Retrieval Pipelines: Build local codebase indexing, RAG, and context-ingestion pipelines that supply AI editors with accurate, real-time platform documentation and API specifications.

About You

Basic Qualifications

  • 4+ years of professional software engineering experience building developer tools, internal platform infrastructure, CLI utilities, or IDE extensions in Python or TypeScript.
  • 2+ years designing developer platforms, SDKs, or developer experience (DevEx) infrastructure.
  • 1+ years of hands-on experience optimizing AI-assisted development workflows (e.g., Cursor, GitHub Copilot, Claude Code, or custom LLM coding extensions).
  • Bachelor's degree in Computer Science, Engineering, or a related field, or equivalent practical experience.

Other Qualifications

  • AI Coding Workflows & Rules: Hands-on experience writing .cursorrules, system prompts, or context-injection pipelines for AI code editors.
  • Schema Contracts & API Validation: Strong knowledge of schema definition standards (JSON Schema, Pydantic, OpenAPI) and API contracts.
  • Agentic Standards & MCP: Familiarity with the Model Context Protocol (MCP), tool-calling specifications, or agent execution harnesses.
  • Developer Experience & Tooling Rigor: Deep empathy for developer ergonomics, API design, CLI interfaces, and technical documentation.
  • Technical Communication: Excellent technical writing skills for quick-start guides, developer documentation, and architecture standards.
