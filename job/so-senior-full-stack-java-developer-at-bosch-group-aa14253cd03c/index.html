About the job

Position Overview

We are seeking a highly skilled Full-Stack Java Developer to design, build, and deploy high-performance enterprise applications. In this role, you will lead end-to-end full-stack feature development using Java Spring Boot on the backend and React on the frontend. You will play a pivotal role in modernizing cloud infrastructure on Microsoft Azure, leveraging Bicep for Infrastructure-as-Code (IaC), containerizing services with Docker, and automating deployment workflows via Azure DevOps Pipelines.

Key Responsibilities

  • Full-Stack Application Development: Architect, develop, and maintain secure, scalable RESTful microservices using Java Spring Boot and intuitive, responsive user interfaces using React.
  • Cloud Infrastructure as Code (IaC): Provision, maintain, and automate Azure cloud infrastructure using Azure Bicep templates to ensure repeatable and consistent deployment environments.
  • DevOps & Pipeline Automation: Design, build, and manage end-to-end CI/CD pipelines using Azure DevOps Pipelines for continuous integration, automated testing, and zero-downtime deployments.
  • Containerization & Deployment: Package applications using Docker and manage container workloads across Microsoft Azure cloud environments (e.g., Azure Container Apps, Azure Kubernetes Service, or Azure App Service).
  • Build & Dependency Management: Standardize and maintain build scripts, multi-module project structures, and dependency configurations using Maven.
  • Quality & Collaboration: Write robust unit/integration tests, conduct rigorous code reviews, adhere to enterprise security standards, and collaborate closely with cross-functional product teams.

Requirements & Qualifications

Technical Skills

  • Backend Core: Deep expertise in Java (Java 11/17+) and the Spring Boot ecosystem (Spring MVC, Spring Data JPA, Spring Security).
  • Frontend Core: Strong hands-on experience with modern React (Hooks, State Management, ES6+ JavaScript/TypeScript).
  • Build Tools: Advanced proficiency with Maven for build automation, lifecycle management, and dependency control.
  • Containerization: Practical experience writing Dockerfiles, multi-stage builds, and running containerized enterprise workloads.
  • Cloud & IaC: Hands-on experience provisioning and managing Azure resources using Azure Bicep (or ARM templates).
  • CI/CD: Proven track record configuring YAML-based Azure DevOps Pipelines for build, test, and release orchestration.
  • Databases: Solid understanding of relational databases (PostgreSQL, MySQL, SQL Server) and ORM frameworks (Hibernate/JPA).

Experience & Soft Skills

  • Experience: 3–5+ years of professional full-stack software development experience in an enterprise or cloud-native environment.
  • Software Engineering Practices: Strong grasp of microservices design patterns, REST API standards, and SOLID principles.
  • Problem-Solving & Communication: Analytical mindset with strong English communication skills to articulate technical architecture decisions across cross-functional teams.

Preferred Qualifications

  • Experience with cloud security, Azure Key Vault integration, and identity management (Azure AD / Entra ID).
  • Knowledge of monitoring and logging tools in Azure (Azure Monitor, Application Insights).
  • Experience working in Agile/Scrum delivery environments.
