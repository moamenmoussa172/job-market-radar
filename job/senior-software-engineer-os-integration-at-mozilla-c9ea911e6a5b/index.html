About the OS Integration team:

The OS Integration team ensures Firefox works well with the host operating system and environment. We’re a distributed team with expertise in Windows, macOS, and Linux-based operating systems. Our responsibilities include developing fixes and improvements for Firefox related to Windows, macOS, and Linux environments. This might include integration with a new OS feature or fixing an OS-specific user interface bug. Other responsibilities include native crash reporting, OS abstraction layers, sandboxing, hardening, updater, and enterprise DLP support.

About the role:

As a member of the OS Integration team, you’ll develop fixes, improvements, and new features for Firefox. In many cases work may be cross-platform or have a cross-platform component. This role will include maintenance and development of the installer and updater of Firefox. You’ll contribute to the team through code review and discussion.

What you’ll do:

  • Improve the quality of Firefox and other Mozilla products by debugging and fixing software defects, improving the browsing experience for hundreds of millions of users.
  • Contribute to new features and improvements.
  • Break down tasks and work with others to deliver solutions.
  • Collaborate with experienced software engineers.
  • Perform code reviews and provide technical direction.
  • Work with a geographically-distributed development team.
  • Interact with teams throughout the organization.

What you’ll bring:

  • 5+ years of overall software engineering experience
  • Strong knowledge of C and C++
  • Experience with desktop application development on Windows, macOS, or Linux with C++.
  • Knowledge of web technologies such as Javascript and HTML.
  • Knowledge of secure coding practices and memory safety concerns.
  • Strong problem-solving and debugging skills.
  • Written and verbal communication skills with a collaborative mindset.
  • Willingness to work effectively in a distributed team environment.
  • Commitment to our values:
  • Play to win
  • Build for People first
  • Engage Evidence over Ego
  • Decide and Deliver
  • Ship, learn and repeat

Bonus Points for experience with:

  • Installer and/or Updater development on any OS
  • Windows internals like the BITS server or MSIX packages
  • Open-source contributions or personal engineering projects
