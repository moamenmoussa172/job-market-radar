About the job

Roles & Responsibilities :
Job Description

Design, develop, integrate, and support full-stack applications, enterprise automation solutions, and system integrations across connected enterprise platforms. The role requires strong hands-on expertise in frontend/backend development, APIs, scripting, automation, and DevOps, with ServiceNow development and integration knowledge preferred, including IntegrationHub, Workflow Studio, REST APIs, and platform automation.

Full-Stack Development

  • Frontend Development: Design and develop responsive, maintainable web applications and user interfaces using JavaScript/TypeScript and modern frontend technologies such as Angular, React or similar frameworks.
  • Backend Engineering: Develop scalable backend applications, services and automation components using Java, Python, Node.js or equivalent technologies.
  • Data & Architecture: Develop database-driven, modular and reusable solutions with security, performance and scalability in mind.
  • Quality Engineering: Implement automated testing, debugging, code reviews and performance optimization

ServiceNow Development, Automation & Integration

  • Platform Development: Build scoped applications, Business Rules, Script Includes, Service Catalog components, and reusable solutions.
  • Workflow & Automation: Develop flows, subflows, scripts, and reusable automation using Workflow Studio/Flow Designer.
  • Integration Engineering: Build secure integrations using IntegrationHub, REST/SOAP and Scripted REST APIs, custom actions/spokes, and enterprise integration patterns.
  • Security & Resilience: Apply ACLs, authentication, error handling, logging, monitoring, retries, and recovery mechanisms.
  • Modernization & AI: Modernize legacy automation and leverage Now Assist, AI Agents, GenAI, and AI-enabled workflow automation where applicable.

DevOps & Production Responsibility

  • CI/CD and Source Control: Manage Git, pipelines, builds, deployments, and releases.
  • Observability: Implement logging, monitoring, diagnostics, and health checks.
  • DevOps Automation: Build automation using Python, PowerShell, Ansible, or equivalent tools.

Experience & Qualifications

  • Experience: 7-12 years of overall software development experience, with strong hands-on experience in full-stack application development, automation and enterprise integrations.
  • Frontend: Experience with JavaScript/TypeScript, HTML, CSS and modern frameworks such as Angular or React.
  • Backend: Strong development skills in at least one primary backend technology such as Java, Python or Node.js.
  • Programming & Scripting: Experience with at least two of Java, Python, PowerShell and JavaScript/TypeScript.
  • API Integration & Automation: Strong experience with REST/SOAP APIs, secure authentication, error handling, and reusable enterprise automation.
  • DevOps: Experience with Git, CI/CD, automated testing, deployment pipelines and application monitoring.
  • ServiceNow Development & Automation: Platform development, Workflow Studio, IntegrationHub, APIs, and AI-enabled automation.

Additional / Preferred Experience

  • ServiceNow Platform Experience: Experience delivering enterprise-scale, upgrade-safe ServiceNow solutions and integrations.
  • ITSM & CMDB: Exposure toITSM, Service Catalog, CMDB/CSDM, and automated fulfillment use cases.
  • AI & Intelligent Automation: Exposure to Now Assist, AI Agents, GenAI, or AI-enabled automation.
  • Containers & Cloud: Experience with Docker, Kubernetes and cloud platforms is advantageous.

Certifications

  • Relevant Java, Python, cloud, DevOps or full-stack development certification – preferred
  • Relevant Agile/DevOps or ITIL Foundation certification – preferred
  • ServiceNow Certified System Administrator (CSA) / ServiceNow Certified System Administrator (CAD) – preferred
