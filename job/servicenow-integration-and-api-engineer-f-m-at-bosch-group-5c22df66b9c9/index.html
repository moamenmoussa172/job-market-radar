About the job

Designs, develops, and maintains robust, secure, and high-performance interfaces connecting the enterprise ServiceNow platform with external systems across Bosch (SAP, Microsoft Azure/Entra ID, corporate Data Lakes, monitoring tools, and partner applications). Serves as the platform's hands-on authority for both inbound and outbound integrations, leveraging native ServiceNow capabilities including IntegrationHub, Scripted REST APIs, Flow Designer integration actions, MID Server clustering, and Service Graph Connectors. Partners with platform architects, security officers, and external system owners to ensure all data flows adhere to the "Configure First, Customize Last" principle, operate asynchronously without impacting platform performance, and comply with enterprise security and data privacy mandates.

Inbound & Outbound API Development

  • Scripted REST APIs: Design and implement custom, versioned Scripted REST APIs, enforcing strict JSON schema validation, and error handling.
  • Outbound Integrations: Configure and script outbound integrations
  • IntegrationHub & Spokes: Develop custom IntegrationHub actions, data stream actions, and spokes using Flow Designer and the ServiceNow Spoke Generator; configure and maintain out-of-the-box spokes for enterprise systems.
  • API Versioning & Deprecation: Manage API lifecycles, ensuring backward compatibility, clear deprecation notices

Enterprise Data Ingestion, ETL & Staging

  • Import Sets & Robust Transform Engine (RTE): Build and maintain high-volume Import Set tables, staging schemas, and Transform Maps; leverage the Robust Transform Engine (RTE) and Integration Commons for complex data transformation.
  • Service Graph Connectors (SGC): Implement and tune Service Graph Connectors and Integration Hub ETL (IH-ETL) to ingest external asset, inventory, and configuration data directly into CSDM 5.0 and CMDB tables via the Identification and Reconciliation Engine (IRE).

Infrastructure, MID Server & Gateway Connectivity

  • MID Server Management: Configure, monitor, and optimize MID Server clusters, capabilities, and IP ranges to ensure reliable communication with on-premises networks and restricted manufacturing domains.
  • Enterprise Gateway Alignment: Partner with corporate API Management teams (Enterprise MCP servers, Azure APIM, Apigee, or Kong) to register ServiceNow endpoints, configure rate-limiting, and enforce corporate proxy and firewall policies.

Integration Security & Governance

  • Authentication & Secrets: Implement and govern secure authentication mechanisms: OAuth 2.0 (Client Credentials, Authorization Code flows)
  • Data Sanitization & Privacy: Enforce logging hygiene, ensuring API keys, bearer tokens, passwords, and unencrypted PII

Experience & Qualifications:

  • Overall Experience: 2 to 5 years in enterprise software development or integration engineering, with at least 1 to 3 years of dedicated, hands-on integration development on the ServiceNow platform.
  • ServiceNow Integration Stack: Deep expertise in Scripted REST APIs, IntegrationHub, Flow Designer Actions, Import Sets, Transform Maps, and Connection & Credential Aliases.
  • Performance Engineering: Proven experience designing high-throughput, data ingestion pipelines
  • Tooling: Proficient with API testing and debugging tools (Postman, SoapUI, cURL, Insomnia) and version control via Git.
  • Education: Bachelor’s degree in Computer Science, Software Engineering, Information Technology, or equivalent practical experience.

Certifications:

Mandatory / Required:

  • ServiceNow Certified System Administrator (CSA).
  • ServiceNow Certified Application Developer (CAD).

Highly Desirable:

  • Micro-Certification: IntegrationHub or Flow Designer.
  • At least one CIS credential (e.g., CIS - Customer Service Management, CIS - ITSM, or CIS - Discovery).

Beneficial:

  • Cloud integration or API certification (Microsoft Azure Developer Associate, AWS Certified Developer, or MuleSoft Certified Developer).
  • ITIL 4 Foundation.
