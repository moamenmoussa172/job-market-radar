About this role

We are seeking a GCP Public Cloud DevOps Engineer to design, build, implement and operate highly available public cloud infrastructure services for internal Vodafone applications and customers. The role focuses primarily on Google Cloud Platform, cloud automation, infrastructure as code and the transformation of legacy IT environments into cloud-ready and cloud-native solutions.

You will contribute to mission-critical infrastructure services, support cloud migrations and provide Level 2 and Level 3 operational support for incidents and problems. The position requires collaboration with solution design, delivery, architecture and IT security teams across multiple technology functions. The role supports 24x7 public cloud services and is located across Europe.

What you’ll do

  • Manage project-led integrations and the day-to-day administration of cloud solutions.
  • Develop prototypes and design, build, maintain and optimise modules and solutions for cloud platforms through iterative Agile delivery.
  • Conduct peer reviews and maintain consistent coding standards.
  • Automate and integrate Google Cloud Platform services and project workloads.
  • Build and deploy GCP infrastructure using Terraform and other infrastructure-as-code approaches.
  • Use Ansible and Python to automate routine activities, including user management and security hardening.
  • Provide technical consultancy for migrating and transforming on-premises applications to public cloud environments.
  • Support cloud-related programmes and established cloud environments.
  • Design and deploy network connectivity between GCP and data centres.
  • Develop GCP knowledge and expertise across the organisation.
  • Troubleshoot cloud networking, storage and performance issues.
  • Support the adoption of DevOps culture, practices and methodologies.
  • Help maintain cloud service stability and minimise risks to production services.
  • Support Level 2 and Level 3 incident and problem management for software-related operations.

Who you are

  • You have in-depth knowledge of cloud technology, networking, security and platforms, with strong expertise in Google Cloud Platform services.
  • You have practical experience with GCP services such as Virtual Private Cloud, Compute Engine, Cloud Storage, Google Kubernetes Engine and Cloud Functions.
  • You are experienced in infrastructure automation and scripting using Terraform, Ansible and Python.
  • You have worked with DevOps technologies such as Jenkins, GoCD, Packer, Docker and Kubernetes.
  • You understand GCP organisation structures and multi-tenant project environments.
  • You can troubleshoot issues relating to cloud networking, storage and performance.
  • You understand ITIL, SOX and relevant security requirements.
  • You have three to five years of experience in programming or systems analysis using Agile frameworks.
  • You have experience with web applications, web hosting and DevOps practices in cloud environments.
  • You have worked with highly business-critical environments.
  • You communicate clearly and produce effective technical documentation.
  • You hold a degree in an IT-related discipline, with at least three years of cloud computing experience or five years of enterprise IT experience.
  • A GCP Cloud Engineer or GCP Professional Cloud Architect certification is preferred.
  • Experience or knowledge of the telecommunications industry is preferred.
  • You demonstrate open-minded, clear and solution-focused thinking, with the judgement and flexibility needed to assess technical requirements and reduce service disruption.

What's in it for you

  • The opportunity to design and operate mission-critical public cloud services within a global telecommunications environment.
  • Exposure to large-scale cloud transformation and migration programmes.
  • Practical involvement in GCP architecture, infrastructure automation, cloud networking and container platforms.
  • Collaboration with solution design, delivery, architecture and IT security teams across the organisation.
  • The opportunity to influence cloud enablement, integration and the wider adoption of DevOps practices.
  • Experience supporting highly available services with a target uptime of 99%.
  • The opportunity to contribute to cloud optimisation, service resilience and the delivery of new platform capabilities.

What skills you will learn

  • Advanced implementation and operation of Google Cloud Platform services.
  • Design and management of multi-tenant GCP environments.
  • Infrastructure-as-code delivery using Terraform and Packer.
  • Configuration management and operational automation using Ansible and Python.
  • Continuous integration and continuous delivery using Jenkins and GoCD.
  • Container orchestration using Docker and Kubernetes.
  • Hybrid connectivity design between GCP and data-centre environments.
  • Cloud migration and application modernisation techniques.
  • Operational support for business-critical cloud platforms.
  • Cloud security hardening, service resilience and performance optimisation.
  • Cross-functional consulting and communication within global technology programmes.
