This is a fully remote job, open to people in United Kingdom.

About the role

LemFi moves over $2B a month across 30+ countries for people who cannot afford mistakes. That makes security a core product feature, not a compliance checkbox. As our Staff Security Engineer for Application Security, you are the most senior technical voice on how we build, ship and defend software. You own the full AppSec surface: intrusion response, pipeline hardening, vulnerability management, OS-level exposure, and the external testing programme spanning AI-driven pen testing, third-party engagements and bug bounty.

You work directly with Engineering, Product and Infrastructure to make security a first-class part of every pull request and every production incident. This is a high-ownership role with no ceiling on scope and no handoffs to hide behind.

What you'll build and own

  • Own the application security posture end to end, from threat modelling in design to triage in production, with no gaps.
  • Harden our build and CI/CD pipelines: integrate SAST, DAST and SCA tooling so vulnerabilities are caught before they ship.
  • Lead intrusion response for application-layer incidents: contain fast, analyse deeply, remediate thoroughly, and feed lessons back into prevention.
  • Run the vulnerability management lifecycle: scanning, OS-level patching cadence, prioritisation by real-world impact, and clear SLAs for remediation.
  • Manage the external security testing programme: scope third-party pen tests, drive AI-assisted pen testing coverage, and operate the bug bounty so researchers are rewarded and findings are actioned at pace.
  • Write the code that scales your work: automation scripts, custom scanner integrations, internal security tooling, using AI coding tools to move faster without cutting corners.
  • Set the bar for the wider engineering team: define secure-by-default patterns, run threat-modelling sessions, and make security a first-class part of engineering culture.

Your experience

  • 5 or more years in a security engineering or AppSec role, with at least one stretch operating at staff or principal level scope.
  • Hands-on coding ability in one or more languages used in modern backend or infrastructure stacks: you write real code, not just review it.
  • Deep, practical knowledge of application vulnerability classes (OWASP Top 10 and beyond), OS-level exposures, and pipeline security risks.
  • Proven track record running vulnerability triage and remediation programmes at scale: you can prioritise under pressure and get fixes shipped, not just filed.
  • Experience managing or contributing to external security testing: third-party pen tests, AI-augmented offensive tooling, or bug bounty operations.
  • Confident using AI coding and analysis tools to build automation, analyse logs at speed, and augment offensive testing coverage.

Nice to have

  • Background in fintech, payments or any regulated environment where the cost of a breach is existential, not just reputational.
  • Offensive security certifications or demonstrable CTF and pen testing experience that shows you think like an attacker, not just a defender.
  • Experience building a security champions programme or embedding AppSec practices across a fast-growing engineering organisation.
