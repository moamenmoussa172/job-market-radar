About the job

You design and build payment-critical backend services end to end on a modern Java stack, with a high bar for correctness, reliability and security.

What you'll do

  • Design and build payment-critical backend services and APIs on Java / Spring Boot.
  • Ensure correctness and reliability under load.
  • Build robust integrations and event-driven flows.
  • Write thorough tests and help maintain high engineering standards.
  • Mentor mid-level engineers.

Requirements

  • 5+ years in Java backend with Spring Boot.
  • Hands-on payments / fintech experience is required — you have worked on real payment or financial-transaction systems.
  • Hands-on experience with at least one payment processor or gateway (e.g. MPGS, Cybersource or mada). This is a requirement for this role.
  • Strong microservices and REST API design; relational databases.
  • Solid grasp of transactional integrity and reliability.
  • Containers / CI/CD and strong automated testing.
  • AI-augmented engineering — you actively use AI coding tools such as Claude Code in your day-to-day development. This is a requirement for this role.

Nice to have

  • Experience with more than one payment processor / gateway.
  • Cloud platforms (OCI, AWS or Azure); Kafka.
