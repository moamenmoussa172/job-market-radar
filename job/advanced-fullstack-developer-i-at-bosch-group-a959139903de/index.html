About the job

The Full Stack Developer is responsible for designing, developing, testing, and maintaining scalable web applications using modern frontend and backend technologies. The role collaborates with cross-functional teams to deliver high-quality software solutions, contribute to technical design, and ensure application performance, reliability, and maintainability.

Activities

  • Develop and maintain frontend and backend application components.
  • Design and implement APIs, database integrations, and business logic.
  • Troubleshoot, optimize, and resolve application issues.
  • Collaborate with cross-functional teams throughout the software development lifecycle.
  • Participate in code reviews, testing, and CI/CD implementation.
  • Contribute to technical improvements and mentor junior developers.

The Full Stack Developer must meet the following minimum requirements:

  • 3–5 years of experience in full stack software development.
  • Proficiency mainly in Java, .NET
  • Springboot and React.js or similar frontend frameworks.
  • Experience developing REST APIs, microservices, and database-driven applications using SQL Server and Entity Framework.
  • Working knowledge of Azure, Git, CI/CD pipelines, and Agile methodologies.
  • Strong analytical, troubleshooting, and problem-solving skills.
  • Effective communication and collaboration abilities.

Position requires time flexibility to work with Americas and India time zones
