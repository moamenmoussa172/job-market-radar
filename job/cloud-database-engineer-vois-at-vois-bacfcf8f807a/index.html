What skills you will learn

  • Advanced cloud‑native database engineering and automation techniques.
  • Deep expertise in AWS, EKS, and enterprise‑scale observability.
  • GitOps, CI/CD optimisation, and zero‑touch operational models.
  • Cost optimisation, resilience engineering, and platform reliability practices.

What you’ll do

We are seeking a Cloud Database Engineer to deliver scalable, secure, and highly available cloud and database platforms that support Vodafone’s mission‑critical services. This role focuses on cloud‑native engineering, automation, CI/CD, and zero‑touch operations, ensuring reliability, performance, and continuous improvement across AWS‑based platforms and database ecosystems.

Who you are

Own the end‑to‑end lifecycle of AWS cloud and database platforms, from design and integration to day‑to‑day operations.Design and implement cloud‑native database solutions aligned to the VFDE CET‑EKS framework.Drive database platform standardisation, governance, peer reviews, and adherence to CET guidelines.Lead automation through CI/CD pipelines, GitHub Actions, ArgoCD, and GitOps practices.Implement Infrastructure as Code using Terraform/Terragrunt and scripting for repeatable, secure deployments.Enable smooth transition from engineering to operations with built‑in monitoring, backup, and recovery.Optimise performance, capacity, storage, and reliability of database platforms across cloud environments.Design and manage hybrid connectivity between on‑premise and cloud systems within CET‑based AWS accounts.Collaborate with architects, project managers, and application teams on infrastructure and database requirements.Provide L2/L3 support, incident resolution, and proactive observability practices to improve MTTR.Mentor team members and promote a DevOps culture with an automation‑first mindset.
