About the job

About the Role
GSS Tech Group is hiring a Senior Full Stack Engineer for a leading bank in the UAE. You will join the Digital Products team for the Wealth business. You will build features end to end with React JS and Node JS, and you will also write the automation scripts that test them. You own both the build and the testing, so quality comes from you and not from a separate QA team.

Key Responsibilities

  • Design, develop and maintain web applications using React JS on the front end and Node JS on the back end
  • Build and consume RESTful APIs and microservices for digital wealth products
  • Write and maintain automated test scripts covering UI, API and regression testing
  • Embed automation in CI/CD pipelines so every release goes out tested
  • Take part in sprint planning, daily standups, reviews and retrospectives in a Scrum team
  • Work closely with product owners, designers and engineers to turn requirements into working features
  • Adapt quickly when requirements change and help drive continuous improvement
  • Do code reviews, troubleshoot production issues and keep code quality and performance high

Required Skills

  • 7+ years of software development experience, with strong hands on work in React JS and Node JS
  • Strong JavaScript and TypeScript skills; good knowledge of HTML5, CSS3 and modern front end practices
  • Experience building REST APIs and working with microservices architecture
  • Hands on test automation with tools such as Cypress, Playwright, Selenium or WebdriverIO
  • Unit and integration testing with Jest, Mocha or similar frameworks
  • API testing experience using Postman, Newman, SuperTest or Rest Assured
  • Experience with Git and CI/CD tools such as Jenkins, Azure DevOps or GitLab CI
  • Working knowledge of SQL and NoSQL databases
  • Proven experience working in Agile/Scrum teams

Preferred Skills

  • Experience in banking, fintech or financial services
  • Knowledge of wealth products such as investments, mutual funds, portfolio management, brokerage or advisory platforms
  • Exposure to BDD frameworks like Cucumber
  • Familiarity with Docker, Kubernetes or cloud platforms (Azure, AWS)
  • Understanding of secure coding practices in regulated environments

What We Look For

  • Highly motivated and eager to learn
  • Adapts fast to changing priorities
  • Team player with an agile, collaborative mindset
  • Takes ownership of quality, not only of delivery
