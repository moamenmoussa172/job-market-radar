About the job

Main responsibility for designing, developing, executing, and maintaining automated test scripts to ensure the quality, reliability, and performance of software applications.
collaborating closely with developers, QA engineers, product owners, and DevOps teams to integrate automated testing into the software development lifecycle, while leveraging AI-powered tools to enhance both manual and automated testing processes, improve test efficiency, and accelerate defect detection.
Key Responsibilities

  • Design, develop, and maintain automated test scripts for web, mobile, and API applications.
  • Execute automated functional, regression, smoke, and integration tests.
  • Integrate automated tests into CI/CD pipelines using GitHub Actions.
  • Collaborate with development teams to troubleshoot issues and improve software quality.
  • Analyze test execution results and prepare clear quality reports.
  • Continuously improve test coverage, automation efficiency, and testing processes.
  • Leverage AI-powered tools to accelerate test case design, test script generation, and maintenance of automated tests.
  • Utilize AI to support manual testing activities, including test scenario identification, test data generation, and exploratory testing.
  • Apply AI-assisted techniques to analyze test results, identify potential defects, and improve testing efficiency.

Requirements

Required Qualifications & Skills

  • Bachelor's degree in Computer Science, Software Engineering, Information Technology, or a related field.
  • Minimum 3 years of experience in Automation Testing.
  • Strong programming skills in JavaScript and Java.
  • Proven experience with automation tools such as Playwright and Appium.
  • Strong understanding of software testing methodologies, STLC, SDLC, and Agile principles.
  • Good understanding of SQL and database testing.
  • Strong analytical, problem-solving, and debugging skills.
