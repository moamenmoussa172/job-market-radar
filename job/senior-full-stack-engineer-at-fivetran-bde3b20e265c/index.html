About the Role

We’re looking for a Senior Software Engineer to join Cloud Signals, the team behind the systems that measure, bill, and talk to our customers across the dbt platform and, more and more, the combined Fivetran + dbt product.

Cloud Signals owns:

  • Billing and usage metering: turning product activity into accurate, auditable usage and billing data, including the integration of Fivetran and dbt billing into one consolidated system.
  • Vortex, our telemetry and event pipeline: high-volume event ingestion that feeds the warehouse, product analytics, and downstream systems.
  • The Notification System: the shared service that sends transactional and product notifications (email, in-app, Slack) for teams across the platform.
  • Usage and admin reporting: giving customers clear visibility into consumption as we move toward consumption-based pricing.

As a Senior engineer you’ll own major features and components of these systems from design to production. You’ll be a go-to technical voice on the team and help shape how we build.

Technologies You’ll Use

  • Python and TypeScript for backend services and APIs (Rust, Go, or Java experience also welcome)
  • Relational databases (PostgreSQL) and cloud data warehouses (Snowflake)
  • Event streaming and messaging systems (Kafka or similar)
  • AWS (plus exposure to GCP or Azure), Docker, and Kubernetes
  • Terraform for infrastructure as code
  • Datadog for observability, alerting, and on-call
  • Third-party billing and payment platforms, plus internal and public REST APIs
  • AI coding assistants and agents (e.g., Claude Code) as part of everyday development

What You’ll Do

  • Design, build, and run features across billing, usage metering, telemetry, and notifications, writing high-quality, well-tested code that holds up in production.
  • Own technical projects from start to finish: break down requirements, write design docs, estimate and plan the work, and see it through rollout.
  • Help deliver the Fivetran + dbt billing integration, with a focus on correct usage data, reliable pipelines, and smooth migrations.
  • Improve Vortex and the Notification System by onboarding new event types and use cases, making them more reliable, and lowering cost.
  • Work closely with Product, Finance, Data, and partner engineering teams, filling gaps in specs and prototyping to test ideas before you commit.
  • Take part in on-call, investigate and resolve production issues, contribute to postmortems, and improve alerting and runbooks.
  • Mentor early-career engineers, give thoughtful, constructive code reviews, and push for good engineering practices on the team.

Skills We’re Looking For

  • 5+ years building and operating production software, with a passion for solving complex engineering problems
  • Strong experience designing and building backend services and APIs, with attention to correctness, reliability, and data integrity
  • Experience with distributed systems and event-driven architectures; exposure to streaming or messaging systems (e.g., Kafka) is a plus
  • Solid knowledge of relational databases and data modeling; experience with a cloud data warehouse such as Snowflake is a plus
  • Ability to independently lead the design of a feature or service to meet project requirements, and to spot and fix design flaws in existing systems
  • Hands-on experience with at least one major cloud provider (AWS preferred) and containerization (Docker, Kubernetes)
  • Familiarity with CI/CD, infrastructure as code (Terraform), and observability tools (Datadog, Grafana, or similar)
  • Experience with code reviews, testing, and troubleshooting, and with being on-call
  • Clear written and verbal communication, including writing design docs and working with cross-functional partners
  • Fluency with AI code assistants and coding agents for building features, fixing bugs, testing, and investigation, and with conversational AI (Claude, ChatGPT, internal chatbots) for researching, writing, and reviewing SDLC artifacts like TDDs, PRDs, postmortems, test plans, and proposals

Bonus Skills

  • Experience with billing, metering, or usage-based pricing systems (e.g., Metronome, Stripe)
  • Experience building telemetry or analytics pipelines (e.g., Snowplow, Iceberg)
  • Experience with notification or messaging platforms (email, in-app, webhooks)
  • Experience with data processing (ETL/ELT), dbt, or other modern data stack tools
  • Experience working on SaaS platforms at scale
