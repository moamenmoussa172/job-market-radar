About the job

As the Bosch Product Owner (PO) for the Display Team, you will be the driving force responsible for the technical realization, alignment, and on-time delivery of all display and screen functionalities for the project. Leading a highly specialized agile software development team, you will translate complex system requirements into a prioritized, high-performance Product Backlog, adhering strictly to Bosch quality, safety, and agile standards.

Key Responsibilities

  • Agile Backlog Management (Bosch Agile Framework - BAF): Own, continuously refine, and prioritize the Product Backlog (Epics, Features, and User Stories) in alignment with BAF. Define clear acceptance criteria and ensure a robust "Definition of Done" (DoD) for embedded software increments.
  • Technical Customer Interface: Serve as the primary technical window and the "voice of the customer" (VoC) to the development team, ensuring customer requirements are clearly understood, while representing Bosch's technical delivery status back to customer.
  • Cross-Functional Collaboration: Actively align with the Bosch System Architect, the Release Train Engineer (RTE), and POs of other VCU domains (e.g., OS/Base Software, Cyber Security, Functional Safety) to manage inter-team dependencies.
  • Requirements Traceability: Ensure full end-to-end traceability of requirements from GM specifications down to the implemented C code and software test cases using Bosch-standard configuration management tools.
  • Release & Sprint Approvals: Evaluate and sign off on completed user stories at the end of each sprint, and coordinate software delivery releases for project integration stages.

Mandatory Skills:

  • Agile Leadership & Bosch Tooling: Experience leading people within the automotive industry.
  • Low-Level Embedded C & QNX RTOS: Solid technical background in hardware-adjacent C programming and the QNX real-time operating system architecture (driver frameworks, resource managers).
  • Display Interface Protocols & SerDes: Expertise in high-speed display interfaces, including DisplayPort (DP), DSI (Display Serial Interface), FPD-Link, and configuring TI Bridgechips.
  • Display Software & Timing Configuration: Practical experience configuring Timing Parameters (porches, sync pulses, pixel clock), OpenWFD (Open Wireless Display / Open Window Framebuffer Device API), and I2C communication interfaces for display initialization.
  • HID (Human Interface Device) & Input Drivers: Direct experience developing or integrating HID driver stacks (e.g., for multi-touch display systems).
  • Lateral Leadership: Excellent communication, negotiation, and conflict-resolution skills. Ability to guide, motivate, and steer a highly technical development team without disciplinary authority (Servant Leadership).
