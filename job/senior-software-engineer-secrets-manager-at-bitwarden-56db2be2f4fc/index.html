About the job

About Bitwarden

Bitwarden is the trusted identity security leader for millions of users worldwide, empowering enterprises, developers, and individuals to securely manage and share sensitive information anywhere. Bitwarden makes it easy for all users to extend robust security across their devices with password management, secrets management, and passwordless and passkey innovations. The company is headquartered in Santa Barbara, California with team members located across the globe. Learn more at bitwarden.com.

The Role

As a Senior Software Engineer on Bitwarden's Secrets Manager team, you will build and operate the application stack that lets developers, DevOps, and cybersecurity teams centrally store, manage, and deploy sensitive credentials. This is a hands-on role. You will spend your time writing, reviewing, and shipping code within core concepts of secrets, projects, machine accounts, and access tokens across the product suite.

Secrets Manager spans a .NET API, a Rust SDK core, and a TypeScript and Angular web client, with SDK bindings in eight further languages and integrations written in Go, C++, Java, PHP and Python. You should be comfortable moving between languages and learning new ones as the work demands, developing deep expertise as you go.

WHAT YOU WILL DO

  • End-to-End Delivery & Ownership: Own features from specification through production. Write the design, build it across the API, client, and SDK, test it, ship it, and stay with it once it is live.
  • Engineering Standards and Automated Quality: Review your teammates' pull requests with care and invite the same scrutiny of your own. Pair on hard problems, share what you learn, and help newer engineers find their footing in a security-sensitive codebase.
  • Decoupled Architecture and Service Boundaries: Maintain clean service boundaries and design resilient APIs so Secrets Manager can evolve independently of the core platform.
  • Deep Technical Work & Codebase Health: Take on the hardest problems in the codebase. Contribute to performance, reliability, accessibility, architecture and maintainability.
  • AI-Assisted Development: Use AI coding assistants effectively in daily engineering, and exercise judgement about where they help and where they do not.
  • Operational Stewardship: Own the operational health, performance, and reliability telemetry of your services in production.
  • Cross-Functional Partnership & Collaboration: Partner closely with Product, Design, Security, and the other team's engineers to design and validate solutions before implementation begins.

WHAT YOU BRING TO BITWARDEN

  • Overall Experience: 5+ years building and operating production software, with a track record of owning substantial, technically demanding features end to end as an individual contributor.
  • Technical Stack - Expertise:
  • Languages such as Rust, Go, and Python
  • Tooling such as Terraform, Ansible, and GitHub Actions
  • Containerized environments such as Kubernetes
  • Writing, consuming, and using SDKs / APIs
  • Technical Stack - Experience:
  • C# / .NET
  • TypeScript / Angular
  • Entity Framework with implementations of Postgres, MySQL, and SQLite
  • Technical Stack - Familiarity:
  • Languages such as C++, Java, PHP
  • WASM instruction format
  • T-Shaped Engineering Mindset: Practical experience with containerized environments (Docker/Kubernetes), automated test frameworks (unit, integration, and end-to-end), and SRE/observability tools (APM, alerting, and telemetry dashboards).
  • Secure Coding: Familiarity with zero-trust and zero-knowledge security architectures, encryption standards, and threat-modeling methodologies.
  • AI-Assisted Development: Practical experience using AI coding assistants in day-to-day engineering, such as Claude Code, Copilot, or similar.
  • Collaborative Spirit: A highly collaborative and adaptable mindset, excited to work in rapid, outcome-driven feedback loops.
  • Open Source Passion: Excitement and enthusiasm for open source, developer advocacy, and building a more secure internet.
  • Problem-Solving: Excellent problem-solving skills, valuing written, clear documentation and using data to make technical decisions.
