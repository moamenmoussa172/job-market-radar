About this Role

We are seeking a Senior Software Developer to design, build, and support scalable software solutions within VOIS Technology. This role involves end-to-end development, from implementation and configuration to testing and operational support, with a strong focus on code quality, collaboration across distributed teams, and delivery of robust backend services.

What you’ll do

  • Develop well-structured, maintainable, and documented code in line with organisational standards.
  • Document system improvements, enhancements, and technical changes.
  • Collaborate effectively within distributed, cross-country and cross-time-zone teams.
  • Contribute to multiple projects simultaneously while ensuring timely delivery.
  • Provide accurate time and effort estimates for implementing technical specifications.

Who you are

  • Experienced in Java (11+) and Spring Boot for backend development.
  • Skilled in designing, developing, and integrating RESTful APIs.
  • Knowledgeable in backend security best practices.
  • Strong understanding of unit testing and Test-Driven Development (TDD).
  • Familiar with microservices architecture and event-driven systems.
  • Solid foundation in object-oriented programming principles.In-depth understanding of the software development lifecycle.
  • Proven experience (minimum 5 years) across technologies including Java Enterprise, Python, JavaScript, TypeScript, Node.js, React, Angular, and working with both relational and non-relational databases.
