About the job

Team Function:

My team is Claims IT Quality Engineering team primarily focused on QA, DevOps, Test Automation, Performance Testing, Service Virtualization and Dashboarding.

Role Description:

This position is a technical QA Engineer role with a focus on AI solutions. It requires collaboration with QA Engineering, Application Engineering/Operations, and Production Support teams. The ideal candidate should have the technical knowledge to deliver effective QA Automation solutions, utilizing new features in Generative AI and Observability.

We are looking for a talented Software Development Engineer in Test (SDET) to create, develop, and manage scalable automated testing systems. Qualified candidates will have solid experience in test automation frameworks, practical skills in Python and Java, and a thorough understanding of the Software Development Life Cycle (SDLC). You’ll work alongside QA, developers, product owners, and DevOps teams to help deliver consistent, high-quality software releases.

Requirements

Other Critical Skills

  • Programming Skills in Python and Java - Advanced
  • Designing and developing scripts for Automation Testing using tools such as Selenium, Playright and Appium or others – Advanced
  • Experience with Playwright for UI automation-Advanced
  • Experience in API testing and backend validation, API testing (REST/SOAP, JSON, XML, MQ) and database validations (Postgres, Oracle) - Intermediate
  • Experience with cloud platforms in DevOps Environments like AWS, Azure and GCP Platforms- Intermediate
  • Application and Logs monitoring in Observability platforms like Dynatrace, AppDynamics or any other APM tools – Intermediate
  • Experience in configuring Dynatrace dashboards for application observability
  • Knowledge of Grid-based execution (e.g., Selenium Grid or similar)
  • Familiarity with CI/CD tools (e.g., Jenkins, GitHub Actions)
  • Experience with version control systems (Git)
  • Strong analytical, debugging, and problem-solving skills

Key Responsibilities

  • Design, develop, and maintain robust test automation frameworks
  • Automate functional, regression, and end-to-end test cases
  • Implement UI automation using Playwright
  • Execute automated tests across multiple environments using test grids
  • Collaborate with development teams throughout the SDLC to ensure testability
  • Analyze test results, identify root causes, and report defects clearly
  • Integrate automated tests into CI/CD pipelines
  • Perform API and backend testing as required
  • Continuously improve automation coverage and test efficiency
  • Adhere to QA best practices, coding standards, and version control processes
  • Create observability dashboards using Dynatrace

Preferred / Good-to-Have Skills

  • Experience with cloud-based testing platforms
  • Exposure to performance or security testing
  • Knowledge of Docker or containerized environments
  • Familiarity with Agile/Scrum methodologies
  • Experience testing microservices architectures
