About the job

Adree a subsidiary of Master Works, bridges business and technology through innovative digital solutions. Its expertise spans Quality Assurance, Quality Control, Low-Code/No-Code development, application performance, and application lifecycle management.

Adree is looking for a a Full Stack .NET, Developer who will be responsible for designing, developing, testing, deploying, and maintaining web applications across both front-end and back-end layers using the Microsoft .NET stack. The role is suitable for a developer with a strong foundation in C#, ASP.NET Core, and modern JavaScript frameworks. The developer will work on assigned features and integrations under the guidance and support of a Technical Lead or Senior Team Member.

Key Responsibilities

  • Develop and maintain full stack web applications using .NET (C#, ASP.NET Core) and a modern front-end framework (Angular, React, or Vue).
  • Convert functional and technical requirements into application features.
  • Build and maintain APIs, services, UI components, and data models.
  • Develop and consume REST APIs and integrate applications with internal and external systems.
  • Work with SQL Server databases, queries, relationships, and basic performance optimization.
  • Design responsive, user-friendly interfaces using HTML, CSS, and JavaScript/TypeScript.
  • Perform unit testing, debugging, defect fixing, and support integration and user acceptance testing.
  • Follow .NET development best practices, coding standards, secure development practices, and source-control procedures.
  • Participate in code reviews and technical discussions with the technical lead.
  • Support application deployments, environment activities, and CI/CD processes.
  • Investigate and resolve assigned application issues in development and testing environments.
  • Prepare and maintain technical documentation for assigned features and integrations.
  • Provide regular updates on progress, risks, dependencies, and technical challenges.

Requirements

Required Qualifications

  • Bachelor’s degree in computer science, Software Engineering, Information Technology, or a related field.
  • 2–3 years of professional software development experience; candidates with more than 3 years are not targeted for this position.
  • Hands-on experience building full stack applications using C# and ASP.NET Core (MVC / Web API).
  • Good knowledge of front-end technologies such as HTML, CSS, JavaScript/TypeScript, and a modern framework (Angular, React, or Vue).
  • Working knowledge of SQL and relational databases, preferably Microsoft SQL Server.
  • Experience with REST APIs, JSON, authentication, and application integration concepts.
  • Basic understanding of SDLC, Agile/Scrum, testing, debugging, and source control.
  • Ability to work on assigned tasks with guidance and collaborate effectively with the development team.
  • Good written and verbal communication and problem-solving skills.

Preferred Qualifications

  • Microsoft Certified: Azure Developer Associate or an equivalent .NET certification, or willingness to obtain it.
  • Exposure to Entity Framework Core, LINQ, and microservices architecture.
  • Basic knowledge of Angular or React in production projects.
  • Exposure to Git, Azure DevOps, GitLab, or similar CI/CD tools.
  • Basic understanding of cloud (Azure) or on-premises deployment environments.
  • Experience integrating with CRM, ERP, ECM, BPM, identity, or other enterprise systems.
