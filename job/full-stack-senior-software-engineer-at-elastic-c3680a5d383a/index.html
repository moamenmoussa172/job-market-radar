About the job

Elastic, the Search AI Company, enables everyone to find the answers they need in real time, using all their data, at scale — unleashing the potential of businesses and people. The Elastic Search AI Platform, used by more than 50% of the Fortune 500, brings together the precision of search and the intelligence of AI to enable everyone to accelerate the results that matter. By taking advantage of all structured and unstructured data — securing and protecting private information more effectively — Elastic’s complete, cloud-based solutions for search, security, and observability help organizations deliver on the promise of AI.

What is The Role

We are looking for a hands-on Full-Stack Senior Software Engineer to join our IT Software Engineering team reporting directly to the Director, IT Software Engineering.

Inside IT Software Engineering, we are shifting from a traditional "SaaS-only" procurement model to an agile Build and Buy strategy. Powered by the Elastic Stack—Elasticsearch, Kibana, Elastic ML, and native AI capabilities—our team builds custom, enterprise-grade applications and AI-powered bots for internal teams (IT, HR, Finance, Ops), replacing expensive third-party software contracts with faster, native solutions.

This is a 100% individual contributor (IC) engineering role. You will lead the technical design, development, and deployment of full-stack internal web applications and conversational AI bots. You will write clean React and Node.js code, integrate backend services natively with Elasticsearch, and leverage modern AI development tools (Cursor, Claude, Copilot) to accelerate delivery—all while taking complete operational ownership of production systems.

What You Will Be Doing

  • Build Enterprise Applications: Write clean, maintainable code across React, TypeScript, and Node.js to design and ship full-stack applications that replace legacy SaaS tools.
  • Develop AI Bots & Workflows: Architect and deploy intelligent internal bots using LLMs, Retrieval-Augmented Generation (RAG), and vector search to automate routine employee workflows and support requests.
  • Build on the Elastic Stack: Connect internal apps directly to Elasticsearch and Kibana, turning our internal tooling into real-world reference architectures for Elastic products.
  • Accelerate Delivery with AI Tools: Utilize modern AI coding assistants (Cursor, Claude, Copilot) to write code faster, generate tests, and increase overall feature velocity.
  • Maintain Code Quality & Operations: Write unit and end-to-end tests, run automated CI/CD deployment pipelines, use feature flags, and participate in on-call rotations to ensure high uptime.

What You Bring

  • 8+ years of hands-on full-stack development experience building, shipping, and operating web applications in production using React, TypeScript, and Node.js.
  • Hands-on Elasticsearch experience with data modeling, indexing, query optimization, and Kibana dashboard integration.
  • Practical AI & bot engineering experience working with LLM APIs, vector search, RAG pipelines, or conversational bot frameworks.
  • Daily proficiency with AI coding tools (Cursor, Claude, or GitHub Copilot) to accelerate workflow while taking full responsibility for code quality.
  • Operational & testing maturity: Experience with automated testing (React Testing Library, Cypress/Playwright), CI/CD pipelines, feature flags, and on-call rotation for production services.

Bonus Points

  • Experience building or integrating internal developer portals, FinOps/cost-governance platforms, or enterprise ticketing and automation workflows.
  • Exposure to advanced Elastic Stack capabilities (ELSER semantic search, hybrid vector search, or Elastic ML).
  • Background replacing legacy enterprise platforms (e.g., ServiceNow, Jira, custom SaaS portals) with custom software solutions.
  • Bachelor’s or Master’s degree in Computer Science or a related engineering field.
  • Strong communication and problem solving skills with the ability to translate business requirements into technical agent architectures.
  • Ability to work and thrive in a dynamic and fast-paced environment.
