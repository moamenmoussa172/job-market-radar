About the job

About this Role

We are seeking a senior full-stack engineer with strong end-to-end software engineering experience and practical experience delivering enterprise Generative AI (GenAI) applications. You will combine modern React and TypeScript frontend development with Python backend engineering, Large Language Model (LLM) integration and cloud-native delivery.

You will bring 5–8+ years of professional software development experience, including strong full-stack expertise, alongside at least 1–2 years of hands-on experience developing GenAI/LLM-powered applications, preferably in production environments.

The role provides end-to-end ownership across solution design, implementation, testing, deployment and production support, with a focus on scalable enterprise applications, microservices, RESTful APIs, Retrieval-Augmented Generation (RAG) and Microsoft Azure technologies.

What you’ll do

  • Design and develop scalable, enterprise-ready full-stack GenAI applications.
  • Build and maintain Python backend services, microservices and RESTful APIs using frameworks such as FastAPI or Django.
  • Develop modern, responsive and reusable web interfaces using React.js, TypeScript/JavaScript, HTML5 and CSS3.
  • Integrate frontend applications with backend APIs, including state management, authentication and performance optimisation.
  • Integrate LLMs using Azure OpenAI, OpenAI APIs or equivalent platforms.
  • Design and implement RAG pipelines using embeddings, vector databases, semantic or hybrid search and document retrieval.
  • Develop prompt engineering approaches, structured outputs, LLM orchestration, tool/function calling and AI-agent workflows.
  • Build reusable GenAI components and shared platform capabilities.
  • Apply asynchronous programming, background processing and external API integrations where appropriate.
  • Work with SQL and NoSQL databases while optimising application performance, logging and error handling.
  • Implement authentication and authorisation using technologies and standards including OAuth 2.0, OpenID Connect and JWT.
  • Ensure secure API development, data protection, application reliability and production readiness.
  • Develop unit, integration and automated tests.
  • Use Docker, Git and CI/CD pipelines to support cloud-native deployment.
  • Monitor and optimise LLM response quality, latency, reliability and token/cost efficiency.
  • Collaborate with Solution Architects, DevOps engineers, product owners and cross-functional engineering teams.
  • Contribute to technical design decisions and mentor junior engineers.
  • Support production troubleshooting, optimisation and continuous improvement.

Who you are

You have:

  • 5–8+ years of professional software development experience, with strong full-stack expertise.
  • At least 1–2 years of hands-on GenAI/LLM application development experience, preferably involving production deployments.
  • Proven experience designing, developing and deploying scalable enterprise applications.
  • Strong Python expertise, preferably using FastAPI or Django.
  • Strong experience designing and developing RESTful APIs and microservices.
  • Experience with asynchronous programming, background processing and API integrations.
  • Experience with SQL and NoSQL databases, performance optimisation, logging and error handling.
  • Strong hands-on experience with React.js and TypeScript/JavaScript.
  • Experience developing responsive, reusable and maintainable UI components using modern frontend practices.
  • Experience with frontend-to-backend API integration, state management, authentication and performance optimisation.
  • Hands-on experience integrating LLMs through Azure OpenAI, OpenAI APIs or equivalent platforms.
  • Practical experience developing Retrieval-Augmented Generation (RAG) solutions.
  • Knowledge of embeddings, vector databases, semantic/hybrid search and document retrieval.
  • Experience with prompt engineering, structured outputs and LLM orchestration.
  • Familiarity with LangChain, LangGraph or LlamaIndex, including tool/function calling and AI-agent workflows.
  • Understanding of LLM evaluation, response quality, latency and token/cost optimisation.
  • Hands-on experience with Microsoft Azure, or strong experience with a comparable cloud platform.
  • Familiarity with Azure AI Search, Azure OpenAI, Cosmos DB, Blob Storage, App Service and Container Apps.
  • Experience with Docker, Git, CI/CD pipelines, monitoring and cloud-native architecture.
  • Good understanding of software architecture, design patterns and clean-code principles.
  • Experience with unit, integration and automated testing.
  • Knowledge of OAuth 2.0, OpenID Connect and JWT.
  • Experience with secure API development, data protection, production troubleshooting and reliability.
  • Analytical thinking, sound judgement and effective problem-solving skills.
  • The ability to own delivery independently and communicate proactively.
  • Experience collaborating with architects, product owners and cross-functional engineering teams.
  • The ability to mentor junior engineers and contribute to technical design decisions.
  • Comfort working in Agile environments across multiple business priorities.

Experience in the following areas would also be valuable:

  • Azure AI Document Intelligence and document ingestion pipelines.
  • Enterprise knowledge bases and conversational AI applications.
  • Agentic AI architectures, Model Context Protocol (MCP) and multi-agent workflows.
  • Real-time applications, WebSockets and streaming APIs.
  • Kubernetes, Terraform and infrastructure as code.
  • Google Cloud Platform (GCP) or multi-cloud architectures.
  • LLM evaluation frameworks, observability and guardrails.
