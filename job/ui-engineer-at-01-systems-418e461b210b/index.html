About the job

Duties and Responsibilities:

  • Collaborate with product leadership, design, software architecture, and other cross function teams, to develop User Interfaces that align with the evolving goals of the product.
  • Create website and application design mock-ups with best-in-class UI features.
  • Create rapid prototypes to validate the design approaches.
  • Write front-end code and develop the application user interface.
  • Develop reusable components, templates and provide guidance to enable development teams to easily implement rich user interfaces with consistent look and feel.
  • Ensure front end code works responsively across desktop, tablet, and mobile devices.
  • Research and analyse products in similar business domains, the latest innovations in design, and emerging browser capabilities, to incorporate these findings into the User Interface development.
  • Design User Interfaces that not only address current requirements but also account for potential future requirements, elegantly and with scale.
  • Support Pre-Sales team with mock-ups and content for demos.
  • Bachelor’s degree in Computer Science, Graphic Design, Web Design, or another related field.
  • 3+ years of professional experience as a UI Engineer developing web applications.
  • In-depth knowledge of user interface models, application design, and website functionality.
  • Proficiency in all front-end languages including HTML, CSS and JavaScript.
  • Experience with modern web development frameworks, such as React, Angular and Vue.
  • Familiarity with IDEs such as Visual Studio Code, and version control concepts and tools such as Git.
  • Strong analytical and problem-solving skills.

Desirable Skills and Experience:

  • High levels of initiative, along with the ability to work with minimal oversight, and capability to multitask.
  • A team player, with willingness to assist other team members through brainstorming, review, and knowledge-sharing to improve the performance of the team as a whole.
  • Strong written and verbal communication skills, including the ability to present complex information in a succinct and easy to understand manner.
  • Experience working in an agile development environment.
  • Drive for continuous learning and self-improvement.
  • Familiarity with prototyping tools including Figma and XD.
  • Familiarity with graphic design software including Adobe Illustrator and Photoshop.
