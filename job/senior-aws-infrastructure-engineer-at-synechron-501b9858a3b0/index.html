Role Description

We are looking for an experienced Senior AWS Infrastructure Engineer to design, implement, operate, and continuously improve enterprise-grade AWS infrastructure and Kubernetes environments.This is a role with a strong focus on AWS EKS platform operations, production reliability, infrastructure automation, observability, networking, and security. You will work directly with existing cloud platforms, take ownership of technical discovery and implementation, and help ensure that business-critical workloads remain scalable, secure, resilient, and highly available.The ideal candidate brings extensive hands-on experience across AWS infrastructure, production Kubernetes operations, Site Reliability Engineering, infrastructure as code, GitOps, observability, and live-system troubleshooting. You should be comfortable working autonomously, quickly understanding an existing platform, and independently resolving complex infrastructure and production challenges.

Key Responsibilities:

  • Design and maintain enterprise-grade, multi-tenant AWS cloud architectures, with a strong focus on high availability, disaster recovery, scalability, security, and operational efficiency.
  • Perform hands-on technical discovery, capacity planning, performance profiling, architectural scoping, and production optimization.
  • Manage Day 2 operations for AWS EKS, including zero-downtime cluster upgrades, managed node group rollouts, platform maintenance, and reliability improvements.
  • Perform active troubleshooting of degraded or failing Kubernetes workloads and restore service health in production environments.
  • Maintain reliable and scalable Kubernetes platforms supporting business-critical applications.
  • Configure and optimize Karpenter-based autoscaling to support workload scalability and efficient resource utilization.
  • Design, implement, and maintain multi-account and multi-environment AWS architectures using Hub-and-Spoke VPC models and AWS Transit Gateway.
  • Implement and maintain network and platform security controls, including AWS Network Firewall, AWS WAF, VPN solutions, IAM policies, and centralized security configurations.
  • Manage Kubernetes cluster networking and security using Cilium, including CNI configuration and network policies.
  • Support ingress architectures and service mesh configurations within Kubernetes environments.
  • Optimize AWS compute and storage resources, including EKS worker nodes, EC2 instances, and high-performance EBS volumes for disk-intensive workloads.
  • Provision, manage, and maintain resilient database and storage solutions using AWS RDS, EBS, and Amazon S3.
  • Use advanced Terraform and Terraform Cloud capabilities to manage AWS and Kubernetes infrastructure as code.
  • Implement and maintain GitOps deployment processes using ArgoCD and Helm.
  • Build and maintain CI/CD pipelines supporting cluster updates, application deployments, and environment promotions across Staging, UAT, and Production.
  • Maintain production observability and telemetry solutions using OpenTelemetry collectors, Prometheus, Grafana, and Amazon Managed Grafana.
  • Configure production alerting, dashboards, and automated notifications to proactively identify issues and reduce application downtime.
  • Produce and maintain technical documentation, infrastructure diagrams, and relevant High-Level and Low-Level Designs.

Your Profile

Must Have Requirements

  • 5+ years of hands-on experience in Cloud Infrastructure Engineering, Platform Engineering, Site Reliability Engineering, or similar roles.
  • Strong experience designing, operating, and supporting large-scale AWS and Kubernetes platforms in production environments.
  • Hands-on experience with platform operations, cluster lifecycle management, performance optimization, capacity planning, and production troubleshooting.
  • Experience managing production incidents, performing root cause analysis, and implementing reliability and resiliency improvements.
  • Strong understanding of cloud architecture, infrastructure design, networking, security, high availability, scalability, and disaster recovery principles.
  • Hands-on experience with Infrastructure as Code, infrastructure automation, and CI/CD practices.
  • Experience implementing and supporting secure cloud networking, access management, and platform security controls.
  • Experience with observability, monitoring, logging, alerting, and operational excellence practices.
  • Strong knowledge of AWS infrastructure services and containerized application platforms.
  • Experience with technical discovery, architecture design, documentation, and infrastructure planning activities.
  • Strong analytical, troubleshooting, and problem-solving skills.
  • Ability to work independently, quickly understand existing environments, and deliver with minimal supervision.

Nice to Have

  • Previous experience in technical leadership, mentoring, or knowledge sharing within engineering teams.
  • Experience leading infrastructure initiatives and coordinating technical delivery across multiple teams.
  • Experience defining cloud governance, security, compliance, and operational standards.
  • Experience working within financial services, banking, or other highly regulated environments.
  • Knowledge of cloud security, compliance, monitoring, and audit frameworks.
  • Experience administering Windows Server environments and supporting enterprise infrastructure operations.
  • Experience with advanced AWS networking, security, and platform management services.
  • AWS certifications such as Solutions Architect, Advanced Networking, Security Specialty, or equivalent.
