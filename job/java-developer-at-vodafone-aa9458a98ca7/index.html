About this Role

We are seeking a Java Developer to join our team and support the maintenance, enhancement, and optimisation of enterprise applications within a modern cloud-based environment. This role is well suited to an individual with strong Java development experience who enjoys troubleshooting production issues, improving system reliability, and contributing to continuous service improvements. The position combines application support, backend and frontend development, cloud operations, and collaboration within an Agile delivery environment.

What you’ll do

  • Maintain and support enterprise applications based on Java 17 and Spring Boot
  • Troubleshoot, debug, and resolve production issues to ensure high availability and system stability
  • Develop and deliver enhancements for both backend and frontend components (Angular / TypeScript)
  • Work with relational databases such as MySQL and Aurora, using JPA/Hibernate for persistence
  • Support and improve API development using OpenAPI Generator
  • Maintain and optimize database migrations using Flyway
  • Work with event-driven solutions using Spring Kafka
  • Contribute to automated testing and quality assurance using Mockito, RestAssured, and Postman
  • Support CI/CD processes using Jenkins (Groovy pipelines) and GitHub Actions
  • Collaborate with teams in an Agile setup and contribute to continuous improvements
  • Support cloud operations and deployments in AWS, including Kubernetes (K8S) and Helm
  • Monitor and support production systems using tools like Kibana and Grafana

Who you are

  • 5+ years of hands-on experience in Java development
  • Understanding of DevOps principles, automation, and cloud-native environments
  • Ability to work autonomously and confidently support and maintain existing applications
  • Strong analytical mindset and excellent problem-solving skills
