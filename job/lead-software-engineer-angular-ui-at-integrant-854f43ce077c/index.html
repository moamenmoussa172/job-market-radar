About the job

Integrant Inc is hiring a Lead Software Angular Engineer primary goal is to implement assigned tasks on time, with the highest quality, and using the best practices. Angular Front-End Lead UI is an experienced and talented developer with a successful delivery track, proven technical expertise, with eager for technology.

Duties and Responsibilities:

  • Deliver fast, clean, pixel-perfect, and scalable front-end code
  • Work with back-end developers, testers, and creative team
  • The Web Developer will be responsible for writing, deploying and maintaining our web application and interfacing with our API’s to support millions of concurrent users
  • Build reusable code and libraries for future use;
  • Ensure the technical feasibility of UI/UX designs;
  • Optimize application for maximum speed and scalability
  • Perform programming tasks according to the project plan and functional specifications.
  • Perform unit testing of the tasks submitted by him.
  • Responsible for handling the development of the project's most complex and risky tasks.
  • Conducting technical research to gain technical knowledge and resolve technical difficulties.
  • Participate in the analysis & design of new functional requirements and systems.
  • Participate in the estimation of new features and components.
  • Participate in product or application definition activities including feature analysis & system tradeoffs.
  • Serve as a mentor to less-experienced software engineers.
  • Perform other related duties as necessary

Requirements

  • Minimum 8+ years of experience
  • Develop various applications using HTML5, CSS, JavaScript, jQuery, Angular.js, and Agile software development methodologies
  • Must have recent Angular and JavaScript experience
  • Ability to use plugins without changing their library files;
  • Writing unit-testable front-end code;
  • Logic & algorithm implementation skills in js & ts file;
  • Ability to hand-code a responsive website with maximum browser support;
  • Good work ethics, Team player, positive and self-motivated.
  • Good Communication & Interpersonal skills.
  • Good command of English language is a plus.
  • Previous experience working with U.S clients is a plus.

Please note that this role is part of a selective talent pipeline we are building, aimed at engaging with strong profiles early and aligning on meaningful opportunities as they emerge, ensuring a faster and more tailored process when the right fit arises.
