Job Description:

Role Overview:

We are seeking a System Administrator with strong expertise in SQL database management and experience in Linux and Windows server environments. The successful candidate will maintain, optimize, and secure our IT infrastructure, ensuring system reliability, managing database performance, and supporting business-critical applications.

Work Location: Attaba Metro Station

Key Responsibilities:

  • Install, configure, and maintain Linux and Windows servers.
  • Monitor system performance and troubleshoot issues.
  • Manage servers and IT equipment, ensuring proper configuration and security policies.
  • Administrator SQL databases (installation, configuration, backup, recovery).
  • Optimize queries and ensure high database performance.
  • Implement data integrity and security measures.
  • Schedule and monitor backups and disaster recovery plans.
  • Apply patches and updates to systems and databases.
  • Develop scripts for routine tasks and system monitoring.
  • Maintain detailed documentation of configurations and procedures.
  • Ensure compliance with IT policies and standards.

Required Skills & Qualifications:

  • Bachelor’s degree in Computer Science, IT, or related field.
  • 3–5 years of experience as a System Administrator with SQL database expertise.
  • Strong knowledge of:
  • Linux and Windows server environments
  • Microsoft SQL Server, MySQL, or PostgreSQL
  • Familiarity with virtualization (VMware, Hyper-V) and cloud platforms.
  • Excellent troubleshooting and problem-solving skills.
  • Knowledge of networking fundamentals and security best practices.
