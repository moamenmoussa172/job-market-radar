About the job

About Vercel:

Vercel is the agentic infrastructure company, freeing people and agents to ship what's next. For more than a decade we've helped builders move from idea to production with speed, security, and exceptional developer experience.

Now we're scaling our products for both agents and people to ship and run software, built in the open and trusted by OpenAI, PayPal, Ramp, Supreme, and millions of developers worldwide.

About the Role:

As a senior engineer on Vercel Connect, you’ll own the APIs, token infrastructure, authorization, and SDKs that let agents securely access the data, tools, and events they need, without wrestling with OAuth and credential complexity. You’ll build the platform for managing agent identity, access, and permissions, plus the connectors linking agents to thousands of systems such as Linear, Slack, GitHub, and Google. You’ll work directly with external companies to make it easier for developers to build agents that integrate with their products, balancing high uptime and performance with the flexibility to connect systems that weren’t built with agents in mind. This is a hybrid role based in San Francisco, in the office on Monday, Tuesday, and Friday.

What You Will Do:

  • Ship provider integrations end to end, from auth flows and token exchange to app registration and configuration UI, covering generic API-key and OAuth presets through bespoke cases like Snowflake Partner Connect, Slack manager apps, and Microsoft Entra
  • Own and improve Connect’s infrastructure, including uptime, performance, and secure storage of credentials and keys, plus the developer experience built on top of it
  • Build and harden event forwarding, including inbound signature verification and project-scoped identity delivered to the right deployment and environment
  • Extend Connect’s SDKs, consent-redirect flow, and framework adapters to make it the default way to give an agent a credential, and reduce the cost of the next hundred integrations so most become configuration rather than code
  • Work with industry partners inside and outside Vercel to propose and implement new authentication and authorization protocols for agents

About You:

  • 6+ years building and operating production backend or full-stack systems, with a track record of owning a service or platform surface rather than a feature
  • Deep, practical understanding of OAuth 2.0/2.1, OIDC, and JWTs: not just wiring up a client library, but reasoning about authorization codes, PKCE, refresh semantics, audience and scope restriction, token exchange, and what each actually protects against
  • A security instinct for integration code specifically: SSRF and DNS rebinding, confused-deputy and mix-up attacks, redirect-URI validation, webhook signature verification, tenant isolation. You’ve either found these bugs or fixed them
  • Hands-on experience shipping production TypeScript across both backend and frontend components
  • Experience integrating with many third-party APIs, and the judgment to absorb undocumented behavior, non-compliant OAuth, and inconsistent errors behind a clean abstraction
