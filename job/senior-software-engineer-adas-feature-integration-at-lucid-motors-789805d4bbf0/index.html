About the job

The Role

Join Lucid’s Autonomous Driving and ADAS organization to develop and maintain the ADAS Integration Applications. You will integrate active safety, driving assistance, parking, viewing, and driver-monitoring functionality across multiple vehicle programs and software variants. This role blends embedded application development, ADAS feature integration, software architecture, build infrastructure, and cross-functional coordination and collaboration.

The successful candidate thrives with minimal guidance, makes sound technical decisions, and turns complex system requirements into robust, adaptive and reliable production software in a fast-moving environment.

What You’ll Do

  • Design, develop, and maintain production ADAS application-layer software in C++ for the ADAS Integration Application. Partner with project management, feature owner, system, validation, infotainment and ADAS development teams to deliver production-ready ADAS features.
  • Analyzeand decompose system-level requirements into clear software requirements; Own software architecture, complete implementation tasks, and support verification criteria definition.
  • Design and implement robust state-machine logic for active safety, parking, viewing, and driving features.
  • Implement vehicle-facing feature behavior, including telltales, notifications, warnings, chimes, settings, diagnostics, fault handling, and HMI interactions.
  • Integrate supplier and in-house ADAS functionality across existing and future vehicle programs and software variants.
  • Develop and maintain communication interfaces using various middleware and communication protocols such as DDS and Ethernet.
  • Build scalable multi-platform software architecture, code-generation workflows, and release strategies that support common code across vehicle programs.
  • Contribute to Bazel-based build systems, CI/CD pipelines, build automation, developer tooling, and code optimization.
  • Participate in code reviews, design reviews, release planning, documentation, and continuous improvement of engineering workflows
  • Perform unit, SIL, HIL, bench, and in-vehicle testing; troubleshoot integration issues and lead root-cause analysis across software and ECU boundaries.

.

Requirements

  • Bachelor’s degree in Computer Science, Computer Engineering, Electrical Engineering, or a related field, or equivalent practical experience.
  • 5+ years of professional software-development experience, including embedded, automotive, robotics, or other safety-critical systems.
  • Strong C/C++ programming, software architecture, debugging, and system-integration skills in Linux-based development environments.
  • Demonstrated experience designing and implementing state machines and translating complex requirements into testable software.
  • Experience with Git-based development, code reviews, automated builds, and modern CI/CD workflows.
  • Ability to work independently, communicate clearly, and collaborate effectively across software, systems, and validation teams.

Preferred Qualifications

  • Master’s or PhD degree in Computer Science, Computer Engineering, Electrical Engineering, Robotics, or a related field.
  • ADAS/AD, HMI, or vehicle application integration experience.
  • Experience delivering the full production lifecycle: requirements, design, implementation, unit testing, SIL/HIL, vehicle validation, release, and field support.
  • Experience with functional safety development, including ISO 26262 concepts and safety-critical application integration.
  • Hands-on experience with QNX or comparable embedded automotive platforms.
  • Experience with middleware communications and ECU network tools such as Vector CANoe or CANape.
  • Experience with Bazel, CMake, code generation, build-server infrastructure, CI/CD optimization, and multi-platform release branches.
  • Experience with MATLAB/Simulink, simulation-based validation, diagnostics, fault handling, logging, and vehicle data analysis.
