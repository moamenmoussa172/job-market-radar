About the job

Key Responsabilities:

  • Assess SAP source systems and define secure, reliable extraction strategies for structured and delta data.
  • Develop and maintain data pipelines that ingest data from SAP into the data lake.
  • Use appropriate SAP extraction mechanisms, such as CDS Views, ODP/ODQ, standard extractors, SLT or APIs, according to the use case and architecture.
  • Design and implement the Medallion Architecture: Bronze for raw and traceable data, Silver for cleansed and conformed data, and Gold for business-ready data products.
  • Implement incremental loads, change data capture, orchestration, monitoring, retry mechanisms and data reconciliation controls.
  • Ensure data quality, lineage, security, access control, documentation and compliance across the data lifecycle.
  • Optimize pipeline performance, storage formats and processing costs for large SAP datasets.
  • Collaborate with SAP functional consultants, data architects, analytics teams and business stakeholders to translate requirements into reusable data products.

Minimum Qualifications:

  • Proficient in SQL, Python and Spark/PySpark for distributed data processing.
  • Advanced knowledge of SAP data extraction and integration patterns, including CDS Views, ODP/ODQ, SAP standard extractors, SLT and APIs.
  • Experience with cloud data lake technologies, preferably Azure Data Lake Storage and Azure Databricks.
  • Experience with Delta Lake, Parquet, medallion architecture, schema evolution and data partitioning.
  • Experience with pipeline orchestration and integration tools such as Azure Data Factory and/or Databricks Workflows.
  • Experience with Git, CI/CD, automated testing, observability and Infrastructure as Code is desirable.
  • Familiarity with SAP BW, SAP Datasphere, SAP HANA and data governance/catalog tools is desirable.

Language skills:

  • Fluent English is mandatory.
  • Native Portuguese is mandatory.
