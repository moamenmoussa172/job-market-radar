Senior Node System Programmer [Snowdrop]

About the job

As a Senior Node System Programmer, you will take ownership of the user-facing code for Snowdrop’s node system. You’ll be the central point of contact for project teams and developers with questions or requests about the system. Working closely with the teams that use these tools, you’ll shape the system’s core development and roadmap around their needs.

What you’ll do

  • Develop integrated editor and game development tools in C++
  • Design, implement and improve new and existing systems and tools
  • Develop Snowdrop as a shared ecosystem for game creation
  • Develop and maintain the node system and tools shared through Snowdrop
  • Shape the node system roadmap around project needs
  • Support teams around the world by sharing knowledge and providing practical help
  • Improve documentation and samples to help teams use the tools

What you'll bring

  • Advanced professional proficiency in C++
  • Experience with node graph patterns and data-driven engines, such as node graphs and Unreal Engine Blueprints
  • Solid Experience working with game engine software
  • Experience developing software in close collaboration with its users
  • Interest in agentic workflows

Ubisoft is a global leader in gaming with teams across the world creating original and memorable gaming experiences, from Assassin’s Creed, Rainbow Six to Just Dance and more. We believe diverse perspectives help both players and teams thrive. If you’re passionate about innovation and pushing entertainment boundaries, join our journey and help us create the unknown!
