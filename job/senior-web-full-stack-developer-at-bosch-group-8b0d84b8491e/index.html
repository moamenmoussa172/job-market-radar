About the job

Roles & Responsibilities :
Key Responsibilities

• Frontend features: build and maintain features in a TypeScript / React 19 Turborepo monorepo, with React Hook Form and Zod for state and validation.

• Python backend services: design, build and maintain backend services and APIs in Python - data models, business logic, integrations and background jobs - with typed contracts and automated tests.

• Data layer: connect the frontend to the GraphQL Backend-for-Frontend using Apollo Client and generated types (@graphql-codegen), and own features end to end across UI, API and data.

• Security: implement Auth0 authentication (multi-organization, JWT) and apply security-first practices - input validation, sanitization, strict CORS, access control - in the UI and at the API.

• Design system: contribute accessible, reusable components to @livanova/ui (Radix UI, TailwindCSS, Storybook), including i18n (i18next) and data visualization (Recharts, TanStack Table).

• Quality: write unit, integration and end-to-end tests on both frontend and backend; take part in CI/CD, performance optimization and Sentry-based monitoring.

• Telehealth: integrate Azure Communication Services for real-time communication.

• Collaboration: work closely with stakeholders, designers, architects, backend and QA teams.

Educational qualification:

B.E/B.Tech

Experience : 8+

Mandatory/requires Skills :
This is the #1 qualification. You don't write code manually when AI can do it faster and better; you focus on architecture, validation and business logic.

• Prompt engineering: precise, context-aware prompts that produce production-ready code with minimal iteration.

• Daily Claude Code use: autonomous coding, refactoring, debugging and documentation, knowing when to use Sonnet (speed) vs Opus (complexity).

• Agentic workflows: delegate entire features to AI agents with the right context, validation and iteration strategy.

• Automation: frontend and backend scaffolding, GraphQL queries and TypeScript types, API contracts, test generation and coverage gaps, legacy refactoring, PR descriptions and review, bug triage, accessibility fixes, living documentation and ADRs.

• Evidence at interview: portfolio (repos, demos or recordings), quantified velocity gains, a walkthrough of your daily AI workflow, and reusable prompt templates.
