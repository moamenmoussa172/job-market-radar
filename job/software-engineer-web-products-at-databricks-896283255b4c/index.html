About the job

Software Engineer, Web Products

P-1581

Location: Mountain View, CA

About Us:

The Web Engineering team at Databricks builds and owns the public-facing web experiences that represent Databricks to the world, across databricks.com, the blog, landing pages, hubs, microsites, and event properties. We are rebuilding the platform from the ground up, AI native from the start, and pioneering an agentic SDLC as our operating model.

The Role:

As Software Engineer on the Web Engineering team, you will build and ship production-quality web experiences across public-facing Databricks properties on an AI native platform designed for humans and agents from the ground up. You will contribute to a web delivery practice where AI native tools and an AI native engineering lifecycle are embedded in how the team builds every day.

The impact you’ll have:

  • Build and ship web experiences across databricks.com including landing pages, blogs, hubs, and event properties on a unified, AI native architectural foundation
  • Implement components and page systems using a shared design system, contributing to a consolidated stack that reduces per-surface maintenance overhead
  • Operate in an AI native SDLC where agents assist across code generation, testing, and deployment, building faster and more reliably alongside them
  • Contribute to ensuring databricks.com surfaces are structured and optimized for how the web is discovered and consumed today, including by AI driven search and discovery systems
  • Participate actively in code review and help establish what rigorous, AI native engineering execution looks like on this team

What we look for:

  • 4+ years of software engineering experience with a track record of shipping production web systems
  • Strong fundamentals across the web stack including component architecture, rendering strategies, build systems, and deployment pipelines
  • Experience building on or integrating with content management systems like Drupal, Contentful
  • Comfort adopting AI native development tools and embedding them into daily engineering practice
  • Ability to take a well-scoped problem and drive it to completion under senior direction
  • Familiarity with headless CMS architectures, edge delivery, or modern frontend frameworks is a strong plus
