About the job

Job Summary

This position works with business stakeholders, solution engineers, product owners, UX designers, and Agile team members to develop, test, and deploy Guidewire PolicyCenter solutions and React-based digital applications. React development is a mandatory capability for this role. The developer uses foundational to intermediate Guidewire configuration and integration skills together with hands-on React, JavaScript or TypeScript, responsive user interface, REST API integration, and automated testing experience. Experience with Guidewire Jutro Digital Platform is a plus. The role follows established coding, design, accessibility, security, and delivery standards and delivers reliable working functionality each sprint with support and guidance from senior developers, solution engineers, or architects.

Essential Job Functions

  • Develops and modifies Guidewire PolicyCenter components and React-based web applications to deliver approved business and digital experience requirements.
  • Interprets customer, business, and user experience needs and provides technical input into feasible application solutions and system design.
  • Builds reusable React components, screens, forms, and workflows using modern JavaScript or TypeScript, HTML, CSS or SCSS, and approved component libraries.
  • Integrates React applications with Guidewire and enterprise services using REST APIs, JSON payloads, and established authentication and authorization patterns.
  • Codes and configures Guidewire programs, objects, components, and packaged software using established standards and conventions.
  • Documents implementation details and performs quality checks on Guidewire configuration, React code, API integrations, test evidence, and supporting documentation.
  • Delivers working functionality incrementally each sprint and modifies existing code or configuration to meet approved requirements.
  • Performs detailed impact assessments across business processes, data, Guidewire applications, APIs, digital channels, and integrations; identifies and raises functional or technical risks.
  • Creates unit and component tests and applies Test-Driven Development or Behavior-Driven Development practices where appropriate.
  • Supports application implementation, release, environment troubleshooting, root cause analysis, and corrective actions across Guidewire and React components with guidance.
  • Takes ownership of assigned deliverables, communicates status and impediments, and completes issue resolution in a timely manner.

Requirements

Guidewire Technical Requirements

  • Minimum 3 years of experience in software development, solution engineering, or a related technology field.
  • Hands-on experience developing web applications using React and modern JavaScript; TypeScript experience is preferred.
  • Working knowledge of React functional components, hooks, props, component composition, state management, routing, reusable design patterns, and front-end error handling.
  • Experience with HTML5, CSS3, responsive web design, SCSS or CSS modules, browser developer tools, and cross-browser compatibility.
  • Experience consuming REST APIs, handling asynchronous operations, processing JSON payloads, and displaying service data in React applications.
  • Experience writing front-end unit and component tests using tools such as Jest and React Testing Library.
  • Working knowledge of Node.js, npm, package management, dependency management, build tooling, linting, code formatting, and front-end CI/CD practices.
  • Ability to apply accessibility, basic internationalization, performance, security, and responsive design practices to customer- and producer-facing applications.
  • Ability to translate approved UX designs or design-system specifications into reusable and accessible React components.
  • Experience with Guidewire Jutro Digital Platform or Jutro-based React applications is a plus.

Agile Delivery and Collaboration

  • Writes and refines user stories with clear technical tasks and acceptance criteria covering Guidewire, APIs, React, and integration changes; estimates work using relative sizing.
  • Partners with the Product Owner, UX designers, and team members to confirm that implementation and acceptance tests reflect the intended functionality and user experience.
  • Participates in PI Planning, Sprint Planning, backlog refinement, daily stand-ups, system demos, retrospectives, and Inspect and Adapt activities.
  • Commits to team PI objectives and sprint goals, communicates progress and impediments, and owns assigned work items.
  • Practices continuous exploration, continuous integration, and continuous deployment to support the Continuous Delivery Pipeline and DevOps.
  • Demonstrates integrated PolicyCenter and React functionality to Product and Business Owners and supports iteration and PI System Demos.
  • Actively develops T-shaped Guidewire and React skills, participates in Communities of Practice, shares knowledge, and contributes ideas for continuous improvement.
  • Works effectively across development, testing, product, UX, architecture, and business partners to improve flow and transparency.

Additional Qualifications

  • Strong verbal communication, listening, writing, and collaboration skills, with the ability to adjust technical detail for the audience.
  • Demonstrated problem-solving skills, including breaking down moderately complex issues, identifying root cause, comparing alternatives, and recommending a viable solution.
  • Ability to use data to identify meaningful information, patterns, or conclusions and organize the steps needed to address an issue.
  • Strong ownership and accountability for individual deliverables, including timely identification and correction of gaps.
  • Ability to work effectively in a fast-paced environment with changing priorities and multiple assignments.
  • Foundational knowledge of object-oriented and component-based programming, defensive coding, error handling, version control, databases, SQL, and integrated development environments.
  • Working-level understanding of applications within the assigned domain and the flow of data between Guidewire, digital applications, and internal or external systems.
  • Broad understanding of insurance concepts, terminology, products, and business processes.
  • Ability to share knowledge, provide constructive feedback, and support others in areas of developing expertise.

Education and Certification Requirements

  • High school diploma or equivalent required; bachelor's degree in computer science, engineering, information systems, or a related field preferred.
  • Guidewire Configuration or Integration certification is preferred or expected based on assignment needs.
  • Relevant React, JavaScript, TypeScript, cloud, or web development training or certification is preferred.
