About the job

About the Team
The Design System team owns Click UI - the open-source Design System of ClickHouse. It is the shared UI foundation for ClickHouse Cloud and several other projects. We operate the system as a service and as the clear entry point for all ClickHouse UI work. We focus on building React components that are accessible, performant, well-documented, token-driven, and capable of resolving challenging product requirements.

What You Will Do

  • Research, build, and maintain accessible React components and their APIs on headless accessibility (WCAG 2.2 AA) primitives. Keyboard interaction, focus management, and theming are part of each component from the start.
  • Work on the library enhancements, focusing on consistent and intuitive components API and developer experience improvements. Enable complex migrations with codemods and semantic versioning.
  • Maintain the shared reliable infrastructure: Storybook, unit, interaction E2E and visual regression tests, accessibility gates, and a reliable release process.
  • Drive adoption: high quality documentation, usage guidelines, migration guides, issue intake and triage (including open-source issues), and code review with product teams.
  • Build the AI-assisted layer: Figma-to-code, component scaffolding, and guardrails that keep AI-generated UI on-token, on-pattern, and accessible.

What We Are Looking For

  • Experience: 6+ years of frontend engineering. You have built or maintained a production design system that multiple teams use, including its migrations and breaking changes.
  • Core Stack: Deep knowledge of React, TypeScript, semantic HTML, and CSS architecture at scale (SASS, CSS Modules, CSS variables, CSS-in-JS). Experience with component API design (atomic design, composition, controlled and uncontrolled, polymorphic patterns) and headless primitives such as React Aria, Ark UI or Radix.
  • Accessibility and Tokens: Working knowledge of WCAG 2.x and WAI-ARIA. You implement and test keyboard navigation, focus management, and screen-reader behavior yourself. Experience with design-token architecture and tools (Style Dictionary, Terrazzo, DTCG, or equivalent) and Figma variables sync.
  • System Mindset: You treat the design system as a product with internal customers. You write clear documentation, review for consistency across the library, and mentor through code review. You measure success by adoption, not by component count. You are fluent in Figma and use AI coding tools (for example Claude Code or Cursor).
  • Ideal Backgrounds: Design system or UI/UX platform teams at developer tools, B2B SaaS, or cloud platforms, or frontend platform roles with a shared UI library and multi-team consumers.

Perks

  • Flexible work environment - ClickHouse is a globally distributed company and remote-friendly. We currently operate in over 25 countries.
  • Healthcare - Employer contributions towards your healthcare.
  • Equity in the company - Every new eligible team member who joins our company receives equity.
  • Time off - Flexible time off in the US, generous entitlement in other countries.
  • A USD$500 Home office setup if you’re a remote employee.
  • Global Gatherings – We believe in the power of in-person connection and offer opportunities to engage with colleagues at company-wide offsites.
