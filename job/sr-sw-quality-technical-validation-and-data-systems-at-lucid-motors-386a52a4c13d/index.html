The Role

We are seeking a Sr. SW Quality Technical Validation & Data Systems Engineer focused on software issue evaluation, hands-on log and data analysis, signal monitoring, bench-based validation, and targeted product validation support. This role collects and analyzes logs, cloud data, PCAP traces, CAN data, diagnostics, vehicle signals, and validation results to identify issue patterns, support root cause analysis, and provide actionable findings to Software Development and Validation teams.

  • Sr. Software Quality Investigation & Validation Engineer Mission Improve software quality through data-driven issue investigation, technical validation, supplier software quality management, software launch readiness, factory software quality support, and cross-functional engineering collaboration. The Role
  • Investigate software issues using logs, cloud telemetry, PCAP, CAN, diagnostics, DTCs, and vehicle signal data to identify failure patterns, timing relationships, and root-cause candidates.
  • Perform targeted product validation, regression testing, release validation, and fix verification to confirm software quality and customer-facing behavior.
  • Analyze vehicle, fleet, and development data to identify emerging software quality risks, recurring defects, and validation gaps.
  • Develop and maintain signal-monitoring dashboards, quality metrics, and visualization tools using Grafana and related analytics platforms.
  • Collaborate with Software Development, Validation, Diagnostics, Cloud, Automation, and Quality teams to accelerate issue resolution and improve software quality.
  • Support Software Safe Launch activities, factory software deployments, ECU flashing validation, OTA release readiness, and production software quality.
  • Investigate and triage software issues identified through manufacturing operations, factory diagnostics, launch-quality activities, service feedback, and early field observations.
  • Support supplier software quality management activities including issue tracking, root-cause review, corrective-action validation, software readiness assessments, and release quality improvement.
  • Partner with internal engineering teams and software suppliers to investigate field and factory issues, validate corrective actions, and drive software quality improvements.
  • Provide technical evidence, validation findings, quality status, and investigation summaries to support software quality gate reviews, milestone assessments, and release decisions.
  • Drive improvements in logging, telemetry, diagnostics, monitoring capability, issue detection, and software quality processes.
  • What Success Looks Like (First 12 Months)
  • Increased issue reproduction rate and reduced time-to-root-cause for critical software issues.
  • Signal-monitoring capability proactively identifies recurring software defects before significant field impact.
  • Successful support of Software Safe Launch activities with rapid identification and containment of software-related production issues.
  • Improved software deployment quality through validation of ECU flashing and OTA release processes.
  • Improved supplier software quality through timely issue resolution, validated corrective actions, and reduced recurring defects.
  • Reduced escaped defects and improved software stability across production releases.
  • Qualifications Collaboration & Execution
  • Strong collaboration skills across Software Development, Validation, Manufacturing Engineering, Diagnostics, Cloud, Automation, Service Engineering, Supplier Engineering, and Quality organizations.
  • Ability to communicate complex technical findings through concise, data-driven summaries, dashboards, signal timelines, and actionable recommendations.
  • Strong ownership mindset with a focus on software quality, launch readiness, validation efficiency, investigation rigor, and cross-functional execution.
  • Technical Qualifications
  • 7+ years of experience in automotive software validation, embedded software testing, diagnostics, software quality engineering, system integration, vehicle launch support, or related technical disciplines.
  • Hands-on experience with software validation, regression testing, release acceptance testing, and customer-facing vehicle software features.
  • Experience collecting and analyzing vehicle logs, PCAP, CAN data, diagnostics, DTCs, cloud telemetry, and large-scale signal datasets.
  • Strong understanding of vehicle networks, ECU communication, CAN, Ethernet, diagnostics, software deployment, and software validation processes.
  • Experience supporting ECU software flashing, OTA updates, release readiness reviews, production software quality activities, or launch support.
  • Experience working with software suppliers to manage defect investigations, review root-cause analyses, validate corrective actions, and support software release readiness.
  • Strong debugging and root-cause analysis skills with the ability to connect customer symptoms, vehicle behavior, signal evidence, and software implementation details.
  • Familiarity with automotive software quality processes, defect management, launch-quality activities, and milestone-based development programs.
  • Proficiency with Python, SQL, CAN DBC databases, Grafana, InfluxDB, Prometheus, or similar data analysis and monitoring tools.
  • Education
  • Bachelor’s degree in Electrical Engineering, Computer Engineering, Computer Science, Software Engineering, Automotive Engineering, or a related technical discipline preferred.
  • Equivalent hands-on experience in automotive software validation, diagnostics, embedded systems, software quality, technical investigations, supplier quality, or manufacturing quality support will also be considered.
