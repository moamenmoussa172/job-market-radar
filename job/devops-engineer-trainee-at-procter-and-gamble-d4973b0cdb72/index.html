About the job

Job Location

WARSAW PLANT & GO

Job Description

As a DevOps Engineer Trainee you will design, build and maintain CI/CD capabilities supporting applications and engineering teams across multiple technology stacks and cloud environments. You will transform engineering requirements into scalable automation, reusable pipeline components and platform capabilities that reduce manual work and make engineering standards easier for application teams to adopt.

This is a hands-on technical engineering role. You will work directly with application teams, platform engineers and other engineering stakeholders to understand delivery challenges, identify opportunities for automation and implement solutions that can be reused across teams.

You will work with GitHub, GitHub Actions, Azure DevOps, Azure and Google Cloud Platform, using infrastructure-as-code, containers and scripting to automate software delivery and cloud engineering processes.

Key Responsibilities

  • Design, develop and maintain CI/CD pipelines that automate build, test, security validation, deployment and release activities across different application technology stacks.
  • Build reusable GitHub Actions workflows and pipeline templates that standardize common delivery patterns and allow application teams to adopt CI/CD capabilities through self-service rather than bespoke implementations.
  • Develop automation using Python, shell scripting and infrastructure-as-code, reducing repetitive operational work and improving consistency across engineering environments.
  • Implement and maintain cloud infrastructure automation across Azure and Google Cloud Platform using tools such as Terraform.
  • Support application teams with CI/CD onboarding and modernization, including assessment of existing pipelines, migration toward standard patterns and resolution of complex pipeline and deployment issues.
  • Integrate SDLC requirements into engineering workflows, helping teams meet engineering, security and application compliance expectations through automation rather than manual controls. This responsibility was explicitly part of the previous role.
  • Implement containerized and cloud-native delivery patterns using technologies including Docker and Kubernetes where appropriate.
  • Improve engineering reliability and developer experience by identifying recurring problems, removing unnecessary manual activities and creating reusable platform solutions.
  • Monitor and analyze CI/CD performance, using engineering metrics and observability capabilities to identify opportunities for improving pipeline reliability and software delivery performance.
  • Troubleshoot software delivery and infrastructure issues, collaborating with development and platform teams to identify root causes and implement sustainable fixes rather than repeated workarounds.
  • Support DevOps capabilities throughout their lifecycle, including implementation, upgrades, maintenance, incident troubleshooting and continuous improvement.
  • Explore and implement AI-assisted DevOps capabilities, including the use of AI coding assistants and engineering agents to accelerate troubleshooting, pipeline management, automation and developer productivity.
  • Collaborate with engineering teams and technical stakeholders to understand development workflows and translate engineering requirements into scalable platform solutions.
  • Document platform capabilities, engineering standards and self-service patterns so that application teams can consume DevOps capabilities consistently and independently.

Job Qualifications

  • 3rd, 4th, 5th year students or graduates - with a real passion for business and technology.
  • Strong hands-on experience in DevOps, Platform Engineering, Cloud Engineering or Software Engineering, with demonstrated experience building and operating automated software delivery solutions.
  • Strong experience with Git, GitHub and GitHub Actions, including implementation and maintenance of CI/CD workflows.
  • Practical cloud engineering experience with Microsoft Azure and/or Google Cloud Platform, with the ability to work effectively across cloud services as required by application architectures.
  • Experience with Infrastructure as Code, preferably Terraform, including creation and maintenance of reusable infrastructure components.
  • Experience with Docker and containerized application delivery; knowledge of Kubernetes or other container orchestration platforms is strongly preferred.
  • Experience developing engineering automation using Python and/or shell scripting.
  • Working knowledge of YAML, JSON and configuration-as-code approaches used by modern CI/CD and cloud platforms.
  • Understanding of modern SDLC and DevSecOps practices, including automated testing, security controls, vulnerability management and compliance within software delivery workflows.
  • Experience designing reusable automation and engineering templates rather than solutions optimized for only one application or team.
  • Ability to troubleshoot complex CI/CD, cloud infrastructure and deployment issues across multiple system components.
  • Understanding of Site Reliability Engineering and observability concepts, including monitoring, reliability and operational support. SRE and observability were identified as desirable experience in the previous role.
  • Understanding of software delivery and engineering performance metrics, including DORA metrics, is preferred.
  • Experience with or strong interest in AI-assisted software engineering, including GitHub Copilot, coding agents or AI-assisted automation and troubleshooting. GenAI and Copilot for Developer Productivity were already listed as desirable experience in the original specification.
  • Strong analytical and problem-solving skills with the ability to identify root causes and translate them into scalable technical solutions.
  • Strong collaboration and communication skills and ability to work effectively with application developers, engineering teams and technical stakeholders.
  • High attention to detail combined with the ability to work autonomously and take ownership of technical deliverables.
  • Continuous-learning mindset and willingness to adopt new cloud, DevOps and AI technologies as the engineering ecosystem evolves.
