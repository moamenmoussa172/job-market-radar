About the job

Job Summary

We are seeking a skilled and proactive .NET Development Lead to join our global engineering team. The ideal candidate will be responsible for developing, reviewing, and maintaining .NET applications while collaborating with cross-functional teams across time zones. This role requires strong technical expertise, ownership, and the ability to troubleshoot production issues, including during off-hours, while continuously improving systems and processes. The .NET Development lead will also be responsible for owning and reviewing designs, owing and reviewing the code, mentoring the team, being accountable for the deliverables, ensuring best practices including security practices are always followed, and collaborating very closely with Scrum Masters, Product Owners, Architects, Stake Holders, Development Managers and rest of the engineering team.

Key Responsibilities

  • Design, develop, and maintain applications using .NET technologies (C#, .NET Core/.NET 4.8+, ASP.NET MVC/Web API)
  • Download, review, and analyze existing codebases to understand functionality and identify improvements
  • Troubleshoot, debug, and resolve application issues efficiently
  • Provide production support, including:
  • Monitoring and supporting live customer environments
  • Troubleshooting and analyzing production issues, especially during off-hours or critical incidents
  • Performing root cause analysis (RCA) and implementing fixes to prevent recurrence
  • Drive and Own design and code reviews, ensuring adherence to coding standards and best practices; Download and test the code hands on during code reviews.
  • Collaborate with global teams across multiple time zones, adjusting work schedules when required
  • Actively engage with team members (Development, QA, DevOps, Product) to resolve issues quickly and effectively
  • Understand and support the release and deployment processes
  • Analyze release workflows and suggest improvements or enhancements
  • Contribute to CI/CD pipeline improvements and automation initiatives
  • Provide regular updates on progress, risks, and dependencies

Technical Skills Required

  • Strong experience with:
  • C#, .NET Core / .NET 4.8+
  • ASP.NET MVC / Web API
  • Visual Studio
  • Azure functions and related services.
  • Solid understanding of Object-Oriented Programming (OOP) and design principles
  • Experience with:
  • SQL Server / Azure DB / relational databases
  • Full text search and equivalent
  • Entity Framework or similar ORM tools
  • Third Party integrations for a web-based application
  • AI integration
  • Familiarity with RESTful APIs and integrations
  • Hands-on experience with version control systems (Git, Azure DevOps, GitHub)
  • Understanding of branching strategies and code management

Release & DevOps Knowledge

  • Experience with build and release processes
  • Familiarity with CI/CD tools (Azure DevOps, Jenkins, or similar)
  • Ability to:
  • Understand release cycles
  • Identify gaps and recommend process enhancements

Production Support & Incident Management

  • Experience supporting production environments
  • Ability to:
  • Handle critical incidents and urgent fixes
  • Perform log analysis, debugging, and performance troubleshooting
  • Work in an on-call or off-hours support model
  • Interact with the customers directly and co-ordinate activities
  • Strong focus on customer impact and service reliability

Soft Skills & Behavioral Competencies

  • Excellent communication and collaboration skills including fluent proficiency (verbal and written) in English language.
  • Strong problem-solving and analytical thinking
  • Ability to take ownership and drive tasks to completion
  • Proactive in reaching out and coordinating with stakeholders
  • Flexible to work across global time zones
  • Strong team player with a continuous learning mindset
