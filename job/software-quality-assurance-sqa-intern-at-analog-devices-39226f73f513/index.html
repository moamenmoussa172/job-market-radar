Software Quality Assurance (SQA) Intern

About the Role

As a Software Quality Assurance (SQA) Intern at ADI, you will be an entry-level engineer focused on developing and maintaining software quality solutions. This role is designed to help you grow your technical skills and understanding of software test and operations practices while contributing to ADI's innovative technology solutions under the guidance of experienced engineers.

Key Responsibilities

  • Write and debug tests, test frameworks, and operations code under the supervision of experienced team members
  • Assist in software testing and documentation activities
  • Learn and apply company software development and test practices and methodologies
  • Contribute to small features or bug fixes within established codebases
  • Participate in code reviews with guidance to improve your skills
  • Support basic software maintenance tasks and routine updates

Must-Have Skills

  • Programming: Basic proficiency in at least one programming language (e.g., Python, C/C++, C#)
  • Data Structures: Understanding of fundamental data structures and algorithms
  • Scripting: Basic scripting abilities for automation and testing
  • SDLC: Fundamental knowledge of software development methodologies
  • Version Control: Experience with version control systems (e.g., Git)

Preferred Education and Experience

  • Pursuing an undergraduate degree in Computer Science, Software Engineering, or a related technical field
  • Internship experience in software development or testing is a plus
