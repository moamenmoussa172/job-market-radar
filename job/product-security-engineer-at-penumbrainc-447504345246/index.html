About the job

The Product Security Engineer is a hands-on security engineer embedded with Penumbra’s software development teams.

This role helps teams build security into products from design through release by implementing the NIST Secure Software Development Framework (SSDF).

The role also owns day-to-day product security and HIPAA compliance activities for Penumbra’s product software and connected products.

The Product Security Engineer works side by side with developers, architects, quality, and regulatory teams to find and fix security issues early and to produce the evidence needed to demonstrate compliance.

Specific Duties and Responsibilities
• Work embedded within product development teams as the primary security resource, participating in planning, design reviews, code reviews, and release activities.
• Implement and operationalize the NIST Secure Software Development Framework (SSDF, SP 800-218) across the product development lifecycle, including defining practices, tooling, and evidence for each phase.
• Perform threat modeling and security architecture reviews for new products, features, and significant changes, document risks, and recommend mitigations.
• Integrate and tune security testing in CI/CD pipelines, including static and dynamic application security testing (SAST/DAST), software composition analysis (SCA), secrets scanning, and container and infrastructure-as-code scanning.
• Triage security findings with developers, validate fixes, and track product vulnerabilities through remediation within defined timelines.
• Own product HIPAA security compliance activities, including risk analyses, safeguard mapping, and documentation for products that create, receive, maintain, or transmit protected health information (PHI).
• Generate and maintain software bills of materials (SBOMs) and manage third-party and open-source component risk.
• Support product security documentation for regulatory submissions, customer security questionnaires, and audits, in partnership with quality and regulatory teams.
• Develop secure coding standards and guidance and deliver practical security training to developers.
• Support coordinated vulnerability disclosure and product security incident response, including investigation, remediation, and customer communication in partnership with other teams.
• Conduct or coordinate penetration testing of products and applications and manage findings through to closure.
• Track and report product security metrics (e.g., open vulnerabilities by severity, time to remediate, SSDF practice adoption).
• Adhere to the Company’s Quality Management System (QMS) as well as domestic and global quality system regulations, standards, and procedures.
• Understand relevant security, privacy, and compliance principles and adhere to the regulations, standards, and procedures that are applicable to the Company.
• Ensure other members of the department follow the QMS, regulations, standards, and procedures.
• Perform other work-related duties as assigned.

Position Qualifications
• Bachelor's degree in Computer Science, Software Engineering, Information Security, or related field with 5+ years of experience, or equivalent combination of education and experience.
• Preferred certifications in any of the following: Certified Secure Software Lifecycle Professional (CSSLP), GIAC Web Application Penetration Tester (GWAPT), Offensive Security Certified Professional (OSCP), or Certified Information Systems Security Professional (CISSP).
• 5+ years of experience in application security, product security, or software engineering, including hands-on security work within a development environment.
• Software development background with the ability to read and review code in one or more modern languages (e.g., C#, JavaScript/TypeScript, C/C++, Python, Java).
• Practical knowledge of the NIST SSDF, OWASP Top 10, OWASP ASVS or SAMM, and secure design principles.
• Hands-on experience with application security tooling (SAST, DAST, SCA, secrets scanning) and CI/CD platforms (e.g., GitHub, GitLab, Azure DevOps, Jenkins).
• Experience with threat modeling methodologies (e.g., STRIDE) and security architecture reviews.
• Working knowledge of HIPAA Security Rule requirements and safeguarding PHI in software products.
• Experience securing cloud-hosted applications and APIs (AWS, Azure, or GCP), including identity, secrets management, and encryption.
• Familiarity with medical device cybersecurity expectations (e.g., FDA premarket cybersecurity guidance, SBOM requirements, IEC 81001-5-1, AAMI TIR57) is highly desirable.
• Experience working within a regulated quality system (e.g., ISO 13485 or FDA quality system requirements) is a plus.
• Ability to build trust with developers and influence without authority, with a pragmatic approach that balances risk with delivery.
• Strong oral, written, and interpersonal communication skills.
• Proficiency with MS Word, Excel, and PowerPoint.
• Excellent organizational skills with the ability to prioritize assignments while handling various projects simultaneously.
