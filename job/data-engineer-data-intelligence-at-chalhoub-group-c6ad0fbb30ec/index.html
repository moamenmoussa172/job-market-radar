What you'll be doing

Implement machine learning algorithms and feature stores, build and deploy model inference endpoints, and develop and test prompt templates for the Group's internal generative AI tools.

• Implement machine learning algorithms and build feature stores to support model development.

• Build and deploy model inference endpoints via REST APIs into production.

• Write and test prompt templates for internal generative AI tools on the company's enterprise GenAI platform (Alia).

• Build and integrate generative AI features using LLM APIs and frameworks, including basic retrieval-augmented generation components.

• Prepare and engineer features from structured and semi-structured datasets using Python (Pandas, NumPy, Scikit-learn).

• Train, evaluate, and tune models using appropriate techniques and metrics (accuracy, precision, recall) to support performance.

• Support MLOps pipelines and model versioning across cloud AI platforms (e.g. Azure AI, Google Vertex AI, AWS SageMaker), and monitor deployed models for performance and drift.

• Document model implementations, experiments, and test results for reproducibility.

• Collaborate with senior engineers on model integration and with data engineering teams on data readiness.

What you’ll need to succeed

• Minimum 3 years of experience in machine learning or AI engineering.

• Proficiency in Python and machine learning libraries (Pandas, NumPy, Scikit-learn, TensorFlow).

• Solid SQL skills for querying and preparing data from databases and cloud data warehouses (e.g. BigQuery, Snowflake).

• Experience building and deploying model inference endpoints via REST APIs.

• Familiarity with generative AI and prompt template development for GenAI tools,including LLM APIs (e.g. OpenAI, Anthropic Claude, Google Gemini) and basic retrievalaugmented generation concepts.

• Exposure to AI frameworks and tools such as LangChain or LlamaIndex, and vector databases.

• Working knowledge of cloud AI platforms (Azure AI, GCP), model evaluation metrics, and basic MLOps concepts (model versioning, monitoring).

• Experience working with structured and semi-structured data and feature engineering.

• Hands-on experience with AI coding assistants (e.g. Claude Code, GitHub Copilot, Cursor) for AI-assisted development.
