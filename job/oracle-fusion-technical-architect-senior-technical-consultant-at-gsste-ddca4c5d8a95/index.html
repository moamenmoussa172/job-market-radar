About the job

Oracle Fusion Technical Architect / Senior Technical Consultant

Location: UAE
Experience: 8+ Years
Employment Type: Full-time

Job Summary

We are looking for an experienced Oracle Fusion Technical Architect / Senior Technical Consultant with strong expertise across Oracle Fusion Finance and Procurement, Oracle Integration Cloud (OIC), PaaS extensions, reporting, and high-volume integrations.

The ideal candidate should have hands-on experience designing and governing enterprise-grade Oracle Cloud solutions, particularly integrations with core banking, payment platforms, trading systems, and other high-volume external applications.

Key Responsibilities

Integration Architecture

  • Design, develop, govern, and maintain high-volume integrations using Oracle Integration Cloud (OIC).
  • Design and validate complex interfaces between Oracle Fusion, Core Banking, Payment Gateways, and third-party/legacy systems.
  • Develop and manage REST/SOAP web services and integration frameworks.
  • Ensure integrations meet performance, scalability, security, and reliability standards.

PaaS & Custom Development

  • Design, develop, and review PaaS extensions using Visual Builder Cloud Service (VBCS).
  • Build custom business logic, forms, workflows, and extensions where standard Fusion SaaS functionality does not meet business requirements.
  • Work with Application Composer and Page Composer for Fusion customizations.
  • Develop solutions using Groovy and other Oracle Cloud technologies.

Reporting & Analytics

  • Own the technical delivery, optimization, and maintenance of BI Publisher (BIP), OTBI, and Financial Reporting Studio (FRS) reports.
  • Develop complex SQL queries against Oracle Fusion data structures.
  • Troubleshoot report performance and optimize queries for large datasets.
  • Support complex Finance and Procurement reporting requirements.

High-Volume Data Processing

  • Design and optimize large-scale data ingestion and processing mechanisms.
  • Work with FBDI and ADFdi for bulk data loads and integrations.
  • Ensure data integrity, performance, error handling, and reconciliation for high-volume transactions such as daily GL interface files.

Security & Environment Administration

  • Manage Oracle Fusion Security Console, including custom roles, privileges, and access controls.
  • Ensure security configurations comply with enterprise security policies.
  • Manage P2T environment refreshes, certificates, and related technical activities.
  • Support troubleshooting across Oracle Fusion environments.

Code Governance & DevOps

  • Establish and enforce coding standards, integration patterns, logging, monitoring, and error-handling frameworks.
  • Review technical designs and code before production deployment.
  • Drive structured code migration and release management across Oracle environments.
  • Work with GitHub and CI/CD pipelines to improve deployment automation and governance.

Required Qualifications & Technical Skills

  • 5+ years of hands-on experience in the Oracle Cloud ecosystem across PaaS/SaaS.
  • Strong experience with Oracle Fusion Finance and/or Procurement modules.
  • Expert understanding of Oracle Fusion data structures, APIs, business processes, and architecture.
  • Strong expertise in:
  • SQL & PL/SQL
  • Groovy Scripting
  • Shell Scripting
  • Oracle Integration Cloud (OIC)
  • BI Publisher (BIP)
  • OTBI
  • Financial Reporting Studio (FRS)
  • FBDI & ADFdi
  • REST/SOAP Web Services
  • Application Composer & Page Composer
  • Visual Builder Cloud Service (VBCS)
  • Workflow & BPM
  • Oracle Fusion Architecture
  • OCI
  • Experience with Oracle Generative AI capabilities is preferred.
  • Experience integrating Oracle ERP/Fusion with high-volume external systems, preferably banking, payments, or trading platforms.
  • Strong understanding of enterprise integration patterns, security, performance optimization, and error handling.
  • Strong DevOps mindset with experience in code migration and release management.
  • GitHub and CI/CD experience will be an added advantage.

Preferred Experience

  • Banking, financial services, or trading domain experience.
  • Experience handling high-volume financial transactions and GL interfaces.
  • Experience working in enterprise-scale Oracle Fusion implementations.
  • Strong troubleshooting and performance-tuning capabilities.
  • Ability to work closely with functional teams, architects, business stakeholders, and infrastructure teams.

Key Competencies

  • Strong technical architecture and problem-solving skills
  • Excellent understanding of Oracle Cloud technologies
  • Ability to design scalable and resilient integrations
  • Strong ownership of production-grade solutions
  • Excellent communication and stakeholder management skills
  • Strong focus on coding standards, security, performance, and quality
