About the job

About the Developer Experience team

The Developer Experience (DevX) team owns how developers learn and build on Together AI. We run the documentation site, API reference, quickstarts, cookbooks, and the tooling that keeps all of it accurate as the platform ships new models and features every week.

We treat docs as a product and as code. Content lives in Git, publishes through Mintlify, and stays in sync with the API through CI/CD automation built on GitHub Actions. We also write for two audiences at once: the human developer reading a guide, and the AI coding agent pulling our docs into its context window. That means a house style guide built for AI-assisted authoring, structured content agents can parse, and automated review passes that check drafts against our quality bar.

Role Overview

As a Technical Writer Intern on DevX, you will write, test, and ship documentation that thousands of developers use to build with open-weight models. You'll be paired with a DevX mentor and own significant projects end to end, from scoping through launch, with real users and real metrics at the finish line.

This is a hands-on, technical role. You'll run the code you document, call our APIs, and open pull requests against the docs repo from your first week.

Potential projects include:

  • Build a closed-to-open migration kit
  • Make a docs section agent-ready, and prove it
  • Generate the CLI reference from source
  • Write an evaluation design tutorial series

Responsibilities

  • Write clear, accurate guides, tutorials, and reference content for Together AI's inference, fine-tuning, and GPU cluster products.
  • Work with engineers, product managers, and researchers to understand new features well enough to explain them simply.
  • Use AI tools in your daily workflow, and help us improve how we use them for drafting, editorial review, and publishing.
  • Test every feature you document by running the code yourself, and file bugs when the product or the docs don't behave as expected.
  • Draft, review, and publish in a docs-as-code workflow: Git, pull requests, code review, and Mintlify.
  • Contribute to release notes and changelog entries as features launch.
  • Use page analytics, search data, and developer feedback to decide what to improve next.

Qualifications

  • Currently enrolled in a bachelor's or master's program in Computer Science, Technical Communication, or a related field, graduating December 2027 or later.
  • Exceptional written communication: you can make a complex technical idea clear and approachable.
  • Working knowledge of at least one programming language (Python or TypeScript preferred) and comfort with Git source control.
  • Curiosity about how developers learn, and how AI is changing the way they do it.

Nice to have

  • Experience calling an LLM API or building a small project with AI tools.
  • Familiarity with Markdown/MDX, static site generators, or docs platforms like Mintlify or Docusaurus.
  • Experience with CI tools such as GitHub Actions.

Writing sample

Your application should include one or two writing samples, representing what you think is your own best work. The subject doesn’t have to be technical, or even nonfiction—though both are a plus! For example:

  • A technical blog post.
  • A README, tutorial, or contribution to open-source docs.
  • A research paper.
  • A personal essay.
  • A school newspaper submission.

About Together AI

Together AI, the AI Native Cloud, is purpose-built for AI engineers. AI application developers get high-performance inference that scales reliably, fine-tuning and reinforcement learning for creating frontier-level specialized models, and pre-training at massive scale for fully custom intelligence, all around a marketplace of leading open models that teams can run, adapt, and own. Trusted by Cursor, Decagon, ElevenLabs, Salesforce, and Zoom, Together serves 400+ trillion tokens a month.

Internship Program Details:

Our internship program runs 12 to 14 weeks, giving you the opportunity to work alongside industry-leading engineers and researchers across multiple teams. This cohort's internship dates span either May 17th to August 6th or June 14th to September 3rd.
