About the job

Your contribution to something big

We make cyclists smile!
Join our eBike Software Development team and help connect embedded firmware with the people and tools that bring it to life. As the first point of contact for stakeholders, you’ll help investigate issues, understand their needs, and work closely with firmware and hardware engineers to find practical solutions. You’ll also build user-friendly web applications with React and FastAPI, creating tools that make it easier to interact with, test, and support embedded systems.

In this role, you will:

  • Act as the first point of contact for stakeholders using embedded firmware tools and applications, helping clarify issues, gather relevant information, and provide timely support.
  • Investigate and triage reported problems, reproduce issues where possible, and coordinate with embedded firmware, software, and hardware teams to find solutions.
  • Develop and maintain user-friendly web interfaces using TypeScript and React to configure, monitor, and interact with embedded firmware.
  • Build and maintain backend services and APIs using Python and FastAPI, connecting web applications with firmware tools, devices, and engineering workflows.
  • Create scripts and automation to support firmware development, testing, debugging, and stakeholder workflows.
  • Work with embedded systems and communication interfaces such as UART, CAN, USB, SPI, or I2C to understand how the GUI communicates with target devices.
  • Contribute to software quality through code reviews, testing, documentation, version control, and maintainable development practices.
  • Collaborate with international, cross-functional teams, translating stakeholder needs into practical tools and improvements.

What distinguishes you

Education:

  • Currently pursuing or recently graduated with a Bachelor’s or Master’s degree in Computer Science, Electrical, Electronic, Mechatronic, Computer Engineering, or a related technical discipline.

Experience and know-how:

  • Experience with TypeScript and a frontend framework such as React.
  • Strong Python skills and familiarity with developing APIs, preferably using FastAPI.
  • Solid understanding of HTML5, CSS3, responsive design, and integrating RESTful APIs.
  • Familiarity with Git and collaborative software development practices.
  • Basic understanding of embedded software and hardware-software integration.
  • Familiarity with communication interfaces such as UART, CAN, USB, SPI, or I2C.
  • Basic Linux knowledge and comfort using command-line tools.
  • Experience with scripting, testing, debugging, or automation is an advantage.
  • Exposure to hardware debugging tools, embedded toolchains, or reading schematics and datasheets is a plus.

Languages and working style:

  • Good written and spoken English communication skills.
  • Helpful and service-oriented, with the ability to communicate clearly with stakeholders and technical teams.
  • Curious, proactive, and eager to learn; comfortable investigating unfamiliar issues and following them through.
  • A collaborative team player with an interest in both web development and embedded systems.
