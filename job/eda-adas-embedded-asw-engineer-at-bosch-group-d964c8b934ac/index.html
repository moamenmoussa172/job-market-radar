About the job

  • Analyse and break down customer and system requirements into clear, testable software requirements for ADAS functions.
  • Design, implement, and maintain embedded automotive software in C++ for driver assistance functions.
  • Collaborate with system, software, testing, and project stakeholders to clarify requirements, resolve technical issues, and ensure timely delivery.
  • Develop and execute unit tests using Google Test (gTest), support software testing, and perform debugging, root-cause analysis, and defect resolution.
  • Participate in code and design reviews, and use configuration management and defect tracking tools to maintain software quality and traceability.
  • Provide effort estimation, technical input, and risk feedback for project planning and release preparation.
  • Ensure compliance with automotive development processes, coding standards, ASPICE expectations, and applicable functional safety practices.
  • Take ownership of assigned software tasks, work independently within a dedicated project team, and meet delivery timelines and software quality targets.
  • Education: Bachelor in software engineering or related field
  • ADAS and embedded domain: Functional knowledge of driver assistance systems. Automotive and embedded domain knowledge is mandatory.
  • Software engineering: Strong C++ programming, requirement engineering, and debugging skills
  • Testing: Working experience with the Google Test (gTest) framework and a strong understanding of unit testing and software test methodologies.
  • Developer tools and processes: Strong knowledge of developer tools; experience with configuration management and defect tracking tools; hands-on experience with Bitbucket, GitHub, Git, and Visual Studio Code; understanding of Automotive SPICE (ASPICE) and functional safety processes and practices.
  • Communication and collaboration: Strong communication and interpersonal skills, with the ability to work independently within a dedicated project team and manage multiple stakeholders.
  • Preferred skills (advantages): Knowledge of CAN / Ethernet communication protocols; Python scripting; Japanese language skills; knowledge of Linux / QNX; expertise in vehicle-specific physics.
