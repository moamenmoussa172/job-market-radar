About the job

We are looking for a passionate student to help us bring AI solutions to life on dedicated embedded HW, for ADAS use cases targeting mobile platforms such as passenger cars, trucks or motorcycles.

In this role you will:

  • Develop / update / maintain various AI / Computer vision component runnables and associated logic, with synchronous / asynchronous behavior and serial / parallel (multi) threading logic
  • Develop / update / maintain various AI “glue” code for inference / post-processing of AI models / CV algos, as well as (inter)dependencies to other parts of the bigger system (incl. non-ML parts)
  • Generate and analyze performance of various AI models / CV algos in terms of semantic KPIs using various metrics, on various datasets
  • Test and analyze performance of various AI models / CV algos in terms of HW efficiency KPIs (e.g. runtime / bandwidth / overall load), both in the form of individual components as well as full system
  • Integrate model binaries in different production environments, ranging from C++ SW resimulation / target HW to Azure cloud pipelines
  • Deploy various neural networks / AI models (Vision / Language / etc.) on selected SoCs by using dedicated tools to generate executable model binaries
  • Understand and apply different optimization methods to improve HW efficiency and overall system stability
