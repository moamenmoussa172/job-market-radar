About the job

About the Role

GSS Tech Group is hiring a Senior Android Engineer for a leading bank in the UAE. You will join a team building a large scale, multi module Android banking application used by millions of customers, and you will help bring AI powered features into the app.

This role is for an engineer who is strong in modern Android architecture and who has built and shipped LLM features inside an Android app. You will work across feature teams to keep the codebase scalable, fast and stable, while integrating conversational and agentic AI capabilities safely into a regulated banking environment

Key Responsibilities:


Android Architecture and Platform

• Build and maintain a large scale, multi module Android application using Kotlin and Jetpack Compose

• Design scalable Gradle architectures, including feature modules, API and implementation separation, convention plugins and version catalogs

• Improve build performance using build cache, configuration cache, KSP and modularization strategies

• Apply strong dependency injection patterns using Hilt or Dagger so code stays testable across feature teams

• Define and enforce architecture standards (Clean Architecture, MVVM or MVI, unidirectional data flow)
Performance and Stability
• Implement and monitor Firebase Crashlytics and maintain a high crash free user rate

• Diagnose and resolve ANRs, memory leaks and performance bottlenecks using Android Studio Profiler, LeakCanary, Perfetto and Macrobenchmark

• Build high performance Compose UIs and optimize recomposition and rendering
AI Integration
• Integrate LLM APIs (such as OpenAI, Gemini or Claude) into production Android features

• Work with MCP (Model Context Protocol) frameworks and tool calling to connect AI models with app and backend services

• Manage tokens, context windows and conversation history efficiently

• Build agentic workflows and contribute to multi agent orchestration where needed

• Design AI error recovery: timeouts, rate limits, invalid or unsafe responses, and graceful fallback to standard app flows

• Make sure AI features meet banking standards for security, privacy and data protection

Collaboration

  • Work closely with product, design, backend, QA and security teams
  • Review code, mentor engineers and contribute to technical decisions

Required Skills and Experience

  • 6+ years of hands on Android development with Kotlin
  • Proven experience shipping at least one LLM or AI powered feature inside an Android app in production (for example, an in app assistant, chatbot, AI search or recommendations)
  • Strong Jetpack Compose experience in production
  • Experience working on a multi module Android codebase, with a clear understanding of how modules are structured and connected
  • Solid Gradle knowledge, including build configuration and build performance
  • Hilt or Dagger for dependency injection
  • Hands on experience with Crashlytics, memory profiling and ANR diagnosis
  • Expertise in at least two of the following:
  • Kotlin Coroutines and Flow
  • DataStore and Room
  • OkHttp and Protocol Buffers
  • WorkManager

Preferred Skills

  • Banking, fintech or payments app experience
  • MCP server or tool integration experience
  • Experience with Firebase AI Logic, Vertex AI or Gemini Nano on Android
  • Baseline Profiles and Macrobenchmark
  • Kotlin Multiplatform
  • Mobile security practices: SSL pinning, Android Keystore, Play Integrity, OAuth 2.0 with PKCE

What We Look For in Your CV

To help us review your profile quickly, please include:

The AI feature you built in an Android app: what it does, which model or API it uses, and roughly how many users it serves

Measurable results, for example: crash free rate, ANR reduction, rendering or startup improvements, build time improvements

The scale of the codebase you worked on, for example: number of modules, team size, user base
