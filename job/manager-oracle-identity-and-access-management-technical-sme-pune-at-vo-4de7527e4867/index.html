About this Role

We are seeking an experienced Oracle Identity & Access Management Technical SME to provide senior technical leadership and end-to-end operational support for enterprise Oracle Identity and Access Management (IDAM/IAM) services.

You will work across Oracle Identity Manager (OIM), Oracle Access Manager (OAM), Oracle Virtual Directory (OVD), Oracle Internet Directory (OID) and Oracle WebLogic Server, supporting secure, highly available and resilient authentication, authorisation and identity lifecycle services.

This role requires strong L3/L4 operations and troubleshooting expertise, with responsibility for critical incident resolution, problem management, platform maintenance, performance optimisation, automation and continual operational improvement. You will also work across application, cybersecurity, infrastructure, database and network teams to resolve complex identity and access issues.

What you’ll do

  • Provide L3/L4 operational support for OIM, OAM, OVD, OID and associated WebLogic environments, helping maintain 24x7 service availability and operational stability.Troubleshoot complex authentication, authorisation, provisioning, reconciliation, SSO and directory-related issues.
  • Investigate OIM provisioning workflows, connectors, adapters, scheduled tasks, reconciliation jobs and access policies.Diagnose OAM authentication flows, WebGates, authentication schemes, policies, sessions and SSO integrations.
  • Support OVD/OID services, including LDAP/LDAPS connectivity, adapters, directory structures and application integrations.Act as a senior technical escalation point for P1/P2 incidents affecting authentication, provisioning or application access.
  • Administer Oracle IDAM and WebLogic environments, including domains, clusters, AdminServer and Managed Servers.Manage SSL/TLS certificates, keystores, truststores and secure application communication.
  • Plan, test and implement Oracle CPU/PSU, WebLogic and IDAM product patches across non-production and production environments.Support disaster recovery, failover, backup/recovery and platform resilience activities.
  • Use Dynatrace, including PurePath, Service Flow, logs, infrastructure and JVM metrics, to investigate incidents and support performance optimisation.Work with observability teams to define IDAM-specific monitoring requirements and improve proactive detection.
  • Analyse JVM heap, garbage collection, JDBC connection pools, threads, application deployments, datasource failures and WebLogic runtime issues. Develop operational automation using WLST, Shell/Bash, Python and SQL, covering health checks, service validation, job monitoring and routine activities.
  • Improve operational runbooks, troubleshooting procedures, recovery processes and technical documentation.Lead root cause analysis and support preventive actions to reduce recurring incidents and operational effort.
  • Lead knowledge transfer, shadow/reverse-shadow and service transition activities into BAU.Mentor L2/L3 engineers and collaborate with architecture, cybersecurity, application, infrastructure and Oracle support teams.

Who you are

You bring strong hands-on experience in enterprise Oracle Identity and Access Management operations, combined with the ability to analyse complex production issues across identity, middleware, directory, database and application layers.

You have:

  • Strong administration and troubleshooting experience with Oracle Identity Manager (OIM), Oracle Access Manager (OAM), Oracle Virtual Directory (OVD), Oracle Internet Directory (OID) and Oracle WebLogic Server.Strong OIM knowledge covering provisioning, reconciliation, connectors, adapters, scheduled tasks, workflows and identity lifecycle processes.Strong OAM knowledge covering SSO, WebGates, authentication schemes, authorisation policies, sessions and identity-store integrations.Good understanding of LDAP/LDAPS, directory structures, OID/OVD and identity-store integrations.Strong operational knowledge of WebLogic domains, clusters, JVM, JDBC, deployments and application troubleshooting.Good Oracle Database and SQL/PL-SQL troubleshooting capability.Strong understanding of SSL/TLS, certificates, keystores, truststores, authentication and authorisation.Practical experience using Dynatrace for monitoring, troubleshooting and performance investigation.Working knowledge of WLST, Shell/Bash, Python and SQL for operational automation.

Desirable experience includes:

  • SAML 2.0, OAuth 2.0, OpenID Connect and federation technologies.Oracle IAM integrations with enterprise and cloud/SaaS applications.Active Directory and Microsoft Entra ID integrations.Oracle IAM or Oracle Middleware certifications.ITIL Foundation certification. CI/CD and configuration automation experience.
