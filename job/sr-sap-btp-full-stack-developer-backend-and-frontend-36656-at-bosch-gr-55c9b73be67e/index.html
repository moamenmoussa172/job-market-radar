About the job

We are looking for an experienced SAP BTP Full-Stack Developer to design, develop, and maintain cloud-based applications and extensions using SAP Business Technology Platform.

This position is not focused only on development, but also on the consulting aspects of new btp applications, working closely with business consultants, solution architects, product owners, and other development teams, the candidate will translate business requirements into technical solutions and contribute to the modernization and digitalization of enterprise applications.

The role will support the development of scalable, secure, and reusable applications that integrate SAP and non-SAP systems across different business divisions and processes. Responsible for designing and building end-to-end solutions, covering backend services, APIs, business logic, database integration, and frontend user interfaces.

The ideal candidate has practical experience with SAP BTP development, strong backend and frontend programming skills, and a solid understanding of enterprise integration, cloud architecture, and SAP application landscapes.

Key Responsibilities

SAP BTP Application Development

  • Design, develop, deploy, and maintain applications and extensions on SAP Business Technology Platform.
  • Develop cloud-native applications following SAP BTP architecture guidelines and development best practices.
  • Build reusable application components and services that can be leveraged across multiple business divisions.
  • Develop applications that extend SAP standard capabilities without unnecessarily modifying the SAP core.
  • Participate in technical solution design, architecture discussions, and development estimations.
  • Ensure applications meet performance, scalability, maintainability, security, and quality requirements.
  • Support application lifecycle management, including development, testing, deployment, monitoring, and maintenance.
  • Contribute to the continuous improvement and evolution of the organization's SAP BTP development platform.

Backend Development

  • Develop backend services, business logic, and application APIs using SAP BTP development frameworks.
  • Design and implement applications using SAP Cloud Application Programming Model (CAP).
  • Design and expose RESTful APIs and OData services for communication between frontend applications and backend systems.
  • Develop integrations with SAP S/4HANA, SAP ECC, SAP SuccessFactors, and non-SAP enterprise applications.
  • Support backend testing, debugging, and troubleshooting.

Frontend Development and User Experience

  • Design and develop modern web applications and user interfaces using SAP Fiori and SAPUI5.
  • Develop responsive and user-friendly applications following SAP Fiori design guidelines.
  • Build reusable frontend components and application interfaces.
  • Integrate frontend applications with backend services using REST APIs and OData.
  • Implement application navigation, user interactions, forms, dashboards, and data visualization.
  • Work with SAP Fiori elements and freestyle SAPUI5 development, depending on business requirements.
  • Ensure consistent user experiences across desktop and mobile devices.
  • Collaborate with UX/UI designers and business stakeholders to translate user requirements into intuitive interfaces.
  • Optimize frontend performance, usability, and accessibility.

SAP Integration and Enterprise Connectivity

  • Develop and maintain integrations between SAP BTP applications and SAP/non-SAP enterprise systems.
  • Work with SAP Integration Suite, including Cloud Integration (CPI), API Management, and related integration capabilities.
  • Develop and consume REST, OData, and SOAP services.
  • Support integration with external technologies such as warehouse management systems, manufacturing applications, automation platforms, and IoT solutions.
  • Understand SAP connectivity options, including destinations, Cloud Connector, and secure communication mechanisms.
  • Troubleshoot integration issues and ensure reliable data exchange across systems.
  • Promote standardized APIs, reusable integration patterns, and loosely coupled application architectures.

AI, Automation, and Emerging Technologies

  • Explore and develop applications leveraging SAP AI capabilities and SAP Business AI services.
  • Evaluate opportunities to use AI, automation, and intelligent workflows to simplify business processes.
  • Develop applications that integrate with robotics, AGVs, manufacturing equipment, printers, access control systems, and other operational technologies.
  • Contribute to proof-of-concepts and innovative solutions that demonstrate the value of SAP BTP across business divisions.

  • Professional experience as software development.
  • Hands-on experience developing applications on SAP Business Technology Platform.
  • Practical experience with SAP Cloud Application Programming Model (CAP).
  • Strong frontend development experience with SAPUI5 and SAP Fiori.
