Job Description

The Avigilon Alta Video team architects the mission-critical cloud and edge infrastructure powering our next-generation video security ecosystem. We are expanding our platform to build deep-tier interconnections across the Motorola Solutions portfolio, delivering high-availability tools that protect people, property, and places. Our team values high engineering discipline, architectural integrity, and an inclusive culture where every perspective helps build more resilient systems.

In this mid-level individual contributor role, you will be based at our office in Uxbridge (West London), operating within a hybrid model with an aim for two days in the office. You will drive automated test coverage for web applications and backend APIs, partnering with engineering teams to enhance software reliability across high-scale microservices. Candidates with equivalent practical experience gained through real-world software delivery are welcome and encouraged to apply.

Key Responsibilities

Automated Test Strategy & Framework Delivery

  • Build, execute, and scale robust automated test suites targeting web applications, microservices, and backend APIs
  • Partner with development teams to analyze system requirements and implement high-efficiency integration tests
  • Maintain automated testing frameworks to help ensure high reliability and repeatable execution across modern browsers and distributed service layers

Platform Quality & Pipeline Automation

  • Integrate automated regression and functional tests directly into continuous integration and delivery pipelines to facilitate reliable releases
  • Analyze and diagnose test execution failures and system defects, working closely with software engineers to reach rapid root-cause resolution
  • Assist in benchmarking quality metrics for real-time video streaming pipelines and assistive AI capabilities

Performance Validation & Test Engineering Health

  • Assist with the execution and initial analysis of performance, load, and stress tests on distributed systems
  • Champion clean test code practices and participate actively in peer code reviews across distributed engineering hubs
  • Oversee test suite health, reducing test flakiness and refining execution runtimes


Basic Requirements

Job Requirements

  • Bachelor's Degree in Computer Science, Software Engineering, or a STEM discipline
  • Solid professional software test automation experience focusing on web applications and APIs
  • Legal authorization to work in the United Kingdom

Technical Expertise

  • Modern Programming Languages to build structured, maintainable test code using JavaScript, TypeScript, or Python
  • API Test Automation to validate RESTful web services, data schemas, and real-time messaging protocols
  • UI & Browser Automation to design and execute end-to-end user workflow test suites
  • CI/CD Integration to incorporate test automation into modern delivery pipelines
  • Actively adopting AI assisted test development practices

Professional Experience

  • Root-Cause Analysis to investigate complex defect patterns, isolate system bottlenecks, and identify sustainable software fixes
  • Distributed Team Collaboration to work across functional and geographic boundaries, fostering an inclusive and supportive engineering environment
  • Technical Adaptability to explore evolving software components and adapt quickly to emerging architectural designs

Preferred Qualifications (Optional)

  • Hands-on experience with modern automation frameworks such as Playwright or Cypress
  • Experience with performance, load, or soak testing methodologies
  • Practical experience with Jenkins or similar pipeline orchestration tools
  • Exposure to real-time video platforms, streaming technologies, or media solutions
  • Exposure to hardware or device automation workflows
  • Understanding of application state patterns (Pinia, Vuex, Redux) and reactive programming concepts
