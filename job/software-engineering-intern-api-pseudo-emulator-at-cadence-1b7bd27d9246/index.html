Intitulé : Software Engineering Intern

Localisation : Rennes (France).

Periode : Stage de 6 mois à pourvoir

Rattachement hiérarchique : Sr Software Engineering Manager

L’objectif de ce stage est de développer un pseudo-émulateur logiciel de l’ISE Neo afin d’accélérer le développement et le débogage des applications utilisant l’API ISE. L’ISE Neo fournit un mécanisme de démarrage sécurisé et des API dédiées aux opérations cryptographiques, à la gestion et au stockage des clés ainsi qu’à d’autres services de sécurité, normalement assurés par du matériel dédié. Le pseudo-émulateur reproduira le comportement fonctionnel des API.

Au cours de ce stage, vous aurez pour missions de :

  • Analyser le comportement des API et définir le périmètre fonctionnel pris en charge par le pseudo-émulateur.
  • Concevoir et implémenter un environnement logiciel rapide, indépendant des cartes matérielles et centré sur le comportement des API plutôt que sur les contraintes temporelles du matériel ou la précision au cycle près.
  • Implémenter l’émulation logicielle des API cryptographiques, des API de gestion des clés, du stockage des clés et des autres services de sécurité inclus dans le périmètre.
  • Développer des tests fonctionnels pour vérifier le comportement des API prises en charge et les interactions avec les applications par rapport aux résultats attendus.
  • Préparer l’environnement pour son intégration aux tests logiciels automatisés et aux flux d’intégration continue (CI).
  • Documenter les API prises en charge, les limites fonctionnelles, les instructions d’installation et de configuration ainsi que des exemples d’utilisation.

Qualifications requises :

  • Préparer un diplôme de niveau master (Bac+5), un diplôme d’ingénieur ou une qualification équivalente en informatique, en génie logiciel ou dans un domaine connexe.
  • Posséder de solides compétences en programmation C, notamment pour concevoir, implémenter et déboguer des logiciels dans ce langage.
  • Savoir concevoir des tests fonctionnels et traduire le comportement documenté d’une API en implémentations logicielles.
  • Disposer de connaissances de base sur les opérations cryptographiques et les concepts de gestion des clés.

Compétences appréciées proposées :

  • Familiarité avec le développement logiciel embarqué.
  • Expérience des tests automatisés et des flux d’intégration continue (CI).
  • Bonne connaissance de la cryptographie et de la gestion des clés.

Informations complémentaires :

Vous intégrerez une équipe de sept personnes et travaillerez sur le produit ISE. Tout au long du stage, vous collaborerez avec d’autres équipes au développement d’un pseudo-émulateur logiciel destiné à faciliter le développement, le débogage et les tests fonctionnels des applications.

Le développement logiciel sera réalisé en C à l’aide d’un environnement de développement intégré (IDE). Le stage vise à remplacer les tests fonctionnels réalisés sur carte FPGA par un environnement logiciel de pseudo-émulation.

Job Title: Software Engineering Intern

Location: Rennes, France

Period : 6 month internship

Reporting to: Senior Software Engineering Manager

The objective is to develop a software-based pseudo-emulator of the ISE Neo to accelerate the development and debugging of applications using the ISE API. The ISE Neo provides a secure boot mechanism and exposes APIs for cryptographic operations, key management, key storage and other security services, which are normally backed by dedicated hardware. The pseudo-emulator would reproduce the functional behavior of the ISE Neo APIs.

Job Responsibilities:

During the internship, you will:

  • Analyze the API behavior and define the pseudo-emulator’s supported functional scope.
  • Design and implement a fast, board-independent software environment focused on API behavior rather than hardware timing or cycle accuracy.
  • Implement software emulation of supported cryptographic APIs, key management APIs, key storage and other in-scope security services.
  • Develop functional tests to check the behavior of supported APIs and application interactions against expected results.
  • Prepare the environment for integration into automated software tests and CI workflows.
  • Document supported APIs, functional limitations, setup instructions and example usage.

Job Qualifications:

  • Currently pursuing a Master’s-level degree (Bac+5), an engineering degree or an equivalent qualification in computer science, software engineering or a related field.
  • Strong C programming skills, including the ability to design, implement and debug software in C.
  • Ability to design functional tests and translate documented API behavior into software implementations.
  • Basic knowledge of cryptographic operations and key management concepts.

Additional Skills/Preferences:

  • Familiarity with embedded software.
  • Experience with automated testing and CI workflows.
  • Good knowledge of cryptography and key management would be a plus.

Additional Information:

  • You will join a seven-person team and work on the ISE product. Throughout the internship, you will collaborate with other teams on the development of a software-based pseudo-emulator to facilitate application development, debugging and functional testing.Software development in C using an integrated development environment (IDE). The internship aims to replace FPGA board-based functional testing with a software-based pseudo-emulation environment
