About the job

This is a fully remote job, open to people in Egypt.

About the Role

We are looking for an experienced Frontend Engineer (React/Next.js) to contribute to building a secure B2B portal that enables business partners to manage their company profiles, cases, documents, notifications, and search functionality.

The portal will be developed using Next.js, with Microsoft Dynamics 365 serving as the system of record. Integration will be handled through Azure API Management and a Node.js API hosted on Azure App Service.

The ideal candidate will be responsible for developing responsive, accessible, and high-quality user interfaces while ensuring seamless integration with backend services and delivering an excellent user experience.

Key Responsibilities

  • Lead frontend development using React and Next.js, ensuring clean, scalable, and maintainable code.
  • Build and maintain responsive, user-friendly interfaces that allow partners to manage their company profiles, cases, documents, notifications, and search functionality.
  • Collaborate with the Development Lead to establish and implement scalable frontend architecture.
  • Integrate frontend components with backend services through Azure API Management and Node.js APIs.
  • Ensure seamless data integration with Microsoft Dynamics 365 as the system of record.
  • Develop accessible interfaces in compliance with WCAG 2.1 AA standards.
  • Implement and maintain automated tests to ensure application quality and reliability.
  • Optimize application performance, responsiveness, and overall user experience.
  • Collaborate with the Product Owner, Senior Project Manager, Scrum Master, and other technical team members to ensure alignment with project requirements.
  • Follow frontend development best practices and stay up to date with the latest React and Next.js features and industry trends.

Requirements

  • 4+ years of professional experience in React development.
  • 2+ years of hands-on experience with Next.js.
  • Strong experience building responsive and accessible user interfaces.
  • Good understanding of WCAG 2.1 AA accessibility standards.
  • Hands-on experience with Jest and React Testing Library (RTL).
  • Experience with Playwright for end-to-end testing.
  • Strong understanding of frontend architecture, component-based development, and performance optimization.
  • Experience integrating frontend applications with REST APIs and backend services.
