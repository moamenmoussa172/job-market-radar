About the job

Join TomTom’s map-making platform team in Łódź as a Software Engineering Intern. You’ll make our map-data quality checks faster and more reliable with Java, performance analysis and AI coding tools, and take part in daily platform engineering work. Hybrid, starting February 2027, 6 months.

What you'll do:

  • Join the team that runs the platform behind TomTom’s map-making, and take part in daily platform work
  • Make our map-data quality checks faster and more reliable: profile slow rules, improve queries and logic, and show that quality stays the same
  • Use logs, metrics and dashboards as your first step when investigating issues, and add that context to tickets
  • Work inside our CI/CD pipelines: run builds, find which stage failed and fix simple pipeline or configuration issues
  • Write clean, tested Java code with JUnit unit tests, and learn from code reviews
  • Measure before and after: collect run times and failure counts and share the results in simple tables or charts
  • Use AI coding agents and MCP tools to speed up your coding, analysis and documentation
  • What you'll need: Must-have:
  • Currently studying Computer Science, Software Engineering or a related field
  • Programming skills in at least one language, ideally Java
  • A good grasp of basic data structures and algorithms
  • Basic SQL and an understanding of relational databases
  • Familiarity with Git and basic testing concepts (unit, functional and regression testing)
  • Hands-on use of AI tools for coding or research, and the habit of checking what they produce
  • Good English, curiosity and openness to feedback
  • Nice-to-have:
  • Spring Boot, Maven or JUnit experience
  • Exposure to CI/CD, Docker or Kubernetes, or a cloud platform such as AWS
  • Experience with an AI coding agent in your IDE or CLI, or with MCP clients
  • Python for scripting
  • Interest in maps, geospatial data or performance tuning
  • What you can expect:
  • Real work on a production platform with clear, measurable goals
  • A dedicated mentor and regular code reviews from experienced engineers
  • Team knowledge-sharing sessions and hands-on learning in Java, cloud, CI/CD and AI tooling
  • Hybrid work from our Łódź office
