About the job

Job Description:

In order to support the department ‘On-Board Processing’ in Ottobrunn, Airbus Defence and Space is looking for a


Software Development Engineer – Embedded Real-Time SW (d/f/m)

Within the Digital Payload Centre of Competences of Space Systems Engineering organization, you will join the transnational entity (France, Germany and United Kingdom) in charge of Payload Processing, encompassing:

  • Delivery of qualified on-board and on-ground processing chain (payload mission SW / applicative VHDL) for Telecom and Navigation Digital Payloads and RF Sensing
  • Software delivery, operations and functional validation support for Optical & Radar Instruments.

Your location:

Our site is just a stone's throw away from Munich, the beautiful capital of Bavaria. You are into sports and other outdoor activities? The Alps and Lake Starnberg are within an hour’s reach, offering a multitude of recreational options.

Our Benefits for You:

  • Fair Compensation & Extras: Attractive remuneration and individual additional benefits, such as company pension schemes, mobility offers (e.g., bike leasing), or corporate discounts with partner companies in accordance with our current guidelines.
  • Time for You (and Your Loved Ones): 30 days of annual leave based on our collective agreement (35-hour week); work-life balance through flexible working hours (flextime), mobile working, part-time options, job sharing, and sabbatical opportunities.
  • Growth Made Easy: Excellent professional development opportunities and international, group-wide career perspectives.
  • Feel Good at Work: On-site company doctor; comprehensive health programs (sports courses, preventive care, etc.), canteen and cafeteria, and local childcare facilities at selected locations.
  • Diversity Connects: Work in a diverse environment with more than 140 nationalities, where exchange, mutual support, and inclusion are part of our DNA.

The local department in Ottobrunn is in charge of the full development process of Instrument Software, as :

- Analysis of Requirements Baseline provided by System Engineering through the SW Architect, defining the functional behaviour of the SW
- Definition of Embedded SW Architecture ( static and dynamic )
- Implementation of all functionalities as given in Requirements Baseline Execution of HW/SW integration and Functional Qualification before integration in Payload AIT
- Execution of all activities according to external and internal SW Process Standards ( ECSS-E-ST-40C, ECSS-Q-ST-80C )
- Piloting continuous internal efficiency improvement, productivity and processes, industrialization topics for the Digital Payload Processing entity.

Tasks and Responsibilities:

- Transformation of System SW requirements ( SSS ) into detailed SW requirements ( SRS )
- Analysis of embedded/real-time implementation constraints ( memory size, CPU load, deadlines )
- SW Design ( task scheduling, I/O, functional algorithms, SW Mode Management )
- HW/SW interface design ( I/O, interrupts, timing )
- Implementation of SW requirements ( coding )
- HW/SW integration and debugging - HW ( JTAG ) & SW ( gdb )
- Support to Verification activities ( coding rules, metrics, code coverage )
- Execution of SW validation activities ( unit testing, functional testing )
- Configuration control of SW and validation elements
- Generation of SW documentation according to SW process ( ECSS )
- Working multi-disciplinary with other functional domains ( Simulator - FVI, Database – DB )
- Support for controlling schedule and cost of SW development

Desired skills and qualifications:

Technical:

- Degree in Computer Science, Electrical Engineering, Physics (or similar studies)

- Minimum 5-7 years of professional experience in a similar field

- Familiar with Space Standards ( ECSS-E-ST-40C, ECSS-Q-ST-80C, , ECSS-E-ST-70-41C )

- Adherence to a given SW development process and development standards and practices ( OPAL, MISRA, Static Code Analysis, Code Coverage )
- Embedded SW ( working with limited resources )
- Real-time systems and operating systems ( RTEMS )
- Experience in development for bare-metal targets w/o memory protection
- Programming language skills : C/C++, Assembler ( SPARC, ARM, .. )
- Ability to understand HW datasheets
- Familiar with standard interfaces ( Mil-Bus, Spacewire, CAN )
- Mastering the GNU compile environment
- Common SW development tools ( Eclipse, make, Confluence, Git, Jira, Gerrit, Doxygen, Polyspace )
- Mastering of standard SW packages ( Linux, Windows, Office )


Non-technical:

- good communication skills
- ability to work autonomously
- teamworking spirit ( intercultural )
- language skills ( English, Deutsch )

Not a 100% match? No worries! Airbus supports your personal growth with customized development solutions.
