About the job

As a Senior Full-stack Developer for us, you will develop and support Bosch’s workflow platform and business workflow applications. The role combines deep Java/Spring Boot backend engineering with senior JavaScript development, enterprise data and integration work, DevOps practices, and L3 production support. You will diagnose complex defects across platform and application layers and help keep business-critical workflow services secure, scalable, and reliable.

Key Responsibilities

· Design, develop, test, and maintain scalable Java/Spring Boot services, REST APIs, and enterprise integration components for the Workflow Platform.

· Develop, enhance, and support JavaScript-based Workflow Applications, including client-side logic, validations, API consumption, error handling, and maintainable reusable components.

· Operate and optimize enterprise data models, SQL queries, transactions, and persistence logic; resolve complex database, data-consistency, and performance issues.

· Diagnose and fix cross-layer defects spanning Workflow Applications, backend services, databases, search, storage, integrations, and the underlying workflow-platform architecture.

· Build and operate integrations with enterprise systems, S3-compatible object storage, Elasticsearch, databases, and messaging solutions using secure and resilient patterns.

· Support automated testing, source control, CI/CD, containerized and cloud/hybrid deployments, monitoring, release activities, and production troubleshooting.

· Provide L3 engineering support for incidents and problem tickets, perform root-cause analysis and sustainable corrective actions, maintain technical records, and participate in the L3/on-call support rotation.

· Education: Bachelor’s or master’s degree in Computer Science, Software Engineering, Information Technology, a related field, or equivalent practical experience.

· Experience: 7+ years of professional software development, including 5+ years hands-on Java, 3+ years with Spring Boot and REST APIs, and 4+ years hands-on JavaScript development.

· Full-stack engineering: Strong knowledge of object-oriented design, service or microservices architecture, modern JavaScript, browser-based application development, API integration, secure coding, and automated unit/integration testing.

· Enterprise data: In-depth production experience with enterprise database design, SQL, data modeling, transactions, ORM/JPA, query optimization, debugging, data-consistency analysis, and complex issue resolution.

· Platform and integrations: Deep experience supporting or developing legacy/customized Atlassian Jira platforms, plus hands-on integration experience with REST/SOAP APIs, messaging, authentication/authorization, data mapping, retries, and resilient error handling

· Quality engineering: Hands-on experience with unit and integration testing, Git-based development, code reviews, build automation, and tools such as JUnit, Mockito, Maven, or Gradle.

· Search and object storage: Hands-on production experience implementing, integrating, troubleshooting, and operating Elasticsearch and S3-compatible object storage.

· DevOps and observability: Hands-on experience with Git-based delivery, build automation, CI/CD pipelines, Docker or equivalent containers, cloud or hybrid environments, and troubleshooting with logs, metrics, and traces; Kubernetes exposure is preferred.

· L3 support: Practical experience owning incident and problem tickets, code-level diagnosis, root-cause analysis, production fixes, corrective/preventive actions, and participation in an on-call or critical-support rotation.

· Production readiness: Demonstrated ability to troubleshoot production applications using logs, metrics, or traces and improve performance, scalability, security, reliability, and resource efficiency.

Nice to Have

· Experience with event-driven systems, message brokers, asynchronous processing, API gateways, caching, or distributed-system resiliency patterns.

· Experience with workflow, process-automation, transaction-oriented, or other high-availability enterprise platforms and applications.

· Experience with Kubernetes, infrastructure automation, cloud-native deployment, and observability platforms.

· Familiarity with identity and access management, ERP, document-management, notification, master-data, or other large-scale enterprise integrations.

Experience modernizing heavily customized legacy platforms while maintaining operational continuity and supporting phased application migration
