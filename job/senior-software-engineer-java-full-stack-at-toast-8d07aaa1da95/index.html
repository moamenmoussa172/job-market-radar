About the job

Toast creates technology to help restaurants and local businesses succeed in a digital world, helping business owners operate, increase sales, engage customers, and keep employees happy.
A day in the life (Responsibilities)

  • Independently design, develop and implement features across the full stack with minimal guidance.
  • Develop and maintain backend services using Java, Spring Boot, Kotlin or .NET.
  • Build and enhance frontend applications using React or Angular.
  • Maintain a balanced full-stack contribution, with approximately 70–80% backend and 20–30% frontend development.
  • Design, develop and consume RESTful APIs and integrate with internal systems.
  • Build scalable, reliable and maintainable microservices and application components.
  • Apply object-oriented programming principles, appropriate design patterns and clean coding practices.
  • Participate in low-level design, high-level design and technical architecture discussions.
  • Identify and resolve performance bottlenecks, production issues and application defects.
  • Demonstrate practical understanding of multithreading, concurrency and data consistency.
  • Participate in code reviews, testing and engineering quality improvements.
  • Collaborate with Product Managers, UX designers, QA and engineering teams.
  • Take ownership of assigned features from requirements through development, testing and production release.
  • Use AI-assisted development tools such as Claude Code, Cursor or similar tools to improve engineering productivity and quality.
  • Communicate progress, risks, technical decisions and dependencies effectively.

What you'll need to thrive (Requirements):

  • A minimum of Bachelor’s degree in any area, or any other related discipline.
  • 6+ years of experience in software or full-stack development.
  • Strong hands-on experience with frontend frameworks such as React or Angular.
  • Proven professional hands-on experience developing backend applications using Java and Spring Boot, or an accepted equivalent such as Kotlin or .NET.
  • Practical working knowledge of Core Java, OOP, collections, exception handling and design patterns.
  • Practical understanding of thread safety, synchronisation, race conditions and concurrent data access.
  • Experience building and consuming RESTful APIs.
  • Professional experience contributing to LLD, HLD or application architecture.
  • Working Experience in SQL and NoSQL databases, including basic schema design and querying.
  • Must have hands-on professional working experience with AWS and Amazon DynamoDB in production applications.
  • Experience integrating Java/Spring Boot microservices with DynamoDB.
  • Demonstrated ability to independently solve coding problems using appropriate data structures and algorithms
  • Working knowledge of multithreading and concurrent programming.
  • Strong problem-solving skills and attention to code quality.
  • Experience designing and implementing maintainable software components.

Nice-to-Have

  • Exposure to AI-assisted development tools (Claude Code, Cursor, Devin).
  • Basic understanding of CI/CD pipelines and deployment workflows.
  • Experience working in a large-scale SaaS or product engineering environment.
