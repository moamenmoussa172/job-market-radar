About the job

The Senior Managed Services Engineer - Database & Middleware is responsible for keeping customer databases and application middleware available, fast and recoverable, as the expert engineer in the Database & Middleware (DBM) pod. The role resolves complex incidents escalated by L2, owns root-cause analysis and permanent fixes, carries out high-risk changes such as upgrades, migrations and high-availability work, and turns repeat work into runbooks and automation.

Working closely with the Technical Tower Lead, the Head of MSSO Operations, the NOC & Service Desk and the Cloud & Compute and Backup & DR pods, the Engineer supports customers across the GCC and helps build the new pod and its database bench.

Responsibilities:

Database Operations (L3)

  • Own escalated P1 / P2 database incidents from diagnosis to confirmed fix, across SQL Server, Oracle, PostgreSQL, MySQL and MongoDB.
  • Diagnose and tune performance, including query plans, indexing, statistics, waits and locking, memory and I/O, and parameter and instance configuration.
  • Design, run and test high availability and replication: SQL Server Always On, Oracle Data Guard, PostgreSQL streaming replication, MySQL replication and MongoDB replica sets.
  • Plan and carry out patching, version upgrades and migrations (on-premises to cloud and between engines), with tested rollback.
  • Own database-level backup and recovery design (RMAN, native backups, point-in-time recovery) with the Backup & DR pod, and run restore tests and DR drills.
  • Manage capacity, storage and growth, and keep each database within its agreed baseline.
  • Apply database security: users, roles and least privilege, auditing, encryption (TDE), and privileged access through PAM.

Middleware

  • Support Oracle WebLogic, Apache Tomcat / HTTP and IIS, covering deployments, configuration, certificates, connection pools and performance issues escalated by L2.
  • Work with Cloud & Compute on operating-system and VM issues that affect the database or middleware tier.

Monitoring, Automation & Standards

  • Define database and middleware monitoring templates, thresholds and alerts with NOC & Service Desk.
  • Write scripts and automation (SQL / T-SQL / PL-SQL, PowerShell, Bash; Python an advantage) for health checks, routine maintenance and bulk changes.
  • Deliver at least one automation a year that measurably reduces manual work in the pod.
  • Help the Technical Tower Lead write the pod’s baseline configurations, runbooks and the technical instructions L1 and L2 work from.

Problem, Change & Knowledge Management

  • Write the technical RCA for every P1 database incident and drive problem records through to a permanent fix.
  • Raise and run normal and emergency changes under the change process (CAB), and design standard-change templates for routine database work.
  • Turn every repeat issue into a knowledge article or runbook update, and shift work left to L2 and L1.

Customers, Onboarding & Presales Support

  • Assess new customer database estates during onboarding, set their baseline and accept the handover from professional services (build to run).
  • Join customer technical reviews and escalations as the database expert.
  • Give effort and feasibility input on RFPs, SOWs and change requests that include database or middleware services.

Team & Development

  • Coach L2 engineers, review their work on complex tickets and run knowledge-transfer sessions.
  • Take part in skills assessments and technical interview panels for the pod, with the Technical Tower Lead.
  • Deputise for the Technical Tower Lead on technical decisions when needed.
  • Take part in the on-call rota.

All employees are expected to uphold our Code of Conduct, which serves as a guiding framework for responsible behavior across everything we do — from how we work with each other to how we engage with clients and partners globally.

Requirements

  • 8+ years as a database administrator, including at least 4 years at senior / L3 level in a managed-services, multi-customer or large enterprise environment.
  • Expert, hands-on production experience in at least one of Oracle Database or Microsoft SQL Server, and solid working experience in at least two of PostgreSQL, MySQL and MongoDB.
  • Experience designing and running high availability and disaster recovery for production databases (Data Guard, Always On, replication), including real recovery from failures.
  • Performance tuning and troubleshooting under pressure in live customer environments.
  • Managed database services in at least one public cloud (OCI, Azure SQL / Managed Instance or AWS RDS).
  • Linux and Windows Server administration at the level a DBA needs, and scripting in SQL, PowerShell and Bash.
  • Working to SLAs in a ticketing tool (ServiceNow preferred), with ITIL incident, problem and change practice.
  • Middleware experience (WebLogic, Tomcat or IIS) is a strong advantage.
  • Fluent English; Arabic preferred for GCC customers.
  • Degree in IT, computer science, engineering or a related field, or equivalent experience.
  • Required Certifications: Oracle Certified Professional (OCP) or Microsoft Azure Database Administrator Associate (DP-300) at hire, and the second of OCP / DP-300 within 12 months of joining.
  • Preferred Certifications: MongoDB Certified DBA Associate, EDB PostgreSQL Associate, Oracle Cloud Infrastructure database certifications, Oracle WebLogic, ITIL 4 Foundation.
