Help shape how AI is built securely at scale. In this role, you’ll combine AI security architecture with hands-on engineering to protect emerging AI and agentic systems from development through deployment. You’ll influence security standards and architecture patterns, design secure agent workflows and Model Context Protocol integrations, and work with engineering teams to embed security across AI platforms, models, data and development pipelines. This is an opportunity to work at the intersection of AI innovation, cybersecurity and software engineering while helping Novartis adopt AI responsibly and securely.

Job Description

Key Responsibilities

  • Shape secure AI architectures, standards and patterns across enterprise AI platforms and solutions.
  • Define security strategies protecting AI models, datasets, pipelines and supporting infrastructure.
  • Assess AI environments, identify vulnerabilities and mitigate risks throughout the AI lifecycle.
  • Design secure agentic AI workflows, Model Context Protocol servers and integrations.
  • Embed security into AI development, deployment and Machine Learning Operations processes.
  • Develop secure Python services, integrations, web applications and developer-facing tools.
  • Build and optimize security scanning capabilities for AI-generated code and software dependencies.
  • Evaluate AI security technologies and recommend solutions based on evolving threats and business needs.
  • Partner with engineering, data science and platform teams to implement security-by-design practices.
  • Communicate AI security risks, architecture decisions and recommendations to technical and senior stakeholders.

Essential Requirements

  • Relevant degree or equivalent experience, with substantial professional experience across security, architecture and software development.
  • At least 2 years of hands-on experience in Artificial Intelligence security and engineering, including securing models, data and deployments.
  • Strong Artificial Intelligence security architecture expertise, including threat modelling, risk identification, security patterns, standards and controls.
  • Practical experience securing agentic Artificial Intelligence, including Model Context Protocol integrations, agent workflows and Artificial Intelligence gateways.
  • Strong software engineering capability with professional Python development, automated testing and experience using Artificial Intelligence coding agents.
  • Strong cloud security and architecture experience, particularly Amazon Web Services, with knowledge of Machine Learning Operations and secure deployment practices.

Desirable Requirements

  • Experience with Artificial Intelligence security technologies such as Cranium, Noma, JFrog Xray, HiddenLayer or Darktrace.
  • Experience building developer-facing command-line tools and working effectively across global, multi-vendor technology environments.
