About the job

This type of work—work that changes the world—is what the tech industry was founded on. So, if you're ready to seize the endless opportunities and leave your mark, come join us.

THE ROLE

As a Software Engineer on our team, you will drive core middleware innovation that unifies and scales Everpure’s™ industry-leading FlashArray and FlashBlade storage platforms. Acting as a key technical anchor, you will own critical backend infrastructure end-to-end while collaborating with cross-functional global engineering teams to deliver high-performance, six 9s reliable systems. You will modernize system architectures, build unified management layers, and extend core capabilities into public cloud environments without impacting customer uptime. If you thrive on individual code ownership, value deep craftsmanship, and want to directly shape enterprise-grade data infrastructure, this role offers an exceptional platform for your impact.

WHAT YOU’LL DO

  • Build Unified Middleware Services: Develop high-throughput, multi-threaded Java and Spring-based middleware components that bridge FlashArray and FlashBlade platforms into a seamless enterprise management layer.
  • Maintain REST API Infrastructure: Implement and refine multi-versioned REST API specifications, developer workflows, and SDKs to support reliable data delivery across CLI, GUI, and cloud interfaces.
  • Deliver Resilient System Features: Write and test fault-tolerant backend software and algorithms end-to-end to maintain six 9s reliability standards across mission-critical systems and public cloud integrations like AWS Cloud Block Store.
  • Refactor & Modernize Codebases: Improve existing backend services by identifying performance bottlenecks, executing clean code refactoring, and leveraging modern developer automation tools.
  • Collaborate Across Engineering Teams: Partner actively with local and global peers through code reviews, technical discussions, and cross-functional feature planning to deliver robust software solutions.

WHAT YOU BRING

  • Strong Computer Science & Backend Fundamentals: Deep understanding of software architecture, data structures, and distributed systems design, paired with a technology-agnostic mindset and an eagerness to work across multiple languages (such as Java, Python, C++, or Go).
  • Core Java & Backend Expertise: Hands-on experience developing, testing, and debugging high-performance backend software and RESTful APIs using Java, Spring, or similar object-oriented frameworks.
  • Technology-Agnostic Mindset: Strong baseline engineering fundamentals paired with a willingness to learn and adapt across multiple programming languages (such as Python, Go or C++) rather than relying exclusively on a single ecosystem.
  • Modern Distributed Systems & Container Awareness: Practical understanding or exposure to cloud-native paradigms, container orchestration tools, or Linux system internals.
  • Collaborative Problem Solving: Exceptional analytical and communication skills to drive technical alignment across cross-functional engineering teams in a fast-moving, high-impact environment.

Office Presence: We are primarily an in-office environment and therefore, you will be expected to work from the Prague office in compliance with Everpure’s policies, unless you are on PTO, or work travel, or other approved leave.
