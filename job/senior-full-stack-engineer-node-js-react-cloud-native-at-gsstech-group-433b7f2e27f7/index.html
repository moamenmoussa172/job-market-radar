About the job

Location: Global Tech Park, Bengaluru, India
About the Role

We are looking for an experienced Full Stack Engineer to build and maintain large scale, cloud native applications across modern frontend and backend stacks. You will design microservices, build event driven services and resilient APIs, and deliver responsive, high performance applications that run in production at scale. You will work closely with product, platform, and DevOps teams, and you will champion automation across development, testing, deployment, and operations to enable faster and more reliable releases.

Key Responsibilities

  • Design, build, and maintain scalable full stack applications using Node.js, Express.js, TypeScript, and ReactJS.
  • Architect and implement microservices, including API gateways, service discovery, and resilience patterns such as retries, circuit breakers, and bulkheads.
  • Build event driven and asynchronous services using Kafka.
  • Design efficient data models and optimize queries, indexes, and aggregations in MongoDB.
  • Use Redis for caching, session management, distributed locking, and performance acceleration.
  • Monitor and improve system performance, reliability, and observability across distributed environments.
  • Automate build, test, deployment, and operational workflows through CI/CD pipelines and Infrastructure as Code.
  • Collaborate with product, platform, and DevOps teams to deliver secure, reliable, production grade solutions.
  • Contribute to code reviews, engineering standards, and technical design discussions.

Mandatory Requirements

  • 6+ years of hands on software engineering experience, with strong full stack delivery.
  • Strong production experience with Node.js, Express.js, and TypeScript.
  • Hands on experience building and operating cloud native applications in production on Azure, AWS, or GCP, including containerized deployments (Docker, Kubernetes).
  • Solid understanding of distributed systems, scalability, resilience, and observability.
  • Experience designing and consuming RESTful APIs within a microservices architecture.

Proven Specialization in at Least Two of the Following

  • ReactJS with component driven architecture, state management, and performance optimization
  • MongoDB schema design, indexing, aggregation, and query optimization
  • Redis for caching, session management, and distributed locking
  • Kafka for event streaming and event driven architecture
  • Microservices patterns including API gateways, service discovery, and resilience
  • Serverless deployments on Azure, AWS, or GCP
  • CI/CD pipelines and Infrastructure as Code (Terraform, ARM, CloudFormation, or similar)

Nice to Have

  • Experience in banking, fintech, or other regulated environments.
  • Exposure to observability tools such as Prometheus, Grafana, ELK, Datadog, or App Insights.
  • Knowledge of secure coding practices and OWASP standards.
  • Relevant cloud certifications (AWS, Azure, or GCP).

What Success Looks Like

  • Services you build are stable, observable, and scale under real production load.
  • Release cycles get faster because you automated the manual steps.
  • Product and platform teams trust your technical judgement.
