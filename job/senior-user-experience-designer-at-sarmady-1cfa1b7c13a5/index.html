About the job

Main Purpose:

Responsible for the design and implementation of creative and usable interfaces for different media, according to pre set requirements in coordination with project managers and the development team for internal and external clients and ensure meeting deadlines.

Responsibilities:


  • Receive project requirements as delegated and create medium and high fidelity wireframes based on preset requirements and objectives
  • Coordinate with project managers to set the project plan and time estimates for each task to ensure the compliance with the preset deadlines.
  • Designing and implementing high standard Websites, Web applications and Mobile sites according to the preset requirements.
  • Design and implement mobile applications interfaces for different mobile operating system.
  • Receive feedback for different deliverables and update them with the necessary changes and amendments.
  • Update and enhance existing websites with new features to meet the requirement and to enhance the user experience.
  • Handle design issues and daily tasks issued on the ticketing system by different users.
  • Create and optimize creative flash banners and promotional material such as mail shots, newsletters, featured banners and sponsorship and takeovers.
  • Prepare presentations, standard documents, business cards, external communication templates and printing materials when required.
  • Coordinate with the development team to finalize the projects within the set time frame.
  • Handle all technical responsibilities related to: performance optimization, search engine optimization
  • Expertise in Adobe Photoshop, Adobe Flash
  • Expertise in HTML/HTML5, CSS/CSS3 and JavaScript
  • Knowledge and demonstrated experience with cross-browser and cross-platform issues (IE, Firefox, Safari, Chrome, etc.)
  • Familiar with Microsoft Visual Studio
  • Familiar with various design programs, web tools and technologies
  • Familiar with User-Centred Design process and paper prototyping technique
  • Knowledge in Usability testing is a plus
  • Knowledge in SEO is a plus

Knowledge in WPO is a plus
