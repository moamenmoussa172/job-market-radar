About the job

About the team

App Distribution is part of the App Platform organization. We build and operate Splunkbase, the marketplace for Splunk apps, and AppInspect, which supports app validation. Our services help developers publish applications and enable customers to discover and use apps built by Splunk, partners, and its community. We work across the marketplace experience and the services that support the Splunk app ecosystem.

About the role

We are looking for a Software Engineer to build and improve fullstack features across Splunkbase and AppInspect. You will work primarily with Python, JavaScript, AWS, and databases, connecting usable web interfaces with reliable backend services. You will independently own well-defined features from design through production, contribute to technical decisions within the team, and collaborate with product management and engineering partners on larger initiatives.

Your responsibilities

  • Design, implement, and deliver features across web interfaces, Python services, REST APIs, and data storage within the existing architecture.
  • Build responsive, accessible user interfaces with TypeScript and React, and integrate them with backend APIs.
  • Own delivery of well-defined features, break work into manageable steps, and communicate progress, technical tradeoffs, and risks.
  • Collaborate with product management, designers, architects, and other engineers to improve app discovery, publishing, and validation workflows.
  • Write maintainable code and automated tests across the frontend and backend; contribute to code reviews and continuous integration and delivery.
  • Maintain and improve existing services, investigate production issues, and address defects and performance bottlenecks across application layers.
  • Add useful logging, metrics, and service level indicators, and use production insights to improve reliability and scalability on AWS.
  • Apply secure development practices, document technical decisions, and share knowledge with teammates in an Agile development environment.

Minimum qualifications

  • 4+ years of professional software engineering experience, including delivery of production web applications or SaaS products.
  • Strong Python skills and experience building and maintaining backend services and REST APIs in production.
  • Practical frontend experience with TypeScript, HTML, CSS, and a modern framework such as React, including API integration and application state management.
  • Hands-on experience deploying, monitoring, or troubleshooting applications on AWS and Kubernetes, with an understanding of cloud application reliability and scalability.
  • Experience with relational databases, data modeling, and query optimization, plus familiarity with NoSQL storage and its tradeoffs.
  • Experience writing automated tests and working with Git, code reviews, and continuous integration and delivery pipelines.
  • Ability to independently deliver well-defined features and debug issues across frontend, backend, and database layers in a service-based architecture.
  • Clear written and verbal communication, a collaborative approach to technical decisions, and a willingness to learn and share knowledge.

Preferred qualifications

  • Experience with React and frontend testing, web accessibility, or browser performance optimization.
  • Experience with message queues and asynchronous processing, particularly for validation or other background workflows.
  • Familiarity with Docker, Kubernetes, or other container technologies, and web frameworks such as Django and Flask, as well as authentication protocols such as OAuth 2.0, OpenID Connect, or SAML.
  • Experience with application marketplaces, developer platforms, or app validation tooling; familiarity with Splunk products is helpful.

What you can expect

You will work with engineers and product partners on services used by the Splunk app ecosystem, with opportunities to see the impact of your work on developers and customers. We support learning through feature ownership, peer feedback, and mentorship in a collaborative team environment.
