About the job

This is a fully remote job, open to people in Colombia.

The purpose of this position is to deploy, operate and maintain NICE’s global customer hosted databases, while also resolving customer issues that require direct access to the database infrastructure, and acting in an appropriate professional working style. The Engineer will report to the Manager, Infrastructure Cloud Operations while acting as part of the Database Team managing the databases in AWS Cloud.

Job Responsibilities

  • AWS console administration
  • New deployment tasks for databases & RDS services
  • AWS RDS DB health check & availability checks using tools like CloudWatch and performance Insight.
  • Read & analyse log/error log for Databases
  • Alerts configuration, monitoring alerts and fine-tuning thresholds
  • Perform RDS instance actions and comparison with Terraform code
  • Export/import (Postgres) or backup/restore (SQL Server) specific data
  • Installing/deploying databases, configuring backups, maintenance jobs and other features as needed to support database capacity, performance or product functionality requirements.
  • Performing database administration tasks, including at latest versions of databases.
  • Performing data restores, patchset / service pack installation and deinstallation, edition upgrade and downgrade, troubleshoot locking, corruption issues as well as suggest and implement solutions with minimal downtime
  • Perform operational duties including database backups, application server health, service recycling.
  • Identify and resolve operational issues (e.g. batch failures, network issues, client data feed errors)
  • Experience in Monitor server performance, memory utilization, CPU, file systems, databases, batch jobs, backup and restore concept with best practise.
  • Prepare, review, test, and execute T-SQL and PowerShell scripts to perform database administrative tasks as assigned.
  • Investigate performance issues, provide and implement tuning solutions
  • Act as part of a global team, creating and extending existing documentation as well as continuously sharing information and assisting on tasks with other team members.
  • Working with monitoring tools
  • Experience providing 24x7 support to production Software as a Service infrastructure, including participating in on-call rota and out of hours/weekend support when needed
  • 6 to 10 Yrs. of experience as DBA in managing multiple DB engines.
  • Minimum 6 years relevant experience as DBA.
  • Hands on experience in multiple versions of Postgres database is mandatory.
  • Knowledge or experience working in Microsoft SQL, Aurora, MySQL will be an added advantage.
  • Hands on experience on AWS Cloud, AWS RDS apart from DB technology.
  • Basic coding skills in Powershell, Python, Terraform
  • Understand how automated backups are performed by AWS, know how to check the historical backup timings and how to perform ad-hoc snapshot
  • Understanding of ITIL – incidents, service requests, change management
  • Willingness to learn about technologies related to database and backup infrastructure, such as storage, backup, operating system and automation tools, cloud solutions or other database technologies.
  • Demonstrated ability to effectively establish and maintain cooperative working relationships within a global, diverse, multicultural environment.
  • Bachelor or Master’s Degree on Computer science or Information technology streams

This position is remote in Colombia for people allowed to legally work in Colombia.
