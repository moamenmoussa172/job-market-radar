About the job

We are looking for an experienced Senior DevOps Engineer with strong expertise in OpenShift, Kubernetes, CI/CD, DevOps, and Cloud Platforms to support enterprise Technology Platforms & Compute initiatives.

The ideal candidate should have hands-on experience in building scalable DevOps platforms, automating deployments, implementing Infrastructure as Code (IaC), managing cloud-native environments, and enabling Agile engineering teams through modern DevOps practices.

The role requires strong technical expertise in container platforms, CI/CD pipelines, cloud infrastructure, platform engineering, infrastructure automation, observability, and DevSecOps while working in highly available enterprise environments.

Requirements

Key Responsibilities

  • Design, implement, and maintain enterprise-grade DevOps platforms and CI/CD pipelines.
  • Build, automate, and manage application deployment pipelines across Kubernetes, OpenShift, and public cloud environments.
  • Automate infrastructure provisioning, deployment, and configuration management using Infrastructure as Code (IaC).
  • Collaborate with development, platform, infrastructure, security, and operations teams to deliver highly scalable and secure environments.
  • Implement deployment automation and self-service capabilities for application onboarding.
  • Troubleshoot complex infrastructure, deployment, platform, and application issues.
  • Build reusable deployment frameworks, shared libraries, and automation workflows.
  • Develop and maintain Jenkins pipelines using Shared Libraries, Groovy, Python scripting, and pipeline automation.
  • Integrate DevOps, SecOps, and quality engineering tools into CI/CD pipelines.
  • Design and implement GitOps deployment models using ArgoCD.
  • Build and manage Kubernetes/OpenShift clusters and containerized application platforms.
  • Implement Service Mesh architecture and GitHub Actions workflows.
  • Configure and manage cloud infrastructure across Azure, AWS, or Oracle Cloud (OCI).
  • Develop and integrate REST APIs and SOAP services within deployment pipelines.
  • Collaborate with cross-functional Agile squads and Platform Engineering teams.
  • Participate in Agile ceremonies and contribute to continuous improvement initiatives.
  • Monitor platform health, logging, performance, and availability using enterprise monitoring solutions.
  • Ensure platform security, authentication, authorization, governance, and compliance standards are maintained.
  • Support production deployments, operational activities, incident management, and root cause analysis.
  • Stay updated with emerging DevOps technologies, cloud-native practices, and engineering best practices.
