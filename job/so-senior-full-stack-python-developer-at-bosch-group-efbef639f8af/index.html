About the job

Position Overview

We are looking for a skilled Full-Stack Python Developer with a strong background in modern web technologies, cloud infrastructure, and generative AI integrations. In this role, you will design, develop, and scale end-to-end web applications and intelligent dashboards, bridging high-performance backend systems with intuitive React/TypeScript frontends. You will leverage cutting-edge Azure cloud and AI services—including Azure OpenAI and Document Intelligence—to automate data extraction and build smart enterprise workflows.

Key Responsibilities

  • Full-Stack Development: Design, build, and maintain scalable web applications, RESTful APIs, and microservices using Python and Node.js.
  • Frontend & Dashboard Engineering: Develop responsive, high-performance user interfaces and real-time data analytics dashboards using React and TypeScript.
  • AI & Intelligent Automation Integration: Implement advanced AI and machine learning capabilities by integrating Azure OpenAI LLMs and Azure Document Intelligence for automated PDF parsing, OCR, and intelligent document processing.
  • Cloud & DevOps Management: Configure, manage, and optimize CI/CD pipelines, automated deployments, and repository workflows using Azure DevOps.
  • System Architecture & Collaboration: Collaborate closely with product managers, data scientists, UX/UI designers, and QA teams to deliver robust, secure, and user-centric features.
  • Code Quality & Maintenance: Write clean, well-tested code, conduct code reviews, troubleshoot production issues, and ensure adherence to best practices in security and performance.

Requirements & Qualifications

Technical Skills

  • Backend: Strong proficiency in Python (Django, FastAPI, or Flask) and Node.js for building scalable backend architectures and robust REST APIs.
  • Frontend: Solid expertise in modern React, TypeScript, state management, and building interactive dashboards or data visualization frontends.
  • Cloud & DevOps: Hands-on experience with Azure DevOps (setting up CI/CD pipelines, build/release management, and source control).
  • AI & Cognitive Services: Proven experience integrating enterprise AI services, specifically Azure OpenAI LLMs and Azure Document Intelligence (PDF text/table extraction and processing).
  • Databases & Storage: Experience with SQL/NoSQL databases and managing data storage solutions.

Experience & Soft Skills

  • Experience: 3+ years of professional full-stack software development experience.
  • Problem-Solving: Strong analytical mindset with the ability to troubleshoot complex asynchronous workflows and data pipelines.
  • Communication: Excellent teamwork and English communication skills, capable of bridging technical engineering concepts with business requirements.

Preferred Qualifications

  • Experience containerizing applications using Docker and deploying to Azure Kubernetes Service (AKS) or Azure App Service.
  • Familiarity with analytics platforms or Azure monitoring/statistics frontend tools.
  • Background in enterprise automation or digital transformation initiatives.
