About the job

We are looking for an experienced Senior Full Stack Engineer with strong expertise in React.js, Node.js, TypeScript, and modern enterprise application architecture to support Digital Products, API Banking, and Merchant Acquiring initiatives.

The ideal candidate will possess strong hands-on development experience in building scalable, high-performance enterprise applications and APIs while working within Agile product engineering teams. The role requires expertise across frontend and backend technologies, modern DevOps practices, API integrations, and enterprise-grade software engineering standards.

Requirements

Key Responsibilities

  • Design, develop, and maintain scalable full-stack enterprise applications using React.js and Node.js.
  • Develop highly responsive, reusable, and testable frontend components using React.js and TypeScript.
  • Design and develop scalable and highly available RESTful APIs and microservices using Node.js.
  • Build responsive and performant web applications adhering to enterprise engineering standards.
  • Develop self-contained, reusable, and maintainable modules and components.
  • Participate in architecture discussions and contribute to technical design decisions.
  • Architect and automate application build and deployment processes.
  • Monitor and optimize frontend and backend application performance.
  • Troubleshoot production issues and perform debugging and performance tuning.
  • Collaborate closely with product owners, architects, QA teams, DevOps teams, and business stakeholders.
  • Participate in code reviews and ensure adherence to coding, security, testing, and documentation standards.
  • Contribute to CI/CD implementation and engineering best practices.
  • Participate in Agile ceremonies, sprint planning, backlog grooming, and release activities.
