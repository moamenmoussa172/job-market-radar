About this Role

We are seeking an experienced Oracle Database and Oracle GoldenGate (OGG) professional with 5–8 years of relevant experience to support application database operations and critical production activities.The role focuses on Oracle and OGG administration, database reliability, replication, performance tuning, upgrades and migrations, backup and recovery, security, and high-priority operational support.

What you’ll do

  • Administer production Oracle databases and support database architecture and operations.
  • Manage Oracle GoldenGate data replication and transaction consistency.
  • Perform database upgrades and migrations and integrate with other RDBMS platforms.
  • Support user access management, security audits, and auditing and SOX compliance activities.
  • Monitor databases using tools such as Oracle Enterprise Manager (OEM) and Datadog.
  • Analyse performance bottlenecks and troubleshoot issues affecting application performance.
  • Support DML operations, SQL and database performance tuning.
  • Manage database backup and recovery activities.
  • Collaborate with application teams to support database operations.
  • Use ticketing tools to manage operational activities and incidents.
  • Provide on-call support for high-priority database issues.
  • Develop and maintain scripts that automate and stabilise BAU operational activities.

Who you are

  • You have 5–8 years of application database support experience, including practical Oracle GoldenGate administration.
  • You have expertise in Oracle Database and Oracle GoldenGate, including experience with Oracle 11g/19c and OGG 11g/19c.
  • You understand database architecture, including memory, storage, cluster and high-availability architectures.
  • You have experience configuring databases and providing operational support.
  • You have strong knowledge of database and SQL performance tuning.
  • You can analyse performance bottlenecks and identify causes of application slowness.
  • You have knowledge of AWS Cloud.
  • You have knowledge of UNIX, shell scripting and at least one additional scripting language such as Perl.
  • You have experience supporting auditing and SOX compliance activities.Telecom knowledge is an advantage.
