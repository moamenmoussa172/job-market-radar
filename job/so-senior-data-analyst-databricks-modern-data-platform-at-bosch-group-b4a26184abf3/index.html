About the job

We are looking for a Senior Data Engineer with strong hands-on experience in Databricks and modern data platforms to design, build, and maintain scalable data solutions for analytics and BI.

The ideal candidate combines strong Data Engineering, SQL, data modeling, cloud, and system optimization skills, with the ability to take technical ownership and work closely with business and technical stakeholders.

Key Responsibilities

  • Design and develop scalable data pipelines and data platforms using Databricks, SQL, Python, and PySpark.
  • Build and optimize ETL/ELT processes for structured and semi-structured data.
  • Optimize performance (including: monitor data injections, monitor queries,...)
  • Work with Databricks, Delta Lake, Azure and/or Microsoft Fabric to build modern cloud data solutions.
  • Ensure data quality, reliability, governance, and security across data solutions.
  • Support integration between on-premise and cloud data sources.
  • Provide reliable datasets and data models for Power BI / BI / analytics.
  • Troubleshoot production issues, perform root-cause analysis, and continuously improve existing solutions.
  • Take ownership of technical solutions and provide guidance to other team members.
  • Work with business stakeholders to translate requirements into practical and scalable data solutions.

Must Have

  • 4-5+ years of experience in Data Engineering, BI, or related data roles.
  • Strong hands-on experience with Databricks in an enterprise/production environment.
  • Strong SQL and database experience.
  • Strong experience with PySpark / Spark SQL and Python.
  • Solid understanding of ETL/ELT, data modeling, data warehousing, and lakehouse architecture.
  • Experience with Delta Lake and large-scale data processing.
  • Experience with Azure, Microsoft Fabric, or similar cloud data platforms.
  • Good understanding of data quality, performance optimization, and production support.
  • Good communication skills and ability to work with both technical and business stakeholders.
  • Fluent English.

Nice to Have

  • Power BI / SSAS experience.
  • Microsoft SQL Server / Oracle.
  • SSIS or other traditional ETL tools.
  • Azure Data Factory or similar orchestration tools.
  • CI/CD, Git, and DevOps experience.
  • Machine Learning / AI experience.
  • Agile/Scrum or project management experience.
