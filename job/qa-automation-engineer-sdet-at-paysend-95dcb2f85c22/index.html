About the job

This is a fully remote job, open to people in Europe.

About The Role:

We are looking for a QA Automation Engineer / SDET with a strong focus on backend and API testing, who will own and drive automated testing in a complex, distributed system. This is an automation‑first role with a clear engineering approach to quality, stability, and system reliability.

Engagement type: B2B service agreement. You’ll work from anywhere in Europe and invoice monthly. Quarterly on-site visits to our Serbian hub are expected, with travel costs covered by the company.


What You'll Do (Responsibilities):

  • Automated testing of backend services and integrations (primary focus)
  • Design, develop, and maintain API automation tests
  • Work with relational databases for data validation and integrity checks
  • Dockerize test frameworks and test execution
  • Integrate automated tests into the CI/CD pipeline
  • Messaging systems (RabbitMQ, Kafka, etc.)
  • Confident knowledge of Java (or a similar OOP language)
  • Maintain and continuously improve the test automation framework
  • Use and maintain Test Management tools (TestRail or equivalent)
  • Collaborate closely with developers during early validation phases
  • Analyze test results and eliminate flaky tests

What You’ll Need To Be Successful In This Role:

  • 5+ years of experience in QA Automation/Development
  • Solid experience in API automation testing (RestAssured, JSON validation)
  • Understanding of backend systems and microservices architecture
  • Experience working with relational databases (SQL, procedures)
  • Experience with Docker (build, run, test execution)
  • Experience with modern UI automation tools (Playwright / Selenide)
  • Experience with Git and CI/CD tools
  • Experience with Test Management Tools (TestRail, Allure TestOps or equivalent)
  • Understanding of SDLC and QA processes

Nice to have:

  • UI automation for critical E2E scenarios
  • Contract testing (PACT or similar)
  • Cloud environments (AWS / GCP / Azure)
  • Experience in boosting routine activities with AI tools and agents
  • Performance testing
