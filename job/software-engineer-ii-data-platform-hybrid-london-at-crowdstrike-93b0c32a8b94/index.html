About the Role:

We are looking for a Software Engineer II (Data) to join our Data Engineering team. In this role, you will design, build, and maintain scalable data pipelines and backend services that ingest, process, and replay massive volumes of security telemetry. You will work closely with senior engineers to implement robust data architecture, optimize Spark job and query performance, and ensure high reliability across our distributed data systems.

What You’ll Do:

  • Design, build, and tune high-throughput Apache Spark or Flink data processing and replay pipelines (using Python/PySpark, Java, or Scala) handling massive volumes of security data.
  • Implement scalable backend microservices and REST/gRPC APIs with guidance from senior engineers to support self-service data workflows.
  • Work with distributed messaging systems such as Kafka to handle real-time streaming data flows.
  • Implement data modeling, partitioning, and storage optimization across data lake table formats and columnar/analytical stores (e.g., Apache Iceberg, Parquet, Hive/Trino, ClickHouse) to optimize query speed and cloud retrieval costs.
  • Write unit, integration, and performance tests to guarantee pipeline stability, scalability, and data accuracy.
  • Participate in team code reviews, CI/CD deployment pipelines, and operational monitoring/alerting using tools like Grafana and Prometheus.

What You’ll Need:

  • Mandatory Must-Have: Hands-on production experience designing, building, and tuning large-scale data pipelines using Apache Spark or Apache Flink (PySpark, Scala, or Java) on terabyte- or petabyte-scale datasets.
  • Core Programming: Strong software engineering fundamentals and proficiency in at least one modern programming language (Python, Java, or Scala), including unit/integration testing, performance profiling, and debugging.
  • Big Data & Storage Ecosystem: Practical experience with distributed streaming and data lake technologies including Kafka, Apache Iceberg (or Delta Lake/Hive), Parquet, and query engines like Trino/Presto.
  • Cloud & Distributed Systems: Hands-on experience running distributed data workloads and managing storage/compute on cloud services (AWS, GCP, or OCI).
  • Experience Level: 3 to 7 years of professional software/data engineering experience with a BS (or 2+ years with an MS) focusing on big data infrastructure and pipelines.
  • Operational Readiness: Familiarity with containerized deployments (Docker, Kubernetes), CI/CD pipelines, and production monitoring/observability tools (Grafana, Prometheus).

Bonus Points:

  • Go (Golang)
  • Kubernetes (Spark/Flink operators)
  • Jenkins / GitOps workflows
  • Protocol Buffers / gRPC
