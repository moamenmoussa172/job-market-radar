This is a fully remote job, open to people in United States.

About the Role

Dots is looking for a Backend Engineer to build the systems that power our product. You’ll work closely with product, design, and engineering to turn ideas into reliable services and deliver features from design through production.

In this role, you will:

  • Design, build, and maintain backend services and APIs.
  • Develop data models and improve database performance.
  • Build integrations with third-party services.
  • Improve system reliability, security, and observability.
  • Write tested, maintainable code and participate in code reviews.
  • Investigate production issues and address their root causes.
  • Help shape technical decisions as the product grows.

You might thrive in this role if you have:

  • Experience building and operating backend applications in production.
  • Strong proficiency in a backend programming language.
  • Solid understanding of API design, relational databases, and data modeling.
  • Experience with cloud infrastructure, automated testing, and deployment workflows.
  • Ability to balance speed with quality and make practical technical decisions.
  • Clear communication and a collaborative approach to solving problems.

Nice to have:

  • Experience with distributed systems, background jobs, and event-driven architectures.
  • Familiarity with caching, queues, and performance optimization.
  • Experience working on a small team or an early-stage product.
