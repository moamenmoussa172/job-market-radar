About the job

About this Role

We are seeking an experienced application developer with 7+ years of software development experience and advanced hands-on expertise in React, Azure cloud technologies, RESTful Web APIs and Microsoft SQL Server. You will lead technical delivery for secure, scalable and business-critical applications, taking ownership of complex development activities from solution design through deployment and production support.

This role combines hands-on engineering with technical leadership, customer engagement, code and design reviews, mentoring, incident resolution and collaboration across Agile product and technology teams.

What you’ll do

  • Lead the design, development, enhancement and maintenance of secure, scalable, enterprise-grade applications using modern software engineering practices.
  • Translate solution designs into implementable components and take ownership of complex development activities.
  • Develop clean, maintainable and efficient code aligned with established architecture, security and engineering standards.
  • Lead code reviews, design reviews and quality checks, providing constructive feedback and ensuring adherence to development standards.
  • Mentor junior developers through knowledge sharing, pair programming, technical guidance and development support.
  • Act as a technical point of contact for customers and stakeholders, communicating solution options, progress, dependencies, risks and technical issues clearly.
  • Participate in customer discussions, requirements clarification, solution walkthroughs, demonstrations, incidents and service-review meetings.
  • Perform unit testing and support integration, system and user acceptance testing, deployment, releases and post-deployment activities.
  • Troubleshoot complex application defects, production incidents and performance issues, undertaking root-cause analysis and implementing sustainable corrective actions.
  • Design and develop responsive user interfaces using React and modern front-end technologies.
  • Develop and consume RESTful Web APIs and integration services.
  • Design, optimise and maintain reliable application data solutions using Microsoft SQL Server.
  • Collaborate with Product Owners, Scrum Masters, Architects, QA Engineers, operations teams and business stakeholders to deliver agreed outcomes.
  • Contribute to Agile ceremonies, estimation, technical planning, continuous improvement and engineering best practices.
  • Use Azure DevOps and GitHub for source control, work-item tracking, CI/CD, release management and engineering governance.
  • Assess relevant emerging technologies and development practices to support evolving customer and business requirements.

Who you are

  • You have 7+ years of application development experience, including responsibility for complex or business-critical solutions.
  • You have advanced, hands-on experience with React and modern front-end technologies.
  • You have substantial experience designing, developing and consuming RESTful Web APIs and integration services.
  • You have strong knowledge of Microsoft SQL Server, relational database design, query optimisation and performance troubleshooting.
  • You have experience with Azure DevOps and GitHub, including source control, CI/CD, work management and release governance.
  • You understand the Software Development Lifecycle (SDLC), secure coding practices, unit testing, automated quality controls, deployment and production support.
  • You have demonstrated experience in technical leadership, design and code reviews, estimation and end-to-end delivery ownership.
  • You have experience mentoring junior developers through coaching and knowledge sharing.
  • You can investigate complex application issues and have experience with incident management, root-cause analysis and technical troubleshooting.
  • You can communicate technical concepts confidently to customers and senior stakeholders and collaborate effectively across business and technology teams.
  • You have substantial experience working within Agile development teams.
  • Exposure to Microsoft Power Platform is desirable.
  • Knowledge of relevant Microsoft Azure services is preferred.
  • Knowledge of GitHub Advanced Security (GHAS) is an added advantage.

What's in it for you

  • Work on secure, scalable and business-critical enterprise applications spanning React, Azure, APIs and Microsoft SQL Server.
  • Take end-to-end technical ownership across design, development, testing, deployment and production support.
  • Build technical leadership experience through mentoring, design reviews, code reviews and engineering decision-making.
  • Collaborate directly with customers, architects, product teams, QA and operations stakeholders.
  • Gain exposure to modern engineering practices including CI/CD, Agile delivery, secure development and engineering governance.
  • Explore emerging technologies and development practices as customer and business requirements evolve.

What skills you will learn

  • Enterprise-scale React application architecture and modern front-end engineering.
  • Azure cloud application development and associated services.
  • RESTful API design, integration patterns and service development.
  • Advanced Microsoft SQL Server design, optimisation and performance troubleshooting.
  • CI/CD and release governance using Azure DevOps and GitHub.
  • Secure software engineering and automated quality controls, including potential exposure to GitHub Advanced Security.
  • Production incident management and structured root-cause analysis.
  • Technical leadership, mentoring, stakeholder communication and customer-facing solution discussions.
  • Cross-functional Agile delivery and continuous improvement.
  • Potential integration and development scenarios involving Microsoft Power Platform.
