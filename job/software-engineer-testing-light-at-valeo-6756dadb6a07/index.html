About the job

Valeo is a tech global company, designing breakthrough solutions to reinvent the mobility. We are an automotive supplier partner to automakers and new mobility actors worldwide. Our vision? Invent a greener and more secured mobility, thanks to solutions focusing on intuitive driving and reducing CO2 emissions. We are leader on our businesses, and recognized as one of the largest global innovative companies.

Job Description

  • Understand and analyze software requirements and identify any missing information to perform Validation/testing activities.
  • Design Test Cases using all applicable testing techniques.and implement .
  • Develop testing plans, test cases, scripts and automation needs to verify that the software meets the customers using Java/Python languages. And the high-level requirements.
  • Test cases execution of test plans for a defined project scope.
  • Analysis, interpret executed test cases, and confirm that the software behavior respects the requirement documents.
  • Learn different testing tools including used test benches.
  • Report findings (SW Bugs) on the defects management tool
  • Continuously communicate work progress through attendance of daily & weekly project meetings. (Internal and external with other Valeo sites).
  • Improve the testing methods and automation.
  • Support his/her colleagues whenever required
  • Participate in providing software validation project estimations and technical risk assessment.
  • Learn the Testing Processes and deploy it in his/her activities.
  • Attend and respond to internal and external audits concerning Software Testing.
  • B.Sc. in Communication, Computer Engineering, Mechatronics, Biomedical, Aerospace or Electronics.
  • B.Sc. in Computer science.
  • Good knowledge in Microcontrollers, System architecture and testing techniques.
  • Different levels of ISTQB certificate is a plus.
  • Excellent command of English language is a must.
