Role Overview

The Cloud Security Engineer is responsible for designing, implementing, and maintaining security controls across AWS environments. This role ensures that cloud workloads, data, identities, and infrastructure remain secure, compliant, and resilient against evolving threats. The engineer works closely with DevOps and Engineering teams to embed security into every layer of the cloud ecosystem.

Key Responsibilities

  • Cloud Security Architecture — Design and implement secure AWS architectures using best-practice frameworks such as the AWS Well-Architected Security Pillar.
  • Identity & Access Management — Configure and manage IAM roles, policies, permission boundaries, and least-privilege access models.
  • Threat Detection & Monitoring — Deploy and tune services like GuardDuty, Security Hub, CloudTrail, and CloudWatch for continuous monitoring.
  • Network Security — Implement VPC security controls, NACLs, security groups, WAF, Shield, and private connectivity patterns.
  • Data Protection — Enforce encryption standards using KMS, Secrets Manager, and secure storage configurations.
  • Incident Response — Lead cloud-focused incident investigations, forensics, and remediation activities.
  • Compliance & Governance — Ensure alignment with standards such as ISO 27001, NIST, SOC 2, and regional regulations relevant to Dubai/UAE.
  • Automation & DevSecOps — Build automated security controls using Terraform, CloudFormation, or CI/CD pipelines.
  • Vulnerability Management — Run regular assessments, patching workflows, and container security checks.
  • Security Documentation — Maintain policies, runbooks, and architecture diagrams.

Required Skills & Qualifications

  • AWS Security Expertise — Deep knowledge of core services: EC2, S3, RDS, Lambda, VPC, IAM, KMS, CloudTrail, GuardDuty, WAF, Shield.
  • Infrastructure as Code — Experience with Terraform or CloudFormation for secure provisioning.
  • Scripting & Automation — Proficiency in Python, Bash, or PowerShell.
  • Container Security — Familiarity with securing Docker, Kubernetes, and AWS EKS.
  • Zero Trust Principles — Ability to apply Zero Trust models in cloud environments.
  • Security Certifications — Preferred: AWS Security Specialty, CISSP, CCSP, CEH.
  • Strong understanding of networking, encryption, authentication, and cloud threat modeling.
