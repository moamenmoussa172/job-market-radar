About the job

  • Develop, test, and maintain application(s) features for SharePoint Online and SharePoint on-premises, independently delivering assigned tasks within the established architecture and agreed development standards
  • Develop and maintain frontend features using React, TypeScript, HTML5, and CSS3, integrating user interfaces with SharePoint and backend services
  • Implement and maintain SQL database access using Microsoft SQL Server (MSSQL), including SQL queries, relational schemas, and troubleshooting data-related issues within established data models
  • Contribute to deploying, configuring, and troubleshooting solutions in SharePoint Online and on-premises environments through established workflows, collaborating with infrastructure, security, and support teams
  • Contribute to sprint planning, estimate development tasks, and deliver tested software increments within the agreed scope
  • Write clean, maintainable code, implement automated tests, participate in code reviews, and use Git for version control and npm for dependency management, following agreed development standards
  • Clarify business requirements and technical details with stakeholders and implement application features and integrations within the established architecture, seeking guidance for complex scenarios where needed
  • Debug and resolve application defects, improve performance, and contribute code changes and technical documentation for releases, upgrades, and migrations

#LI-MM1

Bachelor's Degree

English Fluency

Hands-on software engineering skills, including clean code, automated testing, debugging, and applying established design patterns

Practical experience developing solutions for SharePoint Online and SharePoint on-premises, including React, TypeScript, HTML5, CSS3, REST APIs, and JSON; ability to independently implement assigned features within an established architecture

Hands-on experience with SQL databases and Microsoft SQL Server (MSSQL), including relational data modelling, SQL queries, application data access, and troubleshooting data-related issues within established designs

Practical experience developing and maintaining an additional application using .NET 8.0, Azure SQL Database, and React 18.2.0 for the frontend, including container deployment and troubleshooting in Azure Kubernetes within established workflows

Experience delivering software in agile sprints, including task estimation, Git version control, npm dependency management, and established build and release workflows

Very good written and oral communication skills in English

Nice to have: Practical knowledge of Microsoft Azure and experience contributing to application deployment, configuration, and troubleshooting through established workflows, with guidance for complex infrastructure or security topics
