About the job

Roles & Responsibilities :
We are looking for an experienced Development/Technical Lead – .NET & Azure to lead the design, development, modernization, and technical delivery of enterprise applications.

The ideal candidate should bring strong hands-on expertise in C#, .NET / ASP.NET Core, Microsoft Azure, MS SQL Server, Stored Procedures, REST APIs, and DevOps, along with the ability to guide development teams, review technical designs, resolve complex issues, and drive engineering best practices.

The role also requires a foundational understanding of AI/Generative AI concepts and the ability to identify opportunities for incorporating AI capabilities into enterprise applications.

Key Responsibilities

.NET Development/Technical Lead

  • Lead the design and development of enterprise applications using C#, .NET, ASP.NET Core, Web API, Entity Framework Core, Angular and related technologies.
  • Provide hands-on technical guidance to developers throughout design, development, testing, deployment, and production support.
  • Perform code reviews, technical design reviews, and root-cause analysis for complex application issues.
  • Establish coding standards and promote SOLID principles, design patterns, clean architecture, reusable components, and maintainable code.
  • Guide developers and mentor team members to strengthen overall engineering capability.
  • Support technical estimation, sprint/release planning, dependency management, and technical risk identification.

MS SQL Server & Stored Procedures

The candidate should have strong hands-on database development experience, not merely application-level exposure to SQL.

  • Strong expertise in Microsoft SQL Server (MS SQL).
  • Hands-on experience designing and developing complex Stored Procedures, Functions, Views, Triggers, and SQL scripts.
  • Strong understanding of T-SQL, joins, subqueries, CTEs, transactions, temporary tables, indexing, and data manipulation.
  • Experience analyzing and optimizing complex SQL queries and Stored Procedures for performance.
  • Ability to troubleshoot database performance issues including inefficient queries, locking, blocking, deadlocks, and long-running transactions.
  • Good understanding of execution plans, indexing strategies, query optimization, and database performance tuning.
  • Experience integrating .NET applications with SQL Server using Entity Framework Core, ADO.NET, or similar data-access approaches.
  • Ability to review database code and establish SQL development and database design standards.
  • Understanding of data integrity, security, transaction management, backup/recovery, and database design principles.

Microsoft Azure

  • Hands-on experience developing and deploying applications using Microsoft Azure.
  • Understanding of cloud-native architecture, scalability, resiliency, high availability, security, and cost considerations.
  • Experience modernizing traditional or legacy .NET applications toward modern .NET and Azure-based solutions.

API & Integration

  • Strong experience designing and developing RESTful APIs and Web APIs.
  • Understanding of synchronous and asynchronous integration patterns.
  • Experience with enterprise application integration and messaging.
  • Knowledge of authentication and authorization concepts such as OAuth 2.0, OpenID Connect, JWT, and Microsoft Entra ID.
  • Ability to design secure, scalable, reusable APIs and integration components.

DevOps & Engineering Practices

  • Experience with Azure DevOps and/or GitHub.
  • Strong understanding of Git, branching strategies, pull requests, CI/CD, automated builds, testing, and deployment.
  • Experience with automated unit and integration testing.
  • Knowledge of code-quality, dependency, and security scanning practices.
  • Exposure to Docker, Bicep, Terraform, or Infrastructure as Code is advantageous.
  • Experience establishing application logging, monitoring, alerting, and observability.

AI & Generative AI Fundamentals

The candidate is not expected to be an AI/ML specialist, but should have a good understanding of modern AI concepts and their relevance to application development.

Security & Quality

  • Drive secure coding practices covering authentication, authorization, secrets management, vulnerability remediation, and API security.
  • Ensure adequate unit testing, integration testing, code coverage, and quality gates.
  • Drive resolution of technical debt and application vulnerabilities.
  • Ensure applications meet agreed performance, reliability, maintainability, and security expectations.

Technical Lead Responsibilities

  • Act as the primary technical point of contact for the development team.
  • Translate functional/business requirements into appropriate technical designs.
  • Make technical decisions within the application/team scope and escalate architecture-level decisions when required.
  • Work closely with Solution Architects, Product Owners, Business Analysts, DevOps, Cloud and Infrastructure teams.
  • Mentor developers and support knowledge sharing within the team.
  • Coordinate technical delivery across development and supporting teams.
  • Identify technical risks and dependencies early and drive appropriate mitigation.
  • Support production troubleshooting and root-cause analysis for critical technical issues.

Education & Experience

  • Bachelor's or Master's degree in Computer Science, Information Technology, Engineering, or a related discipline.
  • Preferably 8+ years of software development experience, with substantial hands-on development in the Microsoft technology stack.
  • Strong hands-on experience in .NET/C#, MS SQL Server, Stored Procedures, REST APIs, and Microsoft Azure.
  • Demonstrated experience working as a Technical Lead or Senior Developer with technical leadership responsibilities.

Experience leading technical delivery and mentoring software developers
