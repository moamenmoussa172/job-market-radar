About the job

About The Role:

At Paysend, we operate a complex hybrid infrastructure supporting a global fintech platform.

We are looking for a System Administrator to join our Infrastructure team and help maintain and support our systems across on-premises and cloud environments.

You will work across Linux, AWS, networking, automation, monitoring, and security, while also supporting hardware and software, managing user access and permissions, and carrying out system upgrades, patching, and troubleshooting.

This role is about hands-on infrastructure work, keeping systems stable and secure, and continuously improving how our systems are managed and supported.


What You'll Do (Responsibilities):

  • Deploy and manage software, user access, and system configurations across a hybrid infrastructure, leveraging automation to ensure consistency, security, and scalability
  • Administer and maintain Linux-based systems across on-premises and cloud environments (~70% of the environment), including provisioning, patching, performance tuning, and troubleshooting
  • Support Windows environments (~30%), including core services such as Active Directory, DNS, RDS, and Group Policy
  • Design, deploy, and manage infrastructure in AWS (primary cloud) including EC2, VPC, IAM, S3, and CloudWatch
  • Support and maintain infrastructure in GCP environments (Compute Engine, Cloud Storage, IAM), as part of a multi-cloud setup
  • Build and maintain infrastructure as code using Terraform and automate configuration management using Ansible
  • Develop and maintain automation scripts using Bash, Python, or PowerShell
  • Manage virtualisation platforms (VMware, EC2, Compute Engine) and support both physical and virtual servers (HP Proliant, HP MSA)
  • Administer and maintain storage systems including SAN/NAS and cloud storage (S3, EBS, Google Cloud Storage, Filestore)
  • Configure and troubleshoot networking components across cloud and on-prem environments, including VPCs, VPNs, load balancers, DNS, and firewalls
  • Work with enterprise networking and security equipment (Cisco, Arista, Fortinet, Palo Alto, Juniper, Forcepoint)
  • Implement and maintain monitoring and observability solutions (CloudWatch, Prometheus, Grafana, Zabbix) to ensure system health and performance
  • Ensure backup, disaster recovery, and data protection strategies are in place and operational (Veeam, AWS Backup, GCP Backup and DR)
  • Enforce security best practices, IAM policies, and compliance standards across hybrid and multi-cloud infrastructure
  • Collaborate with DevOps, Security, Monitoring, and DBA teams to ensure reliable and scalable system operations
  • Maintain clear and up-to-date documentation of systems, processes, and configurations (CMDB)


What You’ll Need To Be Successful In This Role:

  • Strong hands-on experience with Linux system administration in production environments
  • Experience managing hybrid infrastructure (on-premises + cloud)
  • Proven experience with AWS (EC2, VPC, IAM, S3, CloudWatch)
  • Hands-on experience with Terraform and/or Ansible for infrastructure automation
  • Solid understanding of networking fundamentals (TCP/IP, DNS, VPNs, load balancing)
  • Experience working with physical and virtual servers, including provisioning and troubleshooting
  • Experience with virtualisation platforms (VMware, EC2, Compute Engine)
  • Scripting experience using Bash, Python, or PowerShell
  • Experience with monitoring and observability tools (CloudWatch, Prometheus, Grafana, Zabbix)
  • Strong understanding of security best practices, IAM, and access control
  • Experience with backup and disaster recovery solutions (Veeam, AWS Backup, GCP Backup,DR)

Great to have:

  • Experience working with GCP (Compute Engine, Cloud Storage, IAM) in a multi-cloud environment
  • Experience with Azure
  • Experience with Windows systems (Active Directory, DNS, RDS)
  • Familiarity with container platforms (EKS, GKE)
  • Experience with CI/CD tools (GitLab CI/CD, Packer)
  • Experience with storage technologies (SAN, NAS, cloud storage platforms)
  • Exposure to network/security appliances (Cisco, Fortinet, Palo Alto, Juniper)
  • Familiarity with web and infrastructure services (IIS, NTP, Certificate Authority, file services)
  • Experience supporting MDM solutions (Intune, Jamf)
  • Familiarity with OpenSearch, Cloudflare, or similar tools
