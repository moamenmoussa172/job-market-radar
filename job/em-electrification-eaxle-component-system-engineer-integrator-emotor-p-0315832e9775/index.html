About the job

電動化 eAxle システムエンジニア (Integrator / eMotor / Performance / Thermal / Transmission / Gearbox / NVH)

BEV/HEV向けeAxle・電動モーターのシステム開発において、日本の自動車メーカーとBoschのグローバル開発チームをつなぐSystem Engineerとして、製品開発をリードしていただきます。

主な業務内容

  • BEV/HEV向けeAxle・電動モーターのシステム開発および要求仕様開発
  • 顧客要求（Customer Requirements）の分析、およびSystem Requirementsへの落とし込み
  • 顧客との技術折衝、仕様調整および技術課題の解決
  • A-SPICE V-modelに基づくSYS1 / SYS2領域のRequirements Engineering
  • ドイツ、インド、中国などのグローバル開発チームとの技術調整および開発リード
  • 車両・システムレベルでの性能評価、信頼性評価、不具合解析
  • 新規eAxle / eMotorプロジェクト獲得に向けた技術提案・顧客サポート

私たちについて

「グローバルなパワートレインの変革を日本からリードする」をミッションとして、電動化コンポーネントおよびシステムの開発に取り組んでいます。

モーター、インバータ、減速機を統合したeAxleをはじめとするBoschのグローバルな電動化技術を、日本の自動車メーカーの要求や車両開発に合わせて製品化していくことが、私たちの重要なミッションです。

日本のお客様と直接技術議論を行う一方で、ドイツを中心としたヨーロッパ各国、インド、中国などのエンジニアと日常的に協働します。

単なる設計・評価業務ではなく、「顧客が何を求めているのか」を理解し、それをSystem Requirementとして定義し、グローバル開発チームとともに製品として実現するところまで関われるポジションです。

OEMや自動車部品サプライヤーで培ったモーター、電動パワートレイン、システム開発、要求仕様開発などの経験を活かしながら、グローバルな環境で電動化技術の未来を一緒につくりませんか？

Qualifications

  • 電動モーター、eAxle、Transmission、または電動パワートレインの開発経験
  • システム開発、システインテグレーション、要求仕様開発、設計・評価いずれかの実務経験
  • OEMとの技術折衝、またはCustomer Interfaceの経験
  • 海外開発チームとの協働経験
  • 日本語：ネイティブレベル / 英語：ビジネスレベル

歓迎する経験・スキル

  • 電動モーターの設計・評価経験
  • eAxle / Powertrain System Integratorとして、複数コンポーネントを横断したシステム開発・技術課題解決の経験
  • Transmission / Gearboxの設計・評価、またはDrivetrain開発の経験
  • Motor / eAxle / Transmissionに関するNVH開発、解析・評価、または課題解決の経験
  • A-SPICE SYS1 / SYS2、Requirements Engineeringの知識・経験
  • グローバル開発プロジェクトをリードした経験

求める人物像 モーターやTransmissionなど個々のコンポーネントだけでなく、eAxle全体をシステムとして捉え、異なる技術領域をつなぐことができる方。技術への好奇心とチャレンジ精神を持ち、顧客とグローバル開発チームをつなぎながら、自ら考え、周囲を巻き込み、課題解決をリードできる方。
