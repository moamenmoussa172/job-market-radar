About the job

The Senior Dynamics 365 Developer will provide hands-on technical delivery capacity for CRM development, customization, integrations, Power Platform implementation, production support, and complex technical troubleshooting across DET CRM initiatives.
Main Responsibilities

  • Design, develop, customize, and support Microsoft Dynamics 365 CRM / Dynamics 365 CE solutions.
  • Develop and maintain custom plugins, workflows, custom actions, Power Automate flows, PCF controls, JavaScript, TypeScript, and custom integrations.
  • Build and support Power Platform solutions including Power Apps, Power Automate, Power Pages, and Dataverse.
  • Develop enterprise integrations using Azure Functions, REST APIs, Logic Apps, Service Bus, and Azure API Management.
  • Work with C#, .NET Framework, .NET Core, SQL Server, Web APIs, JavaScript, TypeScript, PCF, and standard design patterns.
  • Support Dynamics CRM on-premises environments, including SQL Server queries, stored procedures, reporting solutions, and environment troubleshooting.
  • Support CI/CD and deployment activities across development, test, UAT, and production environments.
  • Troubleshoot and resolve complex technical issues, production incidents, integration failures, and performance issues.
  • Collaborate with functional consultants, business analysts, architects, business teams, infrastructure teams, and external vendors.
  • Support integrations with external systems and enterprise applications using secure and scalable patterns.
  • Apply Dynamics 365 security models, role-based access control, field security, and enterprise authentication principles.
  • Use DevOps, source control, branching, build pipelines, release pipelines, and deployment governance.
  • Prepare and maintain technical documentation, solution design notes, deployment notes, and operational handover material handover material.

Requirements:

  • 5+ years of hands-on experience in Microsoft Dynamics CRM / Dynamics 365 CE development.
  • Senior-level experience as a Microsoft Dynamics 365 Technical Consultant, Technical Lead, or equivalent CRM technical delivery role.
  • Strong technical background in custom CRM development, integrations, APIs, Azure services, SQL Server, and enterprise application support.
    DET CRM Time and Material Resource Requirements
  • Experience in both Dynamics 365 cloud and Dynamics CRM on-premises implementations and support.
  • Strong experience with plugins, workflows, custom actions, PCF, JavaScript/TypeScript, and Web APIs, Dataverse, Power Apps, Power Automate, and Power Pages.
  • Good understanding of integration architecture, API security, authentication, authorization, and error handling.
  • Strong analytical, troubleshooting, communication, and documentation skills.
