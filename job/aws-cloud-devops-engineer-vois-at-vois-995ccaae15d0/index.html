About this Role

We are seeking an AWS Cloud DevOps Engineer to design, implement and maintain secure, scalable and highly available AWS cloud and networking solutions supporting business-critical Vodafone applications and customers across Europe.

You will help design, plan and implement AWS cloud services that provide mission-critical infrastructure to internal customers. The role combines cloud infrastructure engineering, Kubernetes platform administration, infrastructure automation, continuous delivery, observability, security, cost optimisation and Level 2 and Level 3 operational support.

You will work with multiple technology functions, including solution design, delivery, architecture and IT security. Your work will directly influence cloud service delivery, production stability and customer services. The position is based in India within VCI Professional Services.

What you’ll do

  • Manage project-led integrations and the day-to-day administration of AWS cloud solutions.
  • Design, prototype and build reusable modules and cloud solutions aligned with the CET framework and Agile delivery cycles.
  • Provision and maintain CET framework components and other AWS services using Terraform and Terragrunt.
  • Manage the lifecycle, maintenance and upgrades of AWS Elastic Kubernetes Service, CET-EKS components and associated observability capabilities.
  • Administer Kubernetes clusters, including capacity management, platform troubleshooting and preparation or modification of Kubernetes manifests and resources.
  • Perform Bottlerocket AMI rotations and worker-node patching.
  • Maintain AWS Relational Database Service infrastructure, including upgrades and rightsizing.
  • Design and deploy hybrid connectivity solutions across CET-based AWS accounts.
  • Build and manage continuous delivery pipelines for Kubernetes modules and applications.
  • Configure ArgoCD environments and deploy infrastructure components using ArgoCD and Helm charts.
  • Apply GitOps practices using GitHub, ArgoCD and Amazon EKS.
  • Drive infrastructure and operational automation through CI/CD pipelines, GitHub Actions, Jenkins, Bash and Python.
  • Conduct peer reviews and maintain established coding standards.
  • Troubleshoot AWS cloud infrastructure, Kubernetes platforms, networking, storage and performance issues.
  • Manage platform monitoring and observability capabilities, including Grafana dashboards.
  • Identify and implement cloud cost optimisation opportunities.
  • Monitor expenditure using AWS Cost Explorer and AWS Budgets.
  • Manage cloud platform security, vulnerabilities and compliance, including security and compliance requirements for EKS clusters.
  • Perform proofs of concept for AWS infrastructure enhancements.
  • Maintain accurate infrastructure and operational documentation in Confluence.
  • Provide Level 2 and Level 3 incident and problem-management support.
  • Help establish collaborative DevOps practices and cloud engineering methodologies across the organisation.
  • Share AWS knowledge and support the development of cloud expertise within the team.
  • Contribute towards cloud-service availability, cloud adoption and consistent feature delivery.

Who you are

Essential experience and knowledge

  • You have at least three years of experience in cloud computing, or at least five years of experience in enterprise IT.
  • You have practical expertise in AWS cloud infrastructure and cloud platform operations.
  • You have experience administering Amazon EKS and Kubernetes platforms.
  • You understand Kubernetes lifecycle management, capacity management, security, compliance and troubleshooting.
  • You have hands-on experience with infrastructure as code using Terraform and Terragrunt.
  • You are experienced in GitOps and continuous delivery using technologies such as GitHub, ArgoCD and Helm.
  • You understand CI/CD practices and have worked with tools such as GitHub Actions or Jenkins.
  • You are proficient in version control using Git.
  • You can use Bash or Python to automate operational tasks, including user administration and security hardening.
  • You understand cloud networking, connectivity, storage, security, monitoring and performance management.
  • You have experience supporting AWS RDS infrastructure.
  • You can manage observability and monitoring solutions, including Grafana dashboards.
  • You understand cloud cost optimisation and can use AWS Cost Explorer and AWS Budgets.
  • You have experience with enterprise ticketing tools and Agile delivery methodologies.
  • You can produce clear technical and operational documentation.
  • You communicate effectively and use structured, solution-focused thinking to address technical challenges.
  • You hold a degree in an IT-related discipline.

Desirable experience and qualifications

  • Three to five years of experience in programming or systems analysis within Agile delivery environments.
  • Experience applying DevOps practices in a cloud environment.
  • Experience managing highly business-critical technology environments.
  • A relevant DevOps, Certified Kubernetes Administrator, AWS or HashiCorp Terraform certification.
  • Broader knowledge of AWS, Microsoft Azure or Google Cloud technologies.
  • Experience evaluating technical requirements, reducing service disruption and adopting emerging cloud technologies.
