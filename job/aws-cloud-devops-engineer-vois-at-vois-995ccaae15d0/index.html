About this Role

We are seeking an AWS Cloud DevOps Engineer to design, build, implement and operate public cloud infrastructure and technology solutions, primarily within AWS. The role will support mission-critical infrastructure services, cloud migration and transformation, automation, and cloud-native solutions. It also involves supporting Level 2 and Level 3 incident and problem management for software-related operations.This role interfaces with technology functions including solution design, delivery, architecture and IT security, with responsibility for supporting cloud service stability and production customer services.

What you’ll do

  • Manage project-driven integrations and the day-to-day administration of cloud solutions.
  • Develop prototypes and design and build cloud platform modules and solutions through iterative Agile delivery.
  • Maintain coding standards and conduct peer reviews.
  • Drive AWS cloud solution automation and integration for project workloads.
  • Build and deploy AWS infrastructure using AWS CloudFormation and Terraform, while using Ansible and Python for automation activities such as user management and security hardening.
  • Provide technical consultancy for migrating and transforming on-premises applications to public cloud environments.
  • Design and deploy AWS Direct Connect connectivity between AWS and data centres.
  • Troubleshoot cloud networking, storage and performance-related issues.
  • Develop AWS expertise within the organisation through knowledge sharing.
  • Support the adoption of DevOps practices and methodologies.

Who you are

You bring practical expertise across AWS cloud technologies, networking, security and cloud platforms, combined with experience in automation and DevOps.

Key technical skills and experience:

  • AWS cloud services including VPC, compute, cloud storage and Kubernetes.
  • Infrastructure automation using Terraform, Ansible and Python.
  • DevOps and container technologies including Jenkins, GoCD, HashiCorp Packer, Terraform, Docker and Kubernetes.
  • Experience working with AWS multi-tenant project environments.
  • Experience with cloud functions, web applications and web hosting.
  • Experience applying DevOps concepts within cloud environments.
  • Experience managing business-critical environments.
  • Knowledge of ITIL, SOX and security regulations.
  • Three to five years' experience in programming and/or systems analysis using Agile frameworks.
  • A degree in IT, with the JD specifying three years' cloud-computing experience or four years' enterprise IT experience.
  • An AWS cloud certification is preferred, alongside telecommunications industry knowledge.
  • Clear documentation and communication skills.

What's in it for you

This role provides the opportunity to contribute to mission-critical AWS cloud infrastructure, cloud transformation and automation initiatives, while working across solution design, delivery, architecture and IT security functions. You will gain exposure to cloud-native solutions, production cloud services and organisation-wide cloud enablement programmes.

What skills you will learn

The role offers opportunities to deepen your experience in:

  • AWS cloud infrastructure design, deployment and operations.
  • Infrastructure as Code using Terraform and AWS CloudFormation.
  • Automation using Ansible and Python.
  • Containerisation and orchestration using Docker and Kubernetes.
  • Cloud networking and AWS Direct Connect.
  • Public cloud migration and application transformation.
  • DevOps practices, CI/CD pipelines and HashiCorp technologies.
  • Operating and troubleshooting business-critical cloud environments.
