About the job

Everpure (NYSE: P) has evolved from storage pioneer to data platform, closing fiscal 2026 with $3.7 billion in revenue, its first billion-dollar quarter, and accelerating growth into FY27. Our strategic agenda spans the companies defining the next era of technology - hyperscalers, AI labs, the AI hardware supply chain, data platform providers, and the broader AI ecosystem.

This type of work—work that changes the world—is what the tech industry was founded on. So, if you're ready to seize the endless opportunities and leave your mark, come join us.

THE ROLE

As a Software Engineer on our team, you will drive core middleware innovation that unifies and scales Everpure’s™ industry-leading FlashArray and FlashBlade storage platforms. Acting as a strong technical anchor, you will own critical backend infrastructure end-to-end while collaborating with cross-functional global engineering teams to deliver high-performance, six 9s reliable systems. You will modernize system architectures, build unified management layers, and extend core capabilities into public cloud environments without impacting customer uptime. If you thrive on individual code ownership, value deep craftsmanship, and want to directly shape enterprise-grade data infrastructure, this role offers an exceptional platform for your impact.

WHAT YOU’LL DO

  • Own REST API Infrastructure. Own infrastructure work from streamlining REST API multi-versioned specification, engineering workflow, process automation, and API SDK productization
  • Drive Middleware Unification & Scaling: Architect, build, and optimize high-throughput Java and Spring-based middleware services, developing the unification layer that bridges FlashArray and FlashBlade product lines for seamless enterprise management.
  • Support End-to-End Features: Support complex features across the full software development lifecycle—from initial API design and CLI/GUI integration to debugging, refactoring, and release deployment.
  • Elevate Engineering Standards: Serve as a domain consultant and mentor for engineering teams across the Java ecosystem, establishing code quality standards, hosting office hours, and upskilling peers.
  • Modernize Core Codebases: Continuously improve codebase health and scalability by refactoring legacy architectures, optimizing performance under high load, and leveraging AI tools to automate routine development tasks.

WHAT YOU BRING

  • Java: Deep technical expertise in core Java and the Spring ecosystem (Spring Boot, Hibernate, jOOQ), with a proven track record of designing, building, and troubleshooting complex backend applications rather than maintaining legacy systems.
  • Enterprise-Scale Project Execution: Proven capability to lead and deliver mid-to-large backend engineering projects in complex enterprise environments, navigating architecture trade-offs with clear technical ownership.
  • Middleware & API Engineering: Demonstrated capability in developing RESTful APIs, CLI tools, and middleware services, backed by strong fundamentals in data structures, concurrency, and system design.
  • Technology-Agnostic Mindset: Strong baseline engineering fundamentals paired with a willingness to learn and adapt across multiple programming languages (such as Python, Go, or C++) rather than relying exclusively on a single ecosystem.
  • Modern Distributed Systems & Container Awareness: Practical understanding or exposure to cloud-native paradigms, container orchestration tools, or Linux system internals.
  • Technical Collaboration & Mentorship: Strong interpersonal and communication skills to effectively mentor other engineers, guide cross-team office hours, and align on technical dependencies across global engineering hubs.

Office Presence: We are primarily an in-office environment and therefore, you will be expected to work from the Prague office in compliance with Everpure’s policies, unless you are on PTO, or work travel, or other approved leave.
